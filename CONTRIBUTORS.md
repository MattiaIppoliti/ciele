# Contributors

Ciele is developed in a private repository and published here as a curated
mirror, so external contributions arrive as pull requests and are imported by a
maintainer rather than merged directly (see
[CONTRIBUTING.md](CONTRIBUTING.md)). The import carries the original author, and
everyone whose work has landed that way is listed here.
