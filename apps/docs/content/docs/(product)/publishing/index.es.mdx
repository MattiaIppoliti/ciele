---
title: Publica un Asistente
description: Crea una instantánea inmutable del widget y controla dónde puede ejecutarse.
---

Una publicación congela la configuración actual del asistente. El widget en vivo
lee la publicación activa en lugar del borrador.

## Prepara la publicación

1. Prueba el borrador en Vista previa.
2. Confirma que las Fuentes de conocimiento necesarias estén listas.
3. Prueba los mensajes de flujo coincidentes y no coincidentes.
4. Prueba el servicio de asistencia y las rutas de autenticación cuando estén
   habilitadas.
5. Abre **Publish**.

## Configura los dominios permitidos

Añade cada origen de sitio web que pueda incrustar el Asistente. Utiliza
exactamente el esquema y el host que envía el navegador.

No añadas un dominio amplio cuando solo una aplicación necesite el widget.

## Crea la publicación

1. Selecciona **Publish**.
2. Confirma la acción de publicación.
3. Copia el código de incrustación.
4. Añade el código a un sitio web permitido.
5. Abre el sitio web en una sesión privada del navegador.
6. Envía un mensaje de prueba.

Los cambios posteriores en el borrador no modifican esta Publicación. Vuelve a
publicar para crear y activar una nueva instantánea inmutable.

## Restaurar una publicación

Selecciona una publicación anterior cuando debas restaurar su configuración. La
acción de restauración vuelve a activar esa versión inmutable.

## Anular la publicación

Utiliza **Unpublish** para desconectar la configuración del widget. El código de
incrustación existente no puede cargar un Asistente activo después de la
operación.

<Callout type="warn" title="Test before publication">
A Publication can change Visitor routing, external API calls, email actions, and Help Desk paths. Test these actions in Preview first.
</Callout>
