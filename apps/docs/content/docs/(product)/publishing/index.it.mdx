---
title: Pubblica un Assistente
description: Crea un'istantanea del widget immutabile e controlla dove può essere eseguito.
---

Una Pubblicazione blocca la configurazione corrente dell'Assistente. Il widget
live legge la Pubblicazione attiva invece della bozza.

## Prepara la pubblicazione

1. Prova la bozza in Anteprima.
2. Verifica che le Knowledge Sources richieste siano pronte.
3. Testa i messaggi del flusso corrispondenti e non corrispondenti.
4. Testa i percorsi di Help Desk e di autenticazione quando sono abilitati.
5. Apri **Publish**.

## Configura i domini consentiti

Aggiungi ogni origine del sito web che può incorporare l'Assistente. Utilizza
esattamente lo schema e l'host inviati dal browser.

Non aggiungere un dominio generico quando solo un'applicazione ha bisogno del
widget.

## Crea la pubblicazione

1. Seleziona **Publish**.
2. Conferma l'azione di pubblicazione.
3. Copia il codice di incorporamento.
4. Aggiungi il codice a un sito web consentito.
5. Apri il sito web in una sessione privata del browser.
6. Invia un messaggio di prova.

Le successive modifiche alla bozza non cambiano questa Pubblicazione. Pubblica
di nuovo per creare e attivare una nuova istantanea immutabile.

## Ripristina una pubblicazione

Seleziona una Pubblicazione precedente quando devi ripristinarne la
configurazione. L'azione di ripristino rende nuovamente attiva quella versione
immutabile.

## Annulla la pubblicazione

Usa **Unpublish** per mettere offline la configurazione del widget. Il codice di
incorporamento esistente non può caricare un Assistente attivo dopo
l'operazione.

<Callout type="warn" title="Test before publication">
A Publication can change Visitor routing, external API calls, email actions, and Help Desk paths. Test these actions in Preview first.
</Callout>
