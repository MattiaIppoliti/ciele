---
title: Veröffentlichung
description: Platzieren Sie einen Assistenten auf Ihrer Website mit einem Einbettungs-Snippet, als schwebendes Widget oder als Inline-Frame.
---

Durch das Veröffentlichen gelangt Ihr Assistent von der Vorschau auf Ihre
Live-Website. Öffnen Sie einen Assistenten und wählen Sie **Publish**, um den
benötigten Snippet zu erhalten. Jede Option öffnet ein Dialogfeld mit einem
Snippet, das Sie auf Ihre Website kopieren.

## Das schwebende Widget

Das schwebende Widget fügt Ihren Seiten eine Startschaltfläche hinzu. Wenn ein
Besucher darauf klickt, öffnet sich das Chat-Fenster über der Seite.

1. Wählen Sie in **Publish** die Option Website-Floater.
2. Kopieren Sie das bereitgestellte Snippet.
3. Fügen Sie es in den Teil Ihrer Website ein, der auf jeder Seite angezeigt
   wird, auf der Sie den Assistenten haben möchten – in der Regel in die
   gemeinsame Kopfzeile der Vorlage Ihrer Website.

Das Snippet lädt das Widget und verweist mithilfe der Assistenten-Kennung auf
Ihren Assistenten, sodass der richtige Assistent angezeigt wird.

## Der Inline-Frame

Wenn Sie möchten, dass der Assistent innerhalb der Seite platziert wird, anstatt
über ihr zu schweben, verwenden Sie die Option Inline-Frame. Sie erhalten einen
Rahmen, den Sie dort platzieren, wo der Chat angezeigt werden soll. Dies ist
nützlich für eine spezielle Hilfeseite oder eine Support-Ecke in Ihrer App.

## Nach der Veröffentlichung

- Besuchen Sie eine Seite, die das Snippet enthält, und vergewissern Sie sich,
  dass das Widget angezeigt wird und sich öffnet.
- Stellen Sie ihm ein paar echte Fragen und prüfen Sie, ob die Antworten und
  Quellen korrekt aussehen.
- Beobachten Sie die ersten Gespräche im [Posteingang](/operations/inbox), um zu
  sehen, wie Besucher ihn nutzen, und passen Sie bei Bedarf das Wissen oder die
  Abläufe an.

<Callout title="One assistant, many places">
Because the snippet references the assistant by its identifier, you can place the
same assistant on several pages or sites. Update the assistant once and every
placement reflects the change.
</Callout>

## Halten Sie die Kennung griffbereit

Für die Veröffentlichung wird die Kennung des Assistenten verwendet, die Sie von
der Assistentenkarte oder aus dem Editor kopieren können. Wenn Sie das Widget
jemals verschieben oder neu installieren müssen, benötigen Sie lediglich diese
Kennung, um ein neues Snippet auf denselben Assistenten zu verweisen.
