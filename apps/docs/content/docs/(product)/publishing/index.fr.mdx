---
title: Publication
description: Placez un assistant sur votre site Web à l'aide d'un extrait d'intégration, sous la forme d'un widget flottant ou d'un cadre en ligne.
---

La publication est le processus par lequel votre assistant passe de l'aperçu à
votre site en ligne. Ouvrez un assistant et sélectionnez **Publish** pour
obtenir l'extrait de code dont vous avez besoin. Chaque option ouvre une boîte
de dialogue contenant un extrait de code que vous copiez sur votre site.

## Le widget flottant

Le widget flottant ajoute un bouton de lancement à vos pages. Lorsqu'un visiteur
le sélectionne, la fenêtre de chat s'ouvre au-dessus de la page.

1. Dans **Publish**, choisissez l'option widget flottant pour site Web.
2. Copiez l'extrait de code fourni.
3. Collez-le dans la partie de votre site qui apparaît sur chaque page, là où
   vous souhaitez que l'assistant soit présent, généralement dans l'en-tête
   partagé du modèle de votre site.

L'extrait de code charge le widget et le dirige vers votre assistant à l'aide de
l'identifiant de l'assistant, afin que le bon assistant apparaisse.

## Le cadre intégré

Si vous souhaitez que l'assistant soit intégré à la page plutôt que de flotter
au-dessus, utilisez l'option de cadre intégré. Elle vous fournit un cadre que
vous placez là où vous souhaitez que le chat apparaisse, ce qui est utile pour
une page d'aide dédiée ou un coin d'assistance de votre application.

## Après la publication

- Consultez une page qui inclut le snippet et vérifiez que le widget s'affiche
  et s'ouvre.
- Posez-lui quelques questions réelles et vérifiez que les réponses et les
  sources semblent correctes.
- Suivez les premières conversations dans la
  [Boîte de réception](/operations/inbox) pour voir comment les visiteurs
  l'utilisent, et ajustez les connaissances ou les flux si nécessaire.

<Callout title="One assistant, many places">
Because the snippet references the assistant by its identifier, you can place the
same assistant on several pages or sites. Update the assistant once and every
placement reflects the change.
</Callout>

## Gardez l'identifiant à portée de main

La publication utilise l'identifiant de l'assistant, que vous pouvez copier
depuis la fiche de l'assistant ou depuis l'éditeur. Si jamais vous devez
déplacer ou réinstaller le widget, cet identifiant est tout ce dont vous avez
besoin pour diriger un nouveau snippet vers le même assistant.
