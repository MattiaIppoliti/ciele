---
title: Obiettivi
description: Pianifica controlli ripetibili per le risposte importanti dell'Assistente.
---

Un Goal pone una domanda ricorrente e verifica la risposta rispetto ad
aspettative deterministiche. Un Goal che non viene soddisfatto genera un Alert.

## Crea un Goal

1. Apri un Assistant.
2. Seleziona **Goals**.
3. Seleziona **Add** nella sezione **Goals**.
4. Inserisci la domanda che Ciele deve porre.
5. Aggiungi una o più aspettative.
6. Salva l'obiettivo.

## Expectation disponibili

| Expectation | Check |
| --- | --- |
| Must cite a source | La risposta contiene almeno una citazione di fonte. |
| Cited URL contains | Un URL citato contiene il testo configurato. |
| Answer contains | La risposta contiene ciascun frammento di testo configurato. |
| Non-fallback answer | Il runtime non ha restituito il suo risultato di fallback. |

Ciele verifica sempre la presenza di una risposta non di fallback. Altre
aspettative dipendono dalla configurazione di Goal.

## Stato dell'obiettivo

Un Goal attivo viene eseguito secondo il suo programma. Ciele può mettere in
quarantena un Goal dopo ripetuti problemi di esecuzione.

Un Goal in quarantena non prosegue secondo il suo normale programma. Rivedi il
Goal e il relativo Alert prima di riattivarlo.

## Esamina un errore

1. Apri **Alerts**.
2. Seleziona il **Goal failure**.
3. Rivedi la risposta e l'expectation non soddisfatta.
4. Correggi Knowledge, Flow o Goal.
5. Esegui di nuovo il Goal.

Gli obiettivi utilizzano controlli esatti. Non utilizzano un model grader
aperto.
