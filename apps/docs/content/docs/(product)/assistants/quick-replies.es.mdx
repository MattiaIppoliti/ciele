Los botones de inicio aparecen cuando un visitante abre el chat. Son una forma
amigable de guiar a las personas hacia lo que tu asistente hace mejor. Los
gestionas en la sección **General** del editor de asistentes.

## Añade un botón

1. En General, busca la lista de botones de inicio.
2. Selecciona **Add button**.
3. Ponle un **nombre** al botón. Esta es la etiqueta que ve el visitante.
4. Elige un **tipo** y, a continuación, completa la configuración específica de
   ese tipo.
5. Guarda el botón.

Puedes añadir varios botones y reordenarlos para que los más útiles aparezcan
primero.

## Tipos de botones

Cada botón realiza una de cuatro acciones.

### Enviar texto al chat

El botón envía un mensaje al chat para el visitante, como si lo hubiera escrito
él. Utiliza esta opción para que el asistente se centre en un tema específico.
Por ejemplo, un botón llamado «Precios» puede enviar el mensaje «Háblame de tus
precios» para que el asistente responda a esa pregunta de inmediato.

### Escalada

El botón conecta al visitante con tu equipo a través de las opciones de
escalamiento que hayas configurado. Utiliza esta opción cuando quieras una forma
clara y siempre visible de contactar con una persona. Se basa en tus
[Help Desks](/help-desks).

### Abrir enlace externo

El botón abre una dirección web en una nueva pestaña. Utiliza esta opción para
enviar a los visitantes a una página de tu sitio, a un formulario o a cualquier
recurso externo.

### Preguntas frecuentes

El botón muestra un par específico de pregunta y respuesta de tu conocimiento.
Utiliza esta opción para dar una respuesta instantánea y exacta a una pregunta
frecuente. Consulta las [Preguntas frecuentes](/knowledge/faqs).

## Consejos

- Mantén las etiquetas cortas para que encajen bien en el widget.
- Empieza con las preguntas que más hacen los visitantes.
- Combina un botón «Enviar texto al chat» con un conocimiento sólido para que el
  asistente tenga preparada una buena respuesta.
