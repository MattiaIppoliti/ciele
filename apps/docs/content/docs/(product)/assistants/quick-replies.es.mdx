---
title: Respuestas rápidas
description: Añade botones de inicio que envíen texto o devuelvan una respuesta seleccionada de las preguntas frecuentes.
---

Las respuestas rápidas aparecen cerca del mensaje de bienvenida. Ayudan a un
visitante a iniciar una tarea habitual.

## Enviar texto

Una respuesta rápida **Send Text** envía su texto configurado como mensaje al
visitante. A continuación, el enrutador Flow normal gestiona ese mensaje.

Utiliza este tipo cuando el Asistente deba interpretar el texto inicial mediante
sus reglas de enrutamiento habituales.

## Preguntas frecuentes

Una respuesta rápida **FAQ** devuelve textualmente la respuesta seleccionada de
las preguntas frecuentes. No llama al modelo de chat.

La respuesta incluye la cita de la fuente de las preguntas frecuentes. Utiliza
este tipo cuando una respuesta aprobada deba permanecer exacta.

## Añade una respuesta rápida

1. Abre **General**.
2. Busca **Quick replies**.
3. Añade un elemento **Send Text** o **FAQ**.
4. Introduce la etiqueta visible.
5. Selecciona o introduce el contenido requerido.
6. Guarda el borrador.
7. Prueba el botón en Vista previa.

Mantén las etiquetas cortas. La etiqueta debe describir la acción que se produce
después de la selección.
