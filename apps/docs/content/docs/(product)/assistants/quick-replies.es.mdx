---
title: Respuestas rápidas
description: Añade botones iniciales que envíen texto, abran el soporte, abran un enlace o devuelvan una respuesta seleccionada de las preguntas frecuentes.
---

Las respuestas rápidas aparecen cerca del mensaje de bienvenida. Ayudan a un
Visitor a iniciar una tarea habitual.

## Enviar texto al chat

Una respuesta rápida **Send Text Into Chat** envía su texto configurado como un
mensaje de Visitor. A continuación, el enrutador de flujo normal se encarga de
ese mensaje.

Utiliza este tipo cuando el asistente deba interpretar el texto inicial mediante
sus reglas de enrutamiento habituales.

## Escalado

Una respuesta rápida **Escalation** abre el panel de asistencia del Asistente. A
continuación, el visitante puede seleccionar un canal del Help Desk.

## Abrir enlace externo

Una respuesta rápida **Open External Link** abre su URL en una nueva pestaña del
navegador. No envía ningún mensaje.

## Preguntas frecuentes

Una respuesta rápida **FAQ** devuelve textualmente la respuesta seleccionada de
las preguntas frecuentes. No llama al modelo de chat.

La respuesta incluye la cita de la fuente de las preguntas frecuentes (FAQ
Source). Utiliza este tipo cuando una respuesta aprobada deba mantenerse
exactamente igual.

## Añade una respuesta rápida

1. Abre **General**.
2. Busca **Quick replies**.
3. Añade un elemento y selecciona su **Type**.
4. Introduce la etiqueta visible.
5. Selecciona o introduce el contenido requerido.
6. Guarda el borrador.
7. Prueba el botón en Preview.

Utiliza etiquetas cortas. La etiqueta debe describir la acción que se produce
después de la selección.
