---
title: Erscheinungsbild
description: Legen Sie die Markenfarbe des Widgets und die Position des Launchers fest.
---

Öffnen Sie einen Assistenten und wählen Sie **Style**.

## Markenfarbe

Wählen Sie die Farbe aus, die das Widget für seine Hauptsteuerelemente und
visuellen Akzente verwendet. Testen Sie in der Vorschau, ob der Kontrast
ausreichend ist.

## Position des Launchers

Platzieren Sie den Launcher unten links oder unten rechts auf der Host-Seite.

Wählen Sie eine Position, die weder die Navigation noch die
Einwilligungssteuerelemente oder andere feste Seitenelemente verdeckt.

## Veröffentlichen Sie das Design

1. Ändern Sie die Markenfarbe oder die Position des Launchers.
2. Speichern Sie den Entwurf.
3. Überprüfen Sie die Desktop- und die mobile Vorschau.
4. Veröffentlichen Sie den Assistenten.
