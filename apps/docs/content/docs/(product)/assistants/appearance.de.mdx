Das Widget sollte sich wie ein Teil Ihrer Website anfühlen. Mit Ciele können Sie
die Markenfarbe des Assistenten festlegen und bestimmen, wo die
Startschaltfläche platziert wird, damit er sich nahtlos in Ihre Seiten einfügt.

## Markenfarbe und Position

In den Einstellungen des Assistenten können Sie die vom Widget verwendete
Markenfarbe festlegen und auswählen, wo die Startschaltfläche auf der Seite
angezeigt wird, beispielsweise in einer Ecke mit ausreichend Platz. Passen Sie
diese an und beobachten Sie, wie sich die Live-Vorschau sofort aktualisiert.

## Was Besucher sehen

- Eine **Startschaltfläche**, die das Chat-Fenster öffnet.
- Ein **Chat-Fenster** mit dem Spitznamen des Assistenten in der Kopfzeile, der
  Begrüßungsnachricht, etwaigen Startschaltflächen und der eigentlichen
  Konversation.

## Praktische Ratschläge

- Wählen Sie eine Markenfarbe mit ausreichendem Kontrast, damit Text und
  Schaltflächen lesbar bleiben.
- Platzieren Sie die Start-Schaltfläche so, dass sie keine wichtigen
  Steuerelemente auf der Seite verdeckt.
- Bestätigen Sie das Ergebnis vor der Veröffentlichung immer in der
  Live-Vorschau und überprüfen Sie es auch auf einem kleineren Bildschirm.
