---
title: Ziele
description: Planen Sie wiederholbare Prüfungen für wichtige Antworten des Assistenten.
---

Ein Goal stellt eine festgelegte Frage und überprüft die Antwort anhand
deterministischer Erwartungen. Ein fehlgeschlagenes Goal erzeugt einen Alert.

## Ein Ziel erstellen

1. Öffnen Sie einen Assistant.
2. Wählen Sie **Goals** aus.
3. Wählen Sie **Add** im Abschnitt **Goals** aus.
4. Geben Sie die Frage ein, die Ciele stellen muss.
5. Fügen Sie eine oder mehrere Erwartungen hinzu.
6. Speichern Sie das Ziel.

## Verfügbare Erwartungen

| Expectation | Check |
| --- | --- |
| Must cite a source | Die Antwort enthält mindestens eine Quellenangabe. |
| Cited URL contains | Eine angegebene URL enthält den konfigurierten Text. |
| Answer contains | Die Antwort enthält jedes konfigurierte Textfragment. |
| Non-fallback answer | Die Runtime hat ihr Fallback-Ergebnis nicht zurückgegeben. |

Ciele überprüft stets, ob eine Nicht-Fallback-Antwort vorliegt. Weitere
Erwartungen hängen von der Konfiguration des Goals ab.

## Status des Ziels

Ein aktives Goal wird gemäß seinem Zeitplan ausgeführt. Ciele kann ein Goal nach
wiederholten Ausführungsproblemen in Quarantäne setzen.

Ein unter Quarantäne gestelltes Goal setzt seinen normalen Zeitplan nicht fort.
Überprüfen Sie das Goal und den zugehörigen Alert, bevor Sie es erneut
aktivieren.

## Einen Fehler überprüfen

1. Öffnen Sie **Alerts**.
2. Wählen Sie den Ziel-Fehler aus.
3. Überprüfen Sie die Antwort und die nicht erfüllte Erwartung.
4. Korrigieren Sie Knowledge, Flow oder Goal.
5. Führen Sie das Goal erneut aus.

Goals verwenden exakte Prüfungen. Sie verwenden keinen offenen Model Grader.
