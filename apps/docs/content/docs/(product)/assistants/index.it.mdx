---
title: Assistenti
description: Configura l'identità, il modello, il comportamento, gli strumenti e i controlli di un Assistente.
---

Un Assistant è l'unità di configurazione principale in Ciele. Ogni Assistente
dispone delle proprie Knowledge, dei propri Flows, delle proprie impostazioni
delle bozze e della propria cronologia delle pubblicazioni.

## Sezioni di configurazione

| Section | Scopo |
| --- | --- |
| General | Imposta i valori predefiniti per identità, modello e conversazione. |
| Knowledge | Aggiungi Sources e FAQ. |
| Flows | Definisci il routing e le risposte. |
| Tools & Skills | Controlla gli strumenti di runtime, l'integrazione delle API e le istruzioni riutilizzabili. |
| Goals | Pianifica i controlli delle risposte deterministiche. |
| Guardrails | Controlla i messaggi dei visitatori e nascondi il testo delle risposte contrassegnate. |
| Assistant Help Desks | Seleziona gli Help Desk per l'escalation. |
| Style | Imposta il colore del brand e la posizione del launcher. |
| Authentication | Richiedi l'accesso con Microsoft Entra per i Visitor. |
| Publish | Crea e gestisci la live snapshot. |

Le modifiche si riflettono immediatamente in Preview. Il widget live cambia solo
dopo la pubblicazione.

Preview può utilizzare il tuo abbonamento locale collegato a Claude o ChatGPT da
**Settings → AI**. Il pannello di avanzamento riporta le ricerche e i relativi
risultati. Non richiede il ragionamento privato del modello. Un modello connesso
ha comunque bisogno di Knowledge Sources per rispondere in modo affidabile a
domande specifiche dell'organizzazione.

## Esamina le fonti in Preview

La modalità Preview mostra le citazioni delle fonti, numerate, all'interno della
risposta dell'Assistente. Passa il mouse su una citazione o spostaci lo stato di
focus con la tastiera per visualizzare il suo titolo e i dettagli della Source.
Premi Escape per chiudere la scheda. Fai clic su una citazione con un URL
pubblico per aprire la pagina originale in una nuova scheda.

Ogni frase o passaggio con fonte riporta la relativa citazione accanto al testo
che supporta. Una Source può essere citata più di una volta nella stessa
risposta. I documenti privati mostrano un'anteprima senza link esterno. Le fonti
senza un riferimento in linea rimangono disponibili nell'elenco Sources sotto la
risposta.

## Duplica un Assistente

La duplicazione copia la configurazione e i Flow. Non copia il contenuto di
Knowledge.

Rivedi il nuovo Assistente prima della pubblicazione. In particolare, aggiungi
le Sources richieste e conferma le connessioni al Help Desk.

## Sposta un Assistente tra le Organizzazioni

Apri il menu Assistant e seleziona **Export bundle** per scaricare un file JSON
con controllo delle versioni. La lettura di un Assistente consente
l'esportazione.

Seleziona **Import bundle as new Assistant** per caricare il file.
L'importazione richiede l'accesso in modalità di modifica e crea sempre un nuovo
Assistant. Gli Existing Assistants rimangono invariati.

Il bundle contiene la configurazione di Publication, i Flows, le Skills, i
Guardrails, le risposte rapide e lo stile. Indica i nomi di Collections, Help
Desks e provider di connessione.

L'importazione associa questi nomi all'Organization di destinazione. Leggi il
report di importazione per individuare le corrispondenze mancanti o ambigue. I
Flow con riferimenti non risolti rimangono disabilitati.

Sono esclusi le credenziali, i valori crittografati, le Conversations e i dati
dei Visitor. Configura le credenziali dopo l'importazione. Le API Integrations
mostrano **Needs setup** finché non sono disponibili le credenziali.

Il contenuto della Collection non è incluso. Importa i link delle Sources di
destinazione esistenti da una Collection corrispondente. Le versioni di bundle
sconosciute vengono rifiutate prima della creazione.

L'API fornisce `GET /api/v1/assistants/{id}/export` e
`POST /api/v1/assistants/import`. MCP fornisce le azioni di esportazione e
importazione di `manage_assistants`.
