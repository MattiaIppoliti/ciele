Un Assistente è la principale unità di configurazione in Ciele. Ogni Assistente
possiede le proprie Conoscenze, i propri Flussi, le impostazioni delle bozze e
la cronologia delle pubblicazioni.

## Sezioni di configurazione

| Sezione | Scopo |
| --- | --- |
| Generale | Imposta l'identità, il modello, il motore di conoscenza e le impostazioni predefinite di conversazione. |
| Conoscenza | Aggiungi fonti e FAQ. |
| Flussi | Definisci il routing e le risposte. |
| Strumenti e competenze | Controlla gli strumenti di runtime, l'integrazione API e le istruzioni riutilizzabili. |
| Obiettivi | Pianifica controlli deterministici delle risposte. |
| Help desk per gli assistenti | Seleziona gli help desk per l'escalation. |
| Stile | Imposta il colore del marchio e la posizione del launcher. |
| Autenticazione | Richiedi l'accesso con Microsoft Entra per i visitatori. |
| Pubblica | Crea e gestisci l'istantanea live. |

Le modifiche si riflettono immediatamente nell'Anteprima. Il widget live cambia
solo dopo la pubblicazione.

## Duplica un Assistente

La duplicazione copia la configurazione e i flussi. Non copia il contenuto della
Knowledge Base.

Rivedi il nuovo Assistente prima della pubblicazione. In particolare, aggiungi
le Fonti richieste e conferma le connessioni con l'Help Desk.
