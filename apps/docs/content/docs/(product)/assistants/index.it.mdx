Un Assistant è l'unità di configurazione principale in Ciele. Ogni Assistente
dispone della propria Knowledge, dei propri Flows, delle proprie impostazioni
delle bozze e della propria cronologia delle pubblicazioni.

## Sezioni di configurazione

| Section | Purpose |
| --- | --- |
| General | Imposta i valori predefiniti per identità, modello e conversazione. |
| Knowledge | Aggiungi Sources e FAQ. |
| Flows | Definisci il routing e le risposte. |
| Tools & Skills | Gestisci gli strumenti di runtime, l'integrazione delle API e le istruzioni riutilizzabili. |
| Goals | Pianifica i controlli delle risposte deterministiche. |
| Guardrails | Controlla i messaggi dei visitatori e nascondi il testo delle risposte contrassegnate. |
| Assistant Help Desks | Seleziona gli Help Desk per l'escalation. |
| Style | Imposta il colore del brand e la posizione del launcher. |
| Authentication | Richiedi l'accesso con Microsoft Entra per i Visitor. |
| Publish | Crea e gestisci la snapshot live. |

Le modifiche si riflettono immediatamente in Preview. Il widget live cambia solo
dopo la pubblicazione.

La Preview può usare il tuo abbonamento locale Claude o ChatGPT collegato in **Impostazioni → AI**.
Il pannello di avanzamento mostra le ricerche e i risultati, senza richiedere il ragionamento privato del modello.
Per rispondere in modo affidabile a domande sull’organizzazione servono comunque fonti di conoscenza.

## Consulta le fonti in Preview

Preview mostra citazioni numerate dentro la risposta dell'Assistente. Passa il puntatore su una
citazione o selezionala con la tastiera per vedere il titolo e i dettagli della fonte. Premi Escape
per chiudere la scheda. Una citazione con URL pubblico apre la pagina originale in una nuova scheda.

Ogni frase o passo basato su una fonte mostra la citazione accanto al testo che supporta. La stessa
fonte può essere citata più volte nella risposta. I documenti privati mostrano una scheda senza
link esterno. Le fonti senza un riferimento inline restano disponibili nell’elenco Sources sotto la risposta.

## Duplica un Assistente

La duplicazione copia la configurazione e i Flow. Non copia il contenuto di
Knowledge.

Rivedi il nuovo Assistente prima della pubblicazione. In particolare, aggiungi
le Sources richieste e conferma le connessioni all'Help Desk.
