---
title: Appearance
description: Set the widget brand color and launcher position.
---

Open an Assistant and select **Style**.

## Brand color

Select the color that the widget uses for its main controls and visual accents. Test sufficient contrast in Preview.

## Launcher position

Place the launcher at the bottom left or bottom right of the host page.

Select a position that does not cover navigation, consent controls, or other fixed page elements.

## Publish the style

1. Change the brand color or launcher position.
2. Save the draft.
3. Inspect the desktop and mobile Preview.
4. Publish the Assistant.
