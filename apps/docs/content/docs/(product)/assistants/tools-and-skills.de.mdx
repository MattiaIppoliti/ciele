Öffnen Sie einen Assistenten und wählen Sie **Tools & Skills**. In diesem
Abschnitt werden die Laufzeitfunktionen und wiederverwendbare Anweisungen
gesteuert.

## Integrierte Tools

| Tool | Standard | Aktuelles Verhalten |
| --- | :---: | --- |
| Knowledge durchsuchen | Ein | Durchsucht verknüpftes Knowledge und gibt zitierte Antworten zurück. |
| Sitzungsspeicher | Ein | Verwendet Informationen aus der aktuellen Gesprächssitzung. |
| URL abrufen | Aus | Liest eine URL, wenn die Laufzeitumgebung das Tool auswählt. |
| Tabelle anzeigen | Aus | Zeigt Fakten in einer Tabelle an, wenn die Laufzeitumgebung das Tool auswählt. |

Die Wissenssuche ist immer verfügbar. Sie können die anderen integrierten Tools
aktivieren oder deaktivieren.

„Show a table“ ordnet Fakten an, die der Assistent in dieser Antwort gefunden
hat. Es werden keine Werte berechnet. Die Tabelle wird über der schriftlichen
Antwort angezeigt, und im Posteingangsprotokoll wird dieselbe Tabelle angezeigt.

Der Assistent kann einer Zeile eine Folgefrage hinzufügen. Der Besucher wählt
die Zeile aus, um diese Frage zu stellen. Das Inbox-Protokoll zeigt diese Zeilen
an, aber ein Mitglied kann sie nicht auswählen.

## Strukturierte Daten verbinden

Der Abschnitt **Data** listet Entitäten auf, die über **Settings → Data**
importiert wurden. Wählen Sie jede Entität aus, die dieser Assistent abfragen
darf.

Jede ausgewählte Entität bietet ein exaktes Filterwerkzeug. Eine Entität mit
Textattributen bietet auch ein Tool für die Stichwortsuche.

Gemeinsam genutzte Entitäten stehen jedem Besucher zur Verfügung, der vom
Assistenten betreut wird. Für Entitäten im Benutzerbereich ist ein verifizierter
[Identitätsanspruch](/authentication/microsoft-entra-id#choose-an-identity-claim)
erforderlich.

Die Entitätsauswahl und das Schema werden in den nächsten
Veröffentlichungs-Snapshot aufgenommen. Der Inhalt des Datensatzes bleibt nach
der Veröffentlichung live.

Informationen zu CSV-Importen, Bereichsoptionen und Identitätsfilterung finden
Sie unter [Entities and Records](/data/entities-and-records).

## Konfigurieren Sie eine API-Integration

Ein Assistent kann eine registrierte API-Integration verwenden. Die Integration
enthält eine Basis-URL, geschützte Anmeldeinformationen und beschriebene
Endpunkte.

Definieren Sie für jeden Endpunkt die Methode, den Pfad, den Zweck, die
Parameter und die Antwortform. Die Laufzeit validiert jeden angeforderten Pfad
anhand dieses Katalogs.

Der Agent kann die Endpunktdetails überprüfen, bevor er eine Anfrage sendet.
Große Antworten bleiben über Fenster-Lesevorgänge verfügbar.

<Callout title="Control the endpoint catalogue">
Add only the endpoints that the Assistant must use. The runtime cannot call an unregistered path through this integration.
</Callout>

## Eine Organisations-Skill anhängen

Eine Skill ist eine wiederverwendbare Anweisungsvorlage. Eine Organisation kann
dieselbe Skill mehreren Assistenten zuweisen.

1. Öffnen Sie **Tools & Skills**.
2. Suchen Sie die erforderliche Organisationskompetenz.
3. Weisen Sie die Skill dem Assistant zu.
4. Testen Sie das Ergebnis in der Vorschau.
5. Veröffentlichen Sie den Assistenten, wenn das Ergebnis korrekt ist.

Änderungen an Skills sind in der Vorschau sofort verfügbar. Das veröffentlichte
Widget verwendet den letzten Veröffentlichungs-Snapshot.

## Testen Sie die Konfiguration

Stellen Sie eine Frage, die jedes aktivierte Tool erfordert. Überprüfen Sie vor
der Veröffentlichung das Thinking-Panel und die Quellen.

Testen Sie für strukturierte Daten eine exakte Attributsuche und eine Textsuche.
Testen Sie den Zugriff auf Benutzerebene mit zwei verschiedenen angemeldeten
Konten.
