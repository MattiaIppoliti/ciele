---
title: Assistenten
description: Konfigurieren Sie die Identität, das Modell, das Verhalten, die Tools und die Prüfungen für einen Assistenten.
---

Ein Assistant ist die wichtigste Konfigurationseinheit in Ciele. Jeder Assistent
verfügt über eigenes Wissen, eigene Flows, eigene Entwurfseinstellungen und
einen eigenen Veröffentlichungsverlauf.

## Einrichtungsabschnitte

| Abschnitt | Zweck |
| --- | --- |
| Allgemein | Legen Sie Identität, Modell, Wissens-Engine und Konversationsstandards fest. |
| Wissen | Quellen und FAQs hinzufügen. |
| Flows | Routing und Antworten definieren. |
| Tools & Skills | Steuern Sie Runtime-Tools, API-Integration und wiederverwendbare Anweisungen. |
| Ziele | Planen Sie deterministische Antwortprüfungen. |
| Helpdesks für Assistenten | Wählen Sie Helpdesks für die Eskalation aus. |
| Stil | Legen Sie die Markenfarbe und die Position des Launchers fest. |
| Authentifizierung | Fordern Sie für Besucher eine Anmeldung mit Microsoft Entra. |
| Veröffentlichen | Erstellen und verwalten Sie den Live-Snapshot. |

Änderungen wirken sich sofort auf die Vorschau aus. Das Live-Widget ändert sich
erst nach der Veröffentlichung.

## Einen Assistenten duplizieren

Durch Duplizieren werden Konfiguration und Flows kopiert. Wissensinhalte werden
dabei nicht kopiert.

Überprüfen Sie den neuen Assistenten vor der Veröffentlichung. Fügen Sie
insbesondere die erforderlichen Quellen hinzu und bestätigen Sie die
Helpdesk-Verbindungen.
