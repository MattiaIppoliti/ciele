---
title: Assistenten
description: Konfigurieren Sie die Identität, das Modell, das Verhalten, die Tools und die Prüfungen für einen Assistenten.
---

Ein Assistant ist die zentrale Konfigurationseinheit in Ciele. Jeder Assistant
verfügt über sein eigenes Knowledge, seine eigenen Flows, seine eigenen
Entwurfseinstellungen und seinen eigenen Veröffentlichungsverlauf.

## Setup-Abschnitte

| Section | Zweck |
| --- | --- |
| General | Legen Sie die Standardeinstellungen für Identität, Modell und Konversation fest. |
| Knowledge | Quellen und FAQs hinzufügen. |
| Flows | Routing und Antworten definieren. |
| Tools & Skills | Steuerung von Runtime-Tools, API-Integration und wiederverwendbaren Anweisungen. |
| Goals | Planen Sie deterministische Antwortprüfungen. |
| Guardrails | Überprüfen Sie Visitor-Nachrichten und blenden Sie markierten Antworttext aus. |
| Assistant Help Desks | Wählen Sie Help Desks für die Eskalation aus. |
| Style | Legen Sie die Markenfarbe und die Position des Launchers fest. |
| Authentication | Für Visitors ist die Anmeldung über Microsoft Entra erforderlich. |
| Publish | Den Live-Snapshot erstellen und verwalten. |

Änderungen wirken sich sofort auf die Vorschau aus. Das Live-Widget ändert sich
erst nach der Veröffentlichung.

Preview kann Ihr verbundenes lokales Claude- oder ChatGPT-Abonnement von
**Settings → AI** verwenden. Das Progress Panel zeigt Suchvorgänge und deren
Ergebnisse an. Es fordert nicht das private Reasoning des Modells an. Ein
verbundenes Modell benötigt nach wie vor Knowledge Sources, um
organisationsspezifische Fragen zuverlässig zu beantworten.

## Quellen in der Vorschau prüfen

In der Vorschau werden nummerierte Quellenangaben innerhalb der Antwort des
Assistenten angezeigt. Bewegen Sie den Mauszeiger über eine Quellenangabe oder
fokussieren Sie sie mit der Tastatur, um ihren Titel und die Details der Quelle
anzuzeigen. Drücken Sie Escape, um die Karte zu schließen. Klicken Sie auf eine
Citation mit einer öffentlichen URL, um die Originalseite in einem neuen Tab zu
öffnen.

Jeder Satz oder Schritt mit Quellenangabe trägt seine Citation neben dem Text,
den er belegt. Eine Quelle kann in derselben Antwort mehrfach zitiert werden.
Private Dokumente werden mit einer Vorschau ohne externen Link angezeigt.
Quellen ohne Inline-Referenz bleiben in der Sources-Liste unterhalb der Antwort
verfügbar.

## Einen Assistenten duplizieren

Beim Duplizieren werden die Konfiguration und die Flows kopiert.
Knowledge-Inhalte werden nicht kopiert.

Überprüfen Sie den neuen Assistant vor der Veröffentlichung. Fügen Sie
insbesondere die erforderlichen Sources hinzu und bestätigen Sie die
Help-Desk-Verbindungen.

## Einen Assistenten zwischen Organisationen verschieben

Öffnen Sie das Menü „Assistant“ und wählen Sie **Export bundle**, um eine
versionierte JSON-Datei herunterzuladen. Das Lesen eines Assistants ermöglicht
den Export.

Wählen Sie **Import bundle as new Assistant** aus, um die Datei hochzuladen. Der
Import erfordert Bearbeitungszugriff und erstellt immer einen neuen Assistant.
Bestehende Assistants bleiben unverändert.

Das Bundle enthält die Publication-Konfiguration, Flows, Skills, Guardrails,
Quick Replies und den Style. Es benennt Collections, Help Desks und Connection
Providers.

Der Import ordnet diese Namen in der Ziel-Organisation zu. Lesen Sie den
Importbericht auf fehlende oder mehrdeutige Übereinstimmungen durch. Flows mit
unaufgelösten Verweisen bleiben deaktiviert.

Credentials, verschlüsselte Werte, Conversations und Visitor-Daten sind
ausgeschlossen. Konfigurieren Sie die Anmeldeinformationen nach dem Import. API
Integrations zeigen **Needs setup** an, bis Anmeldeinformationen verfügbar sind.

Der Inhalt der Collection ist nicht enthalten. Importieren Sie Verknüpfungen zu
vorhandenen Ziel-Sources aus einer passenden Collection. Unbekannte
Bundle-Versionen werden vor der Erstellung abgelehnt.

Die API stellt `GET /api/v1/assistants/{id}/export` und
`POST /api/v1/assistants/import` bereit. MCP stellt die Export- und
Importaktionen von `manage_assistants` bereit.
