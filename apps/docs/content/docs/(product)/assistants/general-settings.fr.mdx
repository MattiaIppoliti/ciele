---

La section Général définit qui est l'assistant et comment il se présente. Ouvrez
un assistant, puis sélectionnez **General** dans le volet de configuration.

## Identité

- **Assistant title** est le nom de l'assistant.
- **Nickname** est le nom abrégé affiché dans l'en-tête du widget, là où les
  visiteurs le voient.
- **Description** explique la finalité de l'assistant. Restez clair et concis.

## Message de bienvenue

Le message de bienvenue est la première chose qu'un visiteur lit lorsqu'il ouvre
le chat. Vous le rédigez dans un éditeur de texte enrichi, ce qui vous permet
d'utiliser le gras, l'italique, les titres, les listes, les citations et les
liens. Utilisez-le pour définir les attentes : ce pour quoi l'assistant peut
vous aider et comment joindre un humain si nécessaire.

## Avis de non-responsabilité concernant l'IA

L'avertissement apparaît sous les réponses de l'assistant. Utilisez-le pour
rappeler aux visiteurs que les réponses sont générées par l'IA et pour les
orienter vers des sources faisant autorité lorsque l'exactitude est importante.

## Style de réponse

Le style de réponse est un guide en texte libre concernant le ton et le format.
Décrivez comment vous souhaitez que l'assistant s'exprime et structure ses
réponses, par exemple de manière concise et conviviale, ou formelle et
détaillée. Ce guide s'applique en complément des instructions propres à la
plateforme, de sorte qu'il façonne chaque réponse générée sans outrepasser les
règles de sécurité.

<Callout title="Verbatim vs generated">
Fixed messages you set in a Flow are shown word for word. The answering style
only affects answers the assistant generates, such as those produced when it
searches your knowledge. See [Flow actions](/flows/actions).
</Callout>

## Boutons de démarrage

Les boutons de démarrage sont des réponses rapides affichées au début d'une
conversation. Ils offrent aux visiteurs un moyen facile d'entrer. Chaque bouton
a un type qui détermine sa fonction. Consultez
[Boutons de démarrage](/assistants/quick-replies) pour la configuration
complète.

## Options de conversation

Le groupe Configuration contient des boutons bascules qui modifient l'expérience
de chat. En fonction de votre configuration, il peut s'agir de la langue de la
fenêtre de chat, d'une vue de progression qui réécrit les réflexions de
l'assistant sous forme de mises à jour courtes et lisibles, ainsi que d'autres
comportements. N'activez que ce qui sera utile à vos visiteurs et confirmez
chaque élément dans l'aperçu en direct.

## Le lanceur de chat

Le bouton **Enable chat launcher** permet de contrôler l'affichage du bouton de
chat flottant. Désactivez-le si vous prévoyez d'ouvrir l'assistant d'une autre
manière, par exemple à partir de votre propre bouton, et activez-le pour le
widget flottant standard.
