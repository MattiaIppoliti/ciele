---
title: Réponses rapides
description: Ajoutez des boutons de démarrage qui envoient du texte ou renvoient une réponse sélectionnée parmi les FAQ.
---

Les réponses rapides apparaissent à côté du message de bienvenue. Elles aident
un Visiteur à démarrer une tâche courante.

## Envoyer un texte

Une réponse rapide **Send Text** envoie le texte configuré en tant que message
du visiteur. Le routeur Flow standard traite ensuite ce message.

Utilisez ce type lorsque l'Assistant doit interpréter le texte de départ selon
ses règles de routage habituelles.

## FAQ

Une réponse rapide **FAQ** renvoie textuellement la réponse FAQ sélectionnée.
Elle n'appelle pas le modèle de chat.

La réponse inclut la citation de la source FAQ. Utilisez ce type lorsqu'une
réponse approuvée doit rester exacte.

## Ajoutez une réponse rapide

1. Ouvrez **General**.
2. Recherchez **Quick replies**.
3. Ajoutez un élément **Send Text** ou **FAQ**.
4. Saisissez le libellé visible.
5. Sélectionnez ou saisissez le contenu requis.
6. Enregistrez le brouillon.
7. Testez le bouton en mode Aperçu.

Utilisez des libellés courts. Le libellé doit décrire l'action qui se produit
après la sélection.
