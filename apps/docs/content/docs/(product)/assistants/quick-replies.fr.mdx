Les boutons de démarrage apparaissent lorsqu'un visiteur ouvre le chat. Ils
permettent de guider les utilisateurs de manière conviviale vers les tâches que
votre assistant maîtrise le mieux. Vous les gérez dans la section **General** de
l'éditeur d'assistant.

## Ajoutez un bouton

1. Dans Général, recherchez la liste des boutons de démarrage.
2. Sélectionnez **Add button**.
3. Donnez un **nom** au bouton. C'est le libellé que le visiteur voit.
4. Choisissez un **type**, puis renseignez les paramètres spécifiques à ce type.
5. Enregistrez le bouton.

Vous pouvez ajouter plusieurs boutons et les réorganiser pour que les plus
utiles apparaissent en premier.

## Types de boutons

Chaque bouton effectue l'une des quatre actions suivantes.

### Envoyer du texte dans le chat

Le bouton envoie un message dans le chat pour le visiteur, comme s'il l'avait
tapé lui-même. Utilisez cette fonctionnalité pour orienter l'assistant vers un
sujet spécifique. Par exemple, un bouton nommé « Pricing » peut envoyer le
message « Tell me about your pricing » afin que l'assistant réponde
immédiatement à cette question.

### Remontée d'information

Le bouton met le visiteur en relation avec votre équipe via les options
d'escalade que vous avez configurées. Utilisez cette option lorsque vous
souhaitez disposer d'un moyen clair et toujours visible de joindre un humain. Il
s'appuie sur vos [Help Desks](/help-desks).

### Ouvrir un lien externe

Le bouton ouvre une adresse Web dans un nouvel onglet. Utilisez cette option
pour diriger les visiteurs vers une page de votre site, un formulaire ou toute
autre ressource externe.

### FAQ

Le bouton fait apparaître une paire spécifique de question-réponse issue de
votre base de connaissances. Utilisez-le pour apporter une réponse instantanée
et exacte à une question courante. Consultez la [FAQ](/knowledge/faqs).

## Conseils

- Utilisez des libellés courts pour qu'ils s'intègrent parfaitement dans le
  widget.
- Commencez par les questions que les visiteurs posent le plus souvent.
- Associez un bouton « Envoyer un texte dans le chat » à des connaissances
  solides afin que l'assistant ait une bonne réponse prête.
