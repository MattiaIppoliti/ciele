Apri un Assistente e seleziona **Tools & Skills**. Questa sezione controlla le
funzionalità di runtime e le istruzioni riutilizzabili.

## Strumenti integrati

| Strumento | Predefinito | Comportamento attuale |
| --- | :---: | --- |
| Cerca nella conoscenza | Attivo | Cerca nella Conoscenza collegata e restituisce le risposte citate. |
| Memoria della sessione | Attivata | Utilizza le informazioni della sessione di conversazione corrente. |
| Recupera URL | Disattivato | Legge un URL quando il runtime seleziona lo strumento. |
| Mostra una tabella | Disattivato | Mostra i fatti in una tabella quando il runtime seleziona lo strumento. |

La ricerca nella Knowledge Base è sempre disponibile. Puoi abilitare o
disabilitare gli altri strumenti integrati.

Mostra una tabella organizza i fatti che l'Assistente ha trovato in questa
risposta. Non calcola valori. La tabella appare sopra la risposta scritta e la
trascrizione della Posta in arrivo mostra la stessa tabella.

L'Assistente può aggiungere una domanda di follow-up a una riga. Il Visitatore
seleziona la riga per porre quella domanda. La trascrizione della Posta in
arrivo mostra queste righe, ma un Membro non può selezionarle.

## Abilita la modalità di studio

**Study Mode** è disattivato per impostazione predefinita. Attivalo per
consentire ai Visitatori di esercitarsi con la Knowledge dell'Assistente tramite
esercizi interattivi.

1. Apri **Tools & Skills** e abilita **Study Mode**.
2. Abilita almeno un formato di domanda.
3. Aggiungi **Custom instructions** per impostare lo stile di insegnamento.
4. Prova un esercizio in Preview.
5. Pubblica l'Assistente per aggiornare il Widget.

Il chat composer mostra un pulsante **Study exercises**. Seleziona un formato,
aggiungi un argomento, quindi invia la richiesta.

Quando è abilitato, **Study Mode** appare anche in **Flows**. Il pulsante
Settings apre questa sezione. Disattiva la modalità di studio in **Tools &
Skills**. Il Flow non ha un interruttore separato. Le richieste dal menu Study
exercises vanno direttamente a questo Flow. Nell'area Thinking viene
visualizzata l'icona di un tocco accademico.

Gli esercizi richiedono materiale pertinente nella Knowledge dell'Assistente. Se
non viene trovato alcun materiale, l'Assistente ti chiede un argomento
supportato o del materiale di studio.

| Format | Come risponde il Visitor |
| --- | --- |
| Multiple choice | Seleziona una sola opzione. Non è disponibile alcuna risposta a testo libero. |
| Trascina le parole | Trascina o seleziona una parola per completare uno spazio vuoto per ogni domanda. |
| True / False | Seleziona una delle due opzioni. |
| Flashcards | Digita la parola mancante o una breve espressione. |

**Choose for me** seleziona un formato abilitato. Ogni esercizio contiene al
massimo cinque domande distinte basate sulle Knowledge recuperate.

Seleziona **Check** per salvare una risposta. Ciele mostra se la risposta è
corretta, qual è la risposta corretta e una spiegazione. Non puoi modificare una
risposta già inviata. Le flashcard accettano le varianti ortografiche definite
al momento della creazione dell'esercizio.

La Inbox mostra le domande, le risposte inviate, le risposte corrette e il
punteggio. Gli esercizi non completati mostrano quante domande sono ancora senza
risposta. Gli esercizi vengono eseguiti all'interno della chat. Non necessitano
di un lettore H5P esterno.

## Collega i dati strutturati

La sezione **Data** elenca le Entità importate tramite **Settings → Data**.
Seleziona ogni Entità che questo Assistente può interrogare.

Ogni Entità selezionata fornisce uno strumento di filtro esatto. Un'Entità con
attributi di testo fornisce anche uno strumento di ricerca per parole chiave.

Le Entità condivise sono disponibili per ogni Visitatore servito
dall'Assistente. Le Entità con ambito utente richiedono una
[dichiarazione di identità](/authentication/microsoft-entra-id#choose-an-identity-claim)
verificata.

La selezione dell'Entità e lo schema entrano nel successivo snapshot di
Pubblicazione. Il contenuto del record rimane attivo dopo la pubblicazione.

Vedi [Entità e record](/data/entities-and-records) per le importazioni CSV, le
scelte di ambito e il filtro delle identità.

## Configura un'integrazione API

Un Assistente può utilizzare una sola integrazione API registrata.
L'integrazione contiene un URL di base, una credenziale protetta ed endpoint
descritti.

Per ogni endpoint, definisci il metodo, il percorso, lo scopo, i parametri e la
forma della risposta. Il runtime convalida ogni percorso richiesto rispetto a
questo catalogo.

L'agente può ispezionare i dettagli dell'endpoint prima di inviare una
richiesta. Le risposte di grandi dimensioni rimangono disponibili tramite
letture a finestra.

<Callout title="Control the endpoint catalogue">
Add only the endpoints that the Assistant must use. The runtime cannot call an unregistered path through this integration.
</Callout>

## Associa una Skill dell'organizzazione

Una Skill è un modello di istruzioni riutilizzabile. Un'Organizzazione può
associare la stessa Skill a più Assistenti.

1. Apri **Tools & Skills**.
2. Trova la competenza organizzativa richiesta.
3. Associa la Skill all'Assistant.
4. Verifica il risultato in Anteprima.
5. Pubblica l'Assistente quando il risultato è corretto.

Le modifiche alle competenze sono immediatamente disponibili in Anteprima. Il
Widget pubblicato utilizza l'ultima istantanea della Pubblicazione.

## Prova la configurazione

Poni una domanda che richieda ciascuno strumento abilitato. Controlla il
pannello Thinking e le Sources prima di pubblicare.

Per i dati strutturati, prova una ricerca esatta per attributo e una ricerca
testuale. Verifica l'accesso con ambito utente con due diversi account connessi.
