description: Gestisci gli strumenti di runtime e associa istruzioni riutilizzabili a un Assistente.

Apri un Assistente e seleziona **Tools & Skills**. Questa sezione controlla le
funzionalità di runtime e le istruzioni riutilizzabili.

## Strumenti integrati

| Tool | Default | Comportamento corrente |
| --- | :---: | --- |
| Search knowledge | On | Cerca nella Knowledge collegata e restituisce risposte con citazioni. |
| Session memory | On | Utilizza le informazioni della sessione di conversazione corrente. |
| Fetch URL | Off | Legge un URL quando il runtime seleziona lo strumento. |
| Interactive tables | Off | Mostra i dati come una tabella semplice, una griglia dei record CRM o una tabella delle attività con filtri di stato. |

Search knowledge è sempre disponibile. Puoi abilitare o disabilitare gli altri
strumenti integrati.

**Interactive tables** organizza i fatti che l'Assistente ha trovato in questa
risposta. Il runtime seleziona la tabella in base alla tua richiesta e ai dati
disponibili.

- Una tabella semplice confronta i fatti e può includere domande di follow-up
  per le righe.
- Una griglia dei record CRM mostra aziende, categorie, ultima interazione,
  stato della relazione e link ai siti web. Seleziona le righe, ordina,
  ridimensiona o fissa le colonne.
- Una tabella delle attività mostra le date, lo stato e i proprietari. Seleziona
  **All**, **To do**, **In Progress** o **Completed** per filtrare le relative
  righe.

I conteggi dei filtri derivano dai dati visualizzati. I dati mancanti rimangono
vuoti. Le impostazioni della tabella influiscono sulla visualizzazione corrente
e non modificano i record CRM.

Usa **New property** o **Add calculation** nella griglia CRM per preparare una
richiesta di proprietà. Rivedi il suo prompt, quindi seleziona **Go calculate**.
Questo invia una normale richiesta di chat. L'harness corrente, le fonti
connesse e le autorizzazioni continuano ad applicarsi. L'interfaccia utente non
simula i valori generati.

Le stesse tabelle vengono visualizzate in Preview, nel Widget pubblicato e nel
transcript dell'Inbox. Pubblica l'Assistente dopo aver abilitato questo
strumento. L'Inbox supporta la visualizzazione, la selezione, il filtraggio e il
layout delle colonne. Non invia richieste di proprietà.

L'Assistente può aggiungere una domanda di follow-up a una riga. Il Visitor
seleziona la riga per porre quella domanda. La trascrizione dell'Inbox mostra
queste righe, ma un Member non può selezionarle.

## Abilita la modalità di studio

**Study Mode** è disattivato per impostazione predefinita. Attivalo per
consentire ai Visitatori di esercitarsi con la Knowledge dell'Assistente tramite
esercizi interattivi.

1. Apri **Tools & Skills** e abilita **Study Mode**.
2. Abilita almeno un formato di domanda.
3. Aggiungi **Custom instructions** per impostare lo stile di insegnamento.
4. Prova un esercizio in Preview.
5. Pubblica l'Assistente per aggiornare il Widget.

Il chat composer mostra un pulsante **Study exercises**. Seleziona un formato,
aggiungi un argomento, quindi invia la richiesta.

Quando è abilitato, **Study Mode** viene visualizzato anche in **Flows**. Il
pulsante Settings apre questa sezione. Disattiva la Study Mode in **Tools &
Skills**. Il Flow non ha un interruttore separato. Le richieste dal menu Study
exercises vanno direttamente a questo Flow. In Thinking viene visualizzata
l'icona di un tocco accademico.

Gli esercizi richiedono materiale pertinente nella Knowledge dell'Assistente. Se
non viene trovato alcun materiale, l'Assistente ti chiede un argomento
supportato o del materiale di studio.

| Format | Come risponde il Visitor |
| --- | --- |
| Multiple choice | Seleziona una sola opzione. Non è disponibile alcuna risposta a testo libero. |
| Drag the words | Trascina o seleziona una parola per completare uno spazio vuoto per ogni domanda. |
| True / False | Seleziona una delle due opzioni. |
| Flashcards | Digita la parola mancante o una breve espressione. |

**Choose for me** seleziona un formato abilitato. Ogni esercizio contiene al
massimo cinque domande distinte basate sulle Knowledge recuperate.

Seleziona **Check** per salvare una risposta. Ciele mostra se la risposta è
corretta, qual è quella giusta e una spiegazione. Non puoi modificare una
risposta già inviata. Le flashcard accettano le varianti ortografiche definite
al momento della creazione dell'esercizio.

La Inbox mostra le domande, le risposte inviate, le risposte corrette e il
punteggio. Gli esercizi non completati mostrano quante domande sono ancora senza
risposta. Gli esercizi vengono eseguiti all'interno della chat. Non richiedono
un lettore H5P esterno.

## Configura un'integrazione API

Un Assistant può utilizzare una sola integrazione API registrata. L'integrazione
contiene un base URL, una credenziale protetta e gli endpoint descritti.

Per ciascun endpoint, definisci il metodo, il percorso, lo scopo, i parametri e
la forma della risposta. Il runtime convalida ogni percorso richiesto
confrontandolo con questo catalogo.

L'agent può esaminare i dettagli dell'endpoint prima di inviare una richiesta.
Le risposte di grandi dimensioni rimangono disponibili tramite letture a
finestra.

<Callout title="Control the endpoint catalogue">
Add only the endpoints that the Assistant must use. The runtime cannot call an unregistered path through this integration.
</Callout>

### Impedisci una scrittura duplicata

Puoi inviare nuovamente una richiesta dopo un timeout o un errore. Se l'endpoint
scrive dati, la seconda richiesta può creare un secondo record.

Per evitare questo problema, assegna all'endpoint una idempotency key. Nel
modulo dell'endpoint, indica dove la tua API legge la chiave:

- `header:Idempotency-Key` invia la chiave in un header della richiesta.
- `body:request_id` invia la chiave nel corpo JSON.

Usa il nome che la tua API legge. Ciele non cerca di indovinare questo nome. API
diverse leggono nomi diversi.

Ciele genera una chiave per ogni chiamata. Un nuovo tentativo della stessa
chiamata invia la stessa chiave. Una chiamata diversa invia una chiave diversa.
La tua API può quindi considerare le due richieste come un'unica operazione di
scrittura.

Anche la tua API deve fare la sua parte. Deve memorizzare la chiave e restituire
il primo risultato quando rileva nuovamente la chiave.

<Callout title="An endpoint with no key is not protected">
If you give no key, a retry of the call can write two times. A `GET` endpoint does not need a key, because a read does not change data.
</Callout>

## Associa una Skill dell'organizzazione

Una Skill è un modello di istruzioni riutilizzabile. Un'organizzazione può
associare la stessa Skill a più Assistenti.

1. Apri **Tools & Skills**.
2. Trova la Organization Skill richiesta.
3. Collega la Skill all'Assistente.
4. Verifica il risultato in Preview.
5. Pubblica l'Assistente quando il risultato è corretto.

Le modifiche alle Skill sono immediatamente disponibili in Preview. Il Widget
pubblicato utilizza l'ultimo snapshot di Publication.

### Consenti alle persone di avviare una Skill dalla finestra della chat

Una Skill può avere un **Opening line**. Scrivilo dal punto di vista della
persona che chiede, non dell'Assistente.

La finestra di chat mostra un menu **/** con ogni Skill che ha una opening line.
Quando l'utente seleziona una Skill, la finestra di chat inserisce la opening
line nella casella dei messaggi. Puoi modificare il testo prima di inviarlo.

Se la battuta di apertura è vuota, la Skill non viene visualizzata nel menu
**/**. Il prompt della Skill continua ad applicarsi a ogni risposta.

Pubblica l'Assistente dopo aver scritto una opening line. Il Widget utilizza
l'ultimo snapshot di Publication.

## Gli allegati e la Knowledge non sono la stessa cosa

Sia un allegato sia una Knowledge Source diventano testo, e Ciele li legge
entrambi con lo stesso extractor. Quello che accade dopo è diverso.

Una Knowledge Source è permanente. Ciele ne memorizza il testo, lo indicizza e
l'Assistente può citarlo in ogni conversazione successiva.

Un allegato appartiene alla sua conversazione. Ciele lo legge una sola volta,
scarta i byte e non lo aggiunge mai alla Library. Nessun'altra conversazione lo
vede.

Per rendere permanente un file, aggiungilo invece in **Library**.

## Verifica la configurazione

Poni una domanda che richieda ciascuno degli strumenti abilitati. Prima di
pubblicare, controlla il pannello Thinking e la sezione Sources.

Per i dati strutturati, esegui il test di una ricerca esatta per attributo e di
una ricerca testuale. Verifica l'accesso con ambito utente utilizzando due
account diversi con cui hai effettuato l'accesso.
