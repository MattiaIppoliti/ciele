---
title: Schnelle Antworten
description: Fügen Sie Starter-Buttons hinzu, die Text senden oder eine kuratierte FAQ-Antwort zurückgeben.
---

Schnelle Antworten werden in der Nähe der Begrüßungsnachricht angezeigt. Sie
helfen einem Besucher, eine gängige Aufgabe zu starten.

## Text senden

Eine **Send Text**-Schnellantwort sendet ihren konfigurierten Text als
Besuchernachricht. Der normale Flow-Router verarbeitet diese Nachricht dann.

Verwenden Sie diesen Typ, wenn der Assistent den Starttext anhand seiner
normalen Routing-Regeln interpretieren muss.

## Häufig gestellte Fragen

Eine **FAQ**-Schnellantwort gibt die kuratierte FAQ-Antwort wortgetreu zurück.
Das Chat-Modell wird dabei nicht aufgerufen.

Die Antwort enthält die Quellenangabe zur FAQ. Verwenden Sie diesen Typ, wenn
eine genehmigte Antwort genau bleiben muss.

## Fügen Sie eine Schnellantwort hinzu

1. Öffnen Sie **General**.
2. Suchen Sie **Quick replies**.
3. Fügen Sie ein **Send Text**- oder **FAQ**-Element hinzu.
4. Geben Sie die sichtbare Beschriftung ein.
5. Wählen Sie den erforderlichen Inhalt aus oder geben Sie ihn ein.
6. Speichern Sie den Entwurf.
7. Testen Sie die Schaltfläche in der Vorschau.

Halten Sie Beschriftungen kurz. Die Beschriftung muss die Aktion beschreiben,
die nach der Auswahl erfolgt.
