---
title: Asistentes
description: Configura la identidad, el modelo, el comportamiento, las herramientas y las comprobaciones de un asistente.
---

Un asistente es la unidad de configuración principal en Ciele. Cada asistente es
propietario de su Knowledge, sus Flows, su configuración de borradores y su
historial de publicaciones.

## Secciones de configuración

| Sección | Propósito |
| --- | --- |
| General | Establece los valores predeterminados de identidad, modelo y conversación. |
| Knowledge | Añade Sources y FAQs. |
| Flows | Define el enrutamiento y las respuestas. |
| Tools & Skills | Controla las herramientas de tiempo de ejecución, la integración de API y las instrucciones reutilizables. |
| Goals | Programa comprobaciones de respuestas deterministas. |
| Guardrails | Revisa los mensajes de los visitantes y oculta el texto de las respuestas marcadas. |
| Assistant Help Desks | Selecciona los Help Desks para la escalada. |
| Style | Establece el color de la marca y la posición del lanzador. |
| Autenticación | Requiere el inicio de sesión con Microsoft Entra para los visitantes. |
| Publish | Crea y gestiona la instantánea en tiempo real. |

Los cambios afectan a Preview de inmediato. El widget en tiempo real solo cambia
después de la publicación.

Preview puede usar tu suscripción local conectada a Claude o a ChatGPT desde
**Settings → AI**. El panel de progreso informa sobre las búsquedas y sus
resultados. No solicita el razonamiento privado del modelo. Un modelo conectado
sigue necesitando Knowledge Sources para responder de forma fiable a preguntas
específicas de la organización.

## Inspeccionar las fuentes en la vista previa

La vista previa muestra citas de fuentes numeradas dentro de la respuesta del
asistente. Coloca el puntero sobre una cita o selecciónala con el teclado para
ver su título y los detalles de la fuente. Pulsa Escape para cerrar la tarjeta.
Haz clic en una cita con una URL pública para abrir la página original en una
nueva pestaña.

Cada oración o paso con fuente lleva su cita junto al texto al que respalda.
Puedes citar una fuente más de una vez en la misma respuesta. Los documentos
privados muestran una vista previa sin enlace externo. Las fuentes sin
referencia en línea siguen estando disponibles en la lista Sources situada
debajo de la respuesta.

## Duplicar un asistente

La duplicación copia la configuración y los Flows. No copia el contenido de
Knowledge.

Revisa el nuevo asistente antes de publicarlo. En particular, añade las Sources
necesarias y confirma sus conexiones con el Help Desk.
