---
title: Objetivos
description: Programa comprobaciones repetibles para las respuestas importantes del asistente.
---

Un Goal plantea una pregunta permanente y compara la respuesta con expectativas
deterministas. Un Goal que falla genera una Alert.

## Crea un objetivo

1. Abre un asistente.
2. Selecciona **Goals**.
3. Selecciona **Add** en la sección **Goals**.
4. Introduce la pregunta que Ciele debe formular.
5. Añade una o varias expectativas.
6. Guarda el objetivo.

## Expectativas disponibles

| Expectativa | Comprobación |
| --- | --- |
| Debe citar una fuente | La respuesta contiene al menos una cita de fuente. |
| Cited URL contains | Una URL citada contiene el texto configurado. |
| Answer contains | La respuesta contiene cada fragmento de texto configurado. |
| Respuesta no alternativa | El entorno de ejecución no devolvió su resultado alternativo. |

Ciele siempre comprueba si hay una respuesta que no sea de fallback. Otras
expectativas dependen de la configuración del Goal.

## Estado del objetivo

Un Goal activo se ejecuta según su programación. Ciele puede poner en cuarentena
un Goal tras repetidos problemas de ejecución.

Un Goal en cuarentena no sigue su programación habitual. Revisa el Goal y su
Alert antes de volver a activarlo.

## Revisar un fallo

1. Abre **Alerts**.
2. Selecciona el fallo del Goal.
3. Revisa la respuesta y la expectativa no cumplida.
4. Corrige el Knowledge, el Flow o el Goal.
5. Ejecuta el Goal de nuevo.

Los objetivos utilizan comprobaciones exactas. No utilizan un evaluador de
modelos de tipo abierto.
