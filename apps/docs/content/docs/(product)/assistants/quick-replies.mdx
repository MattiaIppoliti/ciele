Starter buttons appear when a visitor opens the chat. They are a friendly way to
guide people toward the things your assistant does best. You manage them in the
**General** section of the assistant editor.

## Add a button

1. In General, find the starter buttons list.
2. Select **Add button**.
3. Give the button a **name**. This is the label the visitor sees.
4. Choose a **type**, then fill in the type specific settings.
5. Save the button.

You can add several buttons and reorder them so the most useful ones come first.

## Button types

Each button does one of four things.

### Send text into chat

The button sends a message into the chat for the visitor, as if they had typed it.
Use this to focus the assistant on a specific topic. For example, a button named
"Pricing" can send the message "Tell me about your pricing" so the assistant
answers that question right away.

### Escalation

The button connects the visitor to your team through your configured escalation
options. Use this when you want a clear, always visible way to reach a human. It
relies on your [Help Desks](/help-desks).

### Open external link

The button opens a web address in a new tab. Use this to send visitors to a page
on your site, a form, or any external resource.

### FAQ

The button surfaces a specific question and answer pair from your knowledge. Use
this to give an instant, exact answer to a common question. See
[FAQs](/knowledge/faqs).

## Tips

- Keep labels short so they fit neatly in the widget.
- Lead with the questions visitors ask most.
- Pair a "Send text into chat" button with strong knowledge so the assistant has
  a good answer ready.
