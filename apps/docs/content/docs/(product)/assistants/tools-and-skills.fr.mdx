Ouvrez un Assistant et sélectionnez **Tools & Skills**. Cette section contrôle
les capacités d'exécution et les instructions réutilisables.

## Outils intégrés

| Outil | Par défaut | Comportement actuel |
| --- | :---: | --- |
| Recherche de connaissances | Activée | Recherche les connaissances connectées et renvoie les réponses citées. |
| Mémoire de session | Activée | Utilise les informations de la session de conversation en cours. |
| Récupérer l'URL | Désactivé | Lit une URL lorsque le moteur d'exécution sélectionne l'outil. |
| Afficher un tableau | Désactivé | Affiche les faits dans un tableau lorsque le moteur d'exécution sélectionne l'outil. |

La recherche dans la base de connaissances est toujours disponible. Vous pouvez
activer ou désactiver les autres outils intégrés.

L'option Afficher un tableau organise les faits que l'Assistant a trouvés dans
cette réponse. Il ne calcule pas de valeurs. Le tableau apparaît au-dessus de la
réponse écrite, et la transcription de la boîte de réception affiche le même
tableau.

L'Assistant peut ajouter une question de suivi à une ligne. Le visiteur
sélectionne la ligne pour poser cette question. La transcription de la boîte de
réception affiche ces lignes, mais un membre ne peut pas les sélectionner.

## Activer le mode Étude

**Study Mode** est désactivé par défaut. Activez-le pour permettre aux Visiteurs
de s'exercer sur la Knowledge de l'Assistant grâce à des exercices interactifs.

1. Ouvrez **Tools & Skills** et activez **Study Mode**.
2. Activez au moins un format de question.
3. Ajoutez **Custom instructions** pour définir le style d'enseignement.
4. Testez un exercice dans Preview.
5. Publiez l'Assistant pour mettre à jour le Widget.

Le champ de saisie du chat affiche un bouton **Study exercises**. Sélectionnez
un format, ajoutez un sujet, puis envoyez la requête.

Lorsqu'il est activé, **Study Mode** apparaît également dans **Flows**. Son
bouton Settings ouvre cette section. Désactivez le mode Étude dans **Tools &
Skills**. Le Flow n'a pas de commutateur distinct. Les requêtes provenant du
menu Study exercises sont directement acheminées vers ce Flow. Une icône
représentant un chapeau de diplômé s'affiche dans Thinking.

Les exercices nécessitent des ressources pertinentes dans la Knowledge de
l'Assistant. Si aucun support n'est trouvé, l'Assistant vous demande un sujet
pris en charge ou un support d'étude.

| Format | Comment le visiteur répond |
| --- | --- |
| Choix multiple | Sélectionnez une option. Aucune réponse en texte libre n'est disponible. |
| Faites glisser les mots | Faites glisser ou sélectionnez un mot pour remplir un espace vide par question. |
| True / False | Sélectionnez l'une des deux options. |
| Flashcards | Saisissez le mot manquant ou une courte expression. |

**Choose for me** sélectionne un format activé. Chaque exercice contient au
maximum cinq questions distinctes basées sur les Knowledge extraites.

Sélectionnez **Check** pour enregistrer une réponse. Ciele indique si la réponse
est correcte, fournit la bonne réponse et donne une explication. Une réponse
soumise ne peut pas être modifiée. Les flashcards acceptent les variantes
orthographiques définies lors de la création de l'exercice.

La Inbox affiche les questions, les réponses soumises, les bonnes réponses et le
score. Les exercices non terminés indiquent le nombre de questions restées sans
réponse. Les exercices s'exécutent dans le chat. Ils n'ont pas besoin d'un
lecteur H5P externe.

## Connectez des données structurées

La section **Data** répertorie les Entités importées via **Settings → Data**.
Sélectionnez chaque Entité que cet Assistant peut interroger.

Chaque Entité sélectionnée fournit un outil de filtrage exact. Une entité avec
des attributs de texte fournit également un outil de recherche par mot-clé.

Les Entités partagées sont disponibles pour chaque Visiteur pris en charge par
l'Assistant. Les entités à portée utilisateur nécessitent une
[revendication d'identité](/authentication/microsoft-entra-id#choose-an-identity-claim)
vérifiée.

La sélection d'entité et le schéma sont intégrés au prochain instantané de
publication. Le contenu de l'enregistrement reste en ligne après la publication.

Consultez [Entities and Records](/data/entities-and-records) pour les
importations CSV, les choix de portée et le filtrage d'identité.

## Configurez une intégration d'API

Un Assistant peut utiliser une intégration d'API enregistrée. L'intégration
contient une URL de base, un identifiant protégé et des points de terminaison
décrits.

Pour chaque point de terminaison, définissez la méthode, le chemin, l'objectif,
les paramètres et la forme de la réponse. Le moteur d'exécution valide chaque
chemin demandé par rapport à ce catalogue.

L'agent peut inspecter les détails du point de terminaison avant d'envoyer une
requête. Les réponses volumineuses restent disponibles via des lectures
fenêtrées.

<Callout title="Control the endpoint catalogue">
Add only the endpoints that the Assistant must use. The runtime cannot call an unregistered path through this integration.
</Callout>

## Associer une compétence d'organisation

Une compétence est un modèle d'instruction réutilisable. Une Organisation peut
associer la même Compétence à plusieurs Assistants.

1. Ouvrez **Tools & Skills**.
2. Recherchez la compétence d'organisation requise.
3. Associez la compétence à l'assistant.
4. Testez le résultat dans l'Aperçu.
5. Publiez l'Assistant lorsque le résultat est correct.

Les modifications apportées aux compétences sont immédiatement disponibles dans
l'aperçu. Le widget publié utilise le dernier instantané de publication.

## Testez la configuration

Posez une question qui nécessite chacun des outils activés. Vérifiez le panneau
Thinking et les Sources avant de publier.

Pour les données structurées, testez une recherche exacte d'attribut et une
recherche textuelle. Testez l'accès au niveau de l'utilisateur avec deux comptes
connectés différents.
