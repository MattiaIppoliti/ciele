Ciele is available in two editions that share the same product and the same
documentation. Everything in this **Documentation** section — assistants,
knowledge, flows, help desks, publishing, and operations — works the same way in
both. The editions differ only in **who runs the software** and in a small set of
**managed-only features**.

## The open-source core

The core of Ciele is open source under the **AGPL-3.0** license. It is the whole
product a visitor and an administrator interact with: the admin console, the chat
widget, the flow router, the knowledge and retrieval pipeline, and the operations
surfaces (inbox, improvements, insights, alerts). You can run it on your own
infrastructure at no license cost.

See [Open Source](/self-hosting) for how to install, configure, and operate a
self-hosted deployment, and for exactly where the open-core boundary sits.

## Ciele Cloud

Ciele Cloud is the same core, hosted and operated for you, plus the commercial
features that only make sense for a managed multi-tenant service. You do not
install or patch anything; you sign in and start building.

The managed edition adds:

- **Plans and billing** — subscription plans, invoicing, and payment, handled in
  the console. See [Plans and billing](/cloud/plans-and-billing).
- **Usage limits** — per-plan quotas that meter and cap monthly usage. See
  [Usage and limits](/cloud/usage-and-limits).
- **Managed single sign-on** — organization SSO onboarding run for you. See
  [Team and single sign-on](/cloud/team-and-sso).
- **Operations and support** — hosting, upgrades, backups, and a support channel
  with a service commitment. See [Support](/cloud/support).

These features live outside the open-source core and are not created in a
self-hosted deployment.

## Which edition am I using?

If you signed up at the hosted service and never installed anything, you are on
**Ciele Cloud**. If your organization runs Ciele on its own servers, you are on
the **open-source** edition. Billing, usage limits, and managed SSO appear only on
Ciele Cloud.

<Callout title="Same docs, both editions">
Feature pages that describe a managed-only capability say so at the top. Where a
page has no such note, the feature is part of the open-source core and behaves the
same wherever Ciele runs.
</Callout>
