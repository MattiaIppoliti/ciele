Ciele has a managed Cloud edition and an open-source self-hosted edition. Both editions use the same open-source product core.

| Area | Ciele Cloud | Open Source |
| --- | --- | --- |
| Product operation | Ciele operates the service. | Your team operates the service. |
| Subscription | A Ciele plan controls included usage. | No Ciele subscription is required. |
| Infrastructure | Ciele selects and maintains the deployment. | Your team supplies and maintains the deployment. |
| Model credentials | Use plan models or supported provider connections. | Configure supported provider or compatible local endpoints. |
| Updates | The managed service receives deployed releases. | Your team selects and applies releases. |
| License | Service terms apply. | The core uses AGPL-3.0-only. |

The public Open Source documentation describes only files in the open-source repository. It does not describe enterprise implementation details.

Use [Ciele Cloud](/cloud) for hosted plan information. Use [Open Source](/self-hosting) for installation and operation instructions.
