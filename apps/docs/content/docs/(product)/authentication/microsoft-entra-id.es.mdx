---
title: Microsoft Entra ID
description: Configura la conexión OpenID Connect actual para el inicio de sesión de visitantes.
---

Microsoft Entra ID es el proveedor de identidad de visitantes disponible.

## Crea la aplicación de Entra

1. Registra una aplicación web confidencial en Microsoft Entra ID.
2. Añade la URL de callback de Ciele que se muestra en el formulario del
   proveedor.
3. Crea un secreto de cliente.
4. Registra el ID de inquilino y el ID de cliente.

Utiliza la URL de devolución de llamada exacta. Un esquema, un host, una ruta o
un puerto distintos impiden la respuesta de autorización.

## Configura Ciele

1. Abre **Settings**.
2. Abre la configuración de Visitor authentication.
3. Selecciona **Microsoft Entra ID**.
4. Introduce el ID del inquilino.
5. Introduce el client ID.
6. Introduce el secreto de cliente.
7. Elige un **Identity claim** cuando las funciones por visitante lo requieran.
8. Guarda la conexión.

Ciele utiliza el flujo de código de autorización con Proof Key for Code Exchange
(PKCE).

## Elige una reclamación de identidad

El valor predeterminado es **Off, subject only**. A continuación, Ciele almacena
el sujeto OIDC opaco sin un identificador legible por humanos.

Elige **Email address** o **Username (preferred_username claim)** cuando una
función por visitante necesite un identificador legible. Por ejemplo, una
integración de API puede enviar el valor como `{{identity.claim}}`.

Ciele verifica la reclamación seleccionada dentro del token ID firmado. El
servidor lo traslada a la Conversation y al turno de ejecución.

El cuerpo de una solicitud o la entrada de una herramienta de modelo no pueden
sustituir al valor verificado. Si falta una «claim» configurada, se desactivan
las funciones que la requieren para ese Visitor.

Vuelve a conectar la conexión de Entra para cambiar la afirmación. Ciele
solicita los ámbitos de perfil y correo electrónico cuando se habilita una
claim.

## Configuración del servidor necesaria

Establece `APP_ENCRYPTION_KEY` en la implementación de Ciele. Ciele utiliza esta
clave para proteger la cookie de la puerta de autenticación y los secretos
almacenados.

## Prueba la conexión

1. Exige la autenticación en un borrador de Assistant.
2. Abre Preview en una sesión del navegador en la que no hayas iniciado sesión.
3. Completa el inicio de sesión de Microsoft.
4. Confirma que el chat pasa a estar disponible.
5. Confirma que otra organización no pueda reutilizar la cookie de acceso.
6. Inicia una conversación y confirma que en Inbox se muestra el sujeto que ha
   iniciado sesión.

Cuando esté habilitada una afirmación de identidad, prueba un punto de conexión
de integración de API que utilice `{{identity.claim}}`. Confirma que cada
Visitor que haya iniciado sesión reciba únicamente sus propios datos.
