---
title: Microsoft Entra ID
description: Configura la connessione OpenID Connect corrente per l'accesso dei Visitor.
---

Microsoft Entra ID è l'identity provider disponibile per i Visitor.

## Crea l'applicazione Entra

1. Registra un'applicazione web riservata in Microsoft Entra ID.
2. Aggiungi il Ciele callback URL indicato nel modulo del provider.
3. Crea un client secret.
4. Registra il tenant ID e il client ID.

Usa l'URL di callback esatto. Uno schema, un host, un percorso o una porta
diversi impediscono la risposta di autorizzazione.

## Configura Ciele

1. Apri **Settings**.
2. Apri la configurazione dell'autenticazione dei visitatori.
3. Seleziona **Microsoft Entra ID**.
4. Inserisci il tenant ID.
5. Inserisci il client ID.
6. Inserisci il client secret.
7. Scegli un **Identity claim** quando le funzionalità per singolo visitatore ne
   richiedono uno.
8. Salva la connessione.

Ciele utilizza il flusso authorization-code con Proof Key for Code Exchange
(PKCE).

## Scegli un identity claim

Il valore predefinito è **Off, subject only**. Ciele memorizza quindi il
soggetto OIDC opaco senza un identificatore leggibile da parte di un essere
umano.

Scegli **Email address** o **Username (preferred_username claim)** quando una
funzionalità per singolo visitatore richiede un identificatore leggibile. Ad
esempio, un'integrazione API può inviare il valore come `{{identity.claim}}`.

Ciele verifica il claim selezionato all'interno dell'ID token firmato. Il server
lo trasferisce nella Conversation e nel turno di runtime.

Un request body o un input dello strumento del modello non possono sostituire il
valore verificato. L'assenza di un claim configurato disabilita le funzionalità
che lo richiedono per quel Visitor.

Riconnetti la connessione Entra per modificare il claim. Ciele richiede gli
ambiti profile ed email quando è abilitato un claim.

## Impostazione del server obbligatoria

Imposta `APP_ENCRYPTION_KEY` sull'implementazione di Ciele. Ciele utilizza
questa chiave per proteggere il cookie del gate di autenticazione e i segreti
memorizzati.

## Verifica la connessione

1. Richiedi l'autenticazione su una bozza di Assistant.
2. Apri Preview in una sessione del browser in cui hai effettuato il sign-out.
3. Completa l'accesso con Microsoft.
4. Verifica che la chat diventi disponibile.
5. Verifica che un'altra Organization non possa riutilizzare il gate cookie.
6. Avvia una Conversation e verifica che l'Inbox mostri il soggetto connesso.

Quando è abilitata una dichiarazione di identità, testa un endpoint di
integrazione API che utilizza `{{identity.claim}}`. Verifica che ogni Visitor
connesso riceva solo i propri dati.
