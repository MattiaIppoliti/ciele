title: Microsoft Entra ID
description: Configurez la connexion OpenID Connect actuelle pour la connexion des visiteurs.
---

Microsoft Entra ID est le fournisseur d'identité disponible pour les visiteurs.

## Créer l'application Entra

1. Enregistrez une application web confidentielle dans Microsoft Entra ID.
2. Ajoutez l'URL de rappel Ciele indiquée dans le formulaire du fournisseur.
3. Créez un client secret.
4. Notez le tenant ID et le client ID.

Utilisez l'URL de rappel exacte. Un schéma, un hôte, un chemin ou un port
différent empêche la réponse d'autorisation.

## Configurer Ciele

1. Ouvrez **Settings**.
2. Ouvrez la configuration de l'authentification des visiteurs.
3. Sélectionnez **Microsoft Entra ID**.
4. Saisissez l'identifiant du locataire (tenant ID).
5. Saisissez le client ID.
6. Saisissez le secret client.
7. Choisissez un **Identity claim** lorsque les fonctionnalités par visiteur en
   nécessitent un.
8. Enregistrez la connexion.

Ciele utilise le flux authorization-code avec Proof Key for Code Exchange
(PKCE).

## Choisissez une revendication d'identité

La valeur par défaut est **Off, subject only**. Ciele stocke ensuite le sujet
OIDC opaque sans identifiant lisible par un humain.

Choisissez **Email address** ou **Username (preferred_username claim)**
lorsqu'une fonctionnalité par visiteur nécessite un identifiant lisible. Par
exemple, une intégration d'API peut envoyer la valeur sous la forme
`{{identity.claim}}`.

Ciele vérifie la revendication sélectionnée dans le jeton d'identification
signé. Le serveur le transmet à la Conversation et au tour d'exécution.

Un corps de requête ou une entrée d'outil de modèle ne peut pas remplacer la
valeur vérifiée. L'absence d'une revendication configurée désactive les
fonctionnalités qui en ont besoin pour ce Visiteur.

Reconnectez la connexion Entra pour modifier la revendication. Ciele demande les
portées profile et email lorsqu'une revendication est activée.

## Paramètre serveur requis

Définissez `APP_ENCRYPTION_KEY` sur le déploiement Ciele. Ciele utilise cette
clé pour protéger le cookie de la passerelle d'authentification et les secrets
stockés.

## Tester la connexion

1. Exiger l'authentification sur un brouillon d'Assistant.
2. Ouvrez Preview dans une session de navigateur où vous êtes déconnecté.
3. Terminez la connexion Microsoft.
4. Vérifiez que le chat devient disponible.
5. Vérifiez qu'une autre organisation ne peut pas réutiliser le cookie gate.
6. Démarrez une Conversation et vérifiez que l'Inbox affiche le sujet connecté.

Lorsqu'une revendication d'identité est activée, testez un point de terminaison
d'intégration d'API qui utilise `{{identity.claim}}`. Vérifiez que chaque
Visitor connecté ne reçoit que ses propres données.
