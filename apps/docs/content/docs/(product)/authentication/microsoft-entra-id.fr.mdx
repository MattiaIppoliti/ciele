title: Microsoft Entra ID
description: Configurez la connexion OpenID Connect actuelle pour la connexion des visiteurs.
---

Microsoft Entra ID est le fournisseur d'identité Visiteur disponible.

## Créez l'application Entra

1. Enregistrez une application Web confidentielle dans Microsoft Entra ID.
2. Ajoutez l'URL de rappel Ciele indiquée dans le formulaire du fournisseur.
3. Créez un secret client.
4. Enregistrez l'identifiant du locataire et l'identifiant du client.

Utilisez l'URL de rappel exacte. Un schéma, un hôte, un chemin ou un port
différent empêche la réponse d'autorisation.

## Configurez Ciele

1. Ouvrez **Settings**.
2. Ouvrez la configuration de l'authentification des visiteurs.
3. Sélectionnez **Microsoft Entra ID**.
4. Saisissez l'identifiant du locataire.
5. Saisissez l'identifiant client.
6. Saisissez le secret client.
7. Enregistrez la connexion.

Ciele utilise le flux de code d'autorisation avec Proof Key for Code Exchange
(PKCE). Elle ne demande que l'étendue `openid`.

## Paramètre serveur requis

Définissez `APP_ENCRYPTION_KEY` sur le déploiement Ciele. Ciele utilise cette
clé pour protéger le cookie de la passerelle d'authentification et les secrets
stockés.

## Testez la connexion

1. Exigez l'authentification sur un brouillon d'assistant.
2. Ouvrez l'aperçu dans une session de navigateur sans être connecté.
3. Terminez la connexion Microsoft.
4. Vérifiez que le chat devient disponible.
5. Vérifiez qu'une autre organisation ne peut pas réutiliser le cookie de la
   passerelle.
