---
title: Microsoft Entra ID
description: Konfigurieren Sie die aktuelle OpenID Connect-Verbindung für die Besucher-Anmeldung.
---

Microsoft Entra ID ist der verfügbare Identitätsanbieter für Besucher.

## Erstellen Sie die Entra-Anwendung

1. Registrieren Sie eine vertrauliche Webanwendung in Microsoft Entra ID.
2. Fügen Sie die im Anbieterformular angezeigte Ciele-Callback-URL hinzu.
3. Erstellen Sie ein Client-Geheimnis.
4. Notieren Sie die Mandanten-ID und die Client-ID.

Verwenden Sie die genaue Callback-URL. Ein anderes Schema, ein anderer Host, ein
anderer Pfad oder ein anderer Port verhindert die Autorisierungsantwort.

## Ciele konfigurieren

1. Öffnen Sie **Settings**.
2. Öffnen Sie die Konfiguration für die Besucherauthentifizierung.
3. Wählen Sie **Microsoft Entra ID**.
4. Geben Sie die Mandanten-ID ein.
5. Geben Sie die Client-ID ein.
6. Geben Sie das Client-Geheimnis ein.
7. Speichern Sie die Verbindung.

Ciele verwendet den Autorisierungscode-Flow mit Proof Key for Code Exchange
(PKCE). Es wird nur der Bereich `openid` angefordert.

## Erforderliche Servereinstellung

Legen Sie `APP_ENCRYPTION_KEY` in der Ciele-Bereitstellung fest. Ciele verwendet
diesen Schlüssel, um das Authentication-Gate-Cookie und gespeicherte Geheimnisse
zu schützen.

## Testen Sie die Verbindung

1. Fordern Sie die Authentifizierung für einen Entwurfs-Assistenten an.
2. Öffnen Sie die Vorschau in einer Browser-Sitzung, in der Sie abgemeldet sind.
3. Schließen Sie die Microsoft-Anmeldung ab.
4. Vergewissern Sie sich, dass der Chat verfügbar wird.
5. Vergewissern Sie sich, dass eine andere Organisation das Gate-Cookie nicht
   wiederverwenden kann.
