Ciele offre un'edizione Cloud gestita e un'edizione open source self-hosted.
Entrambe le edizioni utilizzano lo stesso core di prodotto open source.

| Area | Ciele Cloud | Open source |
| --- | --- | --- |
| Gestione del prodotto | Ciele gestisce il servizio. | Il tuo team gestisce il servizio. |
| Abbonamento | Un piano Ciele controlla l'utilizzo incluso. | Non è richiesto alcun abbonamento a Ciele. |
| Infrastruttura | Ciele seleziona e gestisce la distribuzione. | Il tuo team fornisce e gestisce la distribuzione. |
| Credenziali del modello | Utilizza i modelli del piano o le connessioni dei provider supportati. | Configura il provider supportato o gli endpoint locali compatibili. |
| Aggiornamenti | Il servizio gestito riceve le release distribuite. | Il tuo team seleziona e applica le release. |
| Licenza | Si applicano i termini del servizio. | Il core utilizza solo AGPL-3.0. |

La documentazione pubblica open source descrive solo i file presenti nel
repository open source. Non descrive i dettagli dell'implementazione aziendale.

Utilizza [Ciele Cloud](/cloud) per informazioni sul piano in hosting. Utilizza
[Open Source](/self-hosting) per le istruzioni di installazione e funzionamento.
