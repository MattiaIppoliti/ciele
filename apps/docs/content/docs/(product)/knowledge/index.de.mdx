Quellen gehören zur Organisation, und eine Wissenssammlung speichert sie
zusammen mit den Konzepten, die während der Erfassung erstellt wurden. Ein
Assistent durchsucht eine Quelle erst, nachdem Sie diese Quelle mit dem
Assistenten verknüpft haben. Verknüpfen Sie eine Quelle aus der Bibliothek oder
fügen Sie sie innerhalb des Assistenten hinzu, der sie dann für Sie verknüpft.

## Verfügbare Quellentypen

- Website-URL
- Hochgeladene Datei
- Eingefügter Text
- Kuratierte FAQ

Ciele extrahiert Inhalte aus Quellen und erstellt durchsuchbare Konzepte. Die
Laufzeit löst Zitate auf benannte Quellen zurück.

## Quellstatus

| Status | Bedeutung |
| --- | --- |
| Wird verarbeitet | Ciele extrahiert und indiziert die Quelle. |
| Bereit | Die Quelle steht für die Wissenssuche zur Verfügung. |
| Fehlgeschlagen | Die Aufnahme wurde nicht abgeschlossen. Überprüfen Sie den Fehler und wiederholen Sie den Vorgang. |

Testen Sie eine neue Quelle erst, wenn ihr Status **Ready** lautet.

## Abruf

Search Knowledge kann Vektorsuche, lexikalisches Fallback und Navigation im
Wissensgraphen nutzen. Die ausgewählte Knowledge-Engine steuert den primären
Pfad.

Deep Search ermöglicht mehr reine Knowledge-Iterationen. Es durchsucht nicht das
offene Web.
