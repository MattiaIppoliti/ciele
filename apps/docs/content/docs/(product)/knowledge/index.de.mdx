title: Wissen

---

Jeder Assistent verfügt über eine Wissenssammlung. In der Sammlung werden
Quellen und die während der Aufnahme erzeugten Konzepte gespeichert.

## Verfügbare Quellentypen

- Website-URL
- Hochgeladene Datei
- Eingefügter Text
- Kuratierte FAQ

Ciele extrahiert Quellinhalte und erstellt durchsuchbare Konzepte. Die Laufzeit
löst Zitate auf benannte Quellen zurück.

## Quellstatus

| Status | Bedeutung |
| --- | --- |
| Wird verarbeitet | Ciele extrahiert die Quelle und indiziert sie. |
| Bereit | Die Quelle steht für die Wissenssuche zur Verfügung. |
| Fehlgeschlagen | Die Aufnahme wurde nicht abgeschlossen. Überprüfen Sie den Fehler und wiederholen Sie den Vorgang. |

Testen Sie eine neue Quelle erst, wenn ihr Status **Ready** lautet.

## Abruf

Search Knowledge kann Vektorsuche, lexikalisches Fallback und
Wissensgraph-Navigation nutzen. Die ausgewählte Knowledge-Engine steuert den
primären Pfad.

Deep Search ermöglicht mehr reine Knowledge-Iterationen. Es durchsucht nicht das
offene Web.
