Sources gehören zur Organization, und eine Knowledge Collection speichert sie
zusammen mit den während der Ingestion erstellten Documents. Ein Assistant
durchsucht eine Source erst, nachdem Sie diese Source mit dem Assistant
verknüpft haben. Verknüpfen Sie eine Quelle aus der
[Library](/knowledge/library) oder fügen Sie sie im Assistant hinzu, wodurch sie
automatisch für Sie verknüpft wird.

Da eine Quelle für mehrere Assistenten Antworten liefern kann, sind das
Entfernen aus einem Assistenten und das Löschen für die gesamte Organisation
unterschiedliche Vorgänge. Wenn Sie einen Assistenten löschen, bleiben die
Quellen der Organisation erhalten. Es werden nur die Verknüpfungen dieses
Assistants entfernt.

## Verfügbare Quelltypen

- Website-URL
- Hochgeladene Datei
- Eingefügter Text
- Verbundene Anwendung
- Kuratierte FAQ

Ciele extrahiert Source-Inhalte und erstellt durchsuchbare Dokumente. Die
Runtime ordnet Zitate wieder benannten Quellen zu.

## Status der Quelle

| Status | Bedeutung |
| --- | --- |
| Processing | Ciele extrahiert und indiziert die Quelle. |
| Ready | Die Quelle steht für die Suche nach Wissen zur Verfügung. |
| Failed | Die Ingestion wurde nicht abgeschlossen. Überprüfen Sie den Fehler und versuchen Sie den Vorgang erneut. |

Testen Sie eine neue Source erst, wenn ihr Status **Ready** lautet.

## Direkter Zugriff

Eine Datei-Quelle kann dem Visitor neben der Quellenangabe auch die
Originaldatei bereitstellen. Dies ist die Einstellung **Direct access** für
einen Assistant-Link, und sie ist standardmäßig deaktiviert. Legen Sie es in der
Library fest.

## Abruf

Search Knowledge verwendet die Vektorsuche und den lexikalischen Fallback, um
potenzielle Passagen zu finden. Anschließend wählt ein Reranking-Schritt die
Passagen aus, die der Assistant liest.

Deep Search ermöglicht mehr Iterationen, die ausschließlich auf Knowledge
beschränkt sind. Es durchsucht nicht das offene Web.
