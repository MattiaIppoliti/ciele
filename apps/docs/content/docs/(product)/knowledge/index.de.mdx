Sources gehören zur Organization, und eine Knowledge Collection speichert sie
zusammen mit den während der Ingestion erstellten Concepts. Ein Assistent
durchsucht eine Quelle erst, nachdem Sie diese Quelle mit dem Assistenten
verknüpft haben. Verknüpfen Sie eine Quelle aus der
[Bibliothek](/knowledge/library) oder fügen Sie sie innerhalb des Assistenten
hinzu, der sie dann für Sie verknüpft.

Da eine Quelle für mehrere Assistenten antworten kann, sind das Entfernen aus
einem Assistenten und das Löschen für die Organisation unterschiedliche
Vorgänge. Wenn Sie einen Assistenten löschen, bleiben die Quellen der
Organisation erhalten. Es werden nur die Verknüpfungen dieses Assistenten
entfernt.

## Verfügbare Quellentypen

- Website-URL
- Hochgeladene Datei
- Eingefügter Text
- Verbundene Anwendung
- Kuratierte FAQ

Ciele extrahiert Source-Inhalte und erstellt durchsuchbare Concepts. Die
Laufzeit löst Zitate auf die benannten Quellen zurück.

## Quellstatus

| Status | Bedeutung |
| --- | --- |
| Processing | Ciele extrahiert und indiziert die Source. |
| Bereit | Die Quelle steht für die Wissenssuche zur Verfügung. |
| Failed | Die Aufnahme wurde nicht abgeschlossen. Überprüfen Sie den Fehler und wiederholen Sie den Vorgang. |

Testen Sie eine neue Quelle erst, wenn ihr Status **Ready** lautet.

## Direkter Zugriff

Eine Datei-Quelle kann dem Besucher neben der Zitation auch die Originaldatei
zur Verfügung stellen. Dies ist die Einstellung **Direct access** für einen
Assistant-Link und sie ist standardmäßig deaktiviert. Legen Sie dies in der
Bibliothek fest.

## Abruf

Die Wissenssuche kann die Vektorsuche, den lexikalischen Fallback und die
Navigation im Wissensgraphen nutzen. Die ausgewählte Knowledge-Engine steuert
den primären Pfad.

Deep Search ermöglicht mehr reine Knowledge-Iterationen. Es durchsucht nicht das
offene Web.
