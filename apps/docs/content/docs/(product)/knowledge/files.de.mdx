title: Dateien und Text
description: Laden Sie eine Datei hoch oder fügen Sie Text zu einer Assistant Knowledge Collection hinzu.
---

## Datei hochladen

1. Öffnen Sie den Assistant.
2. Wählen Sie **Knowledge**.
3. Fügen Sie eine Dateiquelle hinzu.
4. Wählen Sie die Datei aus.
5. Starten Sie die Aufnahme.
6. Warten Sie, bis der Status der Quelle **Ready** lautet.
7. Testen Sie eine Antwort und deren Zitat.

Ciele speichert die Originaldatei und extrahiert unterstützten Text für die
Aufnahme. Der Status „Source“ zeigt an, ob Extraktion und Indizierung
abgeschlossen sind.

## Eingefügten Text hinzufügen

Verwenden Sie eine Textquelle für kurze Inhalte, für die keine separate Datei
erforderlich ist.

1. Fügen Sie eine Textquelle hinzu.
2. Geben Sie optional einen Quellennamen ein.
3. Fügen Sie den Text ein.
4. Starten Sie die Aufnahme.

Verwenden Sie einen stabilen Quellennamen. Der Name kann in Besucher-Zitaten
erscheinen.

## Veraltete Inhalte ersetzen

Löschen Sie die alte Quelle, bevor Sie sich auf einen Ersatz verlassen.
Bestätigen Sie dann, dass die neue Quelle **Ready** ist und korrekte Zitate
erzeugt.

Durch das Löschen einer Quelle werden ihre Konzepte aus dem aktiven
Wissensgraphen und dem Suchindex entfernt.
