## Datei hochladen

1. Öffnen Sie den Assistant.
2. Wählen Sie **Knowledge** aus.
3. Fügen Sie eine Datei-Quelle hinzu.
4. Wählen Sie die Datei aus.
5. Starten Sie die Ingestion.
6. Warten Sie, bis der Status von Source **Ready** lautet.
7. Testen Sie eine Antwort und ihre Citation.

Ciele speichert die Originaldatei und extrahiert unterstützten Text für die
Ingestion. Der Status „Source“ zeigt an, ob die Extraktion und die Indizierung
abgeschlossen sind.

## Dateien, die Ciele ablehnt

Ciele überprüft vor dem Lesen eines Dokuments den Inhalt der Datei, nicht nur
den Dateinamen. Es wird abgelehnt:

- eine Datei, deren Inhalt nicht mit ihrer Dateierweiterung übereinstimmt,
  beispielsweise eine HTML-Seite mit dem Namen `.pdf`
- ein Programm, unabhängig davon, wie die Datei heißt
- eine Office-Datei, die ein Makroprojekt oder ein eingebettetes Objekt enthält
- eine PDF-Datei mit mehr als 2000 Seiten

Speichern Sie das Dokument ohne Makros oder eingebettete Objekte, oder teilen
Sie eine lange PDF-Datei auf und laden Sie sie erneut hoch.

## Eingefügten Text hinzufügen

Verwenden Sie eine Textquelle für kurze Inhalte, die keine separate Datei
erfordern.

1. Fügen Sie eine Textquelle hinzu.
2. Geben Sie einen optionalen Namen für die Quelle ein.
3. Fügen Sie den Text ein.
4. Starten Sie die Ingestion.

Verwenden Sie einen stabilen Source-Namen. Der Name kann in Visitor-Zitaten
erscheinen.

## Veralteten Inhalt ersetzen

Löschen Sie die alte Source, bevor Sie sich auf einen Ersatz verlassen.
Bestätigen Sie anschließend, dass die neue Source **Ready** ist und korrekte
Zitationen liefert.

Durch das Löschen einer Source werden deren Documents aus dem aktiven Suchindex
entfernt.

## Remove im Vergleich zu Delete

Eine Datei-Quelle kann für mehr als einen Assistenten antworten. Der
Assistant-Editor bietet daher zwei Operationen an.

- **Remove from this Assistant** löscht einen Link. Die anderen Assistants
  behalten die Datei.
- **Delete** entfernt die Source für jeden verknüpften Assistant. Die
  Bestätigung nennt jeden einzelnen.

Wenn nur dieser Assistant aus der Datei antwortet, löscht der Editor sie direkt.

## Geben Sie dem Visitor die Originaldatei

Aktivieren Sie **Direct access** in der [Library](/knowledge/library), damit der
Assistent die Originaldatei an seine Quellenangabe anhängen kann. Die
Einstellung gilt für einen einzelnen Assistant-Link und ist standardmäßig
deaktiviert.
