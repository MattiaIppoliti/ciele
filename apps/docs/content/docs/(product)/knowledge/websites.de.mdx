Websites sind oft die reichhaltigste Wissensquelle, die Sie bereits haben. Ciele
kann eine Website, die Ihnen gehört, durchforsten und ihre Seiten in Wissen
verwandeln, aus dem der Assistent antwortet. Öffnen Sie einen Assistenten,
wählen Sie **Knowledge** aus und öffnen Sie dann die Registerkarte **Websites**.

## Fügen Sie eine Website hinzu

1. Wählen Sie „Website hinzufügen“ aus.
2. Geben Sie einen **Namen** ein, damit Sie die Quelle später wiedererkennen
   können.
3. Geben Sie die **Adresse** der zu durchsuchenden Website oder des zu
   durchsuchenden Abschnitts ein.
4. Legen Sie alle Optionen fest, die für Ihre Website gelten, z. B. die
   Kennzeichnung als durch eine Anmeldung geschützt oder die Erlaubnis, auf den
   Seiten gefundene Dateien zu importieren.
5. Bestätigen Sie die Urheberrechtserklärung und wählen Sie dann **Add
   Website**.

Nach dem Hinzufügen wird die Website gecrawlt und ihre Seiten stehen dem
Assistenten zur Verfügung. Websites können regelmäßig erneut gecrawlt werden,
sodass laufende Änderungen berücksichtigt werden.

## Steuern Sie, was gecrawlt wird

Große Websites enthalten oft Seiten, die der Assistent nicht kennen soll. Zwei
Arten von Regeln helfen Ihnen, das Crawlen gezielt einzustellen.

- **Positive rules** beschreiben die Seiten, die Sie einbeziehen möchten.
- **Negative rules** beschreiben die Seiten, die Sie ausschließen möchten.

Verwenden Sie diese, damit sich der Assistent auf die wichtigen Abschnitte
konzentriert, und um Seiten wie Archive oder Hilfsseiten auszuschließen.

## Erweiterte Crawl-Einstellungen

Für Websites, die eine schonendere Behandlung erfordern, können Sie mit
zusätzlichen Einstellungen das Crawlen verlangsamen, die Ladezeit für jede Seite
verlängern und etwas länger warten, bevor eine Seite gelesen wird, damit auch
Inhalte erfasst werden, die später geladen werden. Greifen Sie nur dann darauf
zurück, wenn ein normales Crawlen Inhalte übersieht oder die Zielseite
empfindlich auf Ladezeiten reagiert.

## Fügen Sie eine spezifische Liste von Seiten hinzu

Wenn Sie nur eine Handvoll Seiten statt eines vollständigen Crawls möchten,
können Sie stattdessen eine Liste mit genauen Adressen angeben. Geben Sie der
Liste einen Namen, fügen Sie eine Adresse pro Zeile ein, legen Sie die gleichen
Optionen wie oben fest und fahren Sie fort. Dies ist ideal, wenn sich die
nützlichen Inhalte auf einigen wenigen bekannten Seiten befinden.
