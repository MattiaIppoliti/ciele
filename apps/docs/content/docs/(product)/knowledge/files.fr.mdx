title: Fichiers

---

Lorsque vos connaissances se trouvent dans des documents plutôt que sur le Web,
importez-les directement. Ouvrez un assistant, sélectionnez **Knowledge**, puis
ouvrez l'onglet **Files**.

## Télécharger des fichiers

1. Faites glisser les fichiers dans la zone de téléchargement ou sélectionnez-la
   pour parcourir vos fichiers.
2. Attendez que chaque fichier ait fini d'être traité. Une fois traité, son
   contenu fait partie des connaissances de l'assistant.

Les fichiers importés sont traités de la même manière que toute autre source :
l'assistant les lit pour répondre aux questions et peut les citer dans ses
réponses.

## Ce que vous pouvez importer

Les formats de documents courants fonctionnent bien, notamment les documents
texte, les feuilles de calcul et les diaporamas. Veillez à ce que chaque fichier
respecte la limite de taille indiquée dans la zone de téléchargement. Si un
fichier est très volumineux, le diviser en documents ciblés permet souvent
d'obtenir de meilleures réponses, car chaque document traite d'un sujet précis.

## Maintenir les fichiers à jour

Les fichiers ne se mettent pas à jour automatiquement. Lorsque le contenu d'un
document change, importez la nouvelle version afin que l'assistant réponde en se
basant sur les informations les plus récentes. Si la
[Boîte de réception](/operations/inbox) indique que l'assistant fournit des
réponses obsolètes, vérifiez si le fichier source doit être actualisé.

## Fichiers, sites Web et FAQ

- Utilisez **Files** pour le contenu qui existe déjà sous forme de documents.
- Utilisez [Websites](/knowledge/websites) pour le contenu en ligne qui évolue
  au fil du temps.
- Utilisez les [FAQ](/knowledge/faqs) lorsque vous souhaitez obtenir une réponse
  exacte à une question spécifique.
