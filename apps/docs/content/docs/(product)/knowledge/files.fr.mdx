## Importer un fichier

1. Ouvrez l'Assistant.
2. Sélectionnez **Knowledge**.
3. Ajoutez une source de type fichier.
4. Sélectionnez le fichier.
5. Démarrer l'ingestion.
6. Attendez que le statut de la source soit **Ready**.
7. Testez une réponse et sa citation.

Ciele conserve le fichier original et extrait le texte pris en charge pour
l'ingestion. Le statut Source indique si l'extraction et l'indexation sont
terminées.

## Fichiers pris en charge

Knowledge accepte les types de fichiers suivants, jusqu'à 25 Mo chacun :

- PDF
- Word (.docx)
- PowerPoint (.pptx)
- Excel (.xlsx)
- Markdown, texte et CSV

Ciele lit un fichier PowerPoint diapositive par diapositive et un fichier Excel
feuille par feuille. Il conserve le texte et les valeurs des cellules. Il ne
conserve pas les images, les formules ni la mise en forme.

## Fichiers refusés par Ciele

Ciele vérifie le contenu du fichier, et pas seulement son nom, avant de lire un
document. Il refuse :

- un fichier dont le contenu ne correspond pas à son extension, par exemple une
  page HTML nommée `.pdf`
- un programme, quel que soit le nom du fichier
- un fichier Office qui contient un projet de macro ou un objet incorporé
- un PDF de plus de 2 000 pages

Enregistrez le document sans macros ni objets incorporés, ou fractionnez un long
PDF, puis téléchargez-le à nouveau.

## Ajouter du texte collé

Utilisez une Source de type texte pour les contenus courts qui ne nécessitent
pas de fichier distinct.

1. Ajoutez une Source de type texte.
2. Saisissez un nom de Source facultatif.
3. Collez le texte.
4. Démarrer l'ingestion.

Utilisez un nom de Source stable. Le nom peut apparaître dans les citations des
visiteurs.

## Remplacer le contenu obsolète

Supprimez l'ancienne Source avant de vous fier à une source de remplacement.
Ensuite, confirmez que la nouvelle Source est **Ready** et qu'elle génère des
citations correctes.

La suppression d'une source retire ses Documents de l'index de recherche actif.

## Supprimer par rapport à effacer

Une Source de type fichier peut répondre pour plusieurs Assistants. L'éditeur
d'Assistant propose donc deux opérations.

- **Remove from this Assistant** supprime un lien. Les autres Assistants
  conservent le fichier.
- **Delete** supprime la Source pour chaque Assistant associé. La confirmation
  indique le nom de chacun d'entre eux.

Lorsque seul cet Assistant répond à partir du fichier, l'éditeur le supprime
directement.

Lorsque vous supprimez une Source, Ciele supprime également le fichier original
du stockage. Si cette étape échoue, le nettoyage nocturne de rétention supprime
le fichier ultérieurement.

## Donner au Visiteur le fichier original

Activez **Direct access** dans la [Library](/knowledge/library) pour permettre à
l'Assistant de joindre le fichier original à sa citation. Ce paramètre
s'applique à un seul lien d'Assistant et est désactivé par défaut.
