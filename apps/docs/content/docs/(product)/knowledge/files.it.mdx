## Carica un file

1. Apri l'Assistant.
2. Seleziona **Knowledge**.
3. Aggiungi una Source di tipo file.
4. Seleziona il file.
5. Avvia l'ingestione.
6. Attendi fino a quando lo stato di Source è **Ready**.
7. Verifica una risposta e la sua citazione.

Ciele memorizza il file originale ed estrae il testo supportato per
l'ingestione. Lo stato Source indica se l'estrazione e l'indicizzazione sono
state completate.

## File che Ciele rifiuta

Ciele verifica il contenuto del file, non solo il nome del file, prima di
leggere un documento. Rifiuta:

- un file il cui contenuto non corrisponde alla sua estensione, ad esempio una
  pagina HTML denominata `.pdf`
- un programma, indipendentemente dal nome del file
- un file di Office che contiene un progetto macro o un oggetto incorporato
- un PDF con più di 2000 pagine

Salva il documento senza macro o oggetti incorporati, oppure dividi un PDF lungo
e caricalo di nuovo.

## Aggiungi il testo incollato

Utilizza una Source di tipo testo per contenuti brevi che non richiedono un file
separato.

1. Aggiungi una Source di tipo testo.
2. Inserisci un nome della Source facoltativo.
3. Incolla il testo.
4. Avvia l'ingestione.

Usa un nome Source stabile. Il nome può comparire nelle citazioni dei Visitor.

## Sostituisci i contenuti obsoleti

Elimina la vecchia Source prima di affidarti a una sostituzione. Quindi verifica
che la nuova Source sia **Ready** e produca citazioni corrette.

L'eliminazione di una Source rimuove i relativi Documents dall'indice di ricerca
attivo.

## Rimuovi rispetto a Elimina

Una Source di tipo file può rispondere per più di un Assistant. L'editor
dell'Assistente offre quindi due operazioni.

- **Remove from this Assistant** elimina un link. Gli altri Assistenti
  conservano il file.
- **Delete** rimuove la Source per ogni Assistant collegato. La conferma indica
  il nome di ciascuno.

Quando solo questo Assistente risponde dal file, l'editor lo elimina
direttamente.

## Fornisci al Visitor il file originale

Attiva **Direct access** nella [Library](/knowledge/library) per consentire
all'Assistente di allegare il file originale alla sua citazione. L'impostazione
si applica a un singolo link dell'Assistente ed è disattivata per impostazione
predefinita.
