Quando le tue conoscenze risiedono nei documenti piuttosto che sul web, caricale
direttamente. Apri un assistente, seleziona **Knowledge** e poi apri la scheda
**Files**.

## Carica file

1. Trascina i file nell'area di caricamento oppure selezionala per sfogliare.
2. Attendi che ogni file finisca di essere elaborato. Una volta elaborato, il
   suo contenuto fa parte della conoscenza dell'assistente.

I file caricati vengono trattati come qualsiasi altra fonte: l'assistente li
legge per rispondere alle domande e può citarli nelle sue risposte.

## Cosa caricare

I formati di documento più comuni funzionano bene, inclusi documenti di testo,
fogli di calcolo e presentazioni. Mantieni i singoli file entro il limite di
dimensione indicato nell'area di caricamento. Se un file è molto grande,
suddividerlo in documenti mirati spesso produce risposte migliori, perché ogni
documento tratta un argomento chiaro.

## Mantenere i file aggiornati

I file non si aggiornano da soli. Quando il contenuto di un documento cambia,
carica la nuova versione in modo che l'assistente risponda sulla base delle
informazioni più recenti. Se nella [Posta in arrivo](/operations/inbox)
l'assistente fornisce risposte obsolete, verifica se il file di origine debba
essere aggiornato.

## File, siti web e FAQ a confronto

- Utilizza **Files** per i contenuti che esistono già come documenti.
- Utilizza [Websites](/knowledge/websites) per i contenuti online che cambiano
  nel tempo.
- Usa [FAQ](/knowledge/faqs) quando vuoi una risposta precisa a una domanda
  specifica.
