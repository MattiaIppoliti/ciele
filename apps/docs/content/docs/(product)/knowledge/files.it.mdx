## Carica un file

1. Apri l'Assistente.
2. Seleziona **Knowledge**.
3. Aggiungi una fonte di file.
4. Seleziona il file.
5. Avvia l'acquisizione.
6. Attendi che lo stato della Sorgente sia **Ready**.
7. Prova una risposta e la sua citazione.

Ciele memorizza il file originale ed estrae il testo supportato per
l'ingestione. Lo stato Source mostra se l'estrazione e l'indicizzazione sono
state completate.

## File rifiutati da Ciele

Prima di leggere un documento, Ciele controlla il contenuto del file, non solo
il nome. Rifiuta:

- un file il cui contenuto non corrisponde alla sua estensione, ad esempio una
  pagina HTML denominata `.pdf`
- un programma, qualunque sia il nome del file
- un file Office che contiene un progetto macro o un oggetto incorporato
- un PDF con più di 2000 pagine

Salva il documento senza macro o oggetti incorporati, oppure suddividi un PDF
lungo e caricalo di nuovo.

## Aggiungi testo incollato

Utilizza una Fonte di testo per contenuti brevi che non richiedono un file
separato.

1. Aggiungi una fonte di testo.
2. Inserisci un nome opzionale per la fonte.
3. Incolla il testo.
4. Avvia l'importazione.

Usa un nome di origine stabile. Il nome può apparire nelle citazioni dei
visitatori.

## Sostituisci i contenuti obsoleti

Elimina la vecchia Fonte prima di fare affidamento su una sostituzione. Quindi
conferma che la nuova Fonte sia **Ready** e produca citazioni corrette.

L'eliminazione della fonte rimuove i suoi concetti dal grafo della conoscenza
attivo e dall'indice di ricerca.

## Rimuovere rispetto a eliminare

Una Source di file può rispondere per più di un Assistente. L'editor Assistant
offre quindi due operazioni.

- **Remove from this Assistant** elimina un collegamento. Gli altri Assistenti
  conservano il file.
- **Delete** rimuove la Sorgente per ogni Assistente collegato. La conferma
  indica il nome di ciascuno.

Quando solo questo Assistente risponde dal file, l'editor lo elimina
direttamente.

## Consegna il file originale al Visitatore

Attiva **Direct access** nella [Libreria](/knowledge/library) per consentire
all'Assistente di allegare il file originale alla sua citazione. L'impostazione
si applica a un collegamento all'Assistente ed è disattivata per impostazione
predefinita.
