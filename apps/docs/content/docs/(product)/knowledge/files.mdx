## Upload a file

1. Open the Assistant.
2. Select **Knowledge**.
3. Add a file Source.
4. Select the file.
5. Start ingestion.
6. Wait until the Source status is **Ready**.
7. Test one answer and its citation.

Ciele stores the original file and extracts supported text for ingestion. The Source status shows whether extraction and indexing completed.

## Add pasted text

Use a text Source for short content that does not require a separate file.

1. Add a text Source.
2. Enter an optional Source name.
3. Paste the text.
4. Start ingestion.

Use a stable Source name. The name can appear in Visitor citations.

## Replace obsolete content

Delete the old Source before you rely on a replacement. Then confirm that the new Source is **Ready** and produces correct citations.

Source deletion removes its Concepts from the active Knowledge graph and search index.

## Remove compared to delete

A file Source can answer for more than one Assistant. The Assistant editor therefore offers two operations.

- **Remove from this Assistant** deletes one link. The other Assistants keep the file.
- **Delete** removes the Source for every linked Assistant. The confirmation names each one.

When only this Assistant answers from the file, the editor deletes it directly.

## Give the Visitor the original file

Turn on **Direct access** in the [Library](/knowledge/library) to let the Assistant attach the original file to its citation. The setting applies to one Assistant link, and it is off by default.
