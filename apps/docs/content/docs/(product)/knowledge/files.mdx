---
title: Files
description: Upload documents and other files so the assistant can answer from them.
---

When your knowledge lives in documents rather than on the web, upload them
directly. Open an assistant, select **Knowledge**, then open the **Files** tab.

## Upload files

1. Drag files onto the upload area, or select it to browse.
2. Wait for each file to finish processing. Once processed, its content is part of
   the assistant's knowledge.

Uploaded files are treated the same way as any other source: the assistant reads
them to answer questions and can cite them in its replies.

## What to upload

Common document formats work well, including text documents, spreadsheets, and
slide decks. Keep individual files within the size limit shown in the upload area.
If a file is very large, splitting it into focused documents often produces better
answers, because each document covers a clear topic.

## Keeping files current

Files do not update themselves. When the content in a document changes, upload the
new version so the assistant answers from the latest information. If the
[Inbox](/operations/inbox) shows the assistant giving outdated answers,
check whether the source file needs refreshing.

## Files versus websites versus FAQs

- Use **Files** for content that already exists as documents.
- Use [Websites](/knowledge/websites) for content that lives online and
  changes over time.
- Use [FAQs](/knowledge/faqs) when you want an exact answer to a specific
  question.
