Sources belong to the Organization, and a Knowledge Collection stores them with the Concepts
produced during ingestion. An Assistant searches a Source only after you link that Source to
the Assistant. Link a Source from the Library, or add it inside the Assistant, which links it
for you.

## Available Source types

- Website URL
- Uploaded file
- Pasted text
- Curated FAQ

Ciele extracts Source content and creates searchable Concepts. The runtime resolves citations back to named Sources.

## Source status

| Status | Meaning |
| --- | --- |
| Processing | Ciele is extracting and indexing the Source. |
| Ready | The Source is available to Search knowledge. |
| Failed | Ingestion did not complete. Review the error and retry the operation. |

Do not test a new Source before its status is **Ready**.

## Retrieval

Search knowledge can use vector search, lexical fallback, and Knowledge graph navigation. The selected Knowledge engine controls the primary path.

Deep Search permits more Knowledge-only iterations. It does not search the open web.
