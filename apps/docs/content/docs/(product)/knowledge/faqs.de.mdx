---
title: Häufig gestellte Fragen
description: Schreiben Sie genaue Frage-Antwort-Paare, um den Assistenten bei häufigen Fragen zu unterstützen.
---

Mit FAQs haben Sie die präzise Kontrolle darüber, wie der Assistent bestimmte
Fragen beantwortet. Jede FAQ ist eine Frage, die mit der Antwort gepaart ist,
die der Assistent verwenden soll. Öffnen Sie einen Assistenten, wählen Sie
**Knowledge** aus und öffnen Sie dann die Registerkarte **FAQs**.

## Fügen Sie eine einzelne FAQ hinzu

1. Wählen Sie „FAQ hinzufügen“ und dann die Option „Einzeleintrag“.
2. Formulieren Sie die **Frage** so, wie ein Besucher sie stellen würde.
3. Schreiben Sie die **Antwort** im Rich-Text-Editor. Eine ausführliche Antwort
   gibt dem Assistenten mehr Material, mit dem er arbeiten kann. Streben Sie
   daher eine vollständige Antwort an, statt nur eine einzige Zeile zu
   verfassen.
4. Speichern Sie die FAQ.

Der Assistent nutzt Ihre FAQs zusammen mit seinem sonstigen Wissen. Eine gut
geschriebene FAQ lenkt ihn daher zu der Antwort, die Sie für diese Frage
bevorzugen.

## Importieren Sie viele FAQs auf einmal

Wenn Sie bereits eine Liste mit Fragen und Antworten haben, können Sie diese in
großen Mengen importieren, anstatt jede einzeln einzugeben.

1. Wählen Sie „FAQ hinzufügen“ aus und wählen Sie dann die Importoption.
2. Stellen Sie Ihre Datei mit Fragen und Antworten im erwarteten Format bereit.
3. Bestätigen Sie den Import.

Dies ist der schnellste Weg, um einen großen FAQ-Satz zu erstellen,
beispielsweise wenn Sie vorhandene Hilfeinhalte in Ciele übertragen.

## Wann Sie FAQs verwenden sollten

FAQs sind das richtige Tool, wenn:

- Eine Frage hat eine richtige Antwort, die jedes Mal verwendet werden soll.
- Die Antwort ist nirgendwo in Ihren anderen Wissensdaten klar angegeben.
- Sie den Ton oder die Formulierung für ein sensibles Thema prägen möchten.

Sie können auch sofort eine bestimmte FAQ über eine
[Start-Schaltfläche](/assistants/quick-replies) anzeigen, wodurch Besucher mit
einem einzigen Tippen zu einer gängigen Antwort gelangen.
