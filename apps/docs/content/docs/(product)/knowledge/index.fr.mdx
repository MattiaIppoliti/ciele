title: Connaissances

---

Les sources appartiennent à l'organisation, et une collection de connaissances
les stocke avec les concepts produits lors de l'ingestion. Un Assistant effectue
une recherche dans une Source uniquement après que vous ayez associé cette
Source à l'Assistant. Associez une source depuis la
[Bibliothèque](/knowledge/library), ou ajoutez-la dans l'Assistant, qui
l'associera pour vous.

Étant donné qu'une Source peut répondre pour plusieurs Assistants, la retirer
d'un Assistant et la supprimer pour l'Organisation sont deux opérations
distinctes. La suppression d'un Assistant laisse les Sources de l'Organisation
en place. Seuls les liens de cet Assistant sont supprimés.

## Types de sources disponibles

- URL du site Web
- Fichier importé
- Texte collé
- Application connectée
- FAQ organisée

Ciele extrait le contenu de la Source et crée des Concepts consultables.
L'environnement d'exécution fait remonter les citations vers les Sources
nommées.

## Statut de la source

| Status | Signification |
| --- | --- |
| En cours de traitement | Ciele extrait et indexe la Source. |
| Prêt | La Source est disponible pour la recherche de connaissances. |
| Failed | L'ingestion n'a pas été menée à terme. Vérifiez l'erreur et réessayez l'opération. |

Ne testez pas une nouvelle Source tant que son statut n'est pas **Ready**.

## Accès direct

Une Source de type fichier peut fournir au Visiteur le fichier original en plus
de la citation. Il s'agit du paramètre **Direct access** sur un lien Assistant,
et il est désactivé par défaut. Définissez-le dans la Bibliothèque.

## Récupération

La recherche de connaissances peut utiliser la recherche vectorielle, le repli
lexical et la navigation dans le graphe de connaissances. Le moteur Knowledge
sélectionné contrôle le chemin principal.

La recherche approfondie permet davantage d'itérations basées uniquement sur les
connaissances. Elle n'effectue pas de recherche sur le Web ouvert.
