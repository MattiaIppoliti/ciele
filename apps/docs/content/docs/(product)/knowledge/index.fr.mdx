La connaissance est ce qui rend un assistant utile. Il s'agit de l'ensemble des
sources que l'assistant lit pour répondre aux questions : vos sites Web, vos
fichiers et des paires de questions-réponses sélectionnées. Ouvrez un assistant
et sélectionnez **Knowledge** pour gérer ces sources.

## Comment la connaissance est utilisée

Lorsque l'assistant doit répondre à partir de votre contenu, il effectue une
recherche dans vos connaissances, trouve les passages les plus pertinents pour
la question et rédige une réponse qui s'appuie sur ces passages. Cette approche
permet de garantir que les réponses sont liées à votre contenu plutôt qu'à des
connaissances générales.

## Sources et citations

Chaque réponse élaborée à partir de vos connaissances peut indiquer les sources
qu'elle a utilisées. Une source renvoie à un contenu réel, tel qu'une page ou un
document, afin que le visiteur puisse vérifier la réponse et en savoir plus.
Cette transparence renforce la confiance et permet de repérer facilement
lorsqu'une source doit être mise à jour.

## Maintenir les connaissances à jour

De bonnes réponses dépendent d'un contenu à jour. Les sites Web peuvent être
explorés à nouveau afin que les modifications apportées à votre site soient
répercutées dans l'assistant. Les fichiers peuvent être remplacés lorsqu'ils
sont modifiés. Les FAQ peuvent être modifiées chaque fois qu'une réponse doit
être affinée. Lorsque la [Boîte de réception](/operations/inbox) ou la section
[Améliorations](/operations/improvements) indique une réponse de faible qualité,
la mise à jour de la source sous-jacente constitue généralement la solution.
