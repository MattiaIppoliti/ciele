---
title: Connaissances
description: Ajoutez des sources que l'assistant peut rechercher et citer.
---

Chaque Assistant dispose d'une Collection de connaissances. La Collection stocke
les Sources et les Concepts produits lors de l'ingestion.

## Types de sources disponibles

- URL du site Web
- Fichier importé
- Texte collé
- FAQ organisée

Ciele extrait le contenu de la Source et crée des Concepts consultables. Le
moteur d'exécution résout les citations en les renvoyant à des Sources nommées.

## Statut de la source

| État | Signification |
| --- | --- |
| En cours de traitement | Ciele extrait et indexe la Source. |
| Prêt | La Source est disponible pour la recherche de connaissances. |
| Échec | L'ingestion n'a pas abouti. Vérifiez l'erreur et réessayez l'opération. |

Ne testez pas une nouvelle Source avant que son statut ne soit **Ready**.

## Récupération

La recherche de connaissances peut utiliser la recherche vectorielle, le repli
lexical et la navigation dans le graphe de connaissances. Le moteur Knowledge
sélectionné contrôle le chemin principal.

La recherche approfondie permet davantage d'itérations basées uniquement sur les
connaissances. Elle n'effectue pas de recherche sur le Web ouvert.
