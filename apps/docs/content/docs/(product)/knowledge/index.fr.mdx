Les sources appartiennent à l'organisation, et une collection de connaissances
les stocke avec les concepts produits lors de l'ingestion. Un Assistant effectue
une recherche dans une Source uniquement après que vous ayez associé cette
Source à l'Assistant. Associez une source depuis la bibliothèque ou ajoutez-la
dans l'assistant, qui l'associera pour vous.

## Types de sources disponibles

- URL du site Web
- Fichier importé
- Texte collé
- FAQ organisée

Ciele extrait le contenu de la Source et crée des Concepts consultables. Le
moteur d'exécution résout les citations en les renvoyant à des Sources nommées.

## Statut de la source

| État | Signification |
| --- | --- |
| En cours de traitement | Ciele extrait et indexe la Source. |
| Prêt | La Source est disponible pour la recherche de connaissances. |
| Échec | L'ingestion n'a pas abouti. Examinez l'erreur et réessayez l'opération. |

Ne testez pas une nouvelle Source tant que son statut n'est pas **Ready**.

## Récupération

Search knowledge peut utiliser la recherche vectorielle, le repli lexical et la
navigation dans le graphe de connaissances. Le moteur Knowledge sélectionné
contrôle le chemin principal.

La recherche approfondie permet davantage d'itérations basées uniquement sur la
connaissance. Elle n'effectue pas de recherche sur le Web ouvert.
