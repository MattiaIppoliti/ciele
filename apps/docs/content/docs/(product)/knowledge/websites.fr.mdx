## Ajoutez une source de site Web

1. Ouvrez l'Assistant.
2. Sélectionnez **Knowledge**.
3. Ajoutez une source de site Web.
4. Saisissez l'URL de la page.
5. Lancez l'ingestion.
6. Attendez que le statut de la source soit **Ready**.
7. Posez une question à laquelle la page répond.
8. Confirmez la citation de la Source renvoyée.

Le robot d'indexation récupère le contenu du site Web configuré. Un worker de
rendu JavaScript est requis pour les pages qui nécessitent un rendu par le
navigateur.

## Analyser à nouveau une source

Utilisez **Recrawl** lorsque le contenu du site Web source change. Ciele relance
l'analyse et remplace le contenu indexé après une ingestion réussie.

L'API et la CLI prennent en charge la réanalyse uniquement pour les sources de
type site Web.

## Accès à la source

Le robot d'indexation doit accéder à l'URL depuis le réseau de déploiement. Le
contenu protégé par authentification n'est pas disponible sans un chemin d'accès
pris en charge.
