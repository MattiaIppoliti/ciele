Le fonti appartengono all'Organizzazione e una Raccolta di conoscenze le
memorizza insieme ai Concetti prodotti durante l'importazione. Un Assistente
cerca in una Fonte solo dopo che tu hai collegato quella Fonte all'Assistente.
Collega una Fonte dalla [Libreria](/knowledge/library) oppure aggiungila
all'interno dell'Assistente, che la collegherà per te.

Poiché una Fonte può rispondere per più Assistenti, rimuoverla da un Assistente
ed eliminarla per l'Organizzazione sono operazioni diverse. L'eliminazione di un
Assistente lascia intatte le Fonti dell'Organizzazione. Rimuove solo i
collegamenti di quell'Assistente.

## Tipi di sorgente disponibili

- URL del sito web
- File caricato
- Testo incollato
- FAQ selezionate

Ciele estrae il contenuto della Fonte e crea Concetti ricercabili. Il runtime
risolve le citazioni riportandole alle Fonti nominate.

## Stato della fonte

| Stato | Significato |
| --- | --- |
| In elaborazione | Ciele sta estraendo e indicizzando la Fonte. |
| Pronto | La Fonte è disponibile per la ricerca di conoscenze. |
| Non riuscito | L'acquisizione non è stata completata. Controlla l'errore e riprova l'operazione. |

Non testare una nuova Fonte prima che il suo stato sia **Ready**.

## Accesso diretto

Una Sorgente di file può fornire al Visitatore il file originale accanto alla
citazione. Questa è l'impostazione **Direct access** su un link Assistant ed è
disattivata per impostazione predefinita. Impostala nella Libreria.

## Recupero

Search knowledge può utilizzare la ricerca vettoriale, il fallback lessicale e
la navigazione nel grafo della conoscenza. Il motore Knowledge selezionato
controlla il percorso principale.

Deep Search consente più iterazioni solo Knowledge. Non effettua ricerche sul
Web aperto.
