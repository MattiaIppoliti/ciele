title: Conoscenza
description: Aggiungi le fonti che l'Assistente può cercare e citare.
---

Le fonti appartengono all'Organization e una Knowledge Collection le memorizza
insieme ai Documents prodotti durante l'ingestione. Un Assistente esegue
ricerche in una Source solo dopo che hai collegato quella Source all'Assistente.
Collega una Source dalla [Library](/knowledge/library) oppure aggiungila
all'interno dell'Assistant, che la collegherà per te.

Poiché una Source può rispondere per conto di più Assistenti, rimuoverla da un
Assistente e cancellarla per l'Organization sono due operazioni distinte.
L'eliminazione di un Assistente lascia intatte le Source dell'Organization.
Rimuove solo i collegamenti di quell'Assistente.

## Tipi di Source disponibili

- URL del sito web
- File caricato
- Testo incollato
- Applicazione connessa
- FAQ curate

Ciele estrae il contenuto delle Source e crea Documenti ricercabili. Il runtime
riconduce le citazioni alle Source denominate.

## Stato della fonte

| Status | Significato |
| --- | --- |
| Processing | Ciele sta estraendo e indicizzando la Source. |
| Ready | La Source è disponibile per la ricerca nella knowledge. |
| Failed | L'ingestione non è stata completata. Esamina l'errore e riprova l'operazione. |

Non testare una nuova Source prima che il suo stato sia **Ready**.

## Accesso diretto

Una Source di tipo file può fornire al Visitor il file originale accanto alla
citazione. Questa è l'impostazione **Direct access** su un link dell'Assistente
ed è disattivata per impostazione predefinita. Impostalo nella Library.

## Recupero

La ricerca nella Knowledge utilizza la ricerca vettoriale e il fallback
lessicale per individuare i passaggi candidati. Una fase di reranking seleziona
quindi i passaggi che l'Assistente legge.

Deep Search consente un maggior numero di iterazioni limitate alla Knowledge.
Non effettua ricerche sul web aperto.
