El conocimiento es lo que hace que un asistente sea útil. Es el conjunto de
fuentes que el asistente lee para responder a las preguntas: tus sitios web, tus
archivos y pares de preguntas y respuestas seleccionados. Abre un asistente y
selecciona **Knowledge** para gestionar estas fuentes.

## Cómo se utiliza el conocimiento

Cuando el asistente necesita responder a partir de tu contenido, busca en tu
conocimiento, encuentra los pasajes más relevantes para la pregunta y redacta
una respuesta basada en ellos. Este enfoque mantiene las respuestas vinculadas a
tu material en lugar de al conocimiento general.

## Fuentes y citas

Cada respuesta generada a partir de tu conocimiento puede mostrar las fuentes
que ha utilizado. Una fuente remite a un contenido real, como una página o un
documento, para que el visitante pueda verificar la respuesta y leer más. Esta
transparencia genera confianza y facilita detectar cuándo es necesario
actualizar una fuente.

## Mantener el conocimiento actualizado

Las buenas respuestas dependen del contenido actual. Los sitios web se pueden
volver a rastrear para que los cambios en tu sitio se reflejen en el asistente.
Los archivos se pueden reemplazar cuando cambian. Las preguntas frecuentes se
pueden editar siempre que sea necesario afinar una respuesta. Cuando la
[Bandeja de entrada](/operations/inbox) o [Mejoras](/operations/improvements)
muestran una respuesta deficiente, la solución suele ser actualizar la fuente
subyacente.
