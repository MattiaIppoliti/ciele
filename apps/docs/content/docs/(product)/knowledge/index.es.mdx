---
title: Conocimiento
description: Añade fuentes que el Asistente pueda buscar y citar.
---

Cada Asistente tiene una Colección de conocimiento. La Colección almacena las
Fuentes y los Conceptos generados durante la ingesta.

## Tipos de fuentes disponibles

- URL del sitio web
- Archivo subido
- Texto pegado
- Preguntas frecuentes seleccionadas

Ciele extrae el contenido de la Fuente y crea Conceptos en los que se puede
buscar. El tiempo de ejecución resuelve las citas y las vincula a Fuentes con
nombre.

## Estado de la fuente

| Estado | Significado |
| --- | --- |
| Procesando | Ciele está extrayendo e indexando la Fuente. |
| Listo | La Fuente está disponible para la búsqueda de conocimiento. |
| Error | La ingesta no se completó. Revisa el error y vuelve a intentar la operación. |

No pruebes una nueva Fuente antes de que su estado sea **Ready**.

## Recuperación

Search Knowledge puede usar la búsqueda vectorial, el respaldo léxico y la
navegación por el grafo de conocimiento. El motor de conocimiento seleccionado
controla la ruta principal.

Deep Search permite más iteraciones solo de Knowledge. No busca en la web
abierta.
