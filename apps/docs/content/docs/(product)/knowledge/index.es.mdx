title: Conocimiento
description: Añade fuentes en las que el asistente pueda buscar y que pueda citar.
---

Las fuentes pertenecen a la Organización, y una Knowledge Collection las
almacena junto con los Documentos generados durante la ingesta. Un asistente
solo busca en una fuente después de que vincules esa fuente al asistente.
Vincula una fuente desde la [Library](/knowledge/library) o añádela dentro del
asistente, que la vinculará por ti.

Dado que una fuente puede responder para varios asistentes, eliminarla de un
asistente y eliminarla para la organización son operaciones distintas. Al
eliminar un asistente, las fuentes de la organización se mantienen intactas.
Solo elimina los enlaces de ese asistente.

## Tipos de fuentes disponibles

- URL del sitio web
- Archivo subido
- Texto pegado
- Aplicación conectada
- Preguntas frecuentes seleccionadas

Ciele extrae el contenido de las fuentes y crea documentos en los que se pueden
realizar búsquedas. El entorno de ejecución resuelve las citas relacionándolas
con las Fuentes con nombre.

## Estado de la fuente

| Status | Significado |
| --- | --- |
| Processing | Ciele está extrayendo e indexando el Source. |
| Ready | El origen está disponible para buscar conocimiento. |
| Failed | La ingesta no se completó. Revisa el error y vuelve a intentar la operación. |

No pruebes un nuevo Source antes de que su estado sea **Ready**.

## Acceso directo

Un Source de tipo archivo puede entregar al Visitor el archivo original junto
con la cita. Este es el ajuste **Direct access** de un enlace de Assistant, y
está desactivado de forma predeterminada. Establécelo en la Library.

## Recuperación

La búsqueda en el conocimiento utiliza la búsqueda vectorial y el recurso léxico
como alternativa para encontrar pasajes candidatos. A continuación, un paso de
reordenación selecciona los pasajes que lee el asistente.

Deep Search permite más iteraciones exclusivas de Knowledge. No realiza
búsquedas en la web abierta.
