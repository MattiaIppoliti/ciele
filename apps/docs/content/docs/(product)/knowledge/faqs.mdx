---
title: FAQs
description: Add approved question and answer pairs to a Knowledge Collection.
---

An FAQ stores one question and one curated answer. Use FAQs for content that requires an exact approved response.

## Add one FAQ

1. Open the Assistant.
2. Select **Knowledge**.
3. Add an FAQ.
4. Enter the question.
5. Enter the approved answer.
6. Save the FAQ.

## Import FAQs

Prepare a CSV file with these columns:

```csv
question,answer
When does enrollment close?,Enrollment closes on October 31.
```

Import the file into the required Collection. Correct rows that do not contain both values.

## Use an FAQ quick reply

An FAQ quick reply returns the curated answer verbatim. It makes no chat-model call and includes the FAQ Source citation.

Use a **Send Text** quick reply when the text must enter the normal Flow router instead.
