## Sube un archivo

1. Abre el Assistant.
2. Selecciona **Knowledge**.
3. Añade una fuente de tipo archivo.
4. Selecciona el archivo.
5. Inicia la ingesta.
6. Espera hasta que el estado de la fuente sea **Ready**.
7. Prueba una respuesta y su cita.

Ciele almacena el archivo original y extrae el texto admitido para su ingesta.
El estado Source indica si se han completado la extracción y la indexación.

## Archivos que Ciele rechaza

Ciele comprueba el contenido del archivo, no solo su nombre, antes de leer un
documento. Rechaza:

- un archivo cuyo contenido no coincide con su extensión, por ejemplo, una
  página HTML llamada `.pdf`
- un programa, independientemente del nombre del archivo
- un archivo de Office que contiene un proyecto de macros o un objeto incrustado
- un PDF con más de 2000 páginas

Guarda el documento sin macros ni objetos incrustados, o bien divide un PDF
largo y súbelo de nuevo.

## Añade el texto pegado

Utiliza un Source de texto para contenidos breves que no requieran un archivo
aparte.

1. Añade una fuente de texto.
2. Introduce un nombre de Source opcional.
3. Pega el texto.
4. Inicia la ingesta.

Utiliza un nombre de fuente estable. El nombre puede aparecer en las citas de
Visitor.

## Sustituye el contenido obsoleto

Elimina la Fuente antigua antes de empezar a usar una de reemplazo. A
continuación, confirma que la nueva fuente es **Ready** y que genera citas
correctas.

Al eliminar una fuente, sus documentos se eliminan del índice de búsqueda
activo.

## Eliminar frente a borrar

Una Source de tipo archivo puede responder para más de un Assistant. Por lo
tanto, el editor del asistente ofrece dos operaciones.

- **Remove from this Assistant** elimina un enlace. Los demás asistentes
  conservan el archivo.
- **Delete** elimina la fuente de todos los asistentes vinculados. La
  confirmación indica el nombre de cada uno.

Cuando solo este asistente responde a partir del archivo, el editor lo elimina
directamente.

Cuando eliminas un Source, Ciele también elimina el archivo original del
almacenamiento. Si ese paso falla, la limpieza nocturna de retención eliminará
el archivo más tarde.

## Entrega al Visitor el archivo original

Activa **Direct access** en la [Library](/knowledge/library) para permitir que
el asistente adjunte el archivo original a su cita. El ajuste se aplica a un
único enlace de Assistant y está desactivado de forma predeterminada.
