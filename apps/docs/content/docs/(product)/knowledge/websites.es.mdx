Los sitios web suelen ser la fuente de conocimiento más rica que ya tienes.
Ciele puede rastrear un sitio web de tu propiedad y convertir sus páginas en
conocimiento con el que el asistente responda. Abre un asistente, selecciona
**Knowledge** y luego abre la pestaña **Websites**.

## Añade un sitio web

1. Selecciona «Añadir un sitio web».
2. Introduce un **nombre** para que puedas reconocer la fuente más adelante.
3. Introduce la **dirección** del sitio o de la sección que quieres rastrear.
4. Establece las opciones que correspondan a tu sitio, como marcarlo como
   protegido por inicio de sesión o permitir la importación de los archivos que
   se encuentren en las páginas.
5. Confirma la declaración de derechos de autor y, a continuación, selecciona
   **Add Website**.

Una vez añadido, el sitio se rastrea y sus páginas quedan disponibles para el
asistente. Los sitios se pueden rastrear de nuevo periódicamente para que los
cambios en curso se reflejen.

## Controla lo que se rastrea

Los sitios grandes suelen contener páginas que no quieres que el asistente
conozca. Dos tipos de reglas te ayudan a orientar el rastreo.

- **Positive rules** describe las páginas que quieres incluir.
- **Negative rules** describe las páginas que quieres excluir.

Úsalas para que el asistente se centre en las secciones importantes y para
excluir páginas como los archivos o las páginas de utilidades.

## Configuración avanzada de rastreo

Para los sitios que necesitan un tratamiento más cuidadoso, hay ajustes
adicionales que te permiten ralentizar el rastreo, ampliar el tiempo de carga de
cada página y esperar un poco más antes de leer una página para que se capture
el contenido que se carga con retraso. Utiliza estas opciones solo si un rastreo
normal omite contenido o si el sitio de destino es sensible a la carga.

## Añade una lista específica de páginas

Si solo quieres unas pocas páginas en lugar de un rastreo completo, puedes
proporcionar en su lugar una lista de direcciones exactas. Ponle un nombre a la
lista, pega una dirección por línea, configura las mismas opciones que antes y
continúa. Esto es ideal cuando el contenido útil se encuentra en unas pocas
páginas conocidas.
