Ciele unterstützt eine Organisation beim Erstellen von KI-Assistenten für
Websites und Anwendungen. Jeder Assistent nutzt konfiguriertes Wissen, Flows,
Tools und Helpdesks.

Die Administratorkonsole enthält eine Vorschau. Verwenden Sie die Vorschau, um
Änderungen zu testen, bevor Sie eine Veröffentlichung erstellen.

## Sounds der Benutzeroberfläche

Die Konsole, die öffentliche Website und Ciele Desktop geben kurze Sounds für
Schaltflächen, Schalter, Menüs und Ergebnisse aus. Chat-Oberflächen in der
Konsole erzeugen ebenfalls Töne, wenn Sie eine Nachricht senden und wenn eine
Antwort eintrifft. Auf einem Smartphone erfolgt in denselben Momenten eine kurze
haptische Rückmeldung.

Um die Töne auszuschalten, öffnen Sie das Konto-Menü und deaktivieren Sie
**Sounds**. Die Auswahl wird auf diesem Gerät gespeichert. Verwenden Sie in
Ciele Desktop **Interface sounds** in **Settings**. Die Haptik folgt der
Einstellung für reduzierte Bewegung des Betriebssystems.

Das veröffentlichte Widget gibt nur zwei Töne wieder. Ein Besucher hört einen
Ton, wenn die Nachricht gesendet wird, und einen weiteren Ton, wenn die Antwort
eintrifft. Nichts in einem Assistenten oder einer Organisation konfiguriert sie.

## Hauptaufgaben

- Erstellen Sie einen Assistenten und wählen Sie sein Modell aus.
- Fügen Sie Websites, Dateien, Text und FAQs zu Knowledge hinzu.
- Importieren Sie strukturierte Datensätze und verknüpfen Sie diese mit einem
  Assistenten.
- Speichern Sie bei Bedarf dauerhafte Fakten für angemeldete Besucher.
- Leiten Sie Nachrichten durch geordnete Flows weiter.
- Senden Sie proaktive Benachrichtigungen aus Seiten- und Chat-Ereignissen.
- Verbinden Sie Besucher mit einem Helpdesk.
- Veröffentlichen Sie einen unveränderlichen Konfigurations-Snapshot.
- Überprüfen Sie Konversationen, Verbesserungen, Erkenntnisse, Exporte, Ziele
  und Warnungen.

Beginnen Sie mit [Erste Schritte](/getting-started). Lesen Sie
[Editions](/editions), bevor Sie sich für eine gehostete oder selbst gehostete
Installation entscheiden.
