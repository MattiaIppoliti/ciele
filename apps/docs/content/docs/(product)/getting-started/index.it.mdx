---
title: Per iniziare
description: Crea, testa e pubblica il tuo primo Assistente.
---

Completa queste attività in ordine:

1. Crea un Assistente.
2. Configura la sua identità e il suo modello.
3. Aggiungi una fonte di conoscenza.
4. Prova le domande in Anteprima.
5. Esamina i flussi integrati.
6. Pubblica l'Assistente.
7. Aggiungi il codice di incorporamento a un sito web consentito.

Utilizza [Core concepts](/getting-started/core-concepts) quando un termine del
prodotto non è chiaro.

<Callout title="Publication boundary">
Preview uses the current draft. A live widget uses the latest publication snapshot.
</Callout>
