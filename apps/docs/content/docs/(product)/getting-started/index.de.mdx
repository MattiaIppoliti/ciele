---
title: Erste Schritte
description: Erstellen, testen und veröffentlichen Sie Ihren ersten Assistenten.
---

Führen Sie diese Aufgaben der Reihe nach aus:

1. Erstellen Sie einen Assistenten.
2. Konfigurieren Sie dessen Identität und Modell.
3. Fügen Sie eine Wissensquelle hinzu.
4. Testen Sie Fragen in der Vorschau.
5. Sehen Sie sich die integrierten Flows an.
6. Veröffentlichen Sie den Assistenten.
7. Fügen Sie den Einbettungscode einer zulässigen Website hinzu.

Verwenden Sie [Core concepts](/getting-started/core-concepts), wenn ein
Produktbegriff nicht klar ist.

<Callout title="Publication boundary">
Preview uses the current draft. A live widget uses the latest publication snapshot.
</Callout>
