In diesem Abschnitt lernen Sie, wie Sie von einem neuen Konto zu einem
funktionierenden Assistenten auf Ihrer Website gelangen. Wenn Sie zuerst die
Fachbegriffe verstehen möchten, lesen Sie
[Kernkonzepte](/getting-started/core-concepts). Wenn Sie schnell vorankommen
möchten, folgen Sie dem unten stehenden Pfad.

## Der schnelle Weg

1. **Create an assistant.** Geben Sie ihm einen Namen und eine kurze
   Beschreibung. Siehe
   [Einen Assistenten erstellen](/getting-started/create-an-assistant).
2. **Add knowledge.** Verweisen Sie den Assistenten auf eine Website, laden Sie
   einige Dateien hoch oder schreiben Sie eine Handvoll FAQs. Siehe
   [Wissen](/knowledge).
3. **Set how it replies.** Schreiben Sie eine Begrüßungsnachricht, fügen Sie
   Startschaltflächen hinzu und legen Sie den Antwortstil fest. Siehe
   [Allgemeine Einstellungen](/assistants/general-settings).
4. **Add rules if you need them.** Verwenden Sie [Flows](/flows), um zu steuern,
   wie der Assistent bestimmte Arten von Nachrichten behandelt.
5. **Set up escalation.** Erstellen Sie einen [Help Desk](/help-desks), damit
   Besucher Ihr Team erreichen können, wenn der Assistent nicht weiterhelfen
   kann.
6. **Publish.** Kopieren Sie den Einbettungscode auf Ihre Website. Siehe
   [Veröffentlichung](/publishing).
7. **Operate.** Lesen Sie Gespräche im [Posteingang](/operations/inbox),
   verfolgen Sie die Antwortqualität mit
   [Verbesserungen](/operations/improvements) und beobachten Sie die Zahlen in
   [Einblicken](/operations/insights).

## Wie Antworten erstellt werden

Wenn ein Besucher eine Nachricht sendet, führt der Assistent zwei Aktionen aus.
Zunächst entscheidet er anhand Ihrer Flows, welche Regel gilt. Anschließend
führt er die Aktionen für diese Regel aus. Eine dieser Aktionen durchsucht Ihre
Wissensdatenbank, findet die relevantesten Passagen und verfasst darauf
basierend eine Antwort. Jede Antwort, die auf Ihrem Wissen basiert, kann ihre
Quellen anzeigen, sodass ein Besucher sehen kann, woher die Informationen
stammen.

Wenn keine Regel zutrifft, greift ein integriertes Fallback namens
Default-Verhalten ein und antwortet aus Ihrem Wissen. Das bedeutet, dass ein
Assistent funktioniert, sobald er über Wissen verfügt, noch bevor Sie auch nur
eine einzige Regel geschrieben haben.

## Was Sie benötigen, bevor Sie beginnen

- Eine Organisation in Ciele und ein dazugehöriges Konto.
- Inhalte, aus denen der Assistent lernen kann: eine Website-Adresse, einige
  Dokumente oder schriftliche Antworten auf häufige Fragen.
- Zugriff auf Ihre Website, damit Sie den Einbettungscode einfügen können, wenn
  Sie veröffentlichen.
