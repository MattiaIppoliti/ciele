---
title: Getting started
description: Create, test, and publish your first Assistant.
---

Complete these tasks in order:

1. Create an Assistant.
2. Configure its identity and model.
3. Add one Knowledge Source.
4. Test questions in Preview.
5. Review the built-in Flows.
6. Publish the Assistant.
7. Add the embed code to an allowed website.

Use [Core concepts](/getting-started/core-concepts) when a product term is not clear.

<Callout title="Publication boundary">
Preview uses the current draft. A live widget uses the latest publication snapshot.
</Callout>
