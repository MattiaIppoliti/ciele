Esta sección te lleva desde una cuenta nueva hasta un asistente que funciona en
tu sitio web. Si prefieres entender primero el vocabulario, lee
[Conceptos básicos](/getting-started/core-concepts). Si quieres avanzar rápido,
sigue el camino que se indica a continuación.

## La ruta rápida

1. **Create an assistant.** Ponle un nombre y una breve descripción. Consulta
   [Crear un asistente](/getting-started/create-an-assistant).
2. **Add knowledge.** Dirige al asistente a un sitio web, sube algunos archivos
   o escribe unas cuantas preguntas frecuentes. Consulta
   [Conocimiento](/knowledge).
3. **Set how it replies.** Escribe un mensaje de bienvenida, añade botones de
   inicio y configura el estilo de respuesta. Consulta
   [Configuración general](/assistants/general-settings).
4. **Add rules if you need them.** Utiliza [Flows](/flows) para controlar cómo
   el asistente gestiona tipos específicos de mensajes.
5. **Set up escalation.** Crea un [Help Desk](/help-desks) para que los
   visitantes puedan contactar con tu equipo cuando el asistente no pueda
   ayudar.
6. **Publish.** Copia el fragmento de incrustación en tu sitio web. Consulta
   [Publicación](/publishing).
7. **Operate.** Lee las conversaciones en la
   [Bandeja de entrada](/operations/inbox), supervisa la calidad de las
   respuestas con [Mejoras](/operations/improvements) y consulta las cifras en
   [Información](/operations/insights).

## Cómo se generan las respuestas

Cuando un visitante envía un mensaje, el asistente hace dos cosas. Primero
decide qué regla se aplica, utilizando tus Flujos. Luego ejecuta las acciones de
esa regla. Una de esas acciones busca en tu conocimiento, encuentra los pasajes
más relevantes y escribe una respuesta basada en ellos. Cada respuesta que se
base en tu conocimiento puede mostrar sus fuentes, para que un visitante pueda
ver de dónde procede la información.

Si no coincide ninguna regla, una solución alternativa integrada llamada
Comportamiento predeterminado toma el relevo y responde a partir de tu
conocimiento. Esto significa que un asistente funciona tan pronto como tiene
conocimiento, incluso antes de que escribas una sola regla.

## Lo que necesitas antes de empezar

- Una organización en Ciele y una cuenta que le pertenezca.
- Contenido del que el asistente pueda aprender: la dirección de un sitio web,
  algunos documentos o respuestas escritas a preguntas habituales.
- Acceso a tu sitio web para que puedas pegar el fragmento de incrustación
  cuando publiques.
