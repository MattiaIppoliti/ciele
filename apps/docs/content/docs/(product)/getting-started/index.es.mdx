---
title: Primeros pasos
description: Crea, prueba y publica tu primer Asistente.
---

Completa estas tareas en orden:

1. Crea un Asistente.
2. Configura su identidad y su modelo.
3. Añade una fuente de conocimiento.
4. Prueba las preguntas en Vista previa.
5. Revisa los flujos integrados.
6. Publica el Asistente.
7. Añade el código de incrustación a un sitio web permitido.

Utiliza [Conceptos básicos](/getting-started/core-concepts) cuando un término
del producto no esté claro.

<Callout title="Publication boundary">
Preview uses the current draft. A live widget uses the latest publication snapshot.
</Callout>
