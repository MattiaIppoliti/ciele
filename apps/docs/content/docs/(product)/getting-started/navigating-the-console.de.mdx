## Einrichtung des Assistenten

Öffnen Sie einen Assistant, um diese Bereiche zu verwenden:

- **Preview** öffnet den Live-Entwurf in einer Vollansicht – die einzige
  Vorschau, die auf einem kleinen Bildschirm verfügbar ist.
- **General** konfiguriert Identity, Model, Answer Style und Chat Defaults.
- **Knowledge** verwaltet die Quellen, aus denen dieser Assistent seine
  Antworten bezieht.
- **Flows** steuert Routing, Trigger, Bedingungen und Aktionen.
- **Tools & Skills** steuert Runtime-Tools und wiederverwendbare Anweisungen.
- **Goals** verwaltet geplante Antwortprüfungen.
- **Guardrails** überprüft Visitor-Nachrichten und blendet markierten
  Antworttext aus.
- **Assistant Help Desks** verbindet verfügbare Help Desks.
- **Style** steuert die Markenfarbe und die Position des Launchers.
- **Authentication** steuert die Anmelde-Anforderung für Besucher.
- **Publish** verwaltet den Widget-Snapshot und die Einbettungskonfiguration.

## Vorgänge der Organisation

Verwenden Sie die Hauptnavigation, um **Inbox**, **Improvements**, **Insights**,
**Library** und **Alerts** zu öffnen.

**Library** ist die Organization-Ansicht von Knowledge. Es listet alle Sources
auf und steuert, welche Assistants aus jeder einzelnen Source antworten. Siehe
[Library](/knowledge/library).

## Suchen

Wählen Sie das Suchsymbol aus oder drücken Sie **F**, um **Find** zu öffnen. Sie
können auch **/** drücken oder **Cmd+K** auf einem Mac und **Ctrl+K** auf
anderen Computern. Bevor Sie etwas eingeben, listet **Find** Ihre 12 zuletzt
verwendeten Elemente auf, gefolgt von den Seiten der Konsole und den Abschnitten
zur Einrichtung des Assistenten. Geben Sie einen Suchbegriff ein, um Tasks,
Projects, Assistants, Conversations, Improvements, Help Desks und Teammates zu
durchsuchen. **Find** listet außerdem die Seiten der Konsole, die Bereiche zur
Einrichtung von Assistants sowie Aktionen wie **New task** und **Keyboard
shortcuts** auf.

**Find** hebt in jedem Ergebnis den Text hervor, der Ihrer Suche entspricht. Ein
Titel kann mit ein oder zwei Tippfehlern übereinstimmen, und die Hervorhebung
zeigt die korrekten Buchstaben an. Wenn ein Ergebnis nur im Text übereinstimmt,
zeigt die Zeile den übereinstimmenden Textabschnitt an.

Verwenden Sie die Filter unter dem Suchfeld, um die Ergebnisse einzugrenzen:

- **Title only** durchsucht Titel und ignoriert den Text der einzelnen
  Ergebnisse.
- **Type** zeigt eine Art von Ergebnis an.
- **Updated** zeigt Ergebnisse an, die sich heute, in den letzten 7 Tagen oder
  in den letzten 30 Tagen geändert haben.

Der Bereich auf der rechten Seite zeigt das ausgewählte Ergebnis als kleine
Seite an. Wichtige Details werden darin angezeigt. Beispielsweise werden der
Status einer Improvement, die Channels eines Help Desks oder die erste Frage
einer Conversation angezeigt. Ciele lädt nicht die vollständige Seite. Wählen
Sie eine Karte oder eine Zeile innerhalb der Vorschau aus, um dieses Element zu
öffnen. Drücken Sie **Enter**, um es zu öffnen. Drücken Sie **Cmd+Enter** oder
**Ctrl+Enter**, um es in einer neuen Registerkarte zu öffnen.

## Tastenkombinationen

Drücken Sie **?**, um alle Tastaturkürzel anzuzeigen. Buchstabenkürzel
funktionieren nicht, während Sie in ein Feld eingeben.

Drücken Sie **G** und anschließend innerhalb von etwa einer Sekunde einen
Buchstaben, um eine Seite zu öffnen:

| Keys | Page |
| --- | --- |
| **G** dann **H** | Home, die Liste der Assistants |
| **G** dann **T** | My Tasks |
| **G** dann **P** | Projects |
| **G** dann **A** | All tasks |
| **G** dann **I** | Inbox |
| **G** dann **S** | Settings. Eigentümer und Administratoren öffnen die Organization settings. Andere Mitglieder öffnen ihre eigenen Einstellungen. |
| **G** dann **N** | Notifications |

Weitere Tastenkombinationen:

- **N** erstellt eine Aufgabe und **P** erstellt ein Projekt.
- **[** blendet die Seitenleiste ein oder aus.
- **D** öffnet das Developer Panel auf Seiten, die eines haben.
- **Cmd+Enter** auf einem Mac oder **Ctrl+Enter** auf anderen Computern sendet
  das Formular oder den von Ihnen eingegebenen Text ab.

## Einstellungen

Verwenden Sie **Settings**, um General Organization-Daten, Members, AI
Provider-Verbindungen, Crawling, API Keys, Usage und Billing zu verwalten.

Wählen Sie **Personal settings** am Ende der Gruppe **Settings**, um Ihr
Profile, Theme und Memory zu öffnen. Das Account-Menü öffnet ebenfalls Ihr
Profile.

Die verfügbaren Aktionen hängen von Ihrer Member-Rolle ab.
