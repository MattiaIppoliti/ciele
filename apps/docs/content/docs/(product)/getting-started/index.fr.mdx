---
title: Premiers pas
description: Créez, testez et publiez votre premier Assistant.
---

Effectuez ces tâches dans l'ordre :

1. Créez un Assistant.
2. Configurez son identité et son modèle.
3. Ajoutez une source de connaissances.
4. Testez les questions en mode Aperçu.
5. Passez en revue les flux intégrés.
6. Publiez l'Assistant.
7. Ajoutez le code d'intégration à un site Web autorisé.

Utilisez [Core concepts](/getting-started/core-concepts) lorsqu'un terme relatif
au produit n'est pas clair.

<Callout title="Publication boundary">
Preview uses the current draft. A live widget uses the latest publication snapshot.
</Callout>
