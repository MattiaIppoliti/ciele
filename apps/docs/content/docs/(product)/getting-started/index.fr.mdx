Cette section vous guide, d'un compte tout juste créé à un assistant
opérationnel sur votre site Web. Si vous préférez d'abord vous familiariser avec
le vocabulaire, lisez [Concepts de base](/getting-started/core-concepts). Si
vous souhaitez avancer rapidement, suivez le chemin ci-dessous.

## Le chemin rapide

1. **Create an assistant.** Donnez-lui un nom et une brève description.
   Consultez [Créer un assistant](/getting-started/create-an-assistant).
2. **Add knowledge.** Orientez l'assistant vers un site Web, importez quelques
   fichiers ou rédigez quelques questions fréquentes. Consultez
   [Knowledge](/knowledge).
3. **Set how it replies.** Rédigez un message de bienvenue, ajoutez des boutons
   de démarrage et définissez le style de réponse. Consultez
   [Paramètres généraux](/assistants/general-settings).
4. **Add rules if you need them.** Utilisez [Flows](/flows) pour contrôler la
   manière dont l'assistant gère certains types de messages.
5. **Set up escalation.** Créez un [Help Desk](/help-desks) afin que les
   visiteurs puissent contacter votre équipe lorsque l'assistant ne peut pas les
   aider.
6. **Publish.** Copiez l'extrait de code d'intégration sur votre site Web. Voir
   [Publication](/publishing).
7. **Operate.** Lisez les conversations dans la
   [Boîte de réception](/operations/inbox), suivez la qualité des réponses avec
   [Améliorations](/operations/improvements) et consultez les chiffres dans
   [Insights](/operations/insights).

## Comment les réponses sont produites

Lorsqu'un visiteur envoie un message, l'assistant effectue deux actions. Tout
d'abord, il décide quelle règle s'applique, en utilisant vos Flux. Ensuite, il
exécute les actions de cette règle. L'une de ces actions effectue une recherche
dans votre base de connaissances, trouve les passages les plus pertinents et
rédige une réponse qui s'appuie sur ceux-ci. Chaque réponse qui s'appuie sur vos
connaissances peut afficher ses sources, afin que le visiteur puisse voir d'où
provient l'information.

Si aucune règle ne correspond, un mécanisme de secours intégré appelé
comportement par défaut prend le relais et répond à partir de vos connaissances.
Cela signifie qu'un assistant fonctionne dès qu'il dispose de connaissances,
avant même que vous n'ayez rédigé la moindre règle.

## Ce dont vous avez besoin avant de commencer

- Une organisation dans Ciele et un compte qui lui est associé.
- Du contenu à partir duquel l'assistant peut apprendre : l'adresse d'un site
  Web, des documents ou des réponses écrites à des questions courantes.
- L'accès à votre site Web pour que vous puissiez coller l'extrait d'intégration
  lors de la publication.
