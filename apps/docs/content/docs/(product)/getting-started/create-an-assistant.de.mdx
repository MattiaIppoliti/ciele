---
title: Erstellen Sie einen Assistenten
description: Erstellen Sie einen Assistenten-Entwurf und überprüfen Sie dessen erste Antwort.
---

## Entwurf erstellen

1. Öffnen Sie **Assistants**.
2. Wählen Sie **Create Assistant**.
3. Geben Sie einen Titel ein.
4. Geben Sie optional einen Spitznamen und eine Beschreibung ein.
5. Bestätigen Sie die Erstellung.

Ciele erstellt den Assistenten mit integrierten Flows und einer Wissenssammlung.

## Konfigurieren Sie die erste Antwort

1. Öffnen Sie **General**.
2. Wählen Sie die Provider-Verbindung und das Modell aus.
3. Geben Sie die Begrüßungsnachricht und den Antwortstil ein.
4. Öffnen Sie **Knowledge**.
5. Fügen Sie eine Quelle oder FAQ hinzu.
6. Warten Sie, bis der Status der Quelle „Bereit“ lautet.

## Testen Sie den Entwurf

1. Öffnen Sie die Vorschau.
2. Stellen Sie eine Frage, die die Quelle beantwortet.
3. Öffnen Sie **Sources** unter der Antwort.
4. Vergewissern Sie sich, dass die Zitierung die erwartete Quelle benennt.
5. Testen Sie eine Frage, die die Quelle nicht beantwortet.

Korrigieren Sie die Knowledge- oder Flow-Konfiguration, wenn das Ergebnis nicht
akzeptabel ist. Veröffentlichen Sie erst, nachdem die Prüfungen erfolgreich
abgeschlossen wurden.
