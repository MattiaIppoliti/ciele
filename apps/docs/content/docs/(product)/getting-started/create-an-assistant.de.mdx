---
title: Erstellen Sie einen Assistenten
description: Erstellen Sie Ihren ersten Assistenten und suchen, duplizieren oder entfernen Sie anschließend Assistenten über das Dashboard.
---

Die Verwaltung der Assistenten erfolgt über das Dashboard, das Sie als Erstes
sehen, wenn Sie die Konsole öffnen.

## Einen neuen Assistenten erstellen

1. Öffnen Sie das Dashboard. Dort werden alle Assistenten in Ihrer Organisation
   als Karten aufgelistet.
2. Wählen Sie **Create New Assistant**.
3. Geben Sie einen **Title** ein. Dies ist der interne Name, den Sie in der
   Liste wiedererkennen werden.
4. Geben Sie einen **Description** ein, der erklärt, wofür der Assistent gedacht
   ist.
5. Bestätigen Sie, um ihn zu erstellen. Der Assistent öffnet sich in seinem
   Editor und kann konfiguriert werden.

Ein neuer Assistent startet leer. Er wird nützlich, sobald Sie
[Wissen](/knowledge) hinzufügen und festlegen, wie er
[antwortet](/assistants/general-settings).

## Einen Assistenten finden

Verwenden Sie das Feld **Search assistants** oben im Dashboard, um die Liste
nach Namen zu filtern. Jede Karte zeigt das Assistenten-Symbol, seinen Namen,
eine kopierbare Kennung und seine Beschreibung.

## Einen Assistenten duplizieren

Das Duplizieren ist der schnellste Weg, um eine Einrichtung, die Ihnen gefällt,
wiederzuverwenden.

1. Öffnen Sie auf einer Assistentenkarte das Aktionsmenü.
2. Wählen Sie **Duplicate assistant**.

Die Kopie enthält die Konfiguration und die Flows des Originals. Das Wissen wird
nicht kopiert, sodass der neue Assistent mit seinem eigenen leeren Wissen
beginnt.

## Einen Assistenten löschen

1. Öffnen Sie auf einer Assistentenkarte das Aktionsmenü.
2. Wählen Sie **Delete assistant** aus und bestätigen Sie.

Wenn Sie einen Assistenten löschen, wird seine Konfiguration entfernt. Tun Sie
dies nur, wenn Sie sicher sind, dass der Assistent nicht mehr benötigt wird.

## Die Assistenten-Kennung

Jeder Assistent hat eine Kennung, die auf seiner Karte und im Editor angezeigt
wird. Sie verwenden diese Kennung, wenn Sie den Assistenten auf Ihrer Website
einbetten. Halten Sie sie daher griffbereit, wenn Sie zum Schritt
[Veröffentlichen](/publishing) gelangen. Sie können sie mit einem Klick
kopieren, wo immer sie angezeigt wird.
