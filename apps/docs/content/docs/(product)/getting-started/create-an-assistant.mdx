---
title: Create an Assistant
description: Create a draft Assistant and verify its first answer.
---

## Create the draft

1. Open **Assistants**.
2. Select **Create Assistant**.
3. Enter a title.
4. Enter an optional nickname and description.
5. Confirm the creation.

Ciele creates the Assistant with built-in Flows and a Knowledge Collection.

## Configure the first answer

1. Open **General**.
2. Select the provider connection and model.
3. Enter the welcome message and answering style.
4. Open **Knowledge**.
5. Add one Source or FAQ.
6. Wait until the Source status is ready.

## Test the draft

1. Open Preview.
2. Ask one question that the Source answers.
3. Open **Sources** below the answer.
4. Confirm that the citation names the expected Source.
5. Test one question that the Source does not answer.

Correct the Knowledge or Flow configuration when the result is not acceptable. Publish only after the checks succeed.
