---
title: Ajustes de la organización
description: Gestiona los miembros, las conexiones con proveedores, las claves de API, el uso y la facturación.
---

Una organización es el límite del inquilino para los datos y permisos de Ciele.

Utiliza **Settings** para estas áreas actuales:

- **General** para la información de la organización.
- **Members** para la suscripción, las invitaciones y los roles.
- **AI Providers** para las conexiones con proveedores.
- **Data** para esquemas de Entidad y Registros importados.
- **API Keys** para las credenciales programáticas.
- **Usage** para el uso reciente de recursos y los límites.
- **Billing** para el plan gestionado y la cuenta de facturación.

La edición autohospedada no muestra un catálogo de suscripciones administradas.

Los roles de miembro y los roles de clave API utilizan la misma escala de
permisos. Una clave API no puede recibir un rol superior al de su creador.

El área **AI Providers** también controla la
[memoria a largo plazo](/data/long-term-memory). Incluye herramientas para
borrar los recuerdos almacenados de un Visitante.
