Una organización es el límite de inquilino para los datos y los permisos de
Ciele.

Usa **Settings** para estas áreas actuales:

- **General** para la información de la organización.
- **Members** para las membresías, las invitaciones y los Roles.
- **AI Providers** para las conexiones con proveedores.
- **Data** para los esquemas de entidades y los registros importados.
- **API Keys** para las credenciales programáticas.
- **Usage** para consultar el uso reciente de los recursos y sus límites.
- **Billing** para el plan gestionado y la cuenta de facturación.

La edición autoalojada no muestra un catálogo de suscripciones gestionadas.

Los Member Roles y los API-key Roles utilizan la misma escala de permisos. Una
clave API no puede recibir un Role superior al de su creador.

El área **AI Providers** también controla la
[memoria a largo plazo](/data/long-term-memory). Incluye herramientas para
borrar los recuerdos almacenados de un Visitor.

La pestaña **General** tiene dos ajustes de retención: uno para los registros de
razonamiento y otro para las conversaciones completas. Consulta
[Data retention](/organization/data-retention).

## Apariencia personal

Abre el menú de la cuenta, selecciona **Personal settings** y, a continuación,
**Theme**. Elige **Light**, **Dark** o **System** y selecciona la paleta
**Midnight** o **Mist Blue**. Estas preferencias afectan a tu consola y se
guardan en este navegador. El widget publicado conserva su estilo de asistente.
