## Rollen

| Role | Aktuelle Berechtigungsstufe |
| --- | --- |
| Viewer | Liest Daten der Organisation und der Produkte. |
| Editor | Ändert den Inhalt und die Konfiguration des Assistants. |
| Admin | Veröffentlicht Assistants und verwaltet Mitglieder sowie API-Schlüssel. |
| Owner | Ändert Roles und verwaltet Owner. |

Die Anwendung führt bei einzelnen Operationen spezifischere
Berechtigungsprüfungen durch.

## Ein Mitglied einladen

1. Öffnen Sie **Settings > Members**.
2. Wählen Sie **Invite member** aus.
3. Geben Sie die E-Mail-Adresse ein.
4. Wählen Sie die minimal erforderliche Role aus.
5. Senden Sie die Einladung.

## Ein Mitglied ändern

Ein Admin kann Mitglieder unterhalb der Stufe Owner verwalten. Ein Owner kann
alle Tiers verwalten.

Ein Mitglied kann seine eigene Zeile in der Mitgliederliste weder bearbeiten
noch entfernen. Verwenden Sie für diesen Vorgang ein anderes autorisiertes
Mitglied.

## API-Schlüssel-Rollen

Ein Admin oder ein Owner kann einen Organization API key erstellen. Die
ausgewählte Role darf nicht höher sein als die Role des Erstellers.

Widerrufen Sie einen Schlüssel, wenn der zugehörige Client keinen Zugriff mehr
benötigt. Ciele bewahrt den Datensatz eines widerrufenen Schlüssels zu
Prüfzwecken auf. Ein Admin oder Owner kann einen widerrufenen Schlüssel löschen,
um dessen Datensatz zu entfernen.
