## Roles

| Role | Nivel de permiso actual |
| --- | --- |
| Viewer | Lee los datos de la organización y del producto. |
| Editor | Modifica el contenido y la configuración del asistente. |
| Admin | Publica asistentes y gestiona miembros y claves API. |
| Owner | Modifica los roles y gestiona a los propietarios. |

La aplicación aplica comprobaciones de capacidades más específicas a operaciones
individuales.

## Invita a un miembro

1. Abre **Settings > Members**.
2. Selecciona **Invite member**.
3. Introduce la dirección de correo electrónico.
4. Selecciona el Role mínimo requerido.
5. Envía la invitación.

## Cambiar un miembro

Un Admin puede gestionar a los miembros que estén por debajo del nivel de Owner.
Un Owner puede gestionar todos los niveles.

Un miembro no puede editar ni eliminar su propia fila de la lista de miembros.
Utiliza a otro miembro autorizado para esa operación.

## Roles de claves API

Un Admin o un Owner puede crear una clave API de la organización. El Role
seleccionado no puede ser de un nivel superior al Role del creador.

Revoca una clave cuando su cliente ya no necesite acceso. Ciele conserva el
registro revocado para fines de auditoría. Un Admin o un Owner puede eliminar
una clave revocada para borrar su registro.
