---
title: Fournisseurs d'IA
description: Connectez un fournisseur de modèles et sélectionnez le modèle pour chaque Assistant.
---

Ciele utilise une abstraction de fournisseur unique pour les modèles Anthropic,
OpenAI et Google. Un Assistant sélectionne sa connexion au fournisseur et son
modèle.

## Types de connexion aux fournisseurs

| Type | Utilisation |
| --- | --- |
| Platform plan | Utilise les modèles fournis par le plan Ciele géré. |
| Subscription | Utilise un abonnement de membre pour les chats propres à ce membre. |
| API key | Utilise une clé de fournisseur gérée par l'organisation. |
| AI Gateway | Utilise les modèles Anthropic, OpenAI et Google via AI Gateway. |

Un abonnement de membre ne prend en charge que les chats propres à ce membre :
l'Assistant Preview et ses chats avec un AI Teammate. Il ne dessert pas un
widget publié et n'exécute pas le chat d'un autre membre. Sélectionnez un
forfait Platform ou une connexion par clé API pour le trafic des éléments
publiés.

## Ajouter une connexion par clé API

1. Ouvrez **Settings**.
2. Sélectionnez **AI Provider**.
3. Ajoutez une connexion de fournisseur.
4. Sélectionnez Anthropic, OpenAI, Google, AI Gateway ou ElevenLabs.
5. Saisissez l'identifiant du fournisseur requis.
6. Enregistrez la connexion.

## AI Gateway

Une clé AI Gateway est une clé unique pour les modèles Anthropic, OpenAI et
Google. Ciele envoie ces appels via votre propre compte Vercel AI Gateway, et ce
compte les prend en charge financièrement.

Si l'Organisation ne dispose pas de clé AI Gateway, Ciele peut utiliser la clé
AI Gateway de la plateforme lorsque le déploiement en possède une. L'abonnement
de la plateforme prend en charge le coût de ces appels.

AI Gateway ne prend pas en charge tous les modèles. Un modèle que l'AI Gateway
ne prend pas en charge n'affiche pas l'AI Gateway comme source.

## Autres types de connexion

- **OpenAI-compatible endpoints** connecte un serveur tel qu'Ollama, vLLM ou LM
  Studio. Saisissez son URL de base, ses modèles et **Context window** en
  tokens. Utilisez la taille de contexte configurée sur ce serveur. La clé API
  est facultative. L'URL de base doit utiliser HTTPS et pointer vers un hôte
  public. Ciele refuse les adresses sur un réseau privé, telles que `localhost`,
  `10.x.x.x` ou `192.168.x.x`. Pour utiliser un endpoint sur un réseau privé,
  définissez-le dans l'environnement de déploiement. Voir
  [Configuration](/self-hosting/configuration).
- **Keyless enterprise auth** connecte Google Vertex, Anthropic ou Azure OpenAI
  via la fédération d'identité des workloads. Ciele ne stocke aucune clé
  statique pour ces connexions.

Ciele chiffre les identifiants avant leur stockage. N'utilisez pas une clé
personnelle qui dispose d'autorisations non pertinentes.

Les connexions ElevenLabs fournissent des modèles vocaux. Sélectionnez ces
modèles dans les paramètres **General** de l'Assistant, sous **Voice mode**. Les
connexions Google et OpenAI peuvent également fournir des modèles vocaux. Les
modèles disponibles dépendent du compte connecté et de ses autorisations API.
ElevenLabs n'apparaît pas dans les sélecteurs de modèle de texte ni dans ceux
d'embedding de connaissances.

## Sélectionnez un modèle d'Assistant

1. Ouvrez l'Assistant.
2. Sélectionnez **General**.
3. Sélectionnez la connexion au fournisseur.
4. Sélectionnez un modèle disponible.
5. En option, sélectionnez la source du modèle.
6. Testez l'Assistant dans Preview.
7. Publiez l'Assistant.

## Sources des modèles

Un modèle peut être disponible auprès de plusieurs sources. Par exemple, Claude
Sonnet 5 peut utiliser votre clé API Anthropic ainsi qu'AI Gateway. Le sélecteur
de source indique lorsqu'un modèle dispose de deux sources ou plus.

- **Automatic** utilise la première source disponible. L'ordre est le suivant :
  votre clé API, l'authentification d'entreprise sans clé, l'abonnement à la
  plateforme, votre clé AI Gateway et la clé AI Gateway de la plateforme.
- **Platform plan**, **API key**, **Keyless**, **AI Gateway · your key** et **AI
  Gateway · platform** n'utilisent que cette source.

**AI Gateway · your key** utilise la connexion AI Gateway de l'organisation, et
votre compte Gateway prend en charge les coûts. **AI Gateway · platform**
utilise la clé AI Gateway de la plateforme, et l'abonnement de la plateforme
prend en charge les coûts.

Si la source sélectionnée ne peut pas desservir le modèle, Ciele répond avec un
autre modèle disponible, comme c'est le cas lorsqu'un fournisseur n'a pas
d'identifiant.

Les modèles que les visiteurs ou les collègues peuvent choisir peuvent également
utiliser une source chacun. La liste affiche un modèle une fois pour chaque
source, le nom de la source figurant après le nom du modèle.

L'abonnement propre d'un membre n'est pas une source que vous sélectionnez. Il
gère les propres conversations de ce membre, quel que soit le modèle ou la
source utilisé(e) par l'Assistant.

Le widget publié utilise le fournisseur et le modèle présents dans son
instantané de publication. Les modifications générales apportées ultérieurement
nécessitent une nouvelle publication.

<Callout title="Provider accounts are separate">
Ciele API keys control Ciele administration. Provider API keys authorize model use. One credential cannot replace the other.
</Callout>
