---
title: Impostazioni dell'organizzazione
description: Gestisci membri, connessioni con i provider, chiavi API, utilizzo e fatturazione.
---

Un'Organizzazione rappresenta il confine del tenant per i dati e le
autorizzazioni di Ciele.

Utilizza **Settings** per queste aree attuali:

- **General** per le informazioni sull'organizzazione.
- **Members** per l'appartenenza, gli inviti e i ruoli.
- **AI Provider** per le connessioni dei modelli.
- **API Keys** per le credenziali programmatiche.
- **Usage** per l'utilizzo recente delle risorse e i relativi limiti.
- **Billing** per il piano gestito e l'account di fatturazione.

L'edizione self-hosted non mostra un catalogo di abbonamenti gestiti.

I ruoli dei membri e i ruoli delle chiavi API utilizzano la stessa scala di
autorizzazioni. Una chiave API non può ricevere un ruolo superiore a quello del
suo creatore.
