An Organization is the tenant boundary for Ciele data and permissions.

Use **Settings** for these current areas:

- **General** for Organization information.
- **Members** for membership, invitations, and Roles.
- **AI Provider** for provider connections.
- **Crawling** for the website crawler of the Organization, such as its own Apify account.
- **API Keys** for programmatic credentials.
- **Usage** for recent resource use and limits.
- **Billing** for the managed plan and billing account.

The self-hosted edition does not show a managed subscription catalogue.

Member Roles and API-key Roles use the same permission ladder. An API key cannot receive a Role above its creator.

The **AI Provider** area also controls [long-term memory](/data/long-term-memory). It includes tools to erase a Visitor's stored memories.

The **General** tab has two retention settings: one for reasoning traces and one for whole conversations.
See [Data retention](/organization/data-retention).

## Personal appearance

In the sidebar, expand **Settings** and select **Personal settings**, then **Theme**.
If you do not see **Settings**, open the account menu and select **Profile**, then **Theme**.
Choose **Light**, **Dark**, or **System**, and select the **Midnight** or **Mist Blue** palette.
These preferences affect your console and are saved in this browser. The published widget keeps its Assistant style.
