---
title: Organization settings
description: Manage members, provider connections, API keys, usage, and billing.
---

An Organization is the tenant boundary for Ciele data and permissions.

Use **Settings** for these current areas:

- **General** for Organization information.
- **Members** for membership, invitations, and Roles.
- **AI Provider** for model connections.
- **API Keys** for programmatic credentials.
- **Usage** for recent resource use and limits.
- **Billing** for the managed plan and billing account.

The self-hosted edition does not show a managed subscription catalogue.

Member Roles and API-key Roles use the same permission ladder. An API key cannot receive a Role above its creator.
