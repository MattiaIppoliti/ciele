---
title: Paramètres de l'organisation
description: Gérez les membres, les connexions aux fournisseurs, les clés API, l'utilisation et la facturation.
---

Une organisation est la limite du locataire pour les données et les
autorisations Ciele.

Utilisez **Settings** pour ces domaines actuels :

- **General** pour les informations sur l'organisation.
- **Members** pour l'adhésion, les invitations et les rôles.
- **AI Providers** pour les connexions aux fournisseurs.
- **Data** pour les schémas d'entité et les enregistrements importés.
- **API Keys** pour les identifiants programmatiques.
- **Usage** pour l'utilisation récente des ressources et les limites.
- **Billing** pour le plan géré et le compte de facturation.

L'édition auto-hébergée n'affiche pas de catalogue d'abonnements gérés.

Les rôles de membre et les rôles de clé API utilisent la même échelle
d'autorisations. Une clé API ne peut pas recevoir un rôle supérieur à celui de
son créateur.

La zone **AI Providers** contrôle également la
[mémoire à long terme](/data/long-term-memory). Elle comprend des outils
permettant d'effacer les souvenirs stockés d'un Visiteur.
