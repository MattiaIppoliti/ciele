---
title: Verbinden Sie einen Helpdesk mit einem Assistenten
description: Wählen Sie aus, welche Helpdesks ein Assistent anbietet und wie er eskaliert.
---

Helpdesks gehören zu Ihrer Organisation, und jeder Assistent wählt aus, welche
er anbietet. So können Sie eine gemeinsame Bibliothek von Helpdesks pflegen und
für jeden Assistenten die passende Teilmenge auswählen. Öffnen Sie einen
Assistenten und wählen Sie **Help Desks** in der Setup-Leiste aus.

## Wählen Sie die Helpdesks aus, die ein Assistent anbietet

Im Abschnitt „Help Desks“ des Assistenten wählen Sie aus, welche Help Desks
Ihrer Organisation dieser Assistent empfehlen darf. Wenn der Assistent
beschließt, zu eskalieren, wählt er unter den ausgewählten Desks auf Grundlage
ihrer Beschreibungen und des Kontexts der Konversation aus. Achten Sie daher
darauf, dass diese Beschreibungen korrekt sind.

Sie können die Liste filtern, um zu sehen, was ausgewählt ist, was noch
bearbeitet werden muss und was insgesamt verfügbar ist. So können Sie die
Eskalationsoptionen eines Assistenten ganz einfach auf dem neuesten Stand
halten.

## Eskalationsverhalten

Im selben Abschnitt legen Sie fest, wie der Assistent Eskalationen handhabt.

- Mit einer Empfehlungsoption kann der Assistent den am besten geeigneten Desk
  vorschlagen, wenn er nicht antworten kann, wobei er diesen anhand der
  Desk-Beschreibungen auswählt.
- Sie können steuern, ob eine immer verfügbare Eskalationsschaltfläche angezeigt
  wird.
- Sie können die Beschriftung der Kontakt-Schaltfläche so einstellen, dass sie
  zu Ihrer Stimme passt.

## Wie die Eskalation den Besucher erreicht

Sobald Desks ausgewählt und die Eskalation konfiguriert ist, kann der Besucher
Ihr Team auf die von Ihnen festgelegten Arten erreichen: über eine
Eskalations-[Startschaltfläche](/assistants/quick-replies), über die
Eskalationsoption im Chat oder wenn ein [Flow](/flows/actions) eskaliert. Die
Kanäle, die ein Besucher sieht, stammen von den Desks, die Sie hier ausgewählt
haben.

<Callout title="Keep descriptions sharp">
The assistant relies on desk and channel descriptions to route escalations well.
Clear, specific descriptions lead to better recommendations.
</Callout>
