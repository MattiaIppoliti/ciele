---
title: Einen Helpdesk verbinden
description: Stellen Sie einem Assistenten einen Helpdesk zur Verfügung.
---

## Verbinden Sie den Helpdesk

1. Öffnen Sie den Assistant.
2. Wählen Sie **Assistant Help Desks**.
3. Wählen Sie den gewünschten Helpdesk aus.
4. Speichern Sie den Entwurf.
5. Öffnen Sie die Vorschau.
6. Wählen Sie **Contact support**.
7. Bestätigen Sie den erwarteten Helpdesk und die erwarteten Kanäle.

Die Helpdesk-Beschreibung hilft der Laufzeitumgebung, einen Desk für die
Konversation zu empfehlen. Verwenden Sie eine präzise Beschreibung des
Geltungsbereichs.

## Verfügbarkeit testen

Testen Sie einen verfügbaren Kanal und einen nicht verfügbaren Kanal.
Vergewissern Sie sich, dass das Widget den korrekten nächsten verfügbaren
Zeitpunkt anzeigt.

## Veröffentlichen Sie die Verbindung

Veröffentlichen Sie den Assistenten nach dem Vorschautest. Ein Live-Widget
verwendet in seiner aktiven Veröffentlichung weiterhin die Helpdesks.
