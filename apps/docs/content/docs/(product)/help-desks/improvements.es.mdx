---
title: Mejoras en el servicio de asistencia
description: Crea respuestas de calidad a partir de las escaladas y los comentarios negativos.
---

Un servicio de asistencia puede crear una mejora a partir de una escalada. El
elemento vincula el feedback operativo a la conversación afectada.

## Habilita las mejoras automáticas

1. Abre el Help Desk.
2. Habilita la creación automática de mejoras.
3. Guarda el Help Desk.
4. Prueba una escalada en Vista previa.
5. Confirma el nuevo elemento en el panel de Mejoras.

El elemento puede incluir el mensaje marcado y una sugerencia de solución
generada. Revisa el contenido generado antes de modificar Knowledge.

## Completa el bucle

1. Abre la mejora.
2. Revisa la conversación vinculada.
3. Identifica el conocimiento que falta o que es incorrecto.
4. Corrige la Fuente o las Preguntas frecuentes.
5. Prueba la pregunta original en Vista previa.
6. Publica el Asistente corregido.
7. Mueve la mejora a **Done**.
