title: Formulare und Verfügbarkeit
description: Erfassen Sie die erforderlichen Eskalationsdaten und zeigen Sie an, wann ein Kanal verfügbar ist.
---

## Formularfelder hinzufügen

Fügen Sie nur die Daten hinzu, die das empfangende Team benötigt. Markieren Sie
ein Feld als Pflichtfeld, wenn der Kanal ohne dieses Feld nicht funktionieren
kann.

Testen Sie das Formular als Besucher. Vergewissern Sie sich, dass Pflichtfelder
eine unvollständige Übermittlung verhindern.

## Gesprächsdaten anhängen

Ein Helpdesk kann konfigurierte Konversationsinformationen an eine Eskalation
anhängen. Zu den verfügbaren Daten können eine Zusammenfassung, ein Verlauf,
Benutzerdaten und Metadaten gehören.

Wählen Sie die Mindestdaten aus, die das empfangende Team benötigt. Überprüfen
Sie die Auswahl anhand Ihrer Datenschutzanforderungen.

## Verfügbarkeit konfigurieren

Legen Sie den Kanalplan und die Zeitzone fest. Das Widget zeigt an, ob der Kanal
verfügbar ist, und kann den nächsten verfügbaren Zeitpunkt anzeigen.

Verwenden Sie die Zeitzone des Teams, das die Eskalation erhält. Testen Sie die
Grenze am Anfang und am Ende eines Verfügbarkeitsfensters.

## E-Mail-Zustellung

Der E-Mail-Kanal erfordert einen konfigurierten Resend-Transport. Wenn dieser
fehlt, meldet Ciele, dass die E-Mail nicht gesendet wurde.
