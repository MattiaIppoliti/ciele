---
title: Connect a Help Desk
description: Make a Help Desk available to one Assistant.
---

## Connect the Help Desk

1. Open the Assistant.
2. Select **Assistant Help Desks**.
3. Select the required Help Desk.
4. Save the draft.
5. Open Preview.
6. Select **Contact support**.
7. Confirm the expected Help Desk and channels.

The Help Desk description helps the runtime recommend a desk for the Conversation. Use a precise scope description.

## Test availability

Test one available channel and one unavailable channel. Confirm that the widget shows the correct next available time.

## Publish the connection

Publish the Assistant after the Preview test. A live widget continues to use the Help Desks in its active Publication.
