---
title: Connecter un centre d'assistance
description: Mettez un centre d'assistance à la disposition d'un assistant.
---

## Connectez le centre d'assistance

1. Ouvrez l'Assistant.
2. Sélectionnez **Assistant Help Desks**.
3. Sélectionnez le centre d'assistance requis.
4. Enregistrez le brouillon.
5. Ouvrez l'aperçu.
6. Sélectionnez **Contact support**.
7. Confirmez le centre d'assistance et les canaux attendus.

La description du centre d'assistance aide le moteur d'exécution à recommander
un centre pour la conversation. Utilisez une description précise du périmètre.

## Tester la disponibilité

Testez un canal disponible et un canal indisponible. Vérifiez que le widget
affiche correctement le prochain créneau disponible.

## Publiez la connexion

Publiez l'Assistant après le test de prévisualisation. Un widget en ligne
continue d'utiliser les Help Desks dans sa publication active.
