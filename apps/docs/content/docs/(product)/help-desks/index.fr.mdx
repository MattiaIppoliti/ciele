---
title: Centres d'assistance
description: Proposez aux visiteurs un chemin configuré pour contacter une équipe humaine.
---

Un centre d'assistance regroupe les canaux de contact, la disponibilité, les
champs de formulaire et les paramètres d'escalade. Une organisation peut
connecter un centre d'assistance à plusieurs assistants.

## Comportement actuel du canal

| Canal | Résultat pour le visiteur |
| --- | --- |
| E-mail | Ciele envoie un e-mail de remontée lorsque le transport d'e-mails est configuré. |
| Téléphone | Le widget affiche le contact téléphonique configuré. |
| Chat en direct | Le widget affiche le chemin de contact configuré pour le chat en direct. |
| Lien externe | Le widget ouvre la destination configurée. |

Ne configurez un canal qu'après avoir testé son parcours visiteur complet.

## Sélection de l'escalade

Un Assistant peut afficher une action **Contact support** toujours disponible.
Ciele peut recommander un service d'assistance connecté à partir de sa
description et du contexte de la conversation.

Le visiteur sélectionne un canal disponible. Le widget affiche alors le
formulaire configuré ou l'action de contact.

## Créez un centre d'assistance

1. Ouvrez **Help Desks**.
2. Créez un centre d'assistance.
3. Saisissez un nom et une description du routage.
4. Ajoutez un canal pris en charge.
5. Configurez la disponibilité et les champs du formulaire.
6. Connectez le centre d'assistance à un assistant.
7. Testez l'escalade en mode Aperçu.
