Ein Helpdesk fasst Kontaktkanäle, Verfügbarkeit, Formularfelder und
Eskalationseinstellungen zusammen. Eine Organisation kann einen Helpdesk mit
mehreren Assistenten verbinden.

## Aktuelles Kanalverhalten

| Kanal | Ergebnis für Besucher |
| --- | --- |
| E-Mail | Ciele sendet eine Eskalations-E-Mail, wenn der E-Mail-Transport konfiguriert ist. |
| Telefon | Das Widget zeigt den konfigurierten Telefonkontakt an. |
| Live-Chat | Das Widget zeigt den konfigurierten Live-Chat-Kontaktpfad an. |
| Externer Link | Das Widget öffnet das konfigurierte Ziel. |

Konfigurieren Sie einen Kanal erst, nachdem Sie seinen vollständigen
Besucherpfad getestet haben.

## Auswahl der Eskalation

Ein Assistent kann eine immer verfügbare **Contact support**-Aktion anzeigen.
Ciele kann anhand der Beschreibung und des Konversationskontexts einen
verknüpften Helpdesk empfehlen.

Der Besucher wählt einen verfügbaren Kanal aus. Das Widget zeigt dann das
konfigurierte Formular oder die Kontaktaktion an.

## Erstellen Sie einen Helpdesk

1. Öffnen Sie **Help Desks**.
2. Erstellen Sie einen Helpdesk.
3. Geben Sie einen Namen und eine Routing-Beschreibung ein.
4. Fügen Sie einen unterstützten Kanal hinzu.
5. Konfigurieren Sie die Verfügbarkeit und die Formularfelder.
6. Verbinden Sie den Help Desk mit einem Assistant.
7. Testen Sie die Eskalation in der Vorschau.
