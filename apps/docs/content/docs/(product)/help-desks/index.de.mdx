title: Übersicht über Helpdesks

---

Ein Assistent sollte seine Grenzen kennen. Wenn er nicht helfen kann oder ein
Besucher einfach eine Person wünscht, erreicht die Konversation Ihr Team über
einen Helpdesk. Ein Helpdesk ist ein Eskalationsziel, das zu Ihrer Organisation
gehört und einen oder mehrere Kanäle gruppiert, die ein Besucher nutzen kann.

Sie verwalten Helpdesks über den Bereich **Help Desks** in der Seitenleiste, in
dem alle Desks Ihres Unternehmens aufgelistet sind. Von dort aus können Sie
einen Desk erstellen oder einen öffnen, um ihn zu bearbeiten.

## Erstellen Sie einen Helpdesk

1. Öffnen Sie **Help Desks** in der Seitenleiste.
2. Erstellen Sie einen neuen Desk und geben Sie ihm einen **Namen** und eine
   **Beschreibung**. Die Beschreibung ist wichtig, denn ein Assistent kann sie
   nutzen, um zu entscheiden, wann dieser Desk der richtige ist, um ihn
   anzubieten.
3. Fügen Sie einen oder mehrere Kanäle hinzu, wie unten beschrieben.

## Support-Kanäle

Ein Kanal ist eine einzelne Möglichkeit, Ihr Team zu erreichen. Jeder Kanal hat
einen Namen, der zur Schaltflächenbeschriftung wird, die ein Besucher sieht,
sowie typenspezifische Einstellungen. Die verfügbaren Kanal-Typen decken die
gängigen Wege ab, auf denen Menschen um Hilfe bitten:

- **Email** sendet die Anfrage an eine Zieladresse.
- **Phone number** zeigt eine Nummer an, die der Besucher anrufen kann.
- **Live chat** öffnet eine Live-Chat-Adresse.
- **Create a ticket** erstellt einen Fall in Ihrem verknüpften Ticketsystem.
- **External link** öffnet eine Webadresse in einem neuen Tab.
- **Salesforce Chat Handover** stellt eine Verbindung zu einem eingebetteten
  Salesforce-Chat her.
- **API endpoint** sendet die Anfrage an einen von Ihnen angegebenen Dienst.

Fügen Sie die Kanäle hinzu, die Ihr Team tatsächlich überwacht, und ordnen Sie
sie so an, dass die bevorzugte Option an erster Stelle steht.

## Neuer Kanal im Vergleich zur Bearbeitung eines Kanals

Wenn Sie einen neuen Kanal hinzufügen, führt Sie ein kurzer Einrichtungsprozess
zunächst durch die wesentlichen Einstellungen und schaltet dann den Rest frei,
sobald die Grundlagen festgelegt sind. Wenn Sie einen bestehenden Kanal öffnen,
stehen Ihnen alle Einstellungen auf einen Blick zur Verfügung und Sie können
Ihre Änderungen direkt speichern.
