Ein Helpdesk kann zwei weitere Dinge tun, die Ihren Betrieb in Ordnung halten:
Fälle in Ihrem Ticketing-System eröffnen und den Moment vor einer Eskalation in
eine Chance verwandeln, zukünftige Antworten zu verbessern.

## Ein Ticketing-System verbinden

Wenn ein Kanal vom Typ **Create a ticket** verwendet wird, wird die Anfrage zu
einem Fall in Ihrem Ticketing-System. Damit dies funktioniert, verbinden Sie das
System mit dem Helpdesk.

1. Öffnen Sie einen Helpdesk und suchen Sie den Abschnitt zur
   Ticketing-Integration.
2. Wählen Sie Ihr Ticketing-System aus den angehefteten Optionen aus oder
   durchsuchen Sie den vollständigen Integrationskatalog.
3. Wählen Sie **Connect** aus und geben Sie die Anmeldeinformationen an, die für
   die Integration erforderlich sind.

Sobald die Verbindung hergestellt ist, können Ticket-Kanäle in diesem Desk
automatisch Fälle erstellen, wobei die Formularfelder und alle von Ihnen
angehängten Gesprächsdaten übernommen werden.

## Automatische Generierung von Verbesserungen

Ein Helpdesk kann automatisch eine Verbesserung aus der letzten Antwort
erstellen, die der Assistent gegeben hat, bevor ein Besucher eskaliert hat.
Dadurch wird genau die Frage erfasst, die der Assistent nicht beantworten
konnte. So können Sie Ihr Wissen oder Ihre Abläufe verbessern und beim nächsten
Mal die gleiche Eskalation verhindern.

Aktivieren Sie dies über den Helpdesk, damit jede Eskalation stillschweigend in
Ihr [Improvements](/operations/improvements)-Board einfließt. Im Laufe der Zeit
werden Eskalationen so zu einem stetigen Strom konkreter, hochwertiger
Korrekturen.

## Verbundene Assistenten

Ein Helpdesk zeigt an, welche Assistenten ihn derzeit anbieten. So erhalten Sie
einen klaren Überblick darüber, wo jeder Eskalationspfad verwendet wird, sodass
Sie einen Desk sicher aktualisieren können.
