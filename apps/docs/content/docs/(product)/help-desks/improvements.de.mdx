title: Helpdesk-Verbesserungen
description: Erstellen Sie qualitativ hochwertige Antworten auf der Grundlage von Eskalationen und negativem Feedback.
---

Ein Helpdesk kann aus einer Eskalation eine Verbesserung erstellen. Das Element
verknüpft operatives Feedback mit der betroffenen Konversation.

## Automatische Verbesserungen aktivieren

1. Öffnen Sie den Helpdesk.
2. Aktivieren Sie die automatische Erstellung von Verbesserungen.
3. Speichern Sie den Helpdesk.
4. Testen Sie eine Eskalation in der Vorschau.
5. Bestätigen Sie das neue Element auf dem Improvements-Board.

Das Element kann die markierte Nachricht und eine generierte Korrekturvorschlag
enthalten. Überprüfen Sie den generierten Inhalt, bevor Sie Knowledge ändern.

## Schließen Sie die Schleife

1. Öffnen Sie die Verbesserung.
2. Überprüfen Sie die verknüpfte Konversation.
3. Identifizieren Sie das fehlende oder falsche Wissen.
4. Korrigieren Sie die Quelle oder die FAQ.
5. Testen Sie die ursprüngliche Frage in der Vorschau.
6. Veröffentlichen Sie den korrigierten Assistenten.
7. Verschieben Sie die Verbesserung nach **Done**.
