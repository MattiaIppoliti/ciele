---
title: Help Desk Improvements
description: Create answer-quality work from escalations and negative feedback.
---

A Help Desk can create an Improvement from an escalation. The item links operational feedback to the affected Conversation.

## Enable automatic Improvements

1. Open the Help Desk.
2. Enable automatic Improvement creation.
3. Save the Help Desk.
4. Test an escalation in Preview.
5. Confirm the new item on the Improvements board.

The item can include the flagged message and a generated suggested fix. Review generated content before you change Knowledge.

## Complete the loop

1. Open the Improvement.
2. Review the linked Conversation.
3. Identify the missing or incorrect Knowledge.
4. Correct the Source or FAQ.
5. Test the original question in Preview.
6. Publish the corrected Assistant.
7. Move the Improvement to **Done**.
