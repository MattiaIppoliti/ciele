---
title: Ediciones
description: Selecciona Ciele Cloud o utiliza la edición de código abierto.
---

Ciele ofrece una edición gestionada en la nube y una edición de código abierto
autohospedada. Ambas ediciones utilizan el mismo núcleo de producto de código
abierto.

| Área | Ciele Cloud | Código abierto |
| --- | --- | --- |
| Funcionamiento del producto | Ciele opera el servicio. | Tu equipo opera el servicio. |
| Cómo empezar | Habla con el equipo de ventas. No hay registro de autoservicio. | Instálalo tú mismo. Es gratis. |
| Suscripción | Un acuerdo Enterprise controla el uso incluido. | No se requiere suscripción a Ciele. |
| Infraestructura | Ciele selecciona y mantiene la implementación. | Tu equipo proporciona y mantiene la implementación. |
| Credenciales de modelo | Utiliza modelos de plan o conexiones de proveedores compatibles. | Configura el proveedor compatible o los puntos de conexión locales compatibles. |
| Actualizaciones | El servicio gestionado recibe las versiones implementadas. | Tu equipo selecciona y aplica las versiones. |
| Licencia | Se aplican los términos del servicio. | El núcleo utiliza únicamente AGPL-3.0. |

La documentación pública de código abierto describe únicamente los archivos del
repositorio de código abierto. No describe los detalles de la implementación
empresarial.

Utiliza [Ciele Cloud](/cloud) para obtener información sobre los planes
alojados. Utiliza [Open Source](/self-hosting) para obtener instrucciones de
instalación y funcionamiento.

Ciele Cloud se vende como una oferta Enterprise orientada a la venta. La opción
gratuita es la edición autoalojada.
