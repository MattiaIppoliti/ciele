title: Editionen
description: Wählen Sie Ciele Cloud oder nutzen Sie die Open-Source-Edition.
---

Ciele bietet eine verwaltete Cloud-Edition und eine selbst gehostete
Open-Source-Edition an. Beide Editionen verwenden denselben
Open-Source-Produktkern.

| Bereich | Ciele Cloud | Open Source |
| --- | --- | --- |
| Produktbetrieb | Ciele betreibt den Dienst. | Ihr Team betreibt den Dienst. |
| Erste Schritte | Sprechen Sie mit dem Vertrieb. Es gibt keine Selbstregistrierung. | Installieren Sie es selbst. Es ist kostenlos. |
| Abonnement | Eine Enterprise-Vereinbarung regelt die enthaltene Nutzung. | Es ist kein Ciele-Abonnement erforderlich. |
| Infrastruktur | Ciele wählt die Bereitstellung aus und wartet sie. | Ihr Team stellt die Bereitstellung bereit und wartet sie. |
| Modell-Anmeldeinformationen | Verwenden Sie Planmodelle oder unterstützte Anbieterverbindungen. | Konfigurieren Sie unterstützte Anbieter oder kompatible lokale Endpunkte. |
| Updates | Der verwaltete Dienst erhält bereitgestellte Releases. | Ihr Team wählt Releases aus und wendet sie an. |
| Lizenz | Es gelten die Servicebedingungen. | Der Core verwendet ausschließlich AGPL-3.0. |

Die öffentliche Open-Source-Dokumentation beschreibt nur Dateien im
Open-Source-Repository. Sie beschreibt keine Details zur Implementierung in
Unternehmen.

Verwenden Sie [Ciele Cloud](/cloud) für Informationen zu gehosteten Plänen.
Verwenden Sie [Open Source](/self-hosting) für Installations- und
Bedienungsanleitungen.

Ciele Cloud wird als ein vertriebsgesteuertes Enterprise-Angebot verkauft. Der
kostenlose Weg ist die selbst gehostete Edition.
