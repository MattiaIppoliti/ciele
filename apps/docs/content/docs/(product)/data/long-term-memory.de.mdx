---
title: Langzeitspeicher
description: Speichern Sie dauerhafte Fakten für angemeldete Besucher und löschen Sie sie bei Bedarf.
---

Das Langzeitgedächtnis überträgt dauerhafte Fakten in spätere Conversations. Es
funktioniert nur für Besucher, die sich über das SSO-Gate des Widgets angemeldet
haben.

Die Funktion ist standardmäßig deaktiviert. Anonyme Besucher erzeugen oder rufen
niemals Langzeiterinnerungen ab.

## Langzeitspeicher aktivieren

1. Öffnen Sie **Settings**.
2. Wählen Sie **AI Provider** aus.
3. Suchen Sie nach **Long-term memory**.
4. **Remember signed-in users across conversations** aktivieren.

Die Organisation benötigt eine funktionierende Verbindung zum Provider. Die
Speicher-Extraktion verwendet das Classifier-Tier-Modell und wird auf das
tägliche AI-Budget angerechnet.

## Was Ciele sich merkt

Ciele hebt explizite Fakten hervor, die auch nach der aktuellen Conversation
noch nützlich sein können. Beispiele hierfür sind eine Kontaktpräferenz oder
eine Daueranweisung.

Der Extractor lässt einmalige Anfragen, Fragen, Vermutungen und Aussagen, die
ausschließlich vom Assistant stammen, außer Acht. Viele Conversations liefern
keine dauerhaften Fakten.

Jede gespeicherte Erinnerung behält die Herkunft zu ihrer Quell-Conversation
bei. Exakte doppelte Fakten werden während der Speicherung entfernt.

Ein angemeldeter Visitor kann bis zu 200 Memories speichern. Bei neuen
Schreibvorgängen werden nach Erreichen dieses Limits die ältesten Fakten
entfernt.

## Promotion und Recall

<Mermaid
  title="Der Lebenszyklus von Promote und Recall"
  chart={`

  QUIET["15 quiet minutes"]
  JOB["promote_memories job"]
  STORE["Extract, deduplicate, and store"]
  NEXT["A later Conversation opens"]
  PROMPT["Up to five memories join the prompt"]
  TURN --> QUIET
  QUIET --> JOB
  JOB --> STORE
  STORE --> NEXT
  NEXT --> PROMPT
`}
/>

Ein Promotion-Job wartet, bis die Conversation 15 Minuten lang inaktiv bleibt.
Eine neuere Nachricht ersetzt einen älteren, ausstehenden Job.

Bevor der Job irgendetwas speichert, überprüft er vier Punkte: den
Organization-Schalter, den SSO-Subject, ein verfügbares Modell und das Budget.
Jeder dieser Punkte kann die Promotion stoppen.

Nur der erste Turn einer späteren Conversation erhält auf diese Weise Memories.
Danach greift die Runtime über das Tool `searchMemories` darauf zu.

Recall überschreitet niemals die Grenzen einer Organisation oder eines
SSO-Subjects.

## Ermöglichen Sie einem Besucher, Erinnerungen einzusehen und zu löschen

Ein angemeldeter Visitor kann das Widget-Verlaufsfenster öffnen. Der Ordner
**Memory** wird angezeigt, wenn das Langzeitgedächtnis aktiviert ist.

Der Ordner listet die gespeicherten Fakten für diesen Besucher auf. Wählen Sie
das Steuerelement „Delete“ neben einer Information aus, um sie zu vergessen.

Durch das Löschen wird die Information aus dem zukünftigen Abruf von Prompts und
aus Suchvorgängen im Speicher entfernt.

## Eine Löschungsanfrage bearbeiten

1. Öffnen Sie **Settings**.
2. Wählen Sie **AI Provider** aus.
3. Suchen Sie nach **Remembered users**.
4. Suchen Sie nach User ID oder Identity Claim.
5. Überprüfen Sie die gespeicherten Fakten.
6. Löschen Sie eine Erinnerung oder wählen Sie **Delete all memories for this
   user** aus.
7. Bestätigen Sie den Löschvorgang im Dialogfeld.

Das Löschen erfolgt sofort, nachdem Sie es bestätigt haben. Sie können diesen
Vorgang nicht rückgängig machen. Mitglieder der Organisation können Memories nur
innerhalb ihrer Organisation verwalten.

<Callout title="Disabling and deleting are different">
Disabling long-term memory stops extraction and recall. Use **Remembered users** when stored facts must also be erased.
</Callout>
