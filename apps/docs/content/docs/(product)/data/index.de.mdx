Ciele kann Organisationsdatensätze mit dauerhaften Fakten über angemeldete
Besucher kombinieren. Diese Funktionen nutzen eine verifizierte Identität und
bleiben unter der Kontrolle der Organisation.

Die Veröffentlichung steuert, welche Entity-Tools vorhanden sind. Die Werte der
Datensätze bleiben live, sodass ein späterer CSV-Import die Antworten ohne eine
weitere Veröffentlichung ändern kann.

Eine auf Benutzerebene beschränkte Entität benötigt einen verifizierten
Identitätsanspruch. Der Server fügt diesen Filter hinzu, nachdem er die
Tool-Eingabe validiert hat, sodass ein Modell ihn weder entfernen noch einen
anderen Besucher benennen kann.

Das Langzeitgedächtnis ist eine separate Funktion mit einem eigenen
Lebenszyklus. Es ist nicht von Entitäten abhängig. Siehe
[Langzeitgedächtnis](/data/long-term-memory).

## Zwei Arten von Speicher

**Session memory** gehört zu einer Konversation. Es folgt einem Besucher nicht
in eine neue Konversation.

**Long-term memory** gehört zu einem verifizierten SSO-Subjekt innerhalb einer
Organisation. Es kann spätere Konversationen unterstützen, wenn die Organisation
dies aktiviert.

<Callout title="Signed-in Visitors only">
Anonymous Visitors never receive user-scoped Entity tools. They also never produce or recall long-term memories.
</Callout>
