Ciele kann Organization Records mit dauerhaften Fakten über angemeldete Visitors
kombinieren. Diese Funktionen verwenden eine verifizierte Identität und bleiben
unter der Kontrolle der Organisation.

Die Publication bestimmt, welche Entity-Tools vorhanden sind. Record-Werte
bleiben aktiv, sodass ein späterer CSV-Import Antworten ändern kann, ohne dass
eine weitere Publication erforderlich ist.

Eine Entity mit Benutzerumfang benötigt einen verifizierten Identitätsnachweis.
Der Server fügt diesen Filter hinzu, nachdem er die Tool-Eingabe validiert hat,
sodass ein Modell ihn weder entfernen noch einen anderen Visitor benennen kann.

Long-term memory ist eine separate Funktion mit einem eigenen Lebenszyklus. Es
ist nicht von Entities abhängig. Siehe
[Long-term memory](/data/long-term-memory).

## Zwei Arten von Speicher

**Session memory** gehört zu einer Conversation. Es folgt einem Visitor nicht in
eine neue Conversation.

**Long-term memory** gehört zu einem verifizierten SSO-Subject innerhalb einer
Organisation. Es kann spätere Conversations unterstützen, wenn die Organisation
dies aktiviert.

<Callout title="Signed-in Visitors only">
Anonymous Visitors never receive user-scoped Entity tools. They also never produce or recall long-term memories.
</Callout>
