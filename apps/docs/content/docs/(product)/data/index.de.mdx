Ciele kann dauerhafte Fakten über angemeldete Besucher speichern. Diese Funktion
verwendet eine verifizierte Identität und bleibt unter der Kontrolle der
Organisation.

## Zwei Arten von Speicher

**Session memory** gehört zu einer Conversation. Es folgt einem Besucher nicht
in eine neue Conversation.

**Long-term memory** gehört zu einem verifizierten SSO-Subjekt innerhalb einer
Organisation. Es kann spätere Conversations unterstützen, wenn die Organisation
dies aktiviert.

<Callout title="Signed-in Visitors only">
Anonymous Visitors never produce or recall long-term memories.
</Callout>
