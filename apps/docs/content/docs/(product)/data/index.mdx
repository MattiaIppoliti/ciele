The Publication controls which Entity tools exist. Record values remain live, so a later CSV import can change answers without another Publication.

Identity filters are applied on the server. A model cannot select another Visitor's identity or remove the filter.

## Two kinds of memory

**Session memory** belongs to one Conversation. It does not follow a Visitor into a new Conversation.

**Long-term memory** belongs to a verified SSO subject within one Organization. It can support later Conversations when the Organization enables it.

<Callout title="Signed-in Visitors only">
Anonymous Visitors never receive user-scoped Entity tools. They also never produce or recall long-term memories.
</Callout>
