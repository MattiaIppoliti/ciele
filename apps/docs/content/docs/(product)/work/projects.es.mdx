Un proyecto contiene Tasks, hitos, archivos, vistas guardadas y un registro de
actividad.

## Crea un proyecto

1. Abre **Projects**.
2. Selecciona **New project**.
3. Escribe un nombre. Ciele te sugiere una clave a partir del nombre. Puedes
   cambiar la clave.
4. Selecciona un estado, un responsable, fechas, un color y, si es necesario, un
   icono.
5. Selecciona la visibilidad.
6. Selecciona **Create**.

La clave debe tener entre dos y cinco letras o dígitos. Debe empezar por una
letra. La clave es el prefijo de cada clave de tarea en el proyecto.

## Visibilidad

| Visibility | Quién puede ver el proyecto |
| --- | --- |
| Organization | Todos los miembros de la organización. |
| Private | Los miembros del proyecto, así como los administradores y los propietarios. |

Ciele añade al creador de un proyecto privado como miembro. Para añadir o
eliminar miembros, selecciona **Share** en el encabezado del proyecto. Si
eliminas al creador, este ya no podrá ver el proyecto.

## La página del proyecto

Las pestañas de la página del proyecto muestran las mismas Tasks en diferentes
vistas:

| Pestaña | Uso |
| --- | --- |
| **Overview** | Consulta el progreso, las próximas fechas y la actividad reciente. |
| **Board** | Mueve tareas entre columnas de estado. |
| **List** | Consulta y modifica las tareas en una lista agrupada. |
| **Table** | Cambia rápidamente muchos campos en una hoja. |
| **Calendar** | Consulta las tareas según sus fechas de vencimiento. |
| **Timeline** | Visualiza las tareas como barras que se extienden desde su fecha de inicio hasta su fecha de vencimiento. |
| **Files** | Busca todos los archivos del proyecto. |
| **Activity** | Lee qué ha cambiado en el proyecto, día a día. |

Un proyecto se abre en la vista que utilizaste por última vez en este navegador.
La primera vez, se abre en **List**.

Para obtener más información sobre las vistas, consulta
[Tasks and views](/work/tasks).

## Archivos

Abre la pestaña **Files** para ver todos los archivos del proyecto. Un archivo
adjunto a una tarea muestra la clave de esa tarea.

- Para subir un archivo, selecciona **Upload** o arrastra y suelta los archivos
  en la vista. El tamaño máximo es de 50 MB.
- Para adjuntar un archivo a una tarea, abre la tarea y selecciona **Attach**.
  También puedes arrastrar y soltar archivos en la sección de archivos adjuntos.
- Para previsualizar una imagen o un PDF, selecciona el archivo.
- Para cambiar el nombre de un archivo, descargarlo, copiar su enlace o
  eliminarlo, abre su menú.

Solo los Editors, los Admins y los Owners pueden subir, renombrar o eliminar
archivos. Un Viewer puede leer y descargar archivos.

Cuando eliminas una tarea o un proyecto, Ciele también elimina sus archivos.

## Hitos

Un hito tiene un nombre y una fecha. Los hitos se muestran como rombos en la
Timeline. Para cambiar los hitos, abre Project settings.

## Archivar o eliminar un proyecto

Abre el menú Project.

- Selecciona **Archive** para ocultar el proyecto y conservar su trabajo.
  Selecciona **Undo** en el mensaje para restaurarlo inmediatamente. También
  puedes restaurar un proyecto archivado más adelante.
- Selecciona **Delete** para eliminar el proyecto, sus tareas, sus archivos y
  sus hitos. Ciele muestra el número de Tasks y archivos que elimina. Desliza
  para confirmar. No podrás deshacer esta acción.
