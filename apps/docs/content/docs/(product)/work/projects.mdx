A Project contains Tasks, milestones, files, saved views, and an activity log.

## Create a Project

1. Open **Projects**.
2. Select **New project**.
3. Type a name. Ciele suggests a key from the name. You can change the key.
4. Select a status, a lead, dates, a color, and an icon if necessary.
5. Select the visibility.
6. Select **Create**.

The key must have two to five letters or digits. It must start with a letter. The key is the prefix of each Task key in the Project.

## Visibility

| Visibility | Who can see the Project |
| --- | --- |
| Organization | All members of the Organization. |
| Private | The members of the Project, and the Admins and Owners. |

Ciele adds the creator of a private Project as a member. To add or remove members, select **Share** in the Project header. If you remove the creator, the creator cannot see the Project after that.

## The Project page

The tabs of the Project page show the same Tasks in different views:

| Tab | Use |
| --- | --- |
| **Overview** | Read the progress, the upcoming dates, and the recent activity. |
| **Board** | Move Tasks between status columns. |
| **List** | Read and change Tasks in a grouped list. |
| **Table** | Change many fields quickly in a sheet. |
| **Calendar** | See Tasks on their due dates. |
| **Timeline** | See Tasks as bars from their start date to their due date. |
| **Files** | Find every file in the Project. |
| **Activity** | Read what changed in the Project, day by day. |

A Project opens on the view that you used last in this browser. The first time, it opens on **List**.

For more information about the views, see [Tasks and views](/work/tasks).

## Files

Open the **Files** tab to see all files of the Project. A file that is attached to a Task shows the key of that Task.

- To upload a file, select **Upload** or drop files on the view. The maximum size is 50 MB.
- To attach a file to a Task, open the Task and select **Attach**. You can also drop files on the attachments.
- To preview an image or a PDF, select the file.
- To rename, download, copy the link, or delete a file, open its menu.

Only Editors, Admins, and Owners can upload, rename, or delete files. A Viewer can read and download files.

When you delete a Task or a Project, Ciele deletes its files too.

## Milestones

A milestone has a name and a date. Milestones show as diamonds on the Timeline. To change the milestones, open the Project settings.

## Archive or delete a Project

Open the Project menu.

- Select **Archive** to hide the Project and keep its work. Select **Undo** in the message to restore it at once. You can also restore an archived Project later.
- Select **Delete** to delete the Project, its Tasks, its files, and its milestones. Ciele shows the number of Tasks and files that it deletes. Slide to confirm. You cannot undo this action.
