El grupo **Work** de la barra lateral contiene el trabajo de tu equipo. Está
separado de la configuración del asistente.

| Sección | Uso |
| --- | --- |
| My Tasks | Consulta las tareas que tienes asignadas en cada proyecto. |
| Notifications | Lee y responde a las Notificaciones de miembros que se te dirigen. |
| Projects | Abre un proyecto y sus tareas, vistas, archivos y actividad. |
| All tasks | Consulta todas las tareas de todos los proyectos que puedes leer. |

## Las partes del trabajo

Un Project contiene el trabajo. Cada proyecto tiene una clave corta, por
ejemplo, `WEB`.

Una tarea es un elemento de trabajo dentro de un proyecto. Cada tarea recibe un
número en su proyecto, por lo que una tarea tiene una clave como `WEB-12`. Una
Task puede tener subtasks de un solo nivel de profundidad.

Una Label marca Tasks en todos los Projects de la Organization. Por ejemplo, una
etiqueta **Bug** puede marcar tareas en diferentes proyectos.

Un hito marca una fecha importante en un proyecto. Los hitos se muestran en la
línea de tiempo (Timeline).

## Quién puede hacer qué

Tu rol en la organización determina lo que puedes hacer. El proyecto determina
lo que puedes ver.

| Role | Qué puedes hacer |
| --- | --- |
| Viewer | Leer proyectos y tareas. Comentar y reaccionar. |
| Editor | Todo lo anterior. Crea y modifica proyectos y tareas. Sube archivos. |
| Admin y Owner | Todo lo anterior. Puedes leer todos los proyectos privados. |

Un Viewer no puede ser el asignado de una Task.

Un proyecto de toda la organización es visible para todos los miembros. Un
proyecto privado solo es visible para sus miembros, su creador y los Admins y
Owners.

## Atajos de teclado

Pulsa **N** para crear una tarea y **P** para crear un proyecto. Pulsa **G** y,
a continuación, una letra para abrir una página; por ejemplo, **G** y luego
**T** para acceder a My Tasks. Pulsa **?** para ver todos los atajos de teclado.
Consulta [Navegar por la consola](/getting-started/navigating-the-console).

Pulsa **F** para abrir Find. Find también muestra Tasks y Projects, así como las
búsquedas que has realizado recientemente. Resalta el texto que coincide con tu
búsqueda.
