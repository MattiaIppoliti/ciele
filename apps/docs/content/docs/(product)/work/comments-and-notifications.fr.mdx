## Commentaires

Ouvrez une tâche et sélectionnez **Comments**. Saisissez votre commentaire et
sélectionnez **Comment**. Vous pouvez également appuyer sur Cmd+Entrée ou
Ctrl+Entrée.

- Pour mentionner un membre, saisissez `@` et sélectionnez le membre. Ciele
  affiche uniquement les membres qui peuvent lire le Projet.
- Pour modifier votre commentaire, sélectionnez l'icône en forme de crayon. Le
  commentaire affiche **Edited**.
- Pour supprimer votre commentaire, sélectionnez l’icône de la corbeille.
  Sélectionnez **Undo** dans le message pour restaurer le commentaire. Vous
  pouvez le restaurer pendant 10 minutes. Ciele supprime définitivement le
  commentaire un jour plus tard. Un commentaire supprimé n'apparaît pas dans
  l'activité de la tâche.
- Pour réagir, sélectionnez l'icône du sourire, puis un emoji. Vous pouvez
  ajouter plusieurs réactions.

Une mention reste correcte lorsque le membre change de nom.

## Activité

Ouvrez une tâche et sélectionnez **Activity** pour voir ce qui a changé dans la
tâche, jour après jour. L’onglet **Activity** d’un projet affiche toutes les
modifications apportées au projet.

Lorsqu’un coéquipier IA modifie une tâche pour vous, l’activité affiche le nom
du coéquipier et votre nom.

## Notifications des membres

Ciele crée une notification de membre pour vous lorsqu’une autre personne
effectue l’une des actions suivantes :

| Type | Action |
| --- | --- |
| Assigned | Vous attribue une tâche. |
| Mentioned | Vous mentionne dans un commentaire. |
| Commented | Commente une tâche que vous avez créée ou qui vous est assignée. |
| Updates | Modifie le statut d'une tâche que vous avez créée ou qui vous est attribuée. |

Vous ne recevez jamais de notification de membre pour vos propres actions.

## La page Notifications

Ouvrez **Notifications** dans la barre latérale. Le badge indique le nombre de
notifications de membre que vous n'avez pas lues.

- Sélectionnez un onglet pour afficher un type spécifique, ou sélectionnez
  **All**.
- Sélectionnez **Unread** pour afficher uniquement les notifications de membre
  que vous n'avez pas lues.
- Sélectionnez **Mark all as read** pour marquer toutes les notifications de
  membres de l’onglet comme lues.

Sélectionnez une Member Notification pour lire sa Task sur le côté droit. Ciele
la marque comme lue. Vous pouvez y modifier le statut, l’assigné, la priorité et
la date d’échéance de la tâche. Vous pouvez également lire les derniers
commentaires et y répondre.

## Archiver, mettre en pause ou supprimer une notification de membre

Faites glisser une Member Notification vers la gauche pour afficher **Snooze**,
**Delete** et **Archive**. Faites glisser vers la droite pour la marquer comme
lue ou non lue.

- **Archive** supprime la notification de membre de la liste. Balayez
  complètement vers la gauche pour l’archiver immédiatement. Sélectionnez
  **Undo** pour l’afficher à nouveau.
- **Snooze** masque la notification de membre jusqu’à demain 9 h 00. Ensuite,
  elle réapparaît dans la liste. Sélectionnez **Undo** pour l’afficher
  maintenant.
- **Delete** supprime définitivement la notification de membre. Ciele vous
  demande d’abord de confirmer. Vous ne pouvez pas la restaurer.

Vous pouvez également survoler une Member Notification avec le pointeur et
sélectionner le bouton Menu pour effectuer ces actions. Le badge ne prend pas en
compte les Member Notifications archivées ou mises en pause.

Les nouvelles notifications de membre s’affichent également dans le coin
inférieur droit pendant que vous travaillez. Sélectionnez **View all** pour
ouvrir la page Notifications.

Ciele supprime les Member Notifications au bout de 90 jours.

## E-mail

Ciele peut également vous envoyer un e-mail lorsqu’une Task vous est attribuée
ou lorsque quelqu’un vous mentionne. Les deux types d'e-mails sont activés par
défaut.

Pour modifier ce paramètre, ouvrez vos paramètres personnels et sélectionnez
**Notifications**. Les commentaires et les changements de statut ne sont jamais
envoyés par e-mail.
