## Comments

Open a Task and select **Comments**. Type your comment and select **Comment**. You can also press Cmd+Enter or Ctrl+Enter.

- To mention a member, type `@` and select the member. Ciele shows only the members who can read the Project.
- To change your comment, select the pencil icon. The comment shows **Edited**.
- To delete your comment, select the trash icon. Select **Undo** in the message to restore the comment. You can restore it for 10 minutes. Ciele deletes the comment permanently one day later. A deleted comment does not show in the activity of the Task.
- To react, select the smile icon and an emoji. You can add more than one reaction.

A mention stays correct when the member changes their name.

## Activity

Open a Task and select **Activity** to see what changed in the Task, day by day. The **Activity** tab of a Project shows all changes in the Project.

When an AI teammate changes a Task for you, the activity shows the teammate and your name.

## Member Notifications

Ciele creates a Member Notification for you when somebody else does one of these actions:

| Type | Action |
| --- | --- |
| Assigned | Assigns a Task to you. |
| Mentioned | Mentions you in a comment. |
| Commented | Comments on a Task that you created or that is assigned to you. |
| Updates | Changes the status of a Task that you created or that is assigned to you. |

You never get a Member Notification for your own actions.

## The Notifications page

Open **Notifications** in the sidebar. The badge shows how many Member Notifications you did not read.

- Select a tab to see one type, or select **All**.
- Select **Unread** to see only the Member Notifications that you did not read.
- Select **Mark all as read** to mark all Member Notifications in the tab as read.

Select a Member Notification to read its Task on the right side. Ciele marks it as read. You can change the status, assignee, priority, and due date of the Task there. You can also read the latest comments and reply.

## Archive, snooze, or delete a Member Notification

Swipe a Member Notification to the left to show **Snooze**, **Delete**, and **Archive**. Swipe it to the right to mark it as read or unread.

- **Archive** removes the Member Notification from the list. Swipe fully to the left to archive it at once. Select **Undo** to show it again.
- **Snooze** hides the Member Notification until 9:00 tomorrow. Then it shows in the list again. Select **Undo** to show it now.
- **Delete** removes the Member Notification permanently. Ciele asks you to confirm first. You cannot restore it.

You can also move the pointer over a Member Notification and select the menu button to do these actions. The badge does not count archived or snoozed Member Notifications.

New Member Notifications also show in the bottom-right corner while you work. Select **View all** to open the Notifications page.

Ciele deletes Member Notifications after 90 days.

## Email

Ciele can also send an email when a Task is assigned to you or when somebody mentions you. Both emails are on by default.

To change this, open your personal settings and select **Notifications**. Comments and status changes are never sent by email.
