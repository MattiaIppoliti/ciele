The **Work** group in the sidebar holds the work of your team. It is separate from Assistant configuration.

| Section | Use |
| --- | --- |
| My Tasks | See the Tasks that are assigned to you, in every Project. |
| Notifications | Read and answer the Member Notifications that are addressed to you. |
| Projects | Open a Project and its Tasks, views, files, and activity. |
| All tasks | See every Task in every Project that you can read. |

## The parts of the work

A Project contains the work. Each Project has a short key, for example `WEB`.

A Task is one item of work in a Project. Each Task gets a number in its Project, so a Task has a key such as `WEB-12`. A Task can have subtasks one level deep.

A Label marks Tasks across all Projects of the Organization. For example, one **Bug** Label can mark Tasks in different Projects.

A milestone marks an important date in a Project. Milestones show on the Timeline.

## Who can do what

Your role in the Organization decides what you can do. The Project decides what you can see.

| Role | Can do |
| --- | --- |
| Viewer | Read Projects and Tasks. Comment and react. |
| Editor | All of the above. Create and change Projects and Tasks. Upload files. |
| Admin and Owner | All of the above. Read every private Project. |

A Viewer cannot be the assignee of a Task.

An Organization-wide Project is visible to all members. A private Project is visible only to its members, its creator, and the Admins and Owners.

## Keyboard shortcuts

Press **N** to create a Task and **P** to create a Project. Press **G** and then a letter to open a page, for example **G** then **T** for My Tasks. Press **?** to see all keyboard shortcuts. See [Navigate the console](/getting-started/navigating-the-console).

Press **F** to open Find. Find also shows Tasks and Projects, and the searches that you used recently. It highlights the text that matches your search.
