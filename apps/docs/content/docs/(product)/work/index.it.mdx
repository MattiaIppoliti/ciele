Il gruppo **Work** nella barra laterale contiene il lavoro del tuo team. È
separato dalla configurazione dell'Assistente.

| Section | Uso |
| --- | --- |
| My Tasks | Visualizza le attività assegnate a te, in ogni progetto. |
| Notifications | Leggi e rispondi alle Member Notifications indirizzate a te. |
| Projects | Apri un Project e i relativi Tasks, views, files e activity. |
| All tasks | Visualizza tutte le attività di tutti i progetti che puoi leggere. |

## Le parti del lavoro

Un Project contiene il lavoro. Ogni Project ha una chiave breve, ad esempio
`WEB`.

Un'attività è un elemento di lavoro all'interno di un progetto. Ogni Task riceve
un numero nel proprio Project, quindi un Task ha una chiave come `WEB-12`. Una
Task può avere subtask di un solo livello di profondità.

Un'etichetta contrassegna le attività in tutti i progetti dell'organizzazione.
Ad esempio, una Label **Bug** può contrassegnare Task in diversi Project.

Un traguardo contrassegna una data importante in un Progetto. I milestone
vengono visualizzati nella Timeline.

## Chi può fare cosa

Il tuo ruolo nell'Organizzazione determina ciò che puoi fare. Il progetto
determina ciò che puoi vedere.

| Role | Cosa puoi fare |
| --- | --- |
| Viewer | Puoi leggere Projects e Tasks. Puoi commentare e reagire. |
| Editor | Tutto quanto sopra. Crea e modifica Progetti e Attività. Carica file. |
| Admin e Owner | Tutto quanto sopra. Leggi tutti i Progetti privati. |

Un Viewer non può essere l'assegnatario di una Task.

Un Progetto a livello di organizzazione è visibile a tutti i membri. Un progetto
privato è visibile solo ai suoi membri, al suo creatore e agli Admins e agli
Owners.

## Tasti di scelta rapida

Premi **N** per creare una Task e **P** per creare un Project. Premi **G** e poi
una lettera per aprire una pagina, ad esempio **G** e poi **T** per My Tasks.
Premi **?** per visualizzare tutte le scorciatoie da tastiera. Consulta
[Navigate the console](/getting-started/navigating-the-console).

Premi **F** per aprire Find. Find mostra anche Tasks e Projects, nonché le
ricerche che hai utilizzato di recente. Evidenzia il testo che corrisponde alla
tua ricerca.
