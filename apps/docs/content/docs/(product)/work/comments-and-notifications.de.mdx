## Kommentare

Öffnen Sie eine Aufgabe und wählen Sie **Comments**. Geben Sie Ihren Kommentar
ein und wählen Sie **Comment**. Sie können auch Cmd+Enter oder Ctrl+Enter
drücken.

- Um ein Mitglied zu erwähnen, geben Sie `@` ein und wählen Sie das Mitglied
  aus. Ciele zeigt nur die Mitglieder an, die das Projekt lesen dürfen.
- Um Ihren Kommentar zu ändern, wählen Sie das Stiftsymbol aus. Der Kommentar
  zeigt **Edited** an.
- Um Ihren Kommentar zu löschen, wählen Sie das Papierkorb-Symbol aus. Wählen
  Sie **Undo** in der Nachricht aus, um den Kommentar wiederherzustellen. Sie
  können ihn innerhalb von 10 Minuten wiederherstellen. Ciele löscht den
  Kommentar einen Tag später endgültig. Ein gelöschter Kommentar wird nicht in
  der Aktivität der Task angezeigt.
- Um zu reagieren, wählen Sie das Smile-Symbol und ein Emoji aus. Sie können
  mehr als eine Reaktion hinzufügen.

Eine Erwähnung bleibt korrekt, wenn das Mitglied seinen Namen ändert.

## Aktivität

Öffnen Sie eine Task und wählen Sie **Activity**, um Tag für Tag zu sehen, was
sich in der Task geändert hat. Die Registerkarte **Activity** eines Projekts
zeigt alle Änderungen im Projekt an.

Wenn ein KI-Teamkollege eine Aufgabe für Sie ändert, werden in der Aktivität der
Name des Teamkollegen und Ihr Name angezeigt.

## Benachrichtigungen für Mitglieder

Ciele erstellt eine Member Notification für Sie, wenn eine andere Person eine
der folgenden Aktionen ausführt:

| Type | Action |
| --- | --- |
| Assigned | Weist Ihnen eine Aufgabe zu. |
| Mentioned | Erwähnt Sie in einem Kommentar. |
| Commented | Kommentiert eine Aufgabe, die Sie erstellt haben oder die Ihnen zugewiesen ist. |
| Updates | Ändert den Status einer Aufgabe, die Sie erstellt haben oder die Ihnen zugewiesen ist. |

Sie erhalten niemals eine Member Notification für Ihre eigenen Aktionen.

## Die Seite „Notifications“

Öffnen Sie **Notifications** in der Seitenleiste. Das Badge zeigt an, wie viele
Member Notifications Sie noch nicht gelesen haben.

- Wählen Sie eine Registerkarte aus, um einen Typ anzuzeigen, oder wählen Sie
  **All**.
- Wählen Sie **Unread** aus, um nur die Member Notifications anzuzeigen, die Sie
  noch nicht gelesen haben.
- Wählen Sie **Mark all as read** aus, um alle Member Notifications auf der
  Registerkarte als gelesen zu markieren.

Wählen Sie eine Member Notification aus, um die zugehörige Task auf der rechten
Seite zu lesen. Ciele markiert sie als gelesen. Dort können Sie den Status, den
Verantwortlichen, die Priorität und das Fälligkeitsdatum der Aufgabe ändern. Sie
können auch die neuesten Kommentare lesen und darauf antworten.

## Eine Member Notification archivieren, pausieren oder löschen

Wischen Sie eine Member Notification nach links, um **Snooze**, **Delete** und
**Archive** anzuzeigen. Wischen Sie nach rechts, um sie als gelesen oder
ungelesen zu markieren.

- **Archive** entfernt die Member Notification aus der Liste. Wischen Sie ganz
  nach links, um sie sofort zu archivieren. Wählen Sie **Undo** aus, um sie
  erneut anzuzeigen.
- **Snooze** blendet die Member Notification bis morgen 9:00 Uhr aus. Dann wird
  sie wieder in der Liste angezeigt. Wählen Sie **Undo** aus, um sie jetzt
  anzuzeigen.
- **Delete** entfernt die Member Notification dauerhaft. Ciele bittet Sie
  zunächst um eine Bestätigung. Sie können sie nicht wiederherstellen.

Sie können den Mauszeiger auch über eine Member Notification bewegen und die
Schaltfläche Menu auswählen, um diese Aktionen auszuführen. Das Badge zählt
keine archivierten oder stummgeschalteten Member Notifications.

Neue Member Notifications werden während Ihrer Arbeit auch in der unteren
rechten Ecke angezeigt. Wählen Sie **View all** aus, um die Seite
„Notifications“ zu öffnen.

Ciele löscht Member Notifications nach 90 Tagen.

## E-Mail

Ciele kann auch eine E-Mail senden, wenn Ihnen eine Aufgabe zugewiesen wird oder
wenn jemand Sie erwähnt. Beide E-Mail-Benachrichtigungen sind standardmäßig
aktiviert.

Um dies zu ändern, öffnen Sie Ihre persönlichen Einstellungen und wählen Sie
**Notifications**. Comments und Statusänderungen werden niemals per E-Mail
versendet.
