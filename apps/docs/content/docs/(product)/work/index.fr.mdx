Le groupe **Work** dans la barre latérale contient le travail de votre équipe.
Il est distinct de la configuration de l’assistant.

| Section | Utilisation |
| --- | --- |
| My Tasks | Consultez les tâches qui vous sont attribuées, dans chaque projet. |
| Notifications | Lisez et répondez aux Member Notifications qui vous sont adressées. |
| Projects | Ouvrez un projet et ses tâches, vues, fichiers et activités. |
| All tasks | Affichez toutes les tâches de tous les projets que vous êtes autorisé à consulter. |

## Les composantes du travail

Un projet contient le travail. Chaque projet dispose d’une clé courte, par
exemple `WEB`.

Une tâche est un élément de travail au sein d'un projet. Chaque tâche reçoit un
numéro dans son projet ; une tâche a donc une clé telle que `WEB-12`. Une Task
peut comporter des sous-tâches d’un seul niveau de profondeur.

Un Label permet de marquer des Tasks dans tous les Projects de l’Organization.
Par exemple, une étiquette **Bug** peut marquer des tâches dans différents
projets.

Un jalon marque une date importante dans un projet. Les jalons s’affichent sur
la Timeline.

## Qui peut faire quoi ?

Votre rôle dans l'Organisation détermine ce que vous pouvez faire. Le projet
détermine ce que vous pouvez voir.

| Role | Peut faire |
| --- | --- |
| Viewer | Lire les projets et les tâches. Commenter et réagir. |
| Editor | Tout ce qui précède. Créer et modifier des Projects et des Tasks. Importer des fichiers. |
| Admin and Owner | Tout ce qui précède. Lire tous les projets privés. |

Un Viewer ne peut pas être l’assigné d’une Task.

Un Projet à l'échelle de l'organisation est visible par tous les membres. Un
projet privé n’est visible que par ses membres, son créateur, ainsi que par les
Admins et les Owners.

## Raccourcis clavier

Appuyez sur **N** pour créer une tâche et sur **P** pour créer un projet.
Appuyez sur **G**, puis sur une lettre pour ouvrir une page ; par exemple, **G**
puis **T** pour My Tasks. Appuyez sur **?** pour afficher tous les raccourcis
clavier. Voir
[Naviguer dans la console](/getting-started/navigating-the-console).

Appuyez sur **F** pour ouvrir Find. Find affiche également les Tasks et les
Projects, ainsi que les recherches que vous avez effectuées récemment. Il met en
surbrillance le texte qui correspond à votre recherche.
