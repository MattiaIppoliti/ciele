Ein Projekt enthält Tasks, Meilensteine, Dateien, gespeicherte Ansichten und ein
Aktivitätsprotokoll.

## Ein Projekt erstellen

1. Öffnen Sie **Projects**.
2. Wählen Sie **New project** aus.
3. Geben Sie einen Namen ein. Ciele schlägt aus dem Namen einen Schlüssel vor.
   Sie können den Key ändern.
4. Wählen Sie bei Bedarf einen Status, einen Lead, Daten, eine Farbe und ein
   Symbol aus.
5. Wählen Sie die Sichtbarkeit aus.
6. Wählen Sie **Create** aus.

Der Schlüssel muss aus zwei bis fünf Buchstaben oder Ziffern bestehen. Er muss
mit einem Buchstaben beginnen. Der Schlüssel ist das Präfix jedes
Task-Schlüssels im Projekt.

## Sichtbarkeit

| Visibility | Wer kann das Projekt sehen? |
| --- | --- |
| Organization | Alle Mitglieder der Organization. |
| Private | Die Mitglieder des Projekts sowie die Admins und Owners. |

Ciele fügt den Ersteller eines privaten Projekts als Mitglied hinzu. Um
Mitglieder hinzuzufügen oder zu entfernen, wählen Sie **Share** in der
Project-Kopfzeile aus. Wenn Sie den Creator entfernen, kann der Creator das
Projekt danach nicht mehr sehen.

## Die Projektseite

Die Tabs der Project-Seite zeigen dieselben Tasks in verschiedenen Ansichten:

| Tab | Verwendung |
| --- | --- |
| **Overview** | Lesen Sie den Fortschritt, die bevorstehenden Termine und die letzten Aktivitäten. |
| **Board** | Verschieben Sie Tasks zwischen den Statusspalten. |
| **List** | Aufgaben in einer gruppierten Liste lesen und ändern. |
| **Table** | Ändern Sie schnell viele Felder in einer Tabelle. |
| **Calendar** | Aufgaben nach ihren Fälligkeitsdaten anzeigen. |
| **Timeline** | Zeigen Sie Tasks als Balken an, die sich vom Startdatum bis zum Fälligkeitsdatum erstrecken. |
| **Files** | Alle Dateien im Projekt suchen. |
| **Activity** | Lesen Sie Tag für Tag, was sich im Projekt geändert hat. |

Ein Projekt wird in der Ansicht geöffnet, die Sie zuletzt in diesem Browser
verwendet haben. Beim ersten Mal öffnet es sich in **List**.

Weitere Informationen zu den Ansichten finden Sie unter
[Tasks and views](/work/tasks).

## Dateien

Öffnen Sie die Registerkarte **Files**, um alle Dateien des Projekts anzuzeigen.
Eine Datei, die an eine Aufgabe angehängt ist, zeigt den Schlüssel dieser
Aufgabe an.

- Um eine Datei hochzuladen, wählen Sie **Upload** aus oder ziehen Sie Dateien
  per Drag-and-drop in die Ansicht. Die maximale Größe beträgt 50 MB.
- Um eine Datei an eine Aufgabe anzuhängen, öffnen Sie die Aufgabe und wählen
  Sie **Attach** aus. Sie können Dateien auch auf den Bereich „Attachments“
  ziehen.
- Um eine Vorschau eines Bildes oder einer PDF-Datei anzuzeigen, wählen Sie die
  Datei aus.
- Um eine Datei umzubenennen, herunterzuladen, den Link zu kopieren oder zu
  löschen, öffnen Sie ihr Menü.

Nur Editors, Admins und Owners können Dateien hochladen, umbenennen oder
löschen. Ein Viewer kann Dateien lesen und herunterladen.

Wenn Sie eine Task oder ein Project löschen, löscht Ciele auch die zugehörigen
Dateien.

## Meilensteine

Ein Meilenstein hat einen Namen und ein Datum. Meilensteine werden auf der
Timeline als Diamanten angezeigt. Um die Meilensteine zu ändern, öffnen Sie die
Project settings.

## Ein Projekt archivieren oder löschen

Öffnen Sie das Menü „Project“.

- Wählen Sie **Archive** aus, um das Projekt auszublenden und seine
  Arbeitsergebnisse zu behalten. Wählen Sie **Undo** in der Nachricht aus, um
  sie sofort wiederherzustellen. Sie können ein archiviertes Projekt auch später
  wiederherstellen.
- Wählen Sie **Delete** aus, um das Projekt, seine Tasks, seine Dateien und
  seine Meilensteine zu löschen. Ciele zeigt die Anzahl der Tasks und Dateien
  an, die gelöscht werden. Zum Bestätigen schieben. Diese Aktion kann nicht
  rückgängig gemacht werden.
