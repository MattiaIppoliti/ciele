Un Project contiene Tasks, milestone, file, saved views e un activity log.

## Crea un progetto

1. Apri **Projects**.
2. Seleziona **New project**.
3. Digita un nome. Ciele suggerisce una chiave basata sul nome. Puoi modificare
   la key.
4. Seleziona uno status, un lead, le date, un colore e, se necessario, un'icona.
5. Seleziona la visibilità.
6. Seleziona **Create**.

La chiave deve essere composta da due-cinque lettere o cifre. Deve iniziare con
una lettera. La chiave è il prefisso di ogni Task key nel Project.

## Visibilità

| Visibility | Chi può vedere il Progetto |
| --- | --- |
| Organization | Tutti i membri dell'Organization. |
| Private | I membri del Progetto, nonché gli Admins e gli Owners. |

Ciele aggiunge il creatore di un Progetto privato come membro. Per aggiungere o
rimuovere membri, seleziona **Share** nell'intestazione del Project. Se rimuovi
il creator, quest'ultimo non potrà più vedere il Project.

## La pagina Project

Le schede della pagina Project mostrano le stesse Tasks in visualizzazioni
diverse:

| Tab | Uso |
| --- | --- |
| **Overview** | Visualizza l'avanzamento, le prossime scadenze e l'attività recente. |
| **Board** | Sposta le attività tra le colonne di stato. |
| **List** | Leggi e modifica le attività in un elenco raggruppato. |
| **Table** | Modifica rapidamente più campi in un foglio. |
| **Calendar** | Visualizza le attività in base alle loro date di scadenza. |
| **Timeline** | Visualizza le attività come barre che vanno dalla data di inizio alla data di scadenza. |
| **Files** | Trova tutti i file nel Progetto. |
| **Activity** | Leggi cosa è cambiato nel Project, giorno per giorno. |

Un progetto si apre nella vista che hai utilizzato per ultima in questo browser.
La prima volta, si apre su **List**.

Per ulteriori informazioni sulle viste, consulta [Tasks and views](/work/tasks).

## File

Apri la scheda **Files** per visualizzare tutti i file del Progetto. Un file
allegato a una Task mostra la key di quella Task.

- Per caricare un file, seleziona **Upload** oppure trascina i file nella vista.
  La dimensione massima è di 50 MB.
- Per allegare un file a una Task, apri la Task e seleziona **Attach**. Puoi
  anche trascinare i file nell'area degli allegati.
- Per visualizzare l'anteprima di un'immagine o di un PDF, seleziona il file.
- Per rinominare, scaricare, copiare il link o eliminare un file, apri il suo
  menu.

Solo gli Editors, gli Admins e gli Owners possono caricare, rinominare o
eliminare i file. Un Viewer può leggere e scaricare i file.

Quando elimini una Task o un Project, Ciele elimina anche i relativi file.

## Traguardi

Un traguardo ha un nome e una data. I traguardi vengono visualizzati come rombi
sulla Timeline. Per modificare i traguardi, apri le impostazioni del progetto.

## Archivia o elimina un Project

Apri il menu Project.

- Seleziona **Archive** per nascondere il progetto e conservarne il lavoro.
  Seleziona **Undo** nel messaggio per ripristinarlo immediatamente. Puoi anche
  ripristinare un Progetto archiviato in un secondo momento.
- Seleziona **Delete** per eliminare il Progetto, le sue Attività, i suoi file e
  le sue milestone. Ciele mostra il numero di Tasks e di file che elimina. Fai
  scorrere per confermare. Non puoi annullare questa azione.
