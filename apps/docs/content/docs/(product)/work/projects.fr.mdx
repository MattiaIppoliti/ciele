Un projet contient des tâches, des jalons, des fichiers, des vues enregistrées
et un journal d’activité.

## Créer un projet

1. Ouvrez **Projects**.
2. Sélectionnez **New project**.
3. Saisissez un nom. Ciele propose une clé à partir du nom. Vous pouvez modifier
   la clé.
4. Sélectionnez un statut, un responsable, des dates, une couleur et, si
   nécessaire, une icône.
5. Sélectionnez la visibilité.
6. Sélectionnez **Create**.

La clé doit comporter de deux à cinq lettres ou chiffres. Elle doit commencer
par une lettre. La clé est le préfixe de chaque clé de tâche dans le projet.

## Visibilité

| Visibility | Qui peut voir le projet ? |
| --- | --- |
| Organization | Tous les membres de l’Organisation. |
| Private | Les membres du projet, ainsi que les Admins et les Owners. |

Ciele ajoute le créateur d’un Projet privé en tant que membre. Pour ajouter ou
supprimer des membres, sélectionnez **Share** dans l'en-tête du projet. Si vous
supprimez le créateur, celui-ci ne pourra plus voir le Projet par la suite.

## La page Project

Les onglets de la page Project affichent les mêmes Tasks dans différentes vues :

| Tab | Utilisation |
| --- | --- |
| **Overview** | Consultez la progression, les dates à venir et l’activité récente. |
| **Board** | Déplacez les tâches entre les colonnes de statut. |
| **List** | Consulter et modifier les tâches dans une liste groupée. |
| **Table** | Modifiez rapidement de nombreux champs dans une feuille. |
| **Calendar** | Affichez les tâches en fonction de leurs dates d’échéance. |
| **Timeline** | Affichez les tâches sous forme de barres s’étendant de leur date de début à leur date d’échéance. |
| **Files** | Recherchez tous les fichiers du projet. |
| **Activity** | Consultez les modifications apportées au projet, jour après jour. |

Un projet s’ouvre sur la vue que vous avez utilisée en dernier dans ce
navigateur. La première fois, il s’ouvre sur **List**.

Pour plus d'informations sur les vues, consultez [Tasks and views](/work/tasks).

## Fichiers

Ouvrez l'onglet **Files** pour afficher tous les fichiers du Projet. Un fichier
joint à une tâche affiche la clé de cette tâche.

- Pour importer un fichier, sélectionnez **Upload** ou déposez des fichiers dans
  la vue. La taille maximale est de 50 Mo.
- Pour joindre un fichier à une tâche, ouvrez la tâche et sélectionnez
  **Attach**. Vous pouvez également déposer des fichiers sur la zone des pièces
  jointes.
- Pour prévisualiser une image ou un PDF, sélectionnez le fichier.
- Pour renommer, télécharger, copier le lien ou supprimer un fichier, ouvrez son
  menu.

Seuls les Editors, les Admins et les Owners peuvent importer, renommer ou
supprimer des fichiers. Un Viewer peut lire et télécharger des fichiers.

Lorsque vous supprimez une tâche ou un projet, Ciele supprime également ses
fichiers.

## Jalons

Un jalon a un nom et une date. Les jalons s’affichent sous la forme de losanges
sur la Timeline. Pour modifier les jalons, ouvrez les paramètres du projet.

## Archiver ou supprimer un projet

Ouvrez le menu Project.

- Sélectionnez **Archive** pour masquer le projet tout en conservant son
  travail. Sélectionnez **Undo** dans le message pour le restaurer
  immédiatement. Vous pouvez également restaurer un Projet archivé
  ultérieurement.
- Sélectionnez **Delete** pour supprimer le projet, ses tâches, ses fichiers et
  ses jalons. Ciele affiche le nombre de Tasks et de fichiers qu’il supprime.
  Faites glisser pour confirmer. Vous ne pourrez pas annuler cette action.
