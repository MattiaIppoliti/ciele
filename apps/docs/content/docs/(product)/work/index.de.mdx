Die Gruppe **Work** in der Seitenleiste enthält die Arbeit Ihres Teams. Es ist
von der Konfiguration des Assistenten getrennt.

| Section | Verwendung |
| --- | --- |
| My Tasks | Zeigt die Ihnen zugewiesenen Tasks in jedem Projekt an. |
| Notifications | Lesen und beantworten Sie die Member Notifications, die an Sie gerichtet sind. |
| Projects | Öffnen Sie ein Projekt sowie dessen Tasks, Ansichten, Dateien und Aktivitäten. |
| All tasks | Zeigt alle Tasks in allen Projekten an, die Sie lesen dürfen. |

## Die Bestandteile der Arbeit

Ein Project enthält die Arbeit. Jedes Projekt hat einen kurzen Schlüssel, zum
Beispiel `WEB`.

Eine Task ist ein Arbeitselement in einem Projekt. Jede Aufgabe erhält in ihrem
Projekt eine Nummer, sodass eine Aufgabe einen Schlüssel wie `WEB-12` hat. Eine
Task kann Subtasks auf einer Ebene darunter enthalten.

Ein Label markiert Tasks in allen Projekten der Organisation. Beispielsweise
kann ein **Bug** Label Aufgaben in verschiedenen Projekten kennzeichnen.

Ein Meilenstein markiert ein wichtiges Datum in einem Projekt. Meilensteine
werden auf der Timeline angezeigt.

## Wer darf was tun?

Ihre Rolle in der Organisation bestimmt, was Sie tun können. Das Projekt
bestimmt, was Sie sehen können.

| Role | Can do |
| --- | --- |
| Viewer | Projekte und Tasks lesen. Kommentieren und reagieren. |
| Editor | Alle oben genannten Berechtigungen. Projekte und Tasks erstellen und ändern. Dateien hochladen. |
| Admin and Owner | Alle oben genannten Berechtigungen. Alle privaten Projekte lesen. |

Ein Viewer kann nicht der Verantwortliche einer Task sein.

Ein organisationsweites Projekt ist für alle Mitglieder sichtbar. Ein privates
Projekt ist nur für seine Mitglieder, seinen Ersteller sowie für Admins und
Owners sichtbar.

## Tastenkombinationen

Drücken Sie **N**, um eine Aufgabe zu erstellen, und **P**, um ein Projekt zu
erstellen. Drücken Sie **G** und anschließend einen Buchstaben, um eine Seite zu
öffnen, zum Beispiel **G** und dann **T** für My Tasks. Drücken Sie **?**, um
alle Tastaturkürzel anzuzeigen. Siehe
[Navigate the console](/getting-started/navigating-the-console).

Drücken Sie **F**, um Find zu öffnen. Find zeigt auch Tasks und Projects sowie
die Suchanfragen an, die Sie zuletzt verwendet haben. Es hebt den Text hervor,
der Ihrer Suche entspricht.
