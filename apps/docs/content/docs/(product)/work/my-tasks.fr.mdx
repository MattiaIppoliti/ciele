**My Tasks** affiche les tâches qui vous sont attribuées dans tous les projets
que vous pouvez consulter. Cela inclut les sous-tâches.

La ligne située sous le titre indique le nombre de Tasks ouvertes, à échéance
aujourd’hui et en retard. Elle indique également le nombre de tâches que vous
avez terminées depuis lundi.

## Groupes

My Tasks organise vos tâches en groupes fixes :

| Group | Tasks |
| --- | --- |
| Overdue | La date d’échéance est antérieure à aujourd’hui. |
| Today | La date d’échéance est aujourd’hui. |
| Upcoming | La date d’échéance est dans le futur. |
| No due date | Il n'y a pas de date d'échéance. |
| Completed | Le statut est **Done**. |

Lorsque vous ajoutez une tâche dans un groupe, Ciele vous l’attribue et définit
la date du groupe.

## Tâches marquées d'une étoile

Pour ajouter une étoile à une tâche, ouvrez-la et sélectionnez l’icône en forme
d’étoile. Sélectionnez **Starred** dans la barre d’outils pour afficher
uniquement les tâches que vous avez marquées d’une étoile. Sélectionnez à
nouveau **Starred** pour afficher toutes vos tâches.

## Calendrier

Sélectionnez **Calendar** dans la barre d'outils pour afficher vos tâches à
leurs dates d'échéance.

## Améliorations

Les améliorations qui vous sont attribuées s’affichent également en haut de My
Tasks. Sélectionnez une Improvement pour l'ouvrir.

## Le badge de la barre latérale

Le badge sur **My Tasks** indique combien de vos tâches ouvertes sont dues
aujourd’hui ou en retard.
