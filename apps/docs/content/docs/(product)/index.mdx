Ciele helps an Organization build AI Assistants for websites and applications. Each Assistant uses configured Knowledge, Flows, tools, and Help Desks.

The administrator console contains a Preview. Use Preview to test changes before you create a Publication.

## Phone and tablet navigation

On phones and tablets, the console hides the sidebar. Three icons stay at the bottom left: **Home**, **Chat**, and **Settings**.

**Home** opens a full-screen navigation picker. Drag vertically, scroll, or use the arrow keys to select a destination. Tap a destination or select **Open** to go there. Scrolling does not open pages.

The picker contains the workspace pages and Assistant sections available to your role. It also includes Organization settings for administrators and Personal settings.

The Search icon at the top left opens **Find** on phones and tablets. It remains available when **Home** is open.

Select the Organization name at the top of **Home** to see the Organizations you can switch to.

**Chat** opens the chat workspace. **Settings** opens a full-screen view on phones and touch tablets, with larger controls. The three icons remain available in Settings. Settings still asks before you leave unsaved changes. In an Assistant editor, the top-right preview icon opens the chatbot full-screen. Close the preview to return to the editor.

## Responsive tables

Console tables keep one column for each heading at every panel width. Column borders continue through the full row.

Drag a column border to change its width. Resize controls remain available in narrow panels. Headings keep their sort and filter controls.

If the columns do not fit the panel, use the horizontal scrollbar to reach them. Values stay in their own columns.

All data columns have the same minimum width of 120 pixels. The console keeps the width you select after you release the resize handle and reload the page. Selection checkboxes use the same position in the heading and every row.

**Total Results** shows the number of items that match the filters. Search and the table's filters sit on its right, alongside **Undo** / **Redo**. Use **Previous**, a page number or **Next** below the table to change pages. Where available, the page-size control changes how many rows appear at once. The total counts matching items across all pages.

These controls also appear on Settings usage tables, Insights data tables and Eval results. Imported documents can be filtered by file type. Recent Eval runs can be filtered by stage, assistant and dataset. Document tables have a visible **Actions** column for opening a document, copying its ID and, where permitted, excluding or restoring it.

In narrow panels, filters move below the result count and history controls. Active filters keep a visible highlight. The search field has a clear button. It keeps focus in the field after you clear the query.

Drag a heading handle to move a data column. Its heading and values stay highlighted while you drag. The checkbox gutter and Actions column keep their positions. Column order is saved only in your browser, separately for each member, organization and table. It does not change the server’s order. Clearing this site’s browser data resets it. Rows follow the table's sorting and pagination and cannot be reordered by dragging. Sorting applies to the result set before pagination.

Focus a column drag handle and use **Alt + Left/Right** to move it. Keyboard moves apply immediately. Click a cell, then Shift-click another cell to select a rectangle. Arrow keys move between cells. Hold Shift to extend the selection. **Copy** copies selected cells as tab-separated text. **Escape** clears the cell selection.

**Undo** and **Redo** restore view changes during the current visit: dragging, widths, supported sorting, column filters and selections. **Cmd/Ctrl + Z** undoes a change. **Cmd/Ctrl + Shift + Z** or **Ctrl + Y** redoes it. These shortcuts leave text fields' own editing history intact. Double-click an editable cell (or press Enter/F2) to change its value. Single-line editors keep the row height stable. **Escape** cancels the edit and returns focus to the cell. Names, linked assistants, FAQ content and alert category/issue/status use the existing permissions and save actions. Crawl URLs, source status and timestamps remain read-only. Members’ roles appear as colored categories and can be changed by authorized admins or owners. Ownership changes retain their confirmation. Record editing, deletion, ingestion and bulk actions retain their workflows and confirmations.


## Text changes

Dashboard counters and changing action labels use Torph to keep text continuous when values change. Text remains readable before the animation library loads. The operating system's reduced-motion setting turns off these transitions.

A successful Publication and a successful newsletter confirmation request show confetti. Completing the newsletter email confirmation shows the same effect. Failed requests show no confetti. Reduced motion turns the effect off.

## Interface sounds

The console, the public site, and Ciele Desktop play short sounds on buttons, switches, menus, and outcomes. Chat surfaces in the console also sound when you send a message and when a reply arrives. On a phone, the same moments give a short haptic.

To turn sounds off, open the account menu and set **Sounds** off. The choice is stored on this device. In Ciele Desktop, use **Interface sounds** in **Settings**. Haptics follow the reduced-motion setting of the operating system.

WebHaptics supplies touch feedback for supported devices. Selecting a destination in the Home picker gives a short tick. Rapid scrolling limits ticks, and reduced motion turns them off.

The published widget plays two sounds only. A Visitor hears one sound when the message goes, and one sound when the answer arrives. Nothing in an Assistant or an Organization configures them.

## Main tasks

- Create an Assistant and select its model.
- Add websites, files, text, and FAQs to Knowledge.
- Import structured Records and connect them to an Assistant.
- Remember durable facts for signed-in Visitors when required.
- Route messages through ordered Flows.
- Send proactive Notifications from page and chat events.
- Connect Visitors to a Help Desk.
- Publish an immutable configuration snapshot.
- Review Conversations, Improvements, Insights, Exports, Goals, and Alerts.

Start with [Getting started](/getting-started). Read [Editions](/editions) before you select a hosted or self-hosted installation.
