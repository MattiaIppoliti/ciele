## Qué hace un conector

Un **Connector** es una acción de respuesta. Ejecuta una acción en un sistema
que tu organización ya ha conectado en **Knowledge → Applications**. El flujo
almacena la conexión y la acción. Nunca almacena ninguna credencial.

Acciones disponibles:

| Proveedor | Acciones |
| --- | --- |
| ServiceNow | Create record, Update record, List records, Delete record |
| Salesforce | Obtener registros de contactos, Obtener registros de casos, Obtener registros de usuarios, Obtener registros de productos, Crear caso, Actualizar caso |
| Slack | Publicar mensaje, Crear canal, Unirse a un canal público, Mostrar lista de canales públicos |
| OneDrive | Create file, Copy file, Find files in folder, Get file content, Get file metadata, Create share link, Delete file |
| Google Drive | Create file, Copy file, Find files in folder, Get file content, Get file metadata, Create share link, Delete file |

Cada acción es una **lectura** o una **escritura**. Una acción de escritura
modifica el sistema externo.

## OneDrive y Google Drive

Una conexión a OneDrive o a Google Drive pertenece a un único Member. El
conector se ejecuta con la cuenta de ese Member. Por este motivo:

- La acción se ejecuta en **Preview** y en **Teammate chat**. No se ejecuta en
  un widget publicado.
- **Publish** rechaza un Flow que contiene un conector de Drive. El motivo
  indica el nombre del Flow.
- Las acciones de escritura necesitan un ámbito adicional. OneDrive necesita
  `Files.ReadWrite`. Google Drive necesita `drive.file`. Selecciona **Grant
  access** para añadirlo.
- Con `drive.file`, Google Drive permite que el conector modifique únicamente
  los archivos que el conector haya creado o que una persona haya abierto con
  él. Las acciones de copiar, compartir y eliminar pueden fallar en otros
  archivos.
- **Get file content** devuelve únicamente texto, hasta un tamaño limitado. Los
  archivos binarios y los documentos de Google Docs no se convierten.

## Añade un conector

1. Abre un Flow.
2. En el **Canvas**, selecciona un proveedor en **Connector** de la paleta. En
   el **Form**, selecciona **Connector** en **Add an action** y, a continuación,
   selecciona el proveedor.
3. Selecciona un **Connection**. La lista muestra las conexiones de la
   organización para ese proveedor.
4. Selecciona un **Action**.
5. Rellena los campos. Se permiten variables de plantilla como `{{user.name}}` y
   `{{workflow.message}}` cuando el campo lo indique.

Si el proveedor no tiene conexión, conéctalo primero en **Knowledge →
Applications**. En el caso de Slack, el panel puede abrir directamente la
ventana de inicio de sesión.

## Casos de Salesforce

**Create case** abre un Case en la organización de Salesforce conectada.
**Update case** modifica un Case existente.

- Los campos son **Subject**, **Description**, **Priority**, **Status**,
  **Origin**, **Requester email** y **Requester name**. Cada campo admite
  variables de plantilla.
- **Create case** establece **Origin** en `Web` de forma predeterminada. Un
  campo en blanco mantiene el valor predeterminado de Salesforce.
- **Requester email** y **Requester name** se introducen en los campos web email
  y web name del Case. Un Visitor que no sea un Salesforce Contact puede abrir
  un Case.
- **Update case** necesita un **Case id**. Normalmente, esto es
  `{{connector.case_id}}` de un **Create case** anterior. Solo cambian los
  campos que rellenas.
- El usuario de Salesforce que conectó la aplicación debe tener el permiso
  **Create** en los casos para **Create case** y el permiso **Edit** para
  **Update case**. La conexión no necesita ningún ámbito nuevo.

Si Salesforce rechaza el caso, por ejemplo porque un campo obligatorio está
vacío o porque falla una regla de validación, la acción falla. El mensaje de
Salesforce se muestra en **Run node** y en el seguimiento de la conversación. El
Flow continúa con su regla de error habitual.

Después de una escritura, Ciele lee el número del caso. Si esa lectura falla, la
escritura sigue completándose correctamente y conserva el ID del caso y el
enlace. El número está vacío. Usa **Get Case records** con ese ID y el campo
`CaseNumber` para leerlo más tarde.

## Campos cargados desde el sistema

Algunos campos cargan sus valores desde el sistema conectado: tablas y columnas
de ServiceNow, campos de Salesforce, listas de selección de casos de Salesforce
(Priority, Status, Origin) y canales de Slack. Selecciona **Load options** para
recuperarlos. Aun así, puedes escribir un valor.

## Requiere configuración

Un nodo Connector muestra **Needs setup** cuando:

- No has seleccionado la acción ni la conexión.
- Un campo obligatorio está vacío.
- A la conexión le falta un ámbito que la acción necesita. Selecciona **Grant
  access** para volver a ejecutar el inicio de sesión del proveedor con los
  ámbitos faltantes añadidos.
- Es necesario volver a establecer la conexión.

## Salidas

Una acción escribe sus resultados en variables de plantilla para acciones
posteriores dentro del mismo Flow. Los nombres comienzan por `connector.`:

| Acción | Variables |
| --- | --- |
| ServiceNow: Crear o actualizar registro | `{{connector.sys_id}}`, `{{connector.number}}`, `{{connector.url}}` (enlace al registro) |
| ServiceNow List records | `{{connector.count}}`, `{{connector.first_sys_id}}`, `{{connector.records}}` |
| Salesforce: Obtener registros | `{{connector.count}}`, `{{connector.first_id}}`, `{{connector.records}}`, `{{connector.api_usage}}` |
| Salesforce: Crear o actualizar caso | `{{connector.case_id}}`, `{{connector.case_number}}`, `{{connector.case_url}}` (un enlace al caso en Salesforce) |
| Slack Publicar mensaje | `{{connector.ts}}`, `{{connector.channel}}` |
| Slack Crear o unirse a un canal | `{{connector.id}}`, `{{connector.name}}` |
| Drive Crear u obtener metadatos, Copiar en Google Drive | `{{connector.id}}`, `{{connector.name}}`, `{{connector.web_url}}` |
| OneDrive Copy | `{{connector.status}}`, `{{connector.monitor_url}}` (la copia se ejecuta en segundo plano) |
| Drive Buscar archivos | `{{connector.count}}`, `{{connector.first_id}}`, `{{connector.items}}` |
| Drive Get content | `{{connector.content}}` |
| Drive Crear enlace para compartir | `{{connector.url}}` |

`{{connector.ok}}` es `true` o `false` después de cada acción. Una acción
**Message** después del conector puede mostrar estos valores.

## Lo que ve el visitante

- Una operación **write** que se completa con éxito muestra el **Success
  message**. El valor predeterminado es una confirmación breve.
- Una acción **read** que se completa correctamente no muestra nada. Usa una
  acción Message para mostrar los resultados.
- Cualquier fallo muestra el **Failure message**. El error del proveedor nunca
  se muestra al Visitor. El Editor lo ve en **Run node** y, en el caso de una
  conexión caducada, en **Alerts**.

## Ejecuta el nodo

Selecciona el nodo y, a continuación, **Run node**. La consola realiza la
llamada real con valores de ejemplo.

- Una **read** se ejecuta inmediatamente.
- Una operación **write** te pide confirmación primero, porque modifica el
  sistema externo.

**Test connection** comprueba que el token de la conexión siga funcionando.

## Publicar

Publicar rechaza un Flow cuyo Connector:

- indica una conexión que ya no existe,
- indica una conexión personal (las cuentas de OneDrive o Google Drive
  pertenecen a un solo miembro),
- indica una conexión que carece de los ámbitos de la acción o que necesita
  volver a conectarse.

El motivo da nombre al Flow. Corrige la conexión o el Flow y, a continuación,
vuelve a publicarlo.

## Conexiones caducadas

Cuando una llamada falla porque el proveedor ha rechazado el token, la conexión
se marca como **Reauthorization required** y se genera una alerta
**Integration**. Vuelve a conectar la aplicación en **Knowledge →
Applications**. La alerta se elimina al volver a conectar.

## API, CLI y MCP

- `GET /api/v1/applications/connections` enumera las conexiones sin
  credenciales.
- `GET /api/v1/applications/connectors` muestra el catálogo.
- `POST /api/v1/applications/connections/{id}/reconsent` devuelve la unión de
  ámbitos y la URL que debes abrir para concederla.

Las mismas operaciones son `ciele applications list|connectors|reconsent` y las
acciones de la herramienta MCP `manage_integrations` `application_list`,
`application_connectors`, `application_reconsent`.
