---
title: Azioni del flusso
description: Seleziona le azioni di risposta che il runtime corrente può eseguire.
---

Le azioni del flusso di messaggi vengono eseguite in ordine. Le azioni non
generative utilizzano il contenuto configurato senza riscrivere il modello.

## Azioni disponibili

| Azione | Utilizzo del modello | Comportamento attuale |
| --- | :---: | --- |
| Messaggio | No | Emette il testo configurato parola per parola. |
| Pulsante | No | Aggiunge un pulsante di collegamento o un pulsante che invia testo in chat. |
| Cerca nella conoscenza | Sì | Esegue il ciclo dell'agente Knowledge e restituisce citazioni. |
| Follow-up | Opzionale | Utilizza le domande configurate o genera domande suggerite. |
| Iframe | No | Incorpora nel chat il contenuto esterno configurato. |
| Richiesta API | No | Chiama un endpoint HTTP configurato e mappa il suo risultato. |
| Invia e-mail | No | Invia un'e-mail tramite il trasporto Resend configurato. |
| Miglioramento | No | Crea un Miglioramento per la risposta applicabile. |
| Passaggio di consegne | Dipende dalla destinazione | Continua una volta in un altro Assistente pubblicato. |

Anche il flusso di interazione di base integrato utilizza **Basic reply**. La
raccomandazione dell'Help Desk utilizza un'azione di runtime che il selettore di
azioni dirette non mostra.

## Messaggio

Inserisci il testo esatto che Ciele deve inviare. Il runtime non parafrasa
questo testo.

## Risposta di base

La risposta di base gestisce brevi saluti, ringraziamenti e congedi. Utilizza
una chiamata al modello e non utilizza strumenti di Knowledge, citazioni o
eventi di Thinking.

Inserisci il testo dell'azione fissa per saltare il modello. Lo stesso testo
fornisce il fallback quando non è disponibile alcun modello di chat.

## Cerca nella Knowledge Base

Search knowledge utilizza gli strumenti Knowledge disponibili fino al limite di
passaggi del runtime. Può restituire citazioni di fonti nominate e passaggi di
ragionamento.

Utilizza le impostazioni per le query non risolte per offrire l'escalation
all'Help Desk o creare un Miglioramento.

## Pulsante

Configura un'etichetta e una destinazione. Una destinazione può aprire un link o
inviare il testo configurato nella Conversazione.

## Domande di follow-up

Inserisci domande di follow-up fisse o abilita la generazione. Le domande di
follow-up generate utilizzano il modello veloce configurato.

## Iframe

Configura il titolo, il link HTTPS, le preferenze della lightbox e l'altezza. Il
sito host può comunque impedire l'incorporamento tramite le sue intestazioni di
sicurezza.

## Richiesta API

Configura il metodo, l'endpoint, l'autenticazione, le intestazioni, i parametri
di query, il corpo JSON e il percorso JSON di risposta.

Le variabili del template possono fornire valori dal contesto corrente. Usa
**Test API** prima di salvare il Flow.

L'azione può mostrare messaggi separati di successo e di errore. Le regole di
uscita della rete si applicano comunque all'URL finale.

## Invia e-mail

Configura i destinatari, l'oggetto, il corpo e il comportamento di risposta. Il
runtime utilizza Resend quando il suo trasporto configurato.

Quando il trasporto non è configurato, l'azione segnala di non aver inviato
l'e-mail. Non conferma la consegna.

## Miglioramento

L'azione crea un'attività di miglioramento. Non aggiunge da sola un testo di
risposta visibile.

## Passaggio di consegne

Seleziona un altro Assistente nella stessa Organizzazione. La destinazione deve
avere una Pubblicazione corrente.

Ciele fa passare lo stesso messaggio del Visitatore attraverso l'Assistente di
destinazione una sola volta. Non prosegue con un secondo passaggio di consegne
da quel turno di destinazione.

## Ordine delle azioni

Inserisci il testo introduttivo prima di Cerca nella knowledge base. Metti i
pulsanti e i follow-up dopo la risposta che supportano.
