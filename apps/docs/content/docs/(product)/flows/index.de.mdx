title: Flows

Ein Flow enthält einen Trigger, verfügbare Bedingungen und geordnete Aktionen.
Der Router verarbeitet aktivierte Flows in der konfigurierten Reihenfolge.

## Nachrichten-Flows

Der Trigger **User sends a message** verwendet die Intent Classification. Ein
Modellklassifikator wählt den am besten geeigneten Flow aus, wenn ein Modell
verfügbar ist.

Der Keyword Router bietet einen Offline- und einen Fehler-Fallback. Beide Router
verwenden denselben Candidate Filter.

Der gesperrte **Default behavior** Flow bleibt an letzter Stelle. Es verarbeitet
eine berechtigte Nachricht, wenn kein früherer Flow ausgewählt wird.

## Proaktive Flows

Diese Trigger klassifizieren keine Nachricht:

- **On page load**
- **Time on page**
- **Chat opens**

Ein proaktiver Flow hat keine Bedingungen und enthält eine Notification-Aktion.
Siehe [Notifications](/flows/notifications).

## Reihenfolge der Flows

Ordnen Sie spezifische Nachrichten-Flows vor allgemeinen Nachrichten-Flows an.
Die Reihenfolge steuert auch den integrierten Shortcut „Basic Interaction“.

Ein früher übereinstimmender benutzerdefinierter Flow kann eine
Höflichkeitsnachricht vor dem integrierten Basic Interaction Flow verarbeiten.

Wenn [Study Mode](/assistants/tools-and-skills#enable-study-mode) aktiviert ist,
wird eine Anfrage für eine Lernübung direkt an den Study Mode Flow
weitergeleitet. Für diese Anfrage wird keine Intent-Klassifizierung ausgeführt.
