title: Einen Flow erstellen
description: Konfigurieren Sie einen Trigger, die verfügbaren Bedingungen und die in der Reihenfolge festgelegten Response Actions.
---

## Den Flow erstellen

1. Öffnen Sie einen Assistant.
2. Wählen Sie **Flows** aus.
3. Erstellen Sie einen Flow.
4. Geben Sie einen eindeutigen Namen und eine aussagekräftige Beschreibung ein.
5. Wählen Sie einen Trigger aus.

Die Beschreibung hilft der Intent Classification, einen Message Flow
auszuwählen. Geben Sie die Absicht des Visitors und den erforderlichen Scope an.

Ein Flow wird durch eine Nachricht eines Besuchers, durch ein Widget-Ereignis
oder durch eine eingehende HTTP-Anfrage ausgelöst. Die Widget-Ereignisse sind
page load, time on page und chat opens. Der Trigger bestimmt, welche Bedingungen
und welche Aktionen der Flow verwenden darf. Siehe
[HTTP and webhooks](/flows/http) für den eingehenden Trigger.

## Nachrichtenbedingungen hinzufügen

Message Flows unterstützen die folgenden Bedingungstypen:

| Condition | Aktuelles Verhalten |
| --- | --- |
| Conversation context | Fügt der Intent Classification semantische Beispiele hinzu. Es handelt sich nicht um ein Hard Gate. |
| URL | Wendet ein Hard Gate vom Typ Matches, Contains oder Regex an. |
| Schedule | Wendet ein Hard Gate für Start, Ende und Zeitzone an. |

Wählen Sie **Any condition matches** oder **All conditions match**, wenn der
Flow mehr als eine Bedingung enthält.

Die Bedingungen URL und Schedule entfernen einen nicht qualifizierten Flow vor
der Klassifizierung. Eine erfüllte Bedingung zwingt den Flow nicht dazu,
ausgewählt zu werden.

## Antwortaktionen hinzufügen

1. Fügen Sie die erforderlichen Aktionen hinzu.
2. Ordnen Sie die Actions in ihrer Ausführungsreihenfolge an.
3. Konfigurieren Sie jedes Pflichtfeld.
4. Speichern Sie den Flow.
5. Testen Sie eine übereinstimmende und eine nicht übereinstimmende Nachricht.

Bewegen Sie den Mauszeiger über einen Action-Knoten und wählen Sie **Copy step**
aus, um unmittelbar danach eine identische Aktion einzufügen. Die Kopie hat ihre
eigenen Einstellungen: Das Bearbeiten, Verschieben oder Löschen der Kopie hat
keine Auswirkungen auf das Original. Die Funktion „Copy“ ist auch in der
Form-Ansicht und im Menü „Step options“ des Knotens verfügbar. Verwenden Sie
**Undo** oder **Redo**, um eine Änderung rückgängig zu machen oder
wiederherzustellen. Ein Flow unterstützt bis zu 20 Actions.

Der Editor begrenzt proaktive Flows auf eine einzige Notification-Aktion, sodass
Copy für diese Flows nicht verfügbar ist. Der Server wendet dieselbe Regel an,
wenn er einen Flow speichert oder versendet.

## Reihenfolge der Flows ändern

Ziehen Sie einen Flow, um die Priorität der Nachrichtenweiterleitung zu ändern.
Setzen Sie mit der Tastatur den Fokus auf den Handle eines Flows und drücken Sie
die Pfeiltaste nach oben oder nach unten. Der Flow „Default behavior“ bleibt an
letzter Stelle.

Deaktivieren Sie einen Flow, wenn Sie dessen Routing stoppen müssen, ohne seine
Konfiguration zu löschen.
