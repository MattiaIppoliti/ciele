---
title: Flux
description: Acheminez les messages et les événements proactifs vers des actions de réponse ordonnées.
---

Un Flow contient un déclencheur, des conditions disponibles et des actions
ordonnées. Le routeur traite les Flows activés dans l'ordre configuré.

## Flux de messages

Le déclencheur **User sends a message** utilise la classification des intentions
(Intent Classification). Un classificateur de modèle sélectionne le meilleur
Flow éligible lorsqu'un modèle est disponible.

Le routeur de mots-clés fournit un mécanisme de repli en cas de déconnexion ou
d'erreur. Les deux routeurs utilisent le même filtre de candidats.

Le Flow verrouillé **Default behavior** reste en dernière position. Il traite un
message éligible lorsqu'aucun Flow antérieur n'est retenu.

## Flux proactifs

Ces déclencheurs ne classent pas un message :

- **On page load**
- **Time on page**
- **Chat opens**

Un Flow proactif n'a pas de conditions et contient une seule action
Notification. Voir [Notifications](/flows/notifications).

## Ordre des flux

Placez les Flows de messages spécifiques avant les Flows de messages généraux.
L'ordre contrôle également le raccourci intégré Basic Interaction.

Un Flow personnalisé correspondant, placé plus haut dans l'ordre, peut prendre
en charge un message de courtoisie avant le Flow Basic Interaction intégré.

Lorsque le [Study Mode](/assistants/tools-and-skills#enable-study-mode) est
activé, une demande d'exercice d'étude est directement dirigée vers le Study
Mode Flow. La classification des intentions n'est pas exécutée pour cette
requête.
