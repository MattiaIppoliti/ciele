---
title: Acciones de flujo
description: Selecciona las acciones de respuesta que el tiempo de ejecución actual puede ejecutar.
---

Las acciones de Message Flow se ejecutan en orden. Las acciones no generativas
utilizan el contenido configurado sin reescribir el modelo.

## Acciones disponibles

| Acción | Uso del modelo | Comportamiento actual |
| --- | :---: | --- |
| Mensaje | No | Emite el texto configurado textualmente. |
| Botón | No | Añade un botón de enlace o un botón que envía texto al chat. |
| Buscar conocimiento | Sí | Ejecuta el bucle del agente de conocimiento y devuelve citas. |
| Seguimientos | Opcional | Utiliza las preguntas configuradas o genera preguntas sugeridas. |
| Iframe | No | Incrusta en el chat el contenido externo configurado. |
| Solicitud de API | No | Llama a un punto de conexión HTTP configurado y mapea su resultado. |
| Enviar correo electrónico | No | Envía correo a través del transporte Resend configurado. |
| Mejora | No | Crea una Mejora para la respuesta correspondiente. |
| Traspaso | Depende del destino | Continúa una vez en otro Asistente publicado. |

El flujo de interacción básico integrado también utiliza **Basic reply**. La
recomendación de Help Desk utiliza una acción de tiempo de ejecución que el
selector de acciones directas no muestra.

## Mensaje

Introduce el texto exacto que Ciele debe enviar. El tiempo de ejecución no
parafrasea este texto.

## Respuesta básica

La respuesta básica gestiona saludos breves, agradecimientos y despedidas.
Utiliza una llamada al modelo y no emplea herramientas de conocimiento, citas ni
eventos de pensamiento.

Introduce el texto de acción fija para omitir el modelo. El mismo texto
proporciona la respuesta alternativa cuando no hay ningún modelo de chat
disponible.

## Búsqueda de conocimiento

Search knowledge utiliza las herramientas de conocimiento disponibles hasta el
límite de pasos de tiempo de ejecución. Puede devolver citas de fuente con
nombre y pasos de razonamiento.

Utiliza su configuración de consultas no resueltas para derivar el caso al
servicio de asistencia o crear una mejora.

## Botón

Configura una etiqueta y un destino. Un destino puede abrir un enlace o enviar
texto configurado a la Conversación.

## Preguntas de seguimiento

Introduce preguntas de seguimiento fijas o habilita su generación. Las preguntas
de seguimiento generadas utilizan el modelo rápido configurado.

## Iframe

Configura el título, el enlace HTTPS, la preferencia de lightbox y la altura. El
sitio de alojamiento aún puede impedir la incrustación mediante sus encabezados
de seguridad.

## Solicitud de API

Configura el método, el punto de conexión, la autenticación, los encabezados,
los parámetros de consulta, el cuerpo JSON y la ruta JSON de respuesta.

Las variables de plantilla pueden proporcionar valores del contexto actual. Usa
**Test API** antes de guardar el flujo.

La acción puede mostrar mensajes separados de éxito y error. Las reglas de
salida de red siguen aplicándose a la URL final.

## Enviar correo electrónico

Configura los destinatarios, el asunto, el cuerpo y el comportamiento de
respuesta. El tiempo de ejecución utiliza Resend cuando su transporte está
configurado.

Cuando el transporte no está configurado, la acción informa de que no ha enviado
el correo electrónico. No confirma la entrega.

## Mejora

La acción crea una tarea de mejora. No añade por sí misma texto de respuesta
visible.

## Traspaso

Selecciona otro Asistente de la misma Organización. El destino debe tener una
Publicación actual.

Ciele pasa el mismo mensaje de visitante por el Asistente de destino una sola
vez. No continúa con un segundo traspaso desde ese turno de destino.

## Orden de las acciones

Coloca el texto de contexto antes de Buscar en el conocimiento. Coloca los
botones y los seguimientos después de la respuesta a la que dan soporte.
