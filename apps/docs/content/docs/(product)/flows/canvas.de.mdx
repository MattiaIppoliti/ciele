## Canvas öffnen

1. Öffnen Sie einen Assistant.
2. Wählen Sie **Flows** aus.
3. Öffnen Sie einen Flow oder erstellen Sie einen.
4. Wählen Sie **Canvas** in der Kopfzeile aus.

Wählen Sie **Form** aus, um zum dreistufigen Formular zurückzukehren. Beide
Ansichten bearbeiten denselben nicht gespeicherten Entwurf. Beim Wechseln der
Ansichten bleiben alle Änderungen erhalten. Die Konsole merkt sich Ihre letzte
Auswahl in diesem Browser.

## Entwürfe

Ihre nicht gespeicherten Änderungen werden in diesem Browser in beiden Ansichten
als Entwurf aufbewahrt. Die Kopfzeile zeigt **Draft saved** an, solange es
Änderungen gibt, die beibehalten werden sollen. Verlassen Sie den Flow, laden
Sie die Seite neu oder schließen Sie die Registerkarte – der Entwurf wartet,
wenn Sie zurückkehren.

Der Entwurf gehört nur Ihnen: Er wird nicht an den Server gesendet, sodass ihn
niemand sonst sieht und nichts davon ausgeführt wird. Wenn Sie den Flow
speichern oder löschen, wird der Entwurf verworfen. Wenn Sie bis zum
Ausgangspunkt zurücksetzen, wird der Entwurf ebenfalls gelöscht, da dann nichts
mehr zu speichern ist.

Wählen Sie **Discard** neben **Draft saved**, um zum gespeicherten Flow
zurückzukehren. Wählen Sie **Undo** aus, um die Änderungen wiederherzustellen.

## Lesen Sie die Chain

Das Canvas zeichnet den Flow von links nach rechts:

| Node | Bedeutung |
| --- | --- |
| Start | Der Trigger. Zeigt den Namen des Triggers an. Bei Time on page wird die Verzögerung angezeigt. |
| Conditions | Die optionalen Bedingungen und ihre Logik. Wird bei proaktiven Triggern oder dem Default-Verhalten nicht angezeigt. |
| Action | Eine Antwortaktion, in der Reihenfolge, in der der Flow sie ausführt. |

Ein **Needs setup**-Badge kennzeichnet einen Knoten, bei dem erforderliche
Einstellungen fehlen. Der Flow kann erst gespeichert werden, wenn alle Badges
verschwunden sind.

## Einen leeren Flow starten

Ein neuer Flow öffnet sich als leere Arbeitsfläche mit einem Feld in der Mitte:
**What should this flow do?** Geben Sie eine Beschreibung ein und drücken Sie
die Eingabetaste, damit der Flows Agent den Flow entwirft. Oder wählen Sie
**build it by hand**, um den Start-Knoten zu platzieren und selbst Schritte
hinzuzufügen. Die Knoten werden angezeigt, sobald der Flow einen Trigger oder
eine Aktion hat.

## Einen Knoten hinzufügen

Es gibt zwei Möglichkeiten, einen Schritt hinzuzufügen.

**From a node.** Halten Sie den Mauszeiger über einen beliebigen Knoten. Am
rechten Rand erscheint ein kleines **+**, das dasselbe Menü öffnet. Die Position
des **+** bestimmt, wo der Schritt eingefügt wird. Ausgehend von einem Knoten in
der Mitte der Kette wird der Schritt nach diesem Knoten eingefügt. Vom letzten
Knoten aus wird er am Ende hinzugefügt. Der neue Schritt wird zur Konfiguration
geöffnet.

**From the bottom bar.** Wählen Sie **Add a step** in der Leiste am unteren Rand
des Canvas aus. Durchsuchen Sie die Liste oder filtern Sie sie mit den Chips
**Trigger**, **Action** und **Connector**. Ziehen Sie eine Zeile auf die Canvas,
um sie zwischen zwei Schritten einzufügen, anstatt sie am Ende hinzuzufügen.

Beide bieten nur die Schritte an, die der aktuelle Trigger ausführen kann, und
keiner zeigt einen Schritt an, den der Flow bereits enthält. Ein Trigger wird
nur angezeigt, solange der Flow keinen Trigger hat. Um einen zu ersetzen, wählen
Sie den Start-Knoten aus und ändern Sie ihn dort. Die Konsole zeigt Ihnen dann
an, was dadurch entfernt wird.

## Vom Canvas aus fragen

Sobald der Flow einen Schritt enthält, zeigt die Leiste unten ein Feld für den
Flows Agent an. Geben Sie ein, was Sie ändern möchten, und drücken Sie die
Eingabetaste. Der Agent öffnet sich im Bereich auf der rechten Seite, und Ihre
Nachricht ist das erste, worauf er antwortet.

## Einen Knoten konfigurieren

Wählen Sie einen Knoten aus. Rechts über dem Canvas erscheint ein schwebendes
Panel mit zwei Tabs:

- **Configure** zeigt dieselben Felder wie das Formular für diesen Schritt.
- **Run node** führt den Knoten allein aus. API request sendet eine Testanfrage
  mit Beispielwerten. Search knowledge öffnet die Vorschau, damit Sie eine Frage
  stellen können.

Sein Header enthält drei Steuerelemente. Die drei Punkte enthalten **Reset
position**, **Open Preview** und **Remove step**. Die Pfeile vergrößern den
Bereich, sodass er das Fenster ausfüllt, und verkleinern ihn wieder. Das Kreuz
schließt das Panel. Wenn das Panel das Fenster ausfüllt, verlässt das Kreuz
zuerst den Vollbildmodus.

Diese beiden Steuerelemente befinden sich ebenfalls unten links, unter den
Zoom-Schaltflächen, wenn ein Schritt ausgewählt ist. Wenn das Panel im
Vollbildmodus ist, befindet sich seine eigene Kopfzeile in der Ecke, abseits der
Canvas-Steuerelemente. **Open full screen** ist ebenfalls im Kontextmenü eines
Knotens zu finden.

## Klicken Sie mit der rechten Maustaste, um Aktionen anzuzeigen

Klicken Sie mit der rechten Maustaste auf die Leinwand, um die
Ansichtssteuerungen anzuzeigen: **Add a step**, **Fit to view**, **Tidy up**,
**Switch to vertical layout** und **Open Preview**. Klicken Sie mit der rechten
Maustaste auf einen Knoten, und das Menü bezieht sich ebenfalls auf diesen
Schritt. **Configure** öffnet seine Einstellungen. **Open full screen** öffnet
ihn im Vollbildmodus. **Reset position** stellt ihn auf das automatische Layout
zurück. **Remove step** löscht ihn. `Delete` entfernt auch den ausgewählten
Schritt.

Auf einem Touchscreen halten Sie den Finger gedrückt, anstatt mit der rechten
Maustaste zu klicken.

## Auf dem Canvas navigieren

Scrollen Sie, um die Leinwand zu verschieben. Auf einem Trackpad geschieht dies
durch eine Zwei-Finger-Wischbewegung in beliebige Richtung. Zum Zoomen zwei
Finger zusammenziehen oder `Ctrl` gedrückt halten und scrollen. Ziehen Sie auf
einem Touchscreen an einer beliebigen Stelle auf dem Canvas, um ihn zu
verschieben.

Mit der Maus legen die beiden Schaltflächen am unteren Rand des Canvas fest, was
beim Ziehen auf leerem Bereich geschieht. **Select** zeichnet einen Rahmen um
Knoten. **Hand** verschiebt das Canvas.

## Reihenfolge ändern und anordnen

- Ziehen Sie einen Action-Knoten an seinem Nachbarn vorbei, um die Reihenfolge
  der Actions zu ändern. Die Reihenfolge entspricht der Reihenfolge, in der der
  Flow sie ausführt.
- Um eine Aktion mit der Tastatur zu verschieben, öffnen Sie das
  Drei-Punkte-Menü des Schritts und wählen Sie **Move earlier** oder **Move
  later**. Jede Aktion in der Formularansicht verfügt über dieselben beiden
  Schaltflächen.
- Ziehen Sie einen Knoten ein kleines Stück, um die Darstellung zu ordnen. Die
  Position wird nur in Ihrem Browser gespeichert.
- Verwenden Sie die Steuerelemente unten links, um zu zoomen und den Flow an das
  Fenster anzupassen. Während ein Schritt ausgewählt ist, enthalten sie auch die
  Steuerelemente für den Vollbildmodus und das Drei-Punkte-Menü dieses Schritts.
- **Tidy up** (`Shift`+`T`) verwirft alle Feinjustierungen und stellt die Kette
  wieder auf das automatische Layout zurück.
- **Switch to vertical layout** lässt die Kette vertikal über die Leinwand
  verlaufen, statt horizontal. Ein langer Flow lässt sich auf diese Weise besser
  lesen. Jede Ausrichtung behält ihre eigene Anordnung bei, sodass Sie beim
  Zurückwechseln das zuletzt verwendete Layout wiederfinden. Die Auswahl wird in
  Ihrem Browser gespeichert.

## Den Flows Agent fragen

Der **Flows Agent** erstellt und bearbeitet den offenen Flow anhand einer
Beschreibung. Es handelt sich um einen KI-Teammate, den die Konsole für jeden
Assistenten erstellt. Es wird nicht in **Teammates** angezeigt.

So öffnen Sie es:

- Geben Sie auf einer leeren Canvas in das Feld in der Mitte ein, was der Flow
  tun soll, und drücken Sie die Eingabetaste.
- Wählen Sie auf einer beliebigen Canvas im Header **Agent** aus.

Der Agent wird im Panel auf der rechten Seite geöffnet, wo sich die
Live-Vorschau befindet, und funktioniert auf die gleiche Weise. Ziehen Sie den
linken Rand, um die Größe zu ändern. Verwenden Sie die Steuerelemente in der
Kopfzeile für frühere Konversationen, einen neuen Chat und den Vollbildmodus.
Die beiden teilen sich diesen Bereich, sodass das Öffnen des Agents die Preview
ausblendet und das Öffnen der Preview den Agent ausblendet. Wählen Sie **Show
preview** am rechten Rand, um zurückzuwechseln.

Der Agent sieht den geöffneten Entwurf, die anderen Flows des Assistenten, seine
Help Desks, FAQs und Application Connections. Jede Änderung, die er vornimmt,
wird als ein einzelner Schritt im nicht gespeicherten Entwurf erfasst. Sie
können dies mit **Undo** rückgängig machen. Der Agent speichert niemals. Wählen
Sie **Save changes** oder **Create flow**, wenn der Entwurf korrekt ist.

Wenn die Anfrage eine zweite Absicht beschreibt, schlägt der Agent einen
separaten Flow vor, anstatt den geöffneten zu ändern. Der Vorschlag wird als
Karte angezeigt. Wählen Sie **Create and open**, um diesen Flow zu erstellen,
oder **Dismiss**.

Nur Editors und Admins können den Agent verwenden. Frühere Konversationen über
denselben Flow finden Sie unter der Schaltfläche „history“ im Header des Panels.
Der Agent nutzt dieselben Provider Connections wie Ihre Teammates,
einschließlich Ihres eigenen persönlichen Abonnements, sofern Sie eines
verbunden haben.

## Rückgängig machen und wiederholen

Verwenden Sie **Undo** und **Redo** in der Kopfzeile oder `Ctrl+Z` und
`Ctrl+Shift+Z` (`Cmd` unter macOS). Undo betrifft nicht gespeicherte Änderungen
in beiden Ansichten. Durch das Speichern des Flows wird der Verlauf nicht
gelöscht. Das Verlassen des Flows hingegen schon.

## Speichern

Die Fußzeile zeigt dieselben drei Kontrollkästchen wie das Formular. Wählen Sie
**Save changes** oder **Create flow**. Der Canvas speichert denselben Flow, den
das Formular speichert.
