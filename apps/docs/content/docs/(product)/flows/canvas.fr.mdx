title: Flow Canvas
description: Modifiez un Flow sous la forme d'une chaîne de nœuds, avec les mêmes champs que ceux du formulaire.

## Ouvrir le canvas

1. Ouvrez un Assistant.
2. Sélectionnez **Flows**.
3. Ouvrez un Flow, ou créez-en un.
4. Sélectionnez **Canvas** dans l'en-tête.

Sélectionnez **Form** pour revenir au formulaire en trois étapes. Les deux vues
permettent d'éditer un même brouillon non enregistré. Le changement de vue
conserve toutes les modifications. La console mémorise votre dernier choix sur
ce navigateur.

## Brouillons

Vos modifications non enregistrées sont conservées dans ce navigateur sous forme
de brouillon, dans les deux vues. L'en-tête affiche **Draft saved** tant qu'il y
a des modifications à conserver. Quittez le Flow, rechargez la page ou fermez
l'onglet : le brouillon vous attendra à votre retour.

Le brouillon vous appartient exclusivement : il n'est pas envoyé au serveur,
donc personne d'autre ne le voit et rien n'est exécuté à partir de lui.
L'enregistrement du Flow, ou sa suppression, efface le brouillon. Le fait
d'annuler jusqu'au point de départ efface également le brouillon, car il ne
reste plus rien à conserver.

Sélectionnez **Discard** à côté de **Draft saved** pour revenir au Flow
enregistré. Sélectionnez **Undo** pour restaurer les modifications.

## Lisez la chaîne

Le canevas dessine le Flow de gauche à droite :

| Node | Signification |
| --- | --- |
| Start | Le déclencheur. Affiche le nom du déclencheur. Pour Time on page, indique le délai. |
| Conditions | Les conditions facultatives et leur logique. Non affiché pour les déclencheurs proactifs ou le comportement par défaut. |
| Action | Une action de réponse, dans l'ordre dans lequel le Flow les exécute. |

Un badge **Needs setup** indique un nœud auquel il manque des paramètres
obligatoires. Le Flow ne peut pas être enregistré tant que tous les badges n'ont
pas disparu.

## Démarrer un Flow vide

Un nouveau Flow s'ouvre sous la forme d'une toile vierge avec un seul bloc au
centre : **What should this flow do?** Saisissez une description et appuyez sur
Entrée pour laisser le Flows Agent rédiger le Flow. Ou sélectionnez **build it
by hand** pour placer le nœud Start et ajouter vous-même les étapes. Les nœuds
apparaissent dès que le Flow dispose d'un trigger ou d'une action.

## Ajouter un nœud

Il existe deux façons d'ajouter une étape.

**From a node.** Maintenez le pointeur sur n'importe quel nœud. Un petit **+**
apparaît sur son bord droit et ouvre le même menu. L'emplacement du **+**
détermine où l'étape est insérée. À partir d'un nœud situé au milieu de la
chaîne, l'étape est insérée après ce nœud. À partir du dernier nœud, il est
ajouté à la fin. La nouvelle étape s'ouvre pour la configuration.

**From the bottom bar.** Sélectionnez **Add a step** dans la barre située en bas
du canevas. Recherchez dans la liste ou filtrez-la à l'aide des puces
**Trigger**, **Action** et **Connector**. Faites glisser une ligne sur le
canevas pour l'insérer entre deux étapes au lieu de l'ajouter à la fin.

Les deux proposent uniquement les étapes que le déclencheur actuel peut
exécuter, et aucun des deux n'affiche d'étape déjà présente dans le Flow. Un
déclencheur n'apparaît que lorsque le Flow n'en a pas. Pour en remplacer un,
sélectionnez le nœud Start et modifiez-le à cet endroit. La console vous indique
ensuite ce que cette action supprime.

## Demander depuis le canevas

Une fois que le Flow comporte une étape, la barre située en bas affiche un champ
destiné au Flows Agent. Saisissez ce que vous souhaitez modifier, puis appuyez
sur Entrée. L'agent s'ouvre dans le panneau de droite et répond en premier lieu
à votre message.

## Configurer un nœud

Sélectionnez un nœud. Un panneau s'affiche en surimpression à droite du canvas,
avec deux onglets :

- **Configure** affiche les mêmes champs que le formulaire de cette étape.
- **Run node** exécute le nœud seul. API request envoie une requête de test avec
  des valeurs d'exemple. Search knowledge ouvre l'onglet Preview afin que vous
  puissiez poser une question.

Son en-tête comporte trois commandes. Les trois points contiennent **Reset
position**, **Open Preview** et **Remove step**. Les flèches agrandissent le
panneau pour qu'il remplisse la fenêtre, puis le rétablissent à sa taille
initiale. La croix ferme le panneau. Lorsque le panneau occupe toute la fenêtre,
la croix quitte d'abord le mode plein écran.

Ces deux commandes se trouvent également en bas à gauche, sous les boutons de
zoom, lorsqu'une étape est sélectionnée. Lorsque le panneau est en plein écran,
son propre en-tête se trouve dans le coin, à l'écart des commandes du canevas.
**Open full screen** figure également dans le menu contextuel d'un nœud.

## Faites un clic droit pour afficher les actions

Faites un clic droit sur le canevas pour afficher les commandes d'affichage :
**Add a step**, **Fit to view**, **Tidy up**, **Switch to vertical layout** et
**Open Preview**. Faites un clic droit sur un nœud ; le menu concerne également
cette étape. **Configure** ouvre ses paramètres. **Open full screen** l'ouvre en
plein écran. **Reset position** le fait revenir à la mise en page automatique.
**Remove step** le supprime. `Delete` supprime également l'étape sélectionnée.

Sur un écran tactile, maintenez appuyé au lieu de faire un clic droit.

## Se déplacer sur le canevas

Faites défiler pour déplacer le canevas ; sur un pavé tactile, il s'agit d'un
balayage à deux doigts dans n'importe quelle direction. Pincez pour zoomer, ou
maintenez `Ctrl` enfoncé et faites défiler. Sur un écran tactile, faites glisser
n'importe où sur le canvas pour le déplacer.

Avec une souris, les deux boutons situés en bas du canvas déterminent l'effet
d'un glissement sur une zone vide. **Select** dessine un cadre autour des nœuds.
**Hand** déplace le canvas.

## Réorganiser et agencer

- Faites glisser un nœud d'action au-delà de son voisin pour modifier l'ordre
  des actions. L'ordre correspond à celui dans lequel le Flow les exécute.
- Pour déplacer une action à l'aide du clavier, ouvrez le menu à trois points de
  l'étape et sélectionnez **Move earlier** ou **Move later**. Chaque action dans
  la vue du formulaire dispose des mêmes deux boutons.
- Faites glisser un nœud sur une courte distance pour organiser la
  représentation visuelle. La position est uniquement stockée dans votre
  navigateur.
- Utilisez les commandes situées en bas à gauche pour zoomer et pour ajuster le
  Flow à la fenêtre. Lorsqu'une étape est sélectionnée, ces commandes affichent
  également les contrôles de plein écran et le menu à trois points de cette
  étape.
- **Tidy up** (`Shift`+`T`) annule tous les déplacements manuels et remet la
  chaîne en mise en page automatique.
- **Switch to vertical layout** fait en sorte que la chaîne s'étende
  verticalement sur le canevas au lieu de s'étendre horizontalement. Un Flow
  long se lit mieux de cette façon. Chaque orientation conserve sa propre
  disposition ; ainsi, en revenant à l'orientation précédente, vous retrouvez
  l'agencement tel que vous l'aviez laissé. Votre choix est mémorisé dans votre
  navigateur.

## Demander à l'agent Flows

Le **Flows Agent** crée et modifie le Flow ouvert à partir d'une description. Il
s'agit d'un AI Teammate que la console crée pour chaque Assistant. Il n'apparaît
pas dans **Teammates**.

Pour l'ouvrir :

- Sur un canevas vide, saisissez ce que le Flow doit faire dans la zone située
  au centre, puis appuyez sur Entrée.
- Sur n'importe quel canevas, sélectionnez **Agent** dans l'en-tête.

L'agent s'ouvre dans le panneau de droite, où se trouve l'aperçu en direct (Live
Preview), et fonctionne de la même manière. Faites glisser son bord gauche pour
le redimensionner. Utilisez les commandes de l'en-tête pour accéder aux
conversations antérieures, ouvrir un nouveau chat et passer en mode plein écran.
Les deux partagent cet espace ; ainsi, l'ouverture de l'agent masque la Preview,
et l'ouverture de la Preview masque l'agent. Sélectionnez **Show preview** sur
le bord droit pour revenir en arrière.

L'agent voit le brouillon ouvert, les autres Flows de l'Assistant, ses Help
Desks, ses FAQs et ses Application Connections. Chaque modification qu'il
apporte est enregistrée dans le brouillon non sauvegardé en tant qu'étape
unique. Vous pouvez l'annuler avec **Undo**. L'agent n'enregistre jamais.
Sélectionnez **Save changes** ou **Create flow** lorsque le brouillon est
correct.

Lorsque la requête décrit une deuxième intention, l'agent propose un Flow
distinct au lieu de modifier celui qui est ouvert. La proposition s'affiche sous
la forme d'une carte. Sélectionnez **Create and open** pour créer ce Flow, ou
**Dismiss**.

Seuls les éditeurs et les administrateurs peuvent utiliser l'agent. Les
conversations antérieures concernant le même Flow se trouvent sous le bouton
History dans l'en-tête du panneau. L'agent s'exécute sur les mêmes Provider
Connections que vos Teammates, y compris votre propre abonnement personnel si
vous en avez associé un.

## Annuler et rétablir

Utilisez **Undo** et **Redo** dans l'en-tête, ou `Ctrl+Z` et `Ctrl+Shift+Z`
(`Cmd` sur macOS). L'action **Undo** annule les modifications non enregistrées
dans les deux vues. L'enregistrement du Flow n'efface pas l'historique. Quitter
le Flow, en revanche, l'efface.

## Enregistrer

Le pied de page affiche les mêmes trois cases à cocher que le formulaire.
Sélectionnez **Save changes** ou **Create flow**. Le canevas enregistre le même
Flow que celui enregistré par le formulaire.
