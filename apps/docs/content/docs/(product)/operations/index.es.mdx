conjunto de herramientas para gestionar bien a los asistentes a lo largo del
tiempo: para ver qué preguntan los visitantes, corregir respuestas deficientes,

## Una rutina saludable

Un sencillo ritmo semanal mantiene a los asistentes en plena forma:

1. Echa un vistazo a la [Bandeja de entrada](/operations/inbox) para ver las
   preguntas que el asistente gestionó mal o no pudo responder.
2. Revisa el panel [Improvements](/operations/improvements) y actualiza el
   conocimiento y los flujos sobre la marcha.
3. Consulta [Insights](/operations/insights) para ver si la tasa de resolución y
   las valoraciones evolucionan en la dirección correcta.
4. Borra cualquier [Alerta](/operations/alerts) para que las integraciones sigan
   funcionando.
