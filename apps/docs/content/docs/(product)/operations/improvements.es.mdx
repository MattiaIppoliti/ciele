---
title: Mejoras
description: Realiza un seguimiento y completa el trabajo para corregir las respuestas deficientes del Asistente.
---

Una mejora registra un problema de calidad de respuesta. Puede incluir mensajes
vinculados, Fuentes, una descripción y una solución sugerida.

## Fuentes de mejoras

- Una acción de flujo de mejora crea un elemento.
- Un servicio de asistencia puede crear un elemento después de la escalada.
- Un administrador puede marcar una respuesta desde la bandeja de entrada.
- La búsqueda de conocimiento puede crear un elemento para una consulta sin
  resolver cuando está configurada.

## Gestionar un elemento

Abre un elemento para revisar sus mensajes vinculados y la solución sugerida
disponible. Puedes cambiar su estado, prioridad, etiquetas, responsable y fecha
de vencimiento.

La API, la CLI y el servidor MCP pueden enumerar, leer y actualizar las mejoras
existentes. La creación de mejoras sigue siendo una operación en tiempo de
ejecución del producto.

## Corrige la respuesta

1. Lee la conversación vinculada.
2. Identifica la fuente, las preguntas frecuentes, el flujo o la instrucción
   incorrectos.
3. Corrige el borrador de la configuración.
4. Haz la pregunta original en Vista previa.
5. Confirma la respuesta y las Fuentes.
6. Publica el Asistente.
7. Marca la mejora como completada.

Revisa las correcciones sugeridas generadas antes de usarlas. La sugerencia
guardada no es un cambio de publicación.
