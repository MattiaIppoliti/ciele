---
title: Miglioramenti
description: Tieni traccia e completa il lavoro per correggere le risposte deboli dell'Assistente.
---

Un Miglioramento registra un problema relativo alla qualità della risposta. Può
includere messaggi collegati, fonti, una descrizione e una correzione suggerita.

## Fonti di miglioramento

- Un'azione del flusso di miglioramento crea un elemento.
- Un Help Desk può creare un elemento dopo l'escalation.
- Un amministratore può contrassegnare una risposta dalla Posta in arrivo.
- Se configurata, la ricerca nella knowledge base può creare un elemento per una
  query irrisolta.

## Gestisci un elemento

Apri un elemento per esaminare i messaggi collegati e la correzione suggerita
disponibile. Puoi modificarne lo stato, la priorità, i tag, l'assegnatario e la
data di scadenza.

L'API, la CLI e il server MCP possono elencare, leggere e aggiornare i
miglioramenti esistenti. La creazione di un miglioramento rimane un'operazione
eseguita in fase di runtime del prodotto.

## Correggi la risposta

1. Leggi la conversazione collegata.
2. Identifica la fonte, la FAQ, il flusso o l'istruzione errati.
3. Correggi la bozza di configurazione.
4. Poni la domanda originale in Anteprima.
5. Conferma la risposta e le Fonti.
6. Pubblica l'Assistente.
7. Contrassegna il Miglioramento come completato.

Rivedi le correzioni suggerite generate prima di usarle. Il suggerimento salvato
non è una modifica alla pubblicazione.
