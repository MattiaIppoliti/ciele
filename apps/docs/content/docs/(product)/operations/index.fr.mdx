---
title: Gérez vos assistants
description: Passez en revue les conversations, la qualité du travail, les analyses, les exportations et les alertes.
---

Utilisez les sections opérationnelles après avoir publié un Assistant.

| Section | Utilisation |
| --- | --- |
| Boîte de réception | Lisez les transcriptions des conversations, les sources, les marqueurs de flux et les détails de la session. |
| Améliorations | Suivez le travail de qualité des réponses. |
| Informations | Consultez les indicateurs agrégés actuels et les graphiques. |
| Exportations | Créez des enregistrements de conversation téléchargeables. |
| Alertes | Examinez les problèmes opérationnels et liés aux objectifs qui ont été détectés. |

Adoptez un cycle de révision régulier :

1. Examinez les nouvelles alertes.
2. Examinez les changements de métriques dans Insights.
3. Lisez des conversations représentatives dans la boîte de réception.
4. Créez ou mettez à jour des améliorations.
5. Corrigez le brouillon de l'Assistant.
6. Testez et publiez la correction.
