La publication d'un assistant est le début, pas la fin. Ciele vous propose un
petit ensemble d'outils pour bien gérer vos assistants au fil du temps : pour
voir ce que demandent les visiteurs, pour corriger les réponses insuffisantes,
pour mesurer l'impact et pour détecter rapidement les problèmes opérationnels.

## Une routine saine

Un rythme hebdomadaire simple permet aux assistants de rester performants :

1. Parcourez la [Boîte de réception](/operations/inbox) pour identifier les
   questions que l'assistant a mal traitées ou auxquelles il n'a pas pu
   répondre.
2. Parcourez le tableau [Améliorations](/operations/improvements) en mettant à
   jour les connaissances et les flux au fur et à mesure.
3. Consultez [Insights](/operations/insights) pour voir si le taux de résolution
   et les évaluations évoluent dans la bonne direction.
4. Effacez toutes les [Alertes](/operations/alerts) pour que les intégrations
   continuent de fonctionner.
