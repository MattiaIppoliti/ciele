title: Warnungen
description: Überprüfen Sie erkannte Fehler, die eine Aktion des Administrators erfordern.
---

Alerts zeichnet aktuelle und behobene Betriebsprobleme auf. Ein Badge kann die
Anzahl der aktiven Warnungen anzeigen.

## Warnungsansichten

- **Needs attention** zeigt aktive Warnungen an.
- **Resolved** zeigt gelöschte Warnungen an.
- **All** zeigt beide Zustände an.

Jede Warnung enthält ihren Typ, ihren Titel, Details, den Erkennungszeitpunkt
und den aktuellen Status.

Fehler bei der Zielerreichung führen zur Erstellung von Warnmeldungen. Auch
andere überwachte Vorgänge können eine Warnung erzeugen, wenn ihre aktuelle
Implementierung einen Fehler meldet.

Ein Alert vom Typ **Knowledge** meldet ein Konfigurationsproblem, keinen Fehler.
Ciele erstellt eine, wenn Sie eine Wissenssammlung löschen, die ein
KI-Teamkollege noch durchsucht. Die Warnung benennt die Teammates, die auf die
gelöschte Sammlung verweisen. Sie wird gelöscht, wenn der letzte von ihnen die
Sammlung aus seinem Wissen entfernt.

## Eine Warnung beheben

1. Öffnen Sie die Warnung.
2. Lesen Sie die aufgezeichnete Ursache und das betroffene Element.
3. Korrigieren Sie das Ziel, die Verbindung, die Quelle oder eine andere
   Konfiguration.
4. Wiederholen Sie den betroffenen Vorgang.
5. Vergewissern Sie sich, dass das Problem nicht mehr auftritt.
6. Markieren Sie die Warnung bei Bedarf als gelöst.

Lösen Sie eine Warnung nicht nur auf, um ihr Badge zu entfernen. Bestätigen Sie
zuerst den betroffenen Vorgang.
