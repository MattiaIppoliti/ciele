Im Posteingang werden die Beiträge von Besuchern und Assistenten gespeichert.
Öffnen Sie eine Konversation, um das genaue gespeicherte Transkript einzusehen.

## Gesprächsübersicht

Verwenden Sie die Suche und die verfügbaren Filter, um die Liste einzugrenzen.
Jede Zeile zeigt die jüngsten Aktivitäten und den aktuellen Status der
Konversation an.

Eine Sitzung, die nur proaktive Benachrichtigungen enthält, ist mit der
Markierung **Notification only** versehen. Sie wird zu einer normalen
Konversation, sobald ein Besucher antwortet.

## Gesprächsdetails

Die Detailansicht kann Folgendes anzeigen:

- Nachrichten von Besuchern und Assistenten
- den Flow, der einen Turn verarbeitet hat
- benannte Quellenangaben
- Besucher-Feedback
- Eskalationsstatus
- Start- und Gerätemetadaten
- der verifizierte SSO-Benutzer und der konfigurierte Identitätsanspruch
- gespeicherte Thinking-Informationen, wenn die Mitgliederrolle den Zugriff
  erlaubt

Verbatim Message-Aktionen und Basic-Antworten enthalten keinen Thinking-Trace.
Search-Knowledge-Antworten können Tool- und Fortschrittsereignisse enthalten.

Generierte Entity-Tools erscheinen ebenfalls im Trace. Ihre Ereignisse zeigen,
welche Live-Daten der Organisation die Antwort unterstützt haben.

## Erstellen Sie hochwertige Arbeit

Verwenden Sie die verfügbare Aktion „Verbesserung“, wenn eine Antwort korrigiert
werden muss. Das neue Element verweist zurück auf die betroffene
Konversationsnachricht.

Verwenden Sie [Exports](/operations/exports), wenn Sie strukturierte Datensätze
außerhalb des Posteingangs benötigen.
