---
title: Assistenten betreiben
description: Überprüfen Sie Konversationen, Qualitätsarbeit, Analysen, Exporte und Warnungen.
---

Verwenden Sie die Betriebsbereiche, nachdem Sie einen Assistenten veröffentlicht
haben.

| Abschnitt | Verwendung |
| --- | --- |
| Posteingang | Lesen Sie Konversationsprotokolle, Quellen, Flow-Markierungen und Sitzungsdetails. |
| Verbesserungen | Verfolgen Sie die Antwortqualität. |
| Einblicke | Überprüfen Sie aktuelle aggregierte Metriken und Diagramme. |
| Exporte | Erstellen Sie herunterladbare Gesprächsaufzeichnungen. |
| Warnungen | Überprüfen Sie erkannte Betriebs- und Zielprobleme. |

Verwenden Sie einen regelmäßigen Überprüfungszyklus:

1. Überprüfen Sie neue Warnungen.
2. Überprüfen Sie Metrikänderungen in Insights.
3. Lesen Sie repräsentative Konversationen in der Inbox.
4. Erstellen oder aktualisieren Sie Verbesserungen.
5. Korrigieren Sie den Entwurf des Assistenten.
6. Testen Sie die Korrektur und veröffentlichen Sie sie.
