---
title: Gestisci gli Assistenti
description: Esamina le conversazioni, il lavoro di qualità, le analisi, le esportazioni e gli avvisi.
---

Utilizza le sezioni operative dopo aver pubblicato un Assistente.

| Sezione | Utilizzo |
| --- | --- |
| Posta in arrivo | Leggi le trascrizioni delle conversazioni, le fonti, i marcatori di flusso e i dettagli della sessione. |
| Miglioramenti | Monitora il lavoro relativo alla qualità delle risposte. |
| Approfondimenti | Esamina le metriche aggregate e i grafici correnti. |
| Esportazioni | Crea record di conversazione scaricabili. |
| Avvisi | Esamina i problemi operativi e relativi agli obiettivi rilevati. |

Utilizza un ciclo di revisione regolare:

1. Controlla i nuovi avvisi.
2. Esamina le variazioni delle metriche in Insights.
3. Leggi le Conversazioni rappresentative nella Posta in arrivo.
4. Crea o aggiorna le migliorie.
5. Correggi la bozza dell'Assistente.
6. Testa e pubblica la correzione.
