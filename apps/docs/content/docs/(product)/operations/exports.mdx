---
title: Exports
description: Create and download Insights reports and Conversation exports.
---

Ciele has two types of export. An Insights export is a report file of your Insights measures. A Conversation export contains the full records of selected Conversations.

## Create an Insights export

1. Open **Insights**.
2. Select **Exports**.
3. Select **New export**.
4. Type a name in **Export name**.
5. Set the filters for the report: the date range, the Assistant, **Aggregated**, **Feedback**, and **Escalated**.
6. Select the export type.
7. Select the file type: **CSV**, **JSON**, or **XLSX**.
8. Select **Create**.

Ciele builds the file as a background job. The export shows in the list with its name, type, and file type. When the status is **Ready**, select **Download**.

The filters are the same as on the Insights page. An export and the Insights page show the same numbers for the same filters.

## Insights export types

- **Aggregated insights**: every chart series, with one row for each day, week, or month.
- **Datapoints**: the headline measures for the range, with one row for each measure. A measure with no data for the range has an empty cell.
- **Languages**: the number of Conversations for each language that Visitors wrote in.

**Shortcut button clicks** shows in the list but you cannot select it. Ciele does not record these clicks yet.

## Downloads

Ciele checks your access each time you download a file. Ciele also records each download.

## Conversation export content

Each Conversation record uses the current 29-field export format. The record includes conversation, Assistant, visitor, session, and outcome information.

Reasoning details depend on the API-key or member Role. A lower Role cannot request hidden reasoning through an export option.

## API and CLI access

The API accepts selected Conversation IDs at `POST /api/v1/conversations/export`.

The CLI can write the same record shape to a file:

```bash
ciele conversations export <conversation-id> --out export.json
```

The MCP `read_inbox` tool can also request an export. Its export action remains available in MCP read-only mode.

## Schedule an Insights export

In **New export**, enable scheduling after selecting the report name, filters, export type, and file type.

Choose a weekly weekday or a monthly day, an hour in UTC, and recipients from the Organization's Members. The interface also shows your local time.

Weekly reports cover the last seven complete UTC days. Monthly reports cover the previous calendar month. Day 31 uses the month's last day when needed.

**Exports** lists schedules and their recipients. Editors can pause, resume, or delete a schedule. Deleting a schedule keeps previously generated files.

Each due slot creates one normal export job. After downtime, the worker creates only the latest missed report. It does not replay every missed slot.

Recipients receive an email when the file is ready. The email links to the console and requires sign-in. It contains no report data or attachment.

Members who leave the Organization are removed from recipient lists. A schedule with no remaining recipients pauses automatically.

A failed scheduled export raises an operational Alert. The next successful run resolves it. Email failures raise a separate Alert.

The authenticated worker must drain exports at least every five minutes. The external Docker worker supports this schedule on Vercel Hobby.

API clients manage schedules under `/api/v1/exports/schedules`. MCP exposes export-schedule actions through `manage_configuration`.
