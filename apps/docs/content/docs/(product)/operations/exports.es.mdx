---
title: Exportaciones
description: Crea y descarga informes de Insights y exportaciones de conversaciones.
---

Ciele ofrece dos tipos de exportación. Una exportación de Insights es un archivo
de informe con tus métricas de Insights. Una exportación de conversaciones
contiene los registros completos de las conversaciones seleccionadas.

## Crea una exportación de Insights

1. Abre **Insights**.
2. Selecciona **Exports**.
3. Selecciona **New export**.
4. Escribe un nombre en **Export name**.
5. Configura los filtros para el informe: el intervalo de fechas, el asistente,
   **Aggregated**, **Feedback** y **Escalated**.
6. Selecciona el tipo de exportación.
7. Selecciona el tipo de archivo: **CSV**, **JSON** o **XLSX**.
8. Selecciona **Create**.

Ciele genera el archivo como una tarea en segundo plano. La exportación aparece
en la lista con su nombre, tipo y tipo de archivo. Cuando el estado sea
**Ready**, selecciona **Download**.

Los filtros son los mismos que en la página Insights. Una exportación y la
página Insights muestran las mismas cifras para los mismos filtros.

## Tipos de exportación de Insights

- **Aggregated insights**: todas las series de gráficos, con una fila por cada
  día, semana o mes.
- **Datapoints**: las métricas principales del intervalo, con una fila por cada
  métrica. Una métrica sin datos para el intervalo tiene una celda vacía.
- **Languages**: el número de Conversations para cada idioma en el que
  escribieron los Visitors.

**Shortcut button clicks** aparece en la lista, pero no puedes seleccionarlo.
Ciele aún no registra estos clics.

## Descargas

Ciele comprueba tu acceso cada vez que descargas un archivo. Ciele también
registra cada descarga.

## Contenido de la exportación de conversaciones

Cada registro de Conversation utiliza el formato de exportación actual de 29
campos. El registro incluye información sobre la conversación, el Assistant, el
visitante, la sesión y el resultado.

Los detalles del razonamiento dependen de la API-key o del Role del miembro. Un
Role de nivel inferior no puede solicitar el razonamiento oculto mediante una
opción de exportación.

## Acceso a la API y a la CLI

La API acepta los ID de conversación seleccionados en
`POST /api/v1/conversations/export`.

La CLI puede escribir la misma estructura de registro en un archivo:

```bash
ciele conversations export <conversation-id> --out export.json
```

La herramienta MCP `read_inbox` también puede solicitar una exportación. Su
acción de exportación sigue estando disponible en el modo de solo lectura de
MCP.
