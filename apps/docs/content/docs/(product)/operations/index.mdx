---
title: Operate Assistants
description: Review Conversations, quality work, analytics, exports, and Alerts.
---

Use the operational sections after you publish an Assistant.

| Section | Use |
| --- | --- |
| Inbox | Read Conversation transcripts, Sources, Flow markers, and session details. |
| Improvements | Track answer-quality work. |
| Insights | Review current aggregate metrics and charts. |
| Exports | Build downloadable Conversation records. |
| Alerts | Review detected operational and Goal problems. |

Use a regular review cycle:

1. Review new Alerts.
2. Inspect metric changes in Insights.
3. Read representative Conversations in Inbox.
4. Create or update Improvements.
5. Correct the draft Assistant.
6. Test and publish the correction.
