Insights berechnet Organisationsmetriken aus gespeicherten Laufzeitereignissen.
Verwenden Sie den verfügbaren Datumsbereich und die Assistenten-Filter, um den
Datensatz zu ändern.

## Aktuelle Übersicht

Die Übersicht kann diese Kennzahlen enthalten:

- Konversationen und eindeutige Besucher
- KI-Antworten
- KI-Lösungsrate
- Antwortbewertungen und Kundenzufriedenheitsdaten
- Eskalationen
- Antworten pro Konversation
- Sprachen und Engagement-Quoten
- Feedback und Bewertungsmaßstäbe
- Gesendete Benachrichtigungen

Die genauen Karten hängen von den verfügbaren Daten für den ausgewählten
Zeitraum ab.

## Zählung von Benachrichtigungen

Eine Benachrichtigung ist keine KI-Antwort. Eine reine Benachrichtigungssitzung
erhöht weder die Konversations-KPIs noch die Antwort-KPIs.

Die Kennzahl **Notifications Sent** und die zugehörige Diagrammreihe erfassen
die proaktive Bereitstellung separat.

## Eine Änderung untersuchen

1. Wählen Sie den gewünschten Datumsbereich und den gewünschten Assistenten aus.
2. Identifizieren Sie die Metrik, die sich geändert hat.
3. Öffnen Sie den Posteingang mit demselben Bereich.
4. Lesen Sie repräsentative Konversationen.
5. Erstellen Sie Verbesserungen für umsetzbare Antwortprobleme.

Verwenden Sie [Exports](/operations/exports) für strukturierte
Gesprächsaufzeichnungen.
