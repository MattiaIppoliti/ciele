---
title: Verbesserungen
description: Verfolgen und erledigen Sie Arbeiten, mit denen schwache Antworten des Assistenten korrigiert werden.
---

Eine Verbesserung erfasst ein Problem mit der Antwortqualität. Sie kann
verknüpfte Nachrichten, Quellen, eine Beschreibung und eine vorgeschlagene
Korrektur enthalten.

## Quellen von Verbesserungen

- Eine Aktion des Verbesserungsablaufs erstellt ein Element.
- Ein Helpdesk kann nach einer Eskalation ein Element erstellen.
- Ein Administrator kann eine Antwort aus dem Posteingang markieren.
- Search Knowledge kann bei entsprechender Konfiguration ein Element für eine
  ungelöste Anfrage erstellen.

## Ein Element verwalten

Öffnen Sie ein Element, um die damit verknüpften Nachrichten und die verfügbare
vorgeschlagene Korrektur zu überprüfen. Sie können dessen Status, Priorität,
Tags, Verantwortlichen und Fälligkeitsdatum ändern.

Die API, die CLI und der MCP-Server können vorhandene Verbesserungen auflisten,
lesen und aktualisieren. Die Erstellung von Verbesserungen bleibt ein Vorgang,
der während der Produktlaufzeit ausgeführt wird.

## Korrigieren Sie die Antwort

1. Lesen Sie die verlinkte Konversation.
2. Identifizieren Sie die falsche Quelle, FAQ, den falschen Flow oder die
   falsche Anweisung.
3. Korrigieren Sie den Konfigurationsentwurf.
4. Stellen Sie die ursprüngliche Frage in der Vorschau.
5. Bestätigen Sie die Antwort und die Quellen.
6. Veröffentlichen Sie den Assistenten.
7. Markieren Sie die Verbesserung als abgeschlossen.

Überprüfen Sie die generierten Korrekturvorschläge, bevor Sie sie verwenden. Der
gespeicherte Vorschlag ist keine Publikationsänderung.
