---
title: Verbesserungen
description: Verfolgen und beheben Sie schwache Antworten auf einem Board, von „offen“ bis „erledigt“.
---

Auf dem Board „Improvements“ wird die Antwortqualität verwaltet. Jedes Element
steht für etwas, das an der Antwort des Assistenten verbessert werden sollte,
und das Board verschiebt die Elemente von „Offen“ nach „Erledigt“. Öffnen Sie
**Improvements** in der Seitenleiste.

## Woher Verbesserungen kommen

Verbesserungen kommen von drei Stellen:

- Ein **Flow** mit einer Verbesserungsaktion kennzeichnet eine Antwort zur
  Überprüfung.
- Ein **Helpdesk**, der so eingestellt ist, dass er automatisch Verbesserungen
  generiert, erstellt eine aus der letzten Antwort vor einer Eskalation. Siehe
  [Ticketing und Verbesserungen](/help-desks/ticketing-and-improvements).
- Eine Person **markiert eine Antwort** manuell, während sie den
  [Posteingang](/operations/inbox) liest.

Da sie aus echten Gesprächen stammen, weisen Verbesserungen auf Probleme hin,
auf die Ihre Besucher tatsächlich stoßen.

## Das Board

Die Elemente sind in Spuren organisiert, die ihren Status darstellen, und
bewegen sich von offenen Aufgaben über „In Bearbeitung“ und „Überprüfung“ bis
hin zu „Erledigt“. Es gibt ein Archiv für Elemente, die Sie behalten, aber
beiseitelegen möchten. Jede Spur zeigt an, wie viele Elemente sie enthält, und
Sie können einen Bericht für eine Spur exportieren.

Ein Element enthält die Details, die Sie benötigen, um zu handeln: einen Titel,
die Häufigkeit, mit der das Problem aufgetreten ist, eine Priorität, Tags und
eine verantwortliche Person aus den Mitgliedern Ihrer Organisation. Nutzen Sie
die Suche und die Filter oben, um sich auf das zu konzentrieren, was jetzt
wichtig ist.

## Bearbeiten Sie ein Element

Öffnen Sie ein Element, um seine vollständige Beschreibung und die Nachrichten
zu sehen, die es ausgelöst haben, einschließlich der beteiligten Antworten und
deren Quellen, mit einem Link zurück zur Konversation für den Kontext. Legen Sie
die Priorität, die Tags, die verantwortliche Person und das Fälligkeitsdatum
fest und arbeiten Sie dann an der Behebung. Wenn das zugrunde liegende Wissen
oder der zugrunde liegende Ablauf korrigiert ist, markieren Sie das Element als
erledigt.

## Der Verbesserungskreislauf

Verbesserungen schließen den Kreis zwischen dem, was Besucher erleben, und dem,
was Sie ändern. Eine schwache Antwort wird zu einem Element, das Element führt
zu einer Korrektur Ihrer Wissensdatenbank oder Ihrer Abläufe, und der nächste
Besucher erhält eine bessere Antwort. Die regelmäßige Bearbeitung des Boards ist
die effektivste Maßnahme, um die Antwortqualität zu verbessern.
