---
title: Verbesserungen
description: Verfolgen und erledigen Sie Aufgaben, die darauf abzielen, unzureichende Antworten des Assistenten zu korrigieren.
---

Eine Improvement erfasst ein Problem mit der Qualität der Antworten. Es kann
verknüpfte Nachrichten, Sources, eine Beschreibung und einen Lösungsvorschlag
enthalten.

## Quellen von Verbesserungen

- Eine Improvement Flow-Aktion erstellt ein Element.
- Ein Help Desk kann nach einer Eskalation ein Element erstellen.
- Ein Administrator kann eine Antwort aus der Inbox markieren.
- Search Knowledge kann, wenn entsprechend konfiguriert, ein Element für eine
  ungelöste Anfrage erstellen.
- Ein fortlaufendes Goal, das fehlschlägt, erstellt ein Item. Spätere Fehler
  fügen demselben Element weitere Evidenz hinzu.

## Ein Item verwalten

Öffnen Sie ein Item, um die damit verknüpften Nachrichten und den verfügbaren
Lösungsvorschlag zu prüfen. Sie können den Status, die Priorität, die Tags, den
Verantwortlichen und das Fälligkeitsdatum ändern.

Die API, die CLI und der MCP-Server können vorhandene Improvements auflisten,
lesen und aktualisieren. Die Erstellung von Verbesserungen bleibt ein Vorgang
zur Laufzeit des Produkts.

## Planen Sie die Arbeit als Tasks

Eine Improvement erfasst das Problem. Eine Task erfasst die Arbeit, die das
Problem behebt. Die Seite „Improvement“ zeigt die Tasks an, die das Improvement
beheben.

1. Öffnen Sie die Improvement.
2. Wählen Sie **Create task**. Die Task erhält den Titel und das Project der
   Improvement.
3. Ändern Sie die Task gegebenenfalls und wählen Sie anschließend **Create
   task**.

Sie können auch eine bereits vorhandene Aufgabe verknüpfen: Öffnen Sie die
Aufgabe und wählen Sie die Verbesserung im Feld **Resolves** aus.

Wenn alle verknüpften Tasks abgeschlossen sind, verschiebt Ciele die Improvement
von **To do** oder **In progress** nach **In review**. Anschließend prüft eine
Person die Antwort und schließt die Improvement. Wenn Sie eine Task erneut
öffnen, wird die Improvement nicht zurückgesetzt.

## Die Antwort korrigieren

1. Lesen Sie die verlinkte Conversation.
2. Identifizieren Sie die falsche Source, FAQ, Flow oder Anweisung.
3. Korrigieren Sie die Entwurfskonfiguration.
4. Stellen Sie die ursprüngliche Frage in der Vorschau.
5. Bestätigen Sie die Antwort und die Quellen.
6. Veröffentlichen Sie den Assistant.
7. Markieren Sie die Verbesserung als abgeschlossen.

Überprüfen Sie die generierten vorgeschlagenen Korrekturen, bevor Sie sie
verwenden. Der gespeicherte Vorschlag stellt keine Veröffentlichungsänderung
dar.
