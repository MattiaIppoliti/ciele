---
title: Exportations
description: Créez et téléchargez des exportations structurées de Conversations.
---

Les exportations créent des enregistrements téléchargeables pour les
conversations sélectionnées. Ciele génère l'exportation en tâche de fond.

## Créez une exportation

1. Ouvrez **Insights**.
2. Sélectionnez **Exports**.
3. Sélectionnez l'étendue d'exportation Conversations ou l'étendue d'exportation
   disponible.
4. Lancez l'exportation.
5. Attendez que le statut de la tâche soit prêt.
6. Téléchargez le fichier avant l'expiration de son lien.

Le téléchargement utilise une URL signée à durée limitée. Lancez une nouvelle
exportation lorsque le lien n'est plus valide.

## Exporter le contenu

Chaque enregistrement de conversation utilise le format d'exportation actuel à
29 champs. L'enregistrement comprend des informations sur la conversation,
l'assistant, le visiteur, la session et le résultat.

Les détails du raisonnement dépendent de la clé API ou du rôle du membre. Un
rôle de niveau inférieur ne peut pas demander le raisonnement masqué via une
option d'exportation.

## Accès API et CLI

L'API accepte les ID de conversation sélectionnés à l'adresse
`POST /api/v1/conversations/export`.

La CLI peut écrire le même format d'enregistrement dans un fichier :

```bash
ciele conversations export <conversation-id> --out export.json
```

L'outil MCP `read_inbox` peut également demander une exportation. Cet outil est
toujours en lecture seule.
