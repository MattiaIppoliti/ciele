---
title: Éditions
description: Choisissez Ciele Cloud ou utilisez l'édition open source.
---

Ciele propose une édition Cloud gérée et une édition open source auto-hébergée.
Les deux éditions utilisent le même cœur de produit open source.

| Espace | Ciele Cloud | Open Source |
| --- | --- | --- |
| Fonctionnement du produit | Ciele exploite le service. | Votre équipe exploite le service. |
| Comment démarrer | Contactez le service commercial. Il n'y a pas d'inscription en libre-service. | Installez-le vous-même. C'est gratuit. |
| Abonnement | Un contrat Enterprise contrôle l'utilisation incluse. | Aucun abonnement Ciele n'est requis. |
| Infrastructure | Ciele sélectionne et gère le déploiement. | Votre équipe fournit et maintient le déploiement. |
| Informations d'identification du modèle | Utilisez des modèles de plan ou des connexions de fournisseurs pris en charge. | Configurez le fournisseur pris en charge ou les points de terminaison locaux compatibles. |
| Mises à jour | Le service géré reçoit les versions déployées. | Votre équipe sélectionne et applique les versions. |
| Licence | Les conditions de service s'appliquent. | Le noyau utilise uniquement la licence AGPL-3.0. |

La documentation publique open source décrit uniquement les fichiers du dépôt
open source. Elle ne décrit pas les détails de l'implémentation en entreprise.

Utilisez [Ciele Cloud](/cloud) pour obtenir des informations sur les forfaits
hébergés. Utilisez [Open Source](/self-hosting) pour obtenir les instructions
d'installation et d'utilisation.

Ciele Cloud est commercialisée en tant qu'offre Entreprise axée sur la vente.
L'option gratuite est l'édition auto-hébergée.
