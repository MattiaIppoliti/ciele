Ciele bietet drei Schnittstellen für die programmatische Administration. Jede
Schnittstelle verwendet dieselben Operationen und Rollenprüfungen wie die
Administrator-Konsole.

Um die Operation hinter einem Steuerelement der Konsole zu ermitteln, öffnen Sie
auf der entsprechenden Seite das [Developer Panel](/developers/developer-panel).

## Gemeinsames Verbindungsmodell

Alle drei Schnittstellen erfordern einen Organization API Key. Die zugewiesene
Rolle bestimmt die Operationen, die mit dem Schlüssel ausgeführt werden dürfen.

<Mermaid
  title="Drei Clients, eine API, ein Satz von Operationen"
  chart={`

  CLI["Ciele CLI"]
  MCP["Ciele MCP server"]

  OPS["Shared operations"]
  DB[("Organization data")]

  MCP --> API
  HTTP --> API
  API --> OPS
  OPS --> DB

/>

Der gehostete Dienst verwendet standardmäßig `https://ciele.app`. Eine selbst
gehostete Installation verwendet ihren eigenen öffentlichen Ursprung.

<Callout title="Use the minimum Role">
Create a Viewer key for read operations. Create a higher-role key only when the client must change data or publish an Assistant. A Viewer key is not a read-only agent: it can also curate the Inbox (pin, leave feedback, delete a conversation).
</Callout>

## Verfügbare Domains

Die [API reference](/api-reference) listet alle verfügbaren
`/api/v1`-Operationen nach Domain auf.

Die API stellt nicht alle Funktionen der Konsole bereit. Beispielsweise sind das
Hochladen von Avataren und das Erstellen von Verbesserungen weiterhin nur in der
Konsole möglich.
