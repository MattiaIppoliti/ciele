---
title: Connecter des clients IA
description: Connectez les clients IA pris en charge au serveur MCP Ciele hébergé ou local.
---

Le serveur MCP de Ciele dispose de deux transports. Les deux enregistrent les
mêmes outils.

- Le **hosted endpoint** est `POST /api/mcp` sur votre déploiement. Tout client
  qui accepte une URL MCP distante peut l'utiliser.
- Le **local server** est un processus `stdio` que le client démarre en tant que
  processus enfant.

Privilégiez le **hosted endpoint**. Il ne nécessite aucun clonage, pas de
Node.js sur la machine cliente, et aucun chemin à maintenir à jour.

Cette page reflète la documentation client vérifiée le 6 août 2026. Les
interfaces client et les formats de configuration peuvent évoluer.

## Compatibilité

| Client | Hosted endpoint | Local `stdio` |
| --- | :---: | :---: |
| Claude Code | Oui | Oui |
| Codex CLI, application Codex et extension Codex pour IDE | Oui | Oui |
| Application de bureau ChatGPT | Oui | Oui |
| Cursor | Oui | Oui |
| OpenCode | Oui | Oui |
| GitHub Copilot dans VS Code | Oui | Oui |
| GitHub Copilot CLI | Oui | Oui |
| ChatGPT web | Oui | Aucun processus local |
| Pi | Aucune procédure intégrée | Aucune procédure intégrée |

## Se connecter au point de terminaison hébergé

1. Créez une [clé API](/developers/api-keys) pour un viewer.
2. Communiquez au client l'URL de l'endpoint de votre déploiement.
3. Configurez l'en-tête `Authorization` comme `Bearer <key>`.

```bash
claude mcp add --transport http ciele https://ciele.example.edu/api/mcp \
  --header "Authorization: Bearer ciele_sk_..."
```

Le point de terminaison hébergé n'a pas d'option lecture seule : ses
autorisations correspondent au Role de la clé. Cependant, une clé Viewer n'est
pas un agent en lecture seule : la consultation des conversations est considérée
comme de la curation, ce qui lui permet d'épingler une conversation, de laisser
un commentaire et d'en supprimer une. Utilisez un serveur stdio local avec
`CIELE_MCP_READ_ONLY=1` lorsque l'agent ne doit absolument rien modifier.

## Préparer une connexion locale

1. Installez Node.js 22.6 ou une version ultérieure.
2. Clonez le dépôt Ciele.
3. Créez une [clé API](/developers/api-keys) pour un viewer.
4. Déterminez le chemin absolu vers `packages/mcp/bin/ciele-mcp.mjs`.
5. Définissez `CIELE_MCP_READ_ONLY=1` pour la première connexion.

Remplacez `<repo>` et l'exemple d'origine dans chaque configuration.

## Claude Code

Exécutez cette commande :

```bash
claude mcp add ciele \
  --env CIELE_API_KEY=ciele_sk_... \
  --env CIELE_BASE_URL=https://ciele.example.edu \
  --env CIELE_MCP_READ_ONLY=1 \
  -- node <repo>/packages/mcp/bin/ciele-mcp.mjs
```

Ouvrez `/mcp` dans Claude Code. Vérifiez que le serveur `ciele` affiche dix-sept
outils.

Consultez le
[Claude Code MCP guide](https://docs.anthropic.com/en/docs/claude-code/mcp) pour
connaître les options client et les portées de configuration.

## Codex et ChatGPT pour ordinateur de bureau

Exécutez cette commande pour Codex CLI :

```bash
codex mcp add ciele \
  --env CIELE_API_KEY=ciele_sk_... \
  --env CIELE_BASE_URL=https://ciele.example.edu \
  --env CIELE_MCP_READ_ONLY=1 \
  -- node <repo>/packages/mcp/bin/ciele-mcp.mjs
```

Codex CLI, l'application Codex, l'extension Codex pour IDE et ChatGPT Desktop
partagent la même configuration Codex MCP.

Vous pouvez également modifier `~/.codex/config.toml` :

```toml
[mcp_servers.ciele]
command = "node"
args = ["<repo>/packages/mcp/bin/ciele-mcp.mjs"]
default_tools_approval_mode = "writes"

[mcp_servers.ciele.env]
CIELE_API_KEY = "ciele_sk_..."
CIELE_BASE_URL = "https://ciele.example.edu"
CIELE_MCP_READ_ONLY = "1"
```

Exécutez `codex mcp list` ou ouvrez `/mcp` pour vérifier la connexion.

Consultez le [Codex MCP guide](https://learn.chatgpt.com/docs/extend/mcp) pour
connaître les paramètres client actuels.

## Cursor

Créez `.cursor/mcp.json` dans un projet. Vous pouvez également utiliser la
configuration globale de Cursor.

```json
{
  "mcpServers": {
    "ciele": {
      "command": "node",
      "args": ["<repo>/packages/mcp/bin/ciele-mcp.mjs"],
      "env": {
        "CIELE_API_KEY": "ciele_sk_...",
        "CIELE_BASE_URL": "https://ciele.example.edu",
        "CIELE_MCP_READ_ONLY": "1"
      }
    }
  }
}
```

Ouvrez **Settings > MCP**. Activez `ciele` et examinez chaque appel d'outil
demandé.

Consultez le
[guide MCP de Cursor](https://docs.cursor.com/context/model-context-protocol)
pour obtenir des informations sur la configuration globale et la sécurité du
client.

## OpenCode

Ajoutez ce serveur à `opencode.json` :

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "ciele": {
        "type": "local",
        "command": ["node", "<repo>/packages/mcp/bin/ciele-mcp.mjs"],
        "environment": {
          "CIELE_API_KEY": "{env:CIELE_API_KEY}",
          "CIELE_BASE_URL": "https://ciele.example.edu",
          "CIELE_MCP_READ_ONLY": "1"
        }
      }
    }
  }
}
```

Exécutez `opencode2 mcp list` pour vérifier la connexion.

Consultez le [OpenCode MCP guide](https://opencode.ai/v2/docs/mcp-servers) pour
le schéma de la version 2 actuelle.

## GitHub Copilot dans VS Code

Créer `.vscode/mcp.json` :

```json
{
  "inputs": [
    {
      "id": "ciele-key",
      "type": "promptString",
      "password": true,
      "description": "Ciele API key"
    }
  ],
  "servers": {
    "ciele": {
      "type": "stdio",
      "command": "node",
      "args": ["<repo>/packages/mcp/bin/ciele-mcp.mjs"],
      "env": {
        "CIELE_API_KEY": "${input:ciele-key}",
        "CIELE_BASE_URL": "https://ciele.example.edu",
        "CIELE_MCP_READ_ONLY": "1"
      }
    }
  }
}
```

Exécutez **MCP: List Servers** depuis la Palette de commandes. Démarrez `ciele`
et examinez sa sortie lorsqu'une connexion échoue.

Consultez le
[VS Code MCP guide](https://code.visualstudio.com/docs/agent-customization/mcp-servers)
pour connaître les emplacements de configuration et les contrôles de confiance.

## CLI GitHub Copilot

Exécutez la commande interactive `/mcp add`. Sélectionnez un serveur local
`stdio` et saisissez la commande Ciele.

Vous pouvez également commencer par cette commande :

```bash
copilot mcp add ciele -- node <repo>/packages/mcp/bin/ciele-mcp.mjs
```

Ajoutez les trois variables d'environnement Ciele via la configuration MCP de
Copilot. Ne placez pas la clé API dans le contrôle de version.

Consultez le
[GitHub Copilot CLI MCP guide](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-mcp-servers)
pour connaître le format de configuration actuel.

## Prompts copiables

Commencez chaque nouvelle connexion par cette vérification en lecture seule :

```text
Call ciele_identity. Show the deployment version, available domains,
Organization ID, and Role. Do not change data.
```

Utilisez cette invite pour examiner les Assistants :

```text
List all Ciele Assistants. For each Assistant, list its enabled Flows.
Identify duplicate or unclear Flow names. Do not change data.
```

Utilisez cette invite pour examiner l'ingestion des connaissances :

```text
List the Sources linked to Assistant <assistant-id>.
List each Source and its ingestion status.
Report Sources that are not ready. Do not retry or delete a Source.
```

Utilisez cette invite après avoir activé l'accès en écriture :

```text
Create one FAQ for Assistant <assistant-id>.
Question: "When does enrollment close?"
Answer: "Enrollment closes on <date>."
Show the proposed tool input and ask for approval before the call.
```

Utilisez cette invite avant la publication :

```text
Read the publication status for Assistant <assistant-id>.
Summarize the current live version. Do not publish or unpublish anything.
```

<Callout type="warn" title="Review write operations">
Read the proposed tool input before you approve it. API Roles and MCP read-only mode are independent controls.
</Callout>

## Clients sans processus local

ChatGPT web ne peut pas démarrer un serveur local `stdio`. Dirigez-le plutôt
vers le point de terminaison hébergé. Le déploiement doit être accessible depuis
l'internet public, ce qui n'est pas le cas d'une pile locale Ciele Desktop.

Pi n'inclut pas de procédure de connexion MCP intégrée. Les extensions Pi
peuvent ajouter la prise en charge de MCP, mais Ciele ne fournit ni ne teste une
telle extension. Utilisez `ciele ... --json` via un workflow shell approuvé, ou
appelez directement l'[HTTP API](/developers/api).
