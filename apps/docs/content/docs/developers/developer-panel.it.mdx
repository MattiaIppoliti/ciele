Il Developer Panel mostra l'equivalente programmatico della pagina della console
che stai visualizzando. Elenca le operazioni di quella pagina come snippet
pronti all'uso, con gli ID della pagina già inclusi.

Usalo per trasformare un'attività manuale in uno script o per scoprire quale
operazione API si nasconde dietro un controllo della console.

## Apri il pannello

Seleziona il pulsante `</>` sulla destra della barra superiore. Tieni il
puntatore del mouse sopra di esso per visualizzare il dominio della pagina, ad
esempio **Flows API**. Puoi anche premere `D`.

Il pannello si apre nella barra laterale destra e rimane aperto quando passi a
un'altra pagina.

Un editor di assistenti utilizza la stessa barra laterale per la Live Preview.
Solo uno dei due è visibile alla volta.

<Callout title="No button means no API">
The button is absent when the page has no API operations. Insights and the Style setup section show none. The absence is correct information, not a defect.
</Callout>

## Leggi uno snippet

Ogni operazione ha tre schede.

| Tab | Contents |
| --- | --- |
| CLI | Il comando `ciele` per l'operazione. |
| cURL | La richiesta HTTP, con l'origine del tuo deployment. |
| MCP | Il nome dello strumento e gli argomenti `action` per un client di IA. |

Accanto a un'operazione possono essere visualizzati due badge:

- Il badge **Role** indica il Role di livello più basso di cui ha bisogno una
  chiave API. Deriva dal guard che l'API applica.
- Il badge **Idempotent** indica una richiesta che può essere riprovata in
  sicurezza con un header `Idempotency-Key`.

## I corpi delle richieste sono shape

Un corpo cURL mostra placeholder tipizzati, non valori di esempio, e si ferma a
due livelli di nidificazione.

È una scelta intenzionale. Un valore inventato ma plausibile è pericoloso,
perché qualcuno potrebbe incollarlo in una Organization reale. Consulta la
[API reference](/developers/api) per il contratto completo di un campo.

## Prima dell'esecuzione di uno snippet

Ogni snippet necessita di una [Organization API key](/developers/api-keys). Il
pannello lo indica quando l'Organization non ne ha nessuno.

Solo un Owner o un Admin può creare una chiave. Il pannello indica il Role
richiesto quando il tuo Role non è sufficiente.
