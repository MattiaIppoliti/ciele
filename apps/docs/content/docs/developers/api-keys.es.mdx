---
title: Claves API
description: Crea, revoca y elimina credenciales de la organización para el acceso programático.
---

Una clave API proporciona a un programa acceso a una organización. Ciele
almacena únicamente el hash del secreto.

## Crea una clave

1. Abre **Settings**.
2. Selecciona **API Keys**.
3. Selecciona **Create API key**.
4. Introduce un nombre para la clave.
5. Selecciona el Role mínimo requerido.
6. Copia el secreto en un almacén de credenciales seguro.

Ciele te muestra el secreto `ciele_sk_...` una sola vez. No podrás recuperar el
mismo secreto más tarde.

El Role seleccionado no puede ser superior a tu propio Role. Ciele comprueba el
Role en cada operación de la API.

## Revocar una clave

1. Abre **Settings > API Keys**.
2. Encuentra la clave.
3. Selecciona **Revoke**.
4. Confirma la acción.

La revocación impide que se realicen nuevas solicitudes que utilicen la clave.
Ciele conserva el registro de la clave para la información de auditoría.

## Eliminar una clave

Solo puedes eliminar una clave que ya esté revocada. Un Admin o un Owner puede
hacer esto.

1. Abre **Settings > API Keys**.
2. Busca la clave revocada.
3. Selecciona el icono rojo de la papelera.
4. Confirma la acción.

Ciele elimina el registro de claves de la lista. No puedes deshacer esta acción.

<Callout type="warn" title="Protect the secret">
Do not put an API key in source control, public logs, prompts, or screenshots. Use an environment variable or a secret store.
</Callout>
