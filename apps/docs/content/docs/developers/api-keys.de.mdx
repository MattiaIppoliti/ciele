---
title: API-Schlüssel
description: Erstellen, widerrufen und löschen Sie Organization-Anmeldedaten für den programmatischen Zugriff.
---

Ein API-Schlüssel gewährt einem Programm Zugriff auf eine Organisation. Ciele
speichert nur den Hash des Secrets.

## Einen Schlüssel erstellen

1. Öffnen Sie **Settings**.
2. Wählen Sie **API Keys** aus.
3. Wählen Sie **Create API key** aus.
4. Geben Sie einen Namen für den Schlüssel ein.
5. Wählen Sie die minimal erforderliche Role aus.
6. Kopieren Sie das Secret in einen sicheren Anmeldedatenspeicher.

Ciele zeigt das `ciele_sk_...`-Secret nur einmal an. Sie können dasselbe Secret
später nicht mehr abrufen.

Die ausgewählte Role darf nicht höher sein als Ihre eigene Role. Ciele überprüft
die Role bei jedem API-Vorgang.

## Einen Schlüssel widerrufen

1. Öffnen Sie **Settings > API Keys**.
2. Suchen Sie den Schlüssel.
3. Wählen Sie **Revoke** aus.
4. Bestätigen Sie die Aktion.

Durch den Widerruf werden neue Anfragen, die den Schlüssel verwenden,
verhindert. Ciele speichert den Schlüsseleintrag für Audit-Informationen.

## Einen Schlüssel löschen

Sie können nur einen Schlüssel löschen, der bereits gesperrt ist. Ein Admin oder
ein Owner kann dies tun.

1. Öffnen Sie **Settings > API Keys**.
2. Suchen Sie den gesperrten Schlüssel.
3. Wählen Sie das rote Papierkorb-Symbol aus.
4. Bestätigen Sie die Aktion.

Ciele entfernt den Key-Datensatz aus der Liste. Sie können diese Aktion nicht
rückgängig machen.

<Callout type="warn" title="Protect the secret">
Do not put an API key in source control, public logs, prompts, or screenshots. Use an environment variable or a secret store.
</Callout>
