Ciele offre tre interfacce per l'amministrazione programmatica. Ogni interfaccia
utilizza le stesse operazioni e gli stessi controlli dei ruoli della console di
amministrazione.

Per individuare l'operazione sottostante un controllo della console, apri il
[Developer Panel](/developers/developer-panel) su quella pagina.

## Modello di connessione comune

Tutte e tre le interfacce richiedono una chiave API dell'organizzazione. Il Role
assegnato controlla le operazioni che la chiave può utilizzare.

<Mermaid
  title="Tre client, una sola API, un unico set di operazioni"
  chart={`
flowchart TB
  CLI["Ciele CLI"]
  MCP["Ciele MCP server"]
  HTTP["HTTP client"]
  API["Ciele API v1"]
  OPS["Shared operations"]
  DB[("Organization data")]
  CLI --> API
  MCP --> API
  HTTP --> API
  API --> OPS
  OPS --> DB
`}
/>

Il servizio ospitato utilizza `https://ciele.app` per impostazione predefinita.
Un'installazione self-hosted utilizza il proprio public origin.

<Callout title="Use the minimum Role">
Create a Viewer key for read operations. Create a higher-role key only when the client must change data or publish an Assistant. A Viewer key is not a read-only agent: it can also curate the Inbox (pin, leave feedback, delete a conversation).
</Callout>

## Domini disponibili

La [API reference](/api-reference) elenca tutte le operazioni `/api/v1`
disponibili per dominio.

L'API non espone tutte le funzioni della console. Ad esempio, il caricamento
dell'avatar e la creazione di un Improvement rimangono disponibili solo nella
console.
