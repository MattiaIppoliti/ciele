Ciele ofrece tres interfaces para la administración programática. Cada interfaz
utiliza las mismas operaciones y comprobaciones de roles que la consola de
administración.

Para encontrar la operación asociada a un control de la consola, abre el
[Panel del desarrollador](/developers/developer-panel) en esa página.

## Modelo de conexión común

Las tres interfaces requieren una clave de API de organización. El rol asignado
controla las operaciones que la clave puede usar.

<Mermaid
  title="Tres clientes, una API, un conjunto de operaciones"

El servicio alojado utiliza `https://platform.ciele.app` de forma
predeterminada. Una instalación autohospedada utiliza su propio origen público.

<Callout title="Use the minimum Role">
Create a viewer key for read operations. Create a higher-role key only when the client must change data or publish an Assistant.
</Callout>

## Dominios disponibles

La API actual incluye Asistentes, Flujos, Conocimiento, publicación,
conversaciones de la Bandeja de entrada y Mejoras.

La API no expone todas las funciones de la consola. Por ejemplo, la subida de
avatares y la creación de mejoras siguen siendo exclusivas de la consola.
