title: Panel del desarrollador
description: Consulta el fragmento de CLI, cURL y MCP correspondiente a la página de la consola que tienes abierta.
---

El Developer Panel muestra el equivalente programático de la página de la
consola que estás viendo. Enumera las operaciones de esa página como fragmentos
de código listos para usar, con los ID de la página ya incluidos en ellos.

Úsalo para convertir una tarea manual en un script o para averiguar qué
operación de la API se encuentra detrás de un control de la consola.

## Abre el panel

Selecciona el botón `</>` situado a la derecha de la barra superior. Mantén el
puntero sobre él para ver el dominio de la página, por ejemplo, **Flows API**.
También puedes pulsar `D`.

El panel se abre en la barra lateral derecha y permanece abierto cuando pasas a
otra página.

Un editor de asistentes utiliza la misma barra lateral para la vista previa en
tiempo real (Live Preview). Solo uno de los dos es visible a la vez.

<Callout title="No button means no API">
The button is absent when the page has no API operations. Insights and the Style setup section show none. The absence is correct information, not a defect.
</Callout>

## Lee un fragmento

Cada operación tiene tres pestañas.

| Tab | Contents |
| --- | --- |
| CLI | El comando `ciele` para la operación. |
| cURL | La solicitud HTTP, con el origen de tu propia implementación. |
| MCP | El nombre de la herramienta y los argumentos `action` para un cliente de IA. |

Pueden aparecer dos insignias junto a una operación:

- La insignia **Role** indica el Role de nivel más bajo que necesita una clave
  de API. Se deriva del control que aplica la API.
- La insignia **Idempotent** indica una solicitud que se puede reintentar de
  forma segura con un encabezado `Idempotency-Key`.

## Los cuerpos de las solicitudes son «shapes»

Un cuerpo cURL muestra marcadores de posición tipados, no valores de ejemplo, y
se detiene en dos niveles de anidamiento.

Esto es intencionado. Un valor inventado que parezca verosímil es peligroso,
porque alguien podría pegarlo en una organización real. Consulta la
[API reference](/developers/api) para conocer el contrato completo de un campo.

## Antes de que se ejecute un snippet

Cada snippet necesita una [clave API de la organización](/developers/api-keys).
El panel lo indica cuando la organización no tiene ninguna.

Solo un Owner o un Admin puede crear una clave. El panel indica el Role
necesario cuando tu propio Role no puede hacerlo.
