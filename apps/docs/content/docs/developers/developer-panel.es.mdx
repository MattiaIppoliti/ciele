title: Panel de desarrollador
description: Lee los fragmentos de CLI, cURL y MCP de la página de la consola que tienes abierta.
---

El Panel de desarrollador muestra el equivalente programático de la página de la
consola que estás viendo. Enumera las operaciones de esa página como fragmentos
listos para usar, con los identificadores de la página ya incluidos en ellos.

Úsalo para convertir una tarea manual en un script o para saber qué operación de
la API hay detrás de un control de la consola.

## Abre el panel

Selecciona el botón de la barra superior. Su etiqueta indica el dominio de la
página, por ejemplo **Flows API**. También puedes pulsar `D`.

El panel se abre en el panel derecho y permanece abierto cuando pasas a otra
página.

Un editor de asistentes utiliza el mismo panel para la vista previa en tiempo
real. Solo se ve uno de los dos a la vez.

<Callout title="No button means no API">
The button is absent when the page has no API operations. Insights and the Style setup section show none. The absence is correct information, not a defect.
</Callout>

## Lee un fragmento

Cada operación tiene tres pestañas.

| Pestaña | Contenido |
| --- | --- |
| CLI | El comando `ciele` para la operación. |
| cURL | La solicitud HTTP, con el origen de tu propia implementación. |
| MCP | El nombre de la herramienta y los argumentos `action` para un cliente de IA. |

Pueden aparecer dos insignias junto a una operación:

- La insignia **Role** indica el rol más bajo que necesita una clave de API. Se
  deriva de la protección que impone la API.
- La insignia **Idempotent** marca una solicitud que se puede reintentar de
  forma segura con un encabezado `Idempotency-Key`.

## Los cuerpos de las solicitudes son formas

Un cuerpo cURL muestra marcadores de posición tipificados, no valores de
ejemplo, y se detiene en dos niveles de anidamiento.

Esto es intencionado. Un valor inventado que parezca plausible es peligroso,
porque alguien podría pegarlo en una organización real. Lee la
[referencia de la API](/developers/api) para conocer el contrato completo de un
campo.

## Antes de que se ejecute un fragmento

Cada fragmento necesita una
[clave de API de la organización](/developers/api-keys). El panel lo indica
cuando la Organización no tiene ninguna.

Solo un Propietario o un Administrador pueden crear una clave. El panel indica
el rol requerido cuando tu propio rol no puede hacerlo.
