Das Developer Panel zeigt das programmatische Äquivalent der Konsolenseite an,
die Sie gerade betrachten. Es listet die Operationen dieser Seite als fertige
Snippets auf, wobei die IDs der Seite bereits darin enthalten sind.

Verwenden Sie es, um eine manuelle Aufgabe in ein Skript zu überführen oder um
herauszufinden, welche API-Operation hinter einem Steuerelement der Konsole
steht.

## Öffnen Sie das Panel

Wählen Sie die Schaltfläche `</>` rechts in der oberen Leiste aus. Halten Sie
den Mauszeiger darüber, um die Domain der Seite anzuzeigen, zum Beispiel **Flows
API**. Sie können auch `D` drücken.

Das Panel öffnet sich in der rechten Leiste und bleibt geöffnet, wenn Sie zu
einer anderen Seite wechseln.

Ein Assistant Editor verwendet dieselbe Seitenleiste für die Live-Vorschau. Es
ist jeweils nur eines der beiden Elemente sichtbar.

<Callout title="No button means no API">
The button is absent when the page has no API operations. Insights and the Style setup section show none. The absence is correct information, not a defect.
</Callout>

## Einen Snippet lesen

Jede Operation verfügt über drei Tabs.

| Tab | Contents |
| --- | --- |
| CLI | Der `ciele`-Befehl für die Operation. |
| cURL | Die HTTP-Anfrage mit dem Ursprung Ihrer eigenen Bereitstellung. |
| MCP | Der Tool-Name und die `action`-Argumente für einen KI-Client. |

Neben einer Operation können zwei Badges angezeigt werden:

- Das **Role**-Badge gibt die niedrigste Role an, die ein API-Schlüssel
  benötigt. Es leitet sich von der Guard ab, die die API durchsetzt.
- Das **Idempotent**-Badge kennzeichnet eine Anfrage, die sicher mit einem
  `Idempotency-Key`-Header wiederholt werden kann.

## Request Bodies sind Shapes

Ein cURL-Body zeigt typisierte Platzhalter, keine Beispielwerte, und endet bei
zwei Verschachtelungsebenen.

Das ist beabsichtigt. Ein plausibel erscheinender, frei erfundener Wert ist
gefährlich, da ihn jemand möglicherweise in eine echte Organisation einfügt.
Lesen Sie die [API reference](/developers/api), um den vollständigen Vertrag
eines Feldes zu erfahren.

## Bevor ein Snippet ausgeführt wird

Jeder Snippet benötigt einen [Organization API key](/developers/api-keys). Der
Bereich weist darauf hin, wenn die Organisation keinen Schlüssel hat.

Nur ein Owner oder ein Admin kann einen Schlüssel erstellen. Das Panel gibt die
erforderliche Role an, wenn Ihre eigene Role dies nicht kann.
