---
title: Conecta clientes de IA
description: Conecta los clientes de IA compatibles al servidor MCP de Ciele alojado o local.
---

El servidor MCP de Ciele tiene dos transportes. Ambos registran las mismas
herramientas.

- El **hosted endpoint** es `POST /api/mcp` en tu implementación. Cualquier
  cliente que acepte una URL de MCP remota puede usarlo.
- El **local server** es un proceso `stdio` que el cliente inicia como proceso
  hijo.

Da preferencia al **hosted endpoint**. No requiere clonación del repositorio, ni
Node.js en el equipo cliente, ni una ruta que mantener actualizada.

Esta página refleja la documentación del cliente revisada el 6 de agosto de
2026. Las interfaces de cliente y los formatos de configuración pueden cambiar.

## Compatibilidad

| Cliente | Hosted endpoint | Local `stdio` |
| --- | :---: | :---: |
| Claude Code | Sí | Sí |
| Codex CLI, aplicación Codex y extensión Codex para IDE | Sí | Sí |
| Aplicación de escritorio de ChatGPT | Sí | Sí |
| Cursor | Sí | Sí |
| OpenCode | Sí | Sí |
| GitHub Copilot en VS Code | Sí | Sí |
| GitHub Copilot CLI | Sí | Sí |
| ChatGPT web | Sí | Sin proceso local |
| Pi | No hay procedimiento integrado | No hay procedimiento integrado |

## Conéctate al endpoint alojado

1. Crea una [API key](/developers/api-keys) para un visor.
2. Proporciona al cliente la URL del endpoint de tu despliegue.
3. Configura la cabecera `Authorization` como `Bearer <key>`.

```bash
claude mcp add --transport http ciele https://ciele.example.edu/api/mcp \
  --header "Authorization: Bearer ciele_sk_..."
```

El endpoint alojado no tiene un conmutador de solo lectura: sus permisos son el
Role de la clave. Sin embargo, una clave de Viewer no es un agente de solo
lectura: revisar conversaciones cuenta como curación, por lo que puede anclar
una conversación, dejar comentarios y eliminarla. Utiliza un servidor stdio
local con `CIELE_MCP_READ_ONLY=1` cuando el agente no deba cambiar absolutamente
nada.

## Prepara una conexión local

1. Instala Node.js 22.6 o una versión posterior.
2. Clona el repositorio de Ciele.
3. Crea una [API key](/developers/api-keys) para un visor.
4. Resuelve la ruta absoluta a `packages/mcp/bin/ciele-mcp.mjs`.
5. Establece `CIELE_MCP_READ_ONLY=1` para la primera conexión.

Sustituye `<repo>` y el origen de ejemplo en cada configuración.

## Claude Code

Ejecuta este comando:

```bash
claude mcp add ciele \
  --env CIELE_API_KEY=ciele_sk_... \
  --env CIELE_BASE_URL=https://ciele.example.edu \
  --env CIELE_MCP_READ_ONLY=1 \
  -- node <repo>/packages/mcp/bin/ciele-mcp.mjs
```

Abre `/mcp` en Claude Code. Confirma que el servidor `ciele` muestre dieciséis
herramientas.

Consulta la
[Claude Code MCP guide](https://docs.anthropic.com/en/docs/claude-code/mcp) para
conocer las opciones del cliente y los ámbitos de configuración.

## Codex y ChatGPT para escritorio

Ejecuta este comando para la CLI de Codex:

```bash
codex mcp add ciele \
  --env CIELE_API_KEY=ciele_sk_... \
  --env CIELE_BASE_URL=https://ciele.example.edu \
  --env CIELE_MCP_READ_ONLY=1 \
  -- node <repo>/packages/mcp/bin/ciele-mcp.mjs
```

Codex CLI, la aplicación Codex, la extensión Codex para IDE y ChatGPT para
escritorio comparten la misma configuración de Codex MCP.

También puedes editar `~/.codex/config.toml`:

```toml
[mcp_servers.ciele]
command = "node"
args = ["<repo>/packages/mcp/bin/ciele-mcp.mjs"]
default_tools_approval_mode = "writes"

[mcp_servers.ciele.env]
CIELE_API_KEY = "ciele_sk_..."
CIELE_BASE_URL = "https://ciele.example.edu"
CIELE_MCP_READ_ONLY = "1"
```

Ejecuta `codex mcp list` o abre `/mcp` para comprobar la conexión.

Consulta la [Codex MCP guide](https://learn.chatgpt.com/docs/extend/mcp) para
conocer la configuración actual del cliente.

## Cursor

Crea `.cursor/mcp.json` en un proyecto. También puedes usar la configuración
global de Cursor.

```json
{
  "mcpServers": {
    "ciele": {
      "command": "node",
      "args": ["<repo>/packages/mcp/bin/ciele-mcp.mjs"],
      "env": {
        "CIELE_API_KEY": "ciele_sk_...",
        "CIELE_BASE_URL": "https://ciele.example.edu",
        "CIELE_MCP_READ_ONLY": "1"
      }
    }
  }
}
```

Abre **Settings > MCP**. Habilita `ciele` y revisa cada llamada a herramienta
solicitada.

Consulta la
[guía de MCP de Cursor](https://docs.cursor.com/context/model-context-protocol)
para obtener información sobre la configuración global y la seguridad del
cliente.

## OpenCode

Añade este servidor a `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "ciele": {
        "type": "local",
        "command": ["node", "<repo>/packages/mcp/bin/ciele-mcp.mjs"],
        "environment": {
          "CIELE_API_KEY": "{env:CIELE_API_KEY}",
          "CIELE_BASE_URL": "https://ciele.example.edu",
          "CIELE_MCP_READ_ONLY": "1"
        }
      }
    }
  }
}
```

Ejecuta `opencode2 mcp list` para comprobar la conexión.

Consulta la [OpenCode MCP guide](https://opencode.ai/v2/docs/mcp-servers) para
ver el esquema actual de la versión 2.

## GitHub Copilot en VS Code

Crea `.vscode/mcp.json`:

```json
{
  "inputs": [
    {
      "id": "ciele-key",
      "type": "promptString",
      "password": true,
      "description": "Ciele API key"
    }
  ],
  "servers": {
    "ciele": {
      "type": "stdio",
      "command": "node",
      "args": ["<repo>/packages/mcp/bin/ciele-mcp.mjs"],
      "env": {
        "CIELE_API_KEY": "${input:ciele-key}",
        "CIELE_BASE_URL": "https://ciele.example.edu",
        "CIELE_MCP_READ_ONLY": "1"
      }
    }
  }
}
```

Ejecuta **MCP: List Servers** desde la Paleta de comandos. Inicia `ciele` e
inspecciona su salida cuando falle una conexión.

Consulta la
[VS Code MCP guide](https://code.visualstudio.com/docs/agent-customization/mcp-servers)
para conocer las ubicaciones de configuración y los controles de confianza.

## CLI de GitHub Copilot

Ejecuta el comando interactivo `/mcp add`. Selecciona un servidor local `stdio`
e introduce el comando Ciele.

También puedes empezar con este comando:

```bash
copilot mcp add ciele -- node <repo>/packages/mcp/bin/ciele-mcp.mjs
```

Añade las tres variables de entorno de Ciele a través de la configuración de MCP
de Copilot. No incluyas la clave de API en el control de versiones.

Consulta la
[guía de MCP de la CLI de GitHub Copilot](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-mcp-servers)
para conocer el formato de configuración actual.

## Prompts copiables

Inicia cada nueva conexión con esta comprobación de solo lectura:

```text
Call ciele_identity. Show the deployment version, available domains,
Organization ID, and Role. Do not change data.
```

Usa este *prompt* para revisar los *Assistants*:

```text
List all Ciele Assistants. For each Assistant, list its enabled Flows.
Identify duplicate or unclear Flow names. Do not change data.
```

Usa este prompt para revisar la ingesta de conocimiento:

```text
List the Sources linked to Assistant <assistant-id>.
List each Source and its ingestion status.
Report Sources that are not ready. Do not retry or delete a Source.
```

Usa este *prompt* después de habilitar el acceso de escritura:

```text
Create one FAQ for Assistant <assistant-id>.
Question: "When does enrollment close?"
Answer: "Enrollment closes on <date>."
Show the proposed tool input and ask for approval before the call.
```

Usa este *prompt* antes de la publicación:

```text
Read the publication status for Assistant <assistant-id>.
Summarize the current live version. Do not publish or unpublish anything.
```

<Callout type="warn" title="Review write operations">
Read the proposed tool input before you approve it. API Roles and MCP read-only mode are independent controls.
</Callout>

## Clientes sin proceso local

La versión web de ChatGPT no puede iniciar un servidor local `stdio`. En su
lugar, dirígelo al endpoint alojado. La implementación debe ser accesible desde
la internet pública, lo cual no ocurre con una pila local de Ciele Desktop.

Pi no incluye un procedimiento de conexión MCP integrado. Las extensiones de Pi
pueden añadir compatibilidad con MCP, pero Ciele no distribuye ni prueba ninguna
extensión de este tipo. Utiliza `ciele ... --json` a través de un flujo de
trabajo de shell aprobado o llama directamente a la [HTTP API](/developers/api).
