---
title: Clés API
description: Créez, révoquez et supprimez les identifiants de l'organisation pour l'accès par programme.
---

Une clé API permet à un programme d'accéder à une Organisation. Ciele ne stocke
que le hachage du secret.

## Créer une clé

1. Ouvrez **Settings**.
2. Sélectionnez **API Keys**.
3. Sélectionnez **Create API key**.
4. Saisissez un nom pour la clé.
5. Sélectionnez le Role minimum requis.
6. Copiez le secret dans un gestionnaire d'identifiants sécurisé.

Ciele affiche le secret `ciele_sk_...` une seule fois. Vous ne pourrez pas
récupérer le même secret ultérieurement.

Le Role sélectionné ne peut pas être supérieur à votre propre Role. Ciele
vérifie le Role pour chaque opération de l'API.

## Révoquer une clé

1. Ouvrez **Settings > API Keys**.
2. Recherchez la clé.
3. Sélectionnez **Revoke**.
4. Confirmez l'action.

La révocation bloque les nouvelles requêtes qui utilisent la clé. Ciele conserve
l'enregistrement de la clé à des fins d'audit.

## Supprimer une clé

Vous ne pouvez supprimer qu'une clé qui a déjà été révoquée. Un Admin ou un
Owner peut effectuer cette action.

1. Ouvrez **Settings > API Keys**.
2. Recherchez la clé révoquée.
3. Sélectionnez l'icône de corbeille rouge.
4. Confirmez l'action.

Ciele supprime l'enregistrement de clé de la liste. Vous ne pouvez pas annuler
cette action.

<Callout type="warn" title="Protect the secret">
Do not put an API key in source control, public logs, prompts, or screenshots. Use an environment variable or a secret store.
</Callout>
