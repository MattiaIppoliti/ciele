title: Panneau Développeur
description: Consultez les extraits de code CLI, cURL et MCP correspondant à la page de la console que vous avez ouverte.
---

Le Developer Panel affiche l'équivalent programmatique de la page de la console
que vous consultez. Il répertorie les opérations de cette page sous forme de
snippets prêts à l'emploi, dans lesquels les identifiants de la page sont déjà
inclus.

Utilisez-le pour transformer une tâche manuelle en script, ou pour savoir quelle
opération d'API se cache derrière un contrôle de la console.

## Ouvrez le panneau

Sélectionnez le bouton `</>` situé à droite de la barre supérieure. Maintenez le
pointeur au-dessus pour afficher le domaine de la page, par exemple **Flows
API**. Vous pouvez également appuyer sur `D`.

Le panneau s'ouvre dans la barre latérale droite et reste ouvert lorsque vous
passez à une autre page.

Un éditeur d'assistant utilise le même rail pour l'aperçu en direct (Live
Preview). Un seul des deux est visible à la fois.

<Callout title="No button means no API">
The button is absent when the page has no API operations. Insights and the Style setup section show none. The absence is correct information, not a defect.
</Callout>

## Lire un extrait de code

Chaque opération comporte trois onglets.

| Tab | Contenu |
| --- | --- |
| CLI | La commande `ciele` pour l'opération. |
| cURL | La requête HTTP, avec l'origine de votre propre déploiement. |
| MCP | Le nom de l'outil et les arguments `action` pour un client IA. |

Deux badges peuvent apparaître à côté d'une opération :

- Le badge **Role** indique le Role le moins élevé dont une clé API a besoin. Il
  découle du guard appliqué par l'API.
- Le badge **Idempotent** indique qu'une requête peut être réessayée en toute
  sécurité avec un en-tête `Idempotency-Key`.

## Les corps de requête sont des formes

Un corps cURL affiche des espaces réservés typés, et non des valeurs d'exemple,
et s'arrête à deux niveaux d'imbrication.

C'est délibéré. Une valeur inventée mais plausible est dangereuse, car quelqu'un
pourrait la coller dans une véritable Organisation. Consultez la
[référence de l'API](/developers/api) pour connaître le contrat complet d'un
champ.

## Avant l'exécution d'un snippet

Chaque snippet nécessite une [clé API d'organisation](/developers/api-keys). Le
panneau l'indique lorsque l'organisation n'en a pas.

Seul un Owner ou un Admin peut créer une clé. Le panneau indique le Role requis
lorsque votre propre Role ne le permet pas.
