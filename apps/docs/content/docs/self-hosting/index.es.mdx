El repositorio contiene la consola de administración, el entorno de ejecución de
widgets, la capa de datos, el ejecutor de migraciones, las tareas programadas,
la API, la CLI y el servidor MCP.

El ejemplo de implementación admitido utiliza Docker Compose en un único host.
No incluye Kubernetes, Helm ni el funcionamiento multinodo.

## Empieza aquí

1. Lee [Installation](/self-hosting/installation) o utiliza
   [Ciele Desktop](/self-hosting/desktop) para una configuración guiada en macOS
   o Windows que no requiere terminal.
2. Revisa [Configuration](/self-hosting/configuration).
3. Selecciona los [Workers](/self-hosting/workers) opcionales.
4. Configura TLS antes de la exposición pública.
5. Lee [Upgrading](/self-hosting/upgrade) antes de cambiar de versión.

Consulta la sección [Architecture](/self-hosting/architecture) para comprender
los límites actuales de los paquetes y las solicitudes.
