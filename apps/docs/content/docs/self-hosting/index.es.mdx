El repositorio contiene la consola de administración, el entorno de ejecución de
widgets, la capa de datos, el ejecutor de migraciones, los trabajos programados,
la API, la CLI y el servidor MCP.

El ejemplo de implementación compatible utiliza Docker Compose en un host. No
incluye Kubernetes, Helm ni el funcionamiento multinodo.

## Empieza aquí

1. Lee [Instalación](/self-hosting/installation).
2. Revisa [Configuración](/self-hosting/configuration).
3. Selecciona [Workers](/self-hosting/workers) opcionales.
4. Configura TLS antes de la exposición pública.
5. Lee [Actualización](/self-hosting/upgrade) antes de cambiar de versión.

Consulta la sección [Arquitectura](/self-hosting/architecture) para comprender
los límites actuales de paquetes y solicitudes.
