Il repository contiene la console di amministrazione, il runtime dei widget, il
livello dati, il runner di migrazione, i job pianificati, l'API, la CLI e il
server MCP.

L'esempio di distribuzione supportato utilizza Docker Compose su un host. Non
include Kubernetes, Helm o il funzionamento multi-nodo.

## Inizia qui

1. Leggi [Installazione](/self-hosting/installation).
2. Consulta [Configurazione](/self-hosting/configuration).
3. Seleziona i [Workers](/self-hosting/workers) opzionali.
4. Configura TLS prima dell'esposizione pubblica.
5. Leggi [Aggiornamento](/self-hosting/upgrade) prima di cambiare versione.

Utilizza la sezione [Architecture](/self-hosting/architecture) per comprendere
gli attuali limiti relativi a pacchetti e richieste.
