Il repository contiene la console di amministrazione, il runtime dei widget, il
livello dati, il runner per le migrazioni, i job pianificati, l'API, la CLI e il
server MCP.

L'esempio di deployment supportato utilizza Docker Compose su un singolo host.
Non include Kubernetes, Helm né il funzionamento multi-nodo.

## Inizia da qui

1. Leggi [Installation](/self-hosting/installation) oppure utilizza
   [Ciele Desktop](/self-hosting/desktop) per una configurazione guidata su
   macOS o Windows che non richiede l'uso del terminale.
2. Consulta [Configuration](/self-hosting/configuration).
3. Seleziona i [Workers](/self-hosting/workers) opzionali.
4. Configura TLS prima dell'esposizione pubblica.
5. Leggi [Upgrading](/self-hosting/upgrade) prima di cambiare versione.

Consulta la sezione [Architecture](/self-hosting/architecture) per comprendere
gli attuali limiti dei pacchetti e delle richieste.
