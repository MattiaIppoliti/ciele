---
title: Confine open-source
description: Identifica il core pubblico e la directory enterprise separata.
---

Il core pubblico di Ciele utilizza la licenza `AGPL-3.0-only`. Il suo codice
sorgente include l'applicazione del prodotto e i pacchetti di runtime condivisi.

Il repository può anche contenere una directory `ee/` separata. Quella directory
ha i propri avvisi di licenza e non fa parte del core AGPL.

## Regola per la documentazione pubblica

La documentazione Open Source descrive solo i componenti necessari per
compilare, eseguire e comprendere il core pubblico.

Non elenca gli elementi interni dell'azienda. Leggi il file della licenza in
ogni area di codice prima di ridistribuire o modificare tale area.

## Principali aree open-source

- `apps/web` contiene l'applicazione del prodotto e i percorsi API.
- `apps/docs` contiene questo sito di documentazione.
- `apps/desktop` contiene l'applicazione Ciele Desktop.
- `packages` contiene i pacchetti condivisi del prodotto e quelli per l'accesso
  programmatico.
- `services` contiene i servizi worker opzionali.
- `supabase` contiene le migrazioni dello schema e la configurazione dei dati
  locali.
- `deploy` contiene l'esempio di deployment su host singolo.
