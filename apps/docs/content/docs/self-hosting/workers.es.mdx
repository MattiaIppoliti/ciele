---

La pila predeterminada no inicia el perfil `workers`. La búsqueda y la ingesta
de sitios web continúan con capacidades reducidas.

Sin el trabajador de grafos, Knowledge utiliza la recuperación vectorial y
léxica. Sin Crawl4AI, Ciele utiliza su rastreador de búsqueda integrado.

## Habilita el perfil

Establece estos valores en `deploy/.env`:

```dotenv
COMPOSE_PROFILES=db,migrate,app,cron,workers
GRAPH_WORKER_API_TOKEN=<generated-token>
GRAPH_LLM_API_KEY=<provider-key>
CRAWL4AI_API_TOKEN=<generated-token>
CRAWL4AI_SECRET_KEY=<generated-token>
```

A continuación, inicia la pila:

```bash
docker compose -f deploy/docker-compose.yml up -d
```

Los dos trabajadores opcionales pueden requerir aproximadamente 8 GiB de
memoria. Mide el uso real en el host que hayas seleccionado.

## Comprueba el estado del trabajador

```bash
docker compose -f deploy/docker-compose.yml ps
docker compose -f deploy/docker-compose.yml logs -f graph-worker crawl4ai
```

No expongas los puertos de los trabajadores ni los tokens a la red pública.
