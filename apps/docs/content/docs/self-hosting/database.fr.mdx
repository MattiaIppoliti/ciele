Ciele utilise Postgres avec pgvector. Le profil Compose `db` exécute également
l'authentification, PostgREST, le stockage et une passerelle.

## Appliquer les migrations

Le service one-shot `migrate` applique les migrations SQL en attente et crée les
compartiments de stockage requis. L'application démarre une fois que ce service
a réussi.

Ne modifiez pas une migration appliquée. Ajoutez une nouvelle migration pour
chaque modification de schéma.

## Développement local

```bash
pnpm db:start
pnpm db:reset
pnpm db:status
```

`pnpm db:reset` supprime les données de la base de données locale et applique à
nouveau les migrations et les données d'amorçage.

## Données persistantes

Le volume `postgres-data` contient la base de données. Le volume `storage-data`
contient les objets téléchargés.

Sauvegardez les deux volumes pour obtenir une copie complète des données. Testez
la restauration avant de vous fier à un processus de sauvegarde.

<Callout type="warn" title="Volume deletion removes data">
`docker compose -f deploy/docker-compose.yml down -v` deletes the database and uploaded-file volumes. Use it only for an intentional reset.
</Callout>

## Isolation des locataires

Les requêtes de la console utilisent un accès authentifié à la base de données
et une sécurité au niveau des lignes. Les opérations avec clé API utilisent un
wrapper de base de données épinglé à l'organisation et des vérifications de
capacité.
