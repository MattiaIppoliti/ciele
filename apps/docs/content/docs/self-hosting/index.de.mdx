Das Repository enthält die Administratorkonsole, die Widget-Laufzeitumgebung,
die Datenschicht, den Migrations-Runner, geplante Jobs, die API, die CLI und den
MCP-Server.

Das unterstützte Bereitstellungsbeispiel verwendet Docker Compose auf einem
Host. Es umfasst weder Kubernetes noch Helm oder den Betrieb mit mehreren
Knoten.

## Beginnen Sie hier

1. Lesen Sie [Installation](/self-hosting/installation) oder verwenden Sie
   [Ciele Desktop](/self-hosting/desktop) für eine geführte Einrichtung auf
   macOS, für die kein Terminal erforderlich ist.
2. Lesen Sie [Konfiguration](/self-hosting/configuration) durch.
3. Wählen Sie optionale [Workers](/self-hosting/workers) aus.
4. Konfigurieren Sie TLS, bevor Sie die Plattform öffentlich zugänglich machen.
5. Lesen Sie [Upgrading](/self-hosting/upgrade), bevor Sie die Version ändern.

Im Abschnitt [Architecture](/self-hosting/architecture) finden Sie Informationen
zu den aktuellen Paket- und Anforderungsgrenzen.
