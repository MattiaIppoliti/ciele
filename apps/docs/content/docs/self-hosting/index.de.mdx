Das Repository enthält die Administrator-Konsole, die Widget-Runtime, die
Datenschicht, den Migration Runner, geplante Jobs, die API, die CLI und den
MCP-Server.

Das unterstützte Bereitstellungsbeispiel verwendet Docker Compose auf einem
einzigen Host. Es umfasst weder Kubernetes noch Helm noch den Betrieb mit
mehreren Knoten.

## Hier beginnen

1. Lesen Sie [Installation](/self-hosting/installation) oder verwenden Sie
   [Ciele Desktop](/self-hosting/desktop) für eine geführte Einrichtung unter
   macOS oder Windows, die kein Terminal erfordert.
2. Überprüfen Sie [Configuration](/self-hosting/configuration).
3. Wählen Sie optionale [Workers](/self-hosting/workers) aus.
4. Konfigurieren Sie TLS, bevor Sie die Anwendung öffentlich zugänglich machen.
5. Lesen Sie [Upgrading](/self-hosting/upgrade), bevor Sie die Version wechseln.

Nutzen Sie den Abschnitt [Architecture](/self-hosting/architecture), um die
aktuellen Grenzen für Pakete und Anfragen zu verstehen.
