Das Repository enthält die Administratorkonsole, die Widget-Runtime, die
Datenschicht, den Migrations-Runner, geplante Jobs, die API, die CLI und den
MCP-Server.

Das unterstützte Bereitstellungsbeispiel verwendet Docker Compose auf einem
Host. Es umfasst weder Kubernetes noch Helm noch den Betrieb mit mehreren
Knoten.

## Beginnen Sie hier

1. Lesen Sie [Installation](/self-hosting/installation).
2. Überprüfen Sie die [Konfiguration](/self-hosting/configuration).
3. Wählen Sie optionale [Workers](/self-hosting/workers) aus.
4. Konfigurieren Sie TLS, bevor Sie die Umgebung öffentlich zugänglich machen.
5. Lesen Sie [Upgrading](/self-hosting/upgrade), bevor Sie die Version ändern.

Verwenden Sie den Abschnitt [Architecture](/self-hosting/architecture), um die
aktuellen Paket- und Anforderungsgrenzen zu verstehen.
