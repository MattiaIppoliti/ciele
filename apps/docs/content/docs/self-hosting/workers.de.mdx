title: Hintergrund-Worker
description: Aktivieren Sie die optionalen Crawl-Dienste für Graph-Abruf und JavaScript-Rendering.
---

Der Standard-Stack startet das Profil `workers` nicht. Die Suche und die
Website-Erfassung werden mit eingeschränkten Funktionen fortgesetzt.

Ohne den Graph-Worker verwendet Knowledge Vektor- und lexikalische Abfrage. Ohne
Crawl4AI verwendet Ciele seinen integrierten Fetch-Crawler.

## Aktivieren Sie das Profil

Legen Sie diese Werte in `deploy/.env` fest:

```dotenv
COMPOSE_PROFILES=db,migrate,app,cron,workers
GRAPH_WORKER_API_TOKEN=<generated-token>
GRAPH_LLM_API_KEY=<provider-key>
CRAWL4AI_API_TOKEN=<generated-token>
CRAWL4AI_SECRET_KEY=<generated-token>
```

Starten Sie dann den Stack:

```bash
docker compose -f deploy/docker-compose.yml up -d
```

Die beiden optionalen Worker können etwa 8 GiB Speicher benötigen. Messen Sie
die tatsächliche Nutzung auf Ihrem ausgewählten Host.

## Überprüfen Sie den Status des Workers

```bash
docker compose -f deploy/docker-compose.yml ps
docker compose -f deploy/docker-compose.yml logs -f graph-worker crawl4ai
```

Stellen Sie Worker-Ports oder -Token nicht dem öffentlichen Netzwerk zur
Verfügung.

## Langzeitspeicher-Jobs

Long-term Memory verwendet das integrierte dauerhafte Job-Ledger. Das optionale
Profil `workers` ist nicht erforderlich.

Jeder angemeldete Turn plant nach einem 15-minütigen Ruhefenster einen
`promote_memories`-Job. Das `cron`-Profil leitet diese Jobs über die bestehende
geplante Route weiter.

Behalten Sie `cron` in `COMPOSE_PROFILES` bei, wenn der Langzeitspeicher
aktiviert ist. Die standardmäßige Self-Host-Konfiguration enthält dies bereits.

Der Job überspringt die Extraktion, wenn der Speicher deaktiviert ist oder das
tägliche Token-Budget aufgebraucht ist. Er wird auch übersprungen, wenn keine
geeignete Modellverbindung vorhanden ist.
