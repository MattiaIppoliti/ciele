Le dépôt contient la console d'administration, le runtime des widgets, la couche
de données, le moteur de migration, les tâches planifiées, l'API, la CLI et le
serveur MCP.

L'exemple de déploiement pris en charge utilise Docker Compose sur un hôte. Il
n'inclut pas Kubernetes, Helm ni le fonctionnement multinœuds.

## Commencez ici

1. Lisez [Installation](/self-hosting/installation) ou utilisez
   [Ciele Desktop](/self-hosting/desktop) pour une configuration guidée sur
   macOS qui ne nécessite pas de terminal.
2. Consultez [Configuration](/self-hosting/configuration).
3. Sélectionnez les [Workers](/self-hosting/workers) facultatifs.
4. Configurez le protocole TLS avant toute exposition publique.
5. Lisez [Mise à niveau](/self-hosting/upgrade) avant de changer de version.

Utilisez la section [Architecture](/self-hosting/architecture) pour comprendre
les limites actuelles des paquets et des requêtes.
