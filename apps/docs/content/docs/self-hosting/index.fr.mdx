Le cœur de Ciele est open source sous la licence **AGPL-3.0**, et vous pouvez
l'exécuter vous-même. L'édition open source est l'ensemble du produit que vos
visiteurs et administrateurs utilisent : la console d'administration, le widget
de chat, le routeur [flow](/flows), le pipeline [knowledge](/knowledge) et de
récupération, ainsi que les surfaces d'opérations — [inbox](/operations/inbox),
[improvements](/operations/improvements), [insights](/operations/insights) et
[alerts](/operations/alerts).

<Callout title="Same product, you operate it">
Every feature page in the main [Documentation](/) applies to a self-hosted
deployment. The difference is operational: you provide the infrastructure, the
database, and the AI provider keys, and you apply upgrades. The managed
alternative is [Ciele Cloud](/cloud).
</Callout>

## Ce que vous fournissez

- **A place to run it.** Les applications sont des applications Next.js standard
  ; tout environnement exécutant Node peut les héberger.
- **A database.** Ciele stocke ses données dans Postgres, en utilisant
  [Supabase](/self-hosting/database) pour la base de données, l'authentification
  et la sécurité au niveau des lignes.
- **AI provider keys.** Les assistants font appel à un fournisseur d'IA pour
  générer des réponses ; vous apportez vos propres clés. Voir
  [Configuration](/self-hosting/configuration).

## La licence, en bref

AGPL-3.0 est une licence open source. Vous pouvez exécuter, étudier, modifier et
partager le logiciel. Sa condition déterminante est la clause réseau : si vous
modifiez Ciele et proposez cette version modifiée à d'autres via un réseau, vous
devez également proposer à ces utilisateurs le code source correspondant de
votre version modifiée. L'exécuter sans modification, ou le modifier uniquement
pour un usage interne à votre propre organisation, ne déclenche pas cette
obligation. Cette page est un résumé pratique, et non un avis juridique ; les
conditions faisant foi se trouvent dans le fichier `LICENSE` à la racine du
dépôt.

Si votre organisation préfère ne pas assumer les obligations de la licence AGPL
ou le travail d'exploitation, [Ciele Cloud](/cloud) propose le même cœur
logiciel dans le cadre d'un accord commercial.

## Ce qui n'est pas inclus dans l'édition open source

Un petit ensemble de fonctionnalités commerciales de services gérés se trouve en
dehors du noyau open source et ne fait pas partie d'un déploiement auto-hébergé.
Consultez [La limite de l'open-core](/self-hosting/open-core-boundary) pour
connaître la démarcation exacte.
