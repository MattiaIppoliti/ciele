Le dépôt contient la console d'administration, le runtime des widgets, la couche
de données, le runner de migration, les tâches planifiées, l'API, la CLI et le
serveur MCP.

L'exemple de déploiement pris en charge utilise Docker Compose sur un seul hôte.
Il n'inclut pas Kubernetes, Helm ni le fonctionnement multi-nœuds.

## Commencez ici

1. Lisez [Installation](/self-hosting/installation), ou utilisez
   [Ciele Desktop](/self-hosting/desktop) pour une configuration guidée sur
   macOS ou Windows qui ne nécessite pas de terminal.
2. Consultez [Configuration](/self-hosting/configuration).
3. Sélectionnez les [Workers](/self-hosting/workers) optionnels.
4. Configurez TLS avant l'exposition publique.
5. Lisez [Upgrading](/self-hosting/upgrade) avant de changer de version.

Consultez la section [Architecture](/self-hosting/architecture) pour comprendre
les limites actuelles des packages et des requêtes.
