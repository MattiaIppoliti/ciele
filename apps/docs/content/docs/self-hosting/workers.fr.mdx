La pile par défaut ne démarre pas le profil `workers`. La recherche et
l'ingestion de sites Web se poursuivent avec des capacités réduites.

Sans le worker graphique, Knowledge utilise la recherche vectorielle et
lexicale. Sans Crawl4AI, Ciele utilise son robot d'indexation Fetch intégré.

## Activez le profil

Définissez ces valeurs dans `deploy/.env` :

```dotenv
COMPOSE_PROFILES=db,migrate,app,cron,workers
GRAPH_WORKER_API_TOKEN=<generated-token>
GRAPH_LLM_API_KEY=<provider-key>
CRAWL4AI_API_TOKEN=<generated-token>
CRAWL4AI_SECRET_KEY=<generated-token>
```

Ensuite, démarrez la pile :

```bash
docker compose -f deploy/docker-compose.yml up -d
```

Les deux workers optionnels peuvent nécessiter environ 8 GiB de mémoire. Mesurez
l'utilisation réelle sur l'hôte que vous avez sélectionné.

## Vérifiez l'état du worker

```bash
docker compose -f deploy/docker-compose.yml ps
docker compose -f deploy/docker-compose.yml logs -f graph-worker crawl4ai
```

N'exposez pas les ports ou les jetons des workers au réseau public.
