Ciele es un monorepo de TypeScript con una aplicación de producto Next.js,
paquetes compartidos, Postgres y workers opcionales.

## Límites principales

<Mermaid
  title="Cada solicitud llega a Postgres a través de la misma capa de acceso a datos"
  chart={`

  UI["Console and widget"]
  API["Server actions and API v1"]

  PG[("Postgres and storage")]
  UI --> API
  API --> OPS
  API --> RUNTIME
  OPS --> DB
  RUNTIME --> DB
  DB --> PG
`}
/>

Un worker opcional se ejecuta junto al entorno de ejecución para realizar el
rastreo. De forma predeterminada, permanece desactivado. Consulta
[Background workers](/self-hosting/workers).

El enrutador de Flow sigue siendo el elemento con autoridad. Un modelo puede
clasificar la intención, generar acciones seleccionadas y llamar a herramientas
registradas.

El modelo no puede sustituir el orden del Flow, las condiciones de los
objetivos, la configuración de las acciones, la autorización de la organización
ni las comprobaciones de salida de red.
