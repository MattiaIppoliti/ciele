Ciele est un monorepo TypeScript avec une application produit Next.js, des
paquets partagés, Postgres et des workers optionnels.

## Limites principales

<Mermaid
  title="Chaque requête parvient à Postgres via la même couche d'accès aux données"

Des processus de travail optionnels s'exécutent en parallèle de l'environnement
d'exécution pour l'indexation et la construction de graphes. Ils lisent la même
base de données et restent désactivés par défaut. Voir
[Processus d'arrière-plan](/self-hosting/workers).

Le routeur Flow reste l'autorité. Un modèle peut classer l'intention, générer
des actions sélectionnées et appeler des outils enregistrés.

Le modèle ne peut pas remplacer l'ordre Flow, les conditions objectives, la
configuration des actions, l'autorisation de l'organisation ou les vérifications
de sortie du réseau.
