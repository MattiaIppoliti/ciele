Ciele est un monorepo TypeScript comprenant une application produit Next.js, des
packages partagés, Postgres et des workers optionnels.

## Principales limites

<Mermaid
  title="Chaque requête atteint Postgres via la même couche d'accès aux données"

/>

Un worker optionnel s'exécute parallèlement au runtime pour le crawling. Il
reste désactivé par défaut. Voir [Background workers](/self-hosting/workers).

Le routeur Flow reste l'autorité de référence. Un modèle peut classer
l'intention, générer des actions sélectionnées et appeler des outils
enregistrés.

Le modèle ne peut pas remplacer l'ordre du Flow, les conditions d'objectif, la
configuration des actions, l'autorisation de l'organisation ni les contrôles de
sortie réseau.
