Knowledge verwendet Concepts im Open Knowledge Format (OKF). Ein Concept enthält
einen Verweis auf seine ursprüngliche Source.

Durch die Aufnahme von FAQs wird ein kuratiertes Concept mit Frage- und
Antwort-Herkunft erstellt. Bei der Aufnahme von Dateien und Websites bleibt das
ursprüngliche Source-Objekt gegebenenfalls erhalten.

## Abruf

Die Laufzeitumgebung kann Concepts über Vektorsuche und lexikalisches Fallback
abrufen. Im Graph-Modus kann die Navigation über indizierte Concept-Beziehungen
hinzugefügt werden.

Jeder Pfad wird durch die Links vom Assistenten zur Quelle begrenzt. Ein Treffer
von einer Quelle, die nicht mit dem anfragenden Assistenten verknüpft ist, wird
sowohl im Graph-Pfad als auch im Vektor-Pfad verworfen.

Ein Kontexthinweis kann den Abruf auf eine relevante Sammlung oder einen
kursähnlichen Kontext beschränken, wenn die Laufzeitumgebung einen solchen
bereitstellt.

Deep Search verbessert die Wissensnavigation innerhalb der Grenzen der
Laufzeitumgebung. Es werden keine Abfragen im öffentlichen Web durchgeführt.

## Zitatauflösung

Die endgültige Antwort zitiert benannte Quellen, nicht undurchsichtige
Suchblöcke. Zitierkennungen verweisen über das Konzept auf die ursprüngliche
Quelle.

Der Besucher kann nach der Antwort die Quellen-Ansicht öffnen. Der Posteingang
speichert dieselben Zitierteile zusammen mit der Konversation.

## Löschen und erneutes Durchforsten

Durch das Löschen einer Quelle werden zugehörige Konzepte für jeden verknüpften
Assistenten aus dem aktiven Graphen und den Suchdaten entfernt. Durch das
Entfernen eines Links wird nichts zurückgezogen. Es verhindert, dass ein
Assistent die Quelle erreicht.

Ein erneutes Durchforsten der Website startet die Extraktion und Indizierung für
diese Quelle neu.
