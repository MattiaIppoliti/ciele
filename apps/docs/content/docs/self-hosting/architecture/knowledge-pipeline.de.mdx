Ciele speichert Wissen als Dokumente im Open Knowledge Format (OKF). Ein
Document behält eine Referenz auf seine ursprüngliche Source. OKF bezeichnet
denselben Datensatz als Concept, und die Datenbanktabellen behalten diesen Namen
bei.

Bei der Erfassung von Dateien, Texten und Websites wird der extrahierte Text
unverändert gespeichert. Ciele schreibt eine Source nicht mit einem Modell um.
Die FAQ-Erfassung erstellt ein kuratiertes Dokument mit Herkunftsnachweis für
Fragen und Antworten. Bei der Erfassung von Dateien und Websites bleibt das
ursprüngliche Source-Objekt, soweit zutreffend, erhalten.

## Abruf

Die Runtime ruft 20 Kandidat-Passagen über die Vektorsuche und den lexikalischen
Fallback ab. Anschließend wählt ein Reranking-Modell die 6 Passagen aus, die der
Assistant liest.

Der Schritt „Rerank“ verwendet die Plattform `AI_GATEWAY_API_KEY`. Wenn der
Schlüssel nicht gesetzt ist oder das Reranking-Modell nicht rechtzeitig
antwortet, behält die Suche die Reihenfolge des Index bei. In beiden Fällen
werden die Antworten fortgesetzt.

Jede Suche wird durch die Verknüpfungen vom Assistenten zur Quelle eingegrenzt.
Ciele lässt einen Treffer aus einer Source weg, die nicht mit dem abfragenden
Assistant verknüpft ist.

Ein Context Hint kann die Abfrage auf eine relevante Collection oder einen
kursähnlichen Kontext einschränken, wenn die Runtime einen solchen bereitstellt.

Deep Search verbessert die Navigation im Knowledge innerhalb der
Laufzeitgrenzen. Es werden keine Abfragen im öffentlichen Web durchgeführt.

## Auflösung von Quellenangaben

Die endgültige Antwort zitiert benannte Sources, keine undurchsichtigen
Suchchunks. Citation identifiers werden über das Document bis zu ihrer
ursprünglichen Source aufgelöst.

Der Visitor kann nach der Antwort die Anzeige „Sources“ öffnen. Die Inbox
speichert dieselben Zitatteile zusammen mit der Conversation.

## Löschen und erneutes Crawlen

Das Löschen einer Quelle entfernt die zugehörigen Documents aus den aktiven
Suchdaten für jeden verknüpften Assistant. Das Entfernen eines einzelnen Links
führt zu keiner Deaktivierung. Dadurch wird verhindert, dass ein Assistant auf
die Source zugreifen kann.

Ein erneutes Crawlen der Website startet die Extraktion und Indizierung für
diese Quelle neu.
