## Acquisizione

Ciele memorizza la Knowledge come Documents in Open Knowledge Format (OKF). Un
Document mantiene un riferimento alla sua Source originale. OKF chiama lo stesso
record Concept, e le tabelle del database mantengono quel nome.

L'ingestione di file, testo e siti web memorizza il testo estratto senza
modifiche. Ciele non riscrive una Source con un modello. L'ingestione delle FAQ
crea un Document curato con provenienza di domande e risposte. L'ingestione di
file e siti web preserva l'oggetto Source originale, ove applicabile.

## Recupero

Il runtime recupera 20 passaggi candidati tramite ricerca vettoriale e fallback
lessicale. Un modello di reranking seleziona quindi i 6 passaggi che
l'Assistente legge.

La fase di reranking utilizza la piattaforma `AI_GATEWAY_API_KEY`. Se la chiave
non è impostata o il modello di reranking non risponde in tempo, la ricerca
mantiene l'ordine dell'indice. In entrambi i casi, le risposte proseguono.

Ogni ricerca viene delimitata dai collegamenti Assistant-to-Source. Ciele scarta
un risultato proveniente da una Source che non è collegata all'Assistant che
effettua la query.

Un Context Hint può limitare il recupero a una Collection pertinente o a un
contesto di tipo corso quando il runtime ne fornisce uno.

Deep Search aumenta il lavoro di navigazione nella Knowledge entro i limiti del
runtime. Non esegue query sul web pubblico.

## Risoluzione delle citazioni

La risposta finale cita Sources denominate, non frammenti di ricerca opachi. Gli
identificatori delle citazioni vengono risolti attraverso il Document fino alla
Source originale.

Puoi aprire la visualizzazione Sources dopo la risposta. L'Inbox memorizza le
stesse parti di citazione insieme alla Conversation.

## Eliminazione e nuovo crawling

L'eliminazione di una Source ritira i Document correlati dai dati di ricerca
attivi, per ogni Assistant collegato. La rimozione di un singolo link non
comporta l'archiviazione di nulla. Impedisce a un Assistente di accedere alla
Source.

Il recrawling del sito web riavvia l'estrazione e l'indicizzazione per quella
Source.
