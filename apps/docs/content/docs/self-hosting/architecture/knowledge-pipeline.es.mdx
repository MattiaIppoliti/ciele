Ciele almacena el Conocimiento como Documentos en Open Knowledge Format (OKF).
Un Document conserva una referencia a su Source original. OKF denomina Concept a
ese mismo registro, y las tablas de la base de datos mantienen ese nombre.

La ingesta de archivos, texto y sitios web almacena el texto extraído sin
cambios. Ciele no reescribe un Source con un modelo. La ingesta de preguntas
frecuentes crea un Documento depurado con la procedencia de las preguntas y
respuestas. La ingesta de archivos y sitios web conserva el objeto Source
original cuando procede.

## Recuperación

El tiempo de ejecución recupera 20 pasajes candidatos mediante búsqueda
vectorial y fallback léxico. A continuación, un modelo de reordenación
selecciona los 6 pasajes que lee el asistente.

El paso de reranking utiliza la plataforma `AI_GATEWAY_API_KEY`. Si no se ha
establecido la clave o el modelo de reordenación no responde a tiempo, la
búsqueda mantiene el orden del índice. En ambos casos, las respuestas continúan.

Cada búsqueda se delimita según los enlaces de asistente a fuente. Ciele
descarta un resultado de una Source que no está vinculada al Assistant que
realiza la consulta.

Un Context Hint puede limitar la recuperación a una Collection relevante o a un
contexto de tipo curso cuando el entorno de ejecución proporciona uno.

Deep Search aumenta el trabajo de navegación por Knowledge dentro de los límites
del tiempo de ejecución. No realiza consultas en la web pública.

## Resolución de citas

La respuesta final cita Sources con nombre, no fragmentos de búsqueda opacos.
Los identificadores de citas se resuelven a través del Document hasta su Source
original.

Puedes abrir la pantalla Sources después de la respuesta. La Inbox almacena las
mismas partes de las citas junto con la Conversation.

## Eliminación y nuevo rastreo

La eliminación de una fuente retira los Documentos relacionados de los datos de
búsqueda activos, para cada Asistente vinculado. Eliminar un enlace no retira
nada. Impide que un asistente acceda a la fuente.

El recrawleo del sitio web reinicia la extracción y la indexación para esa
Fuente.
