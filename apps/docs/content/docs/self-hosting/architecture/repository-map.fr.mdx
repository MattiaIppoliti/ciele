## Applications

| Chemin | Responsabilité |
| --- | --- |
| `apps/web` | Administrator console, widget runtime, pages publiques, actions serveur et API v1. |
| `apps/docs` | Application de documentation Fumadocs et pipeline de traduction. |

## Packages partagés

| Chemin | Responsabilité |
| --- | --- |
| `packages/core` | Types de domaine, règles Flow pures, valeurs par défaut, conditions et logique d'analyse. |
| `packages/db` | Interfaces de persistance, stockage simulé et implémentation Supabase. |
| `packages/agent` | Exécution des tours, fournisseurs de modèles, outils de connaissances, ingestion et évaluation. |
| `packages/ops` | Opérations d'organisation partagée utilisées par les actions de la console et l'API v1. |
| `packages/client` | Client typé pour l'API v1. |
| `packages/cli` | Interface de terminal au-dessus du client typé. |
| `packages/mcp` | Adaptateur MCP local à quatorze outils, basé sur le client typé. |
| `packages/ui` | Composants d'interface utilisateur partagés. |
| `packages/charts` | Visualisations d'analyses partagées. |

## Services et infrastructure

| Path | Responsibility |
| --- | --- |
| `services/crawl4ai` | Configuration optionnelle du crawler avec rendu JavaScript. |
| `supabase/migrations` | Modifications du schéma de base de données, dans l'ordre. |
| `deploy` | Déploiement Docker Compose sur un seul hôte et scripts de bootstrap. |

## Sens des dépendances

Les règles pures appartiennent à `packages/core`. Le comportement de persistance
relève de `packages/db`.

Les mutations réutilisables ont leur place dans `packages/ops`. Le comportement
du modèle et de la récupération relève de `packages/agent`.

Les adaptateurs de surface dans `apps/web`, `packages/cli` et `packages/mcp` ne
doivent pas créer de comportements de domaine distincts.
