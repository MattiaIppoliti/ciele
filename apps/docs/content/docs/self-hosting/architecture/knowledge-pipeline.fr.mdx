## Ingestion

<Mermaid
  title="Une Source devient un Concept consultable avant d'indiquer qu'elle est prête"
  chart={`

  SOURCE["Website, file, text, or FAQ"]
  EXTRACT["Extract the content"]
  CONCEPT["Create OKF Concepts"]
  INDEX["Index for search"]

Knowledge utilise des Concepts au format Open Knowledge Format (OKF). Un Concept
conserve une référence à sa Source d'origine.

L'ingestion de FAQ crée un Concept organisé dont la provenance est la question
et la réponse. L'ingestion de fichiers et de sites Web préserve l'objet Source
d'origine, le cas échéant.

## Récupération

Le moteur d'exécution peut récupérer des Concepts via la recherche vectorielle
et le repli lexical. Le mode graphe peut ajouter une navigation à travers les
relations indexées entre Concepts.

Chaque chemin est délimité par les liens Assistant-Source. Un résultat provenant
d'une Source qui n'est pas liée à l'Assistant effectuant la requête est ignoré,
aussi bien dans le chemin du graphe que dans le chemin vectoriel.

Un indice contextuel peut limiter la récupération à une collection pertinente ou
à un contexte de type cours lorsque le moteur d'exécution en fournit un.

La recherche approfondie améliore la navigation dans les connaissances dans les
limites du moteur d'exécution. Elle n'effectue pas de requêtes sur le Web
public.

## Résolution des citations

La réponse finale cite des Sources nommées, et non des fragments de recherche
opaques. Les identifiants de citation sont résolus via le Concept jusqu'à sa
Source d'origine.

Le visiteur peut ouvrir l'affichage des sources après la réponse. La boîte de
réception stocke les mêmes éléments de citation avec la conversation.

## Suppression et nouvelle analyse

La suppression d'une Source retire les Concepts associés du graphe actif et des
données de recherche, pour chaque Assistant lié. La suppression d'un lien ne
retire rien. Cela empêche un Assistant d'accéder à la Source.

La réanalyse du site Web relance l'extraction et l'indexation pour cette Source.
