## Aplicaciones

| Ruta | Responsabilidad |
| --- | --- |
| `apps/web` | Administrator console, widget runtime, páginas públicas, acciones del servidor y API v1. |
| `apps/docs` | Aplicación de documentación de Fumadocs y canalización de traducción. |

## Paquetes compartidos

| Ruta | Responsabilidad |
| --- | --- |
| `packages/core` | Tipos de dominio, reglas de Flow puras, valores predeterminados, condiciones y lógica de análisis. |
| `packages/db` | Interfaces de persistencia, almacenamiento simulado e implementación de Supabase. |
| `packages/agent` | Ejecución de turnos, proveedores de modelos, herramientas de Knowledge, ingesta y evaluación. |
| `packages/ops` | Operaciones compartidas de la organización utilizadas por las acciones de la consola y la API v1. |
| `packages/client` | Cliente tipado para API v1. |
| `packages/cli` | Interfaz de terminal sobre el cliente tipado. |
| `packages/mcp` | Adaptador MCP local de catorce herramientas sobre el cliente tipado. |
| `packages/ui` | Componentes compartidos de la interfaz de usuario. |
| `packages/charts` | Visualizaciones de análisis compartidas. |

## Servicios e infraestructura

| Path | Responsibility |
| --- | --- |
| `services/crawl4ai` | Configuración opcional del rastreador con renderizado JavaScript. |
| `supabase/migrations` | Cambios ordenados en el esquema de la base de datos. |
| `deploy` | Implementación de Docker Compose en un solo host y scripts de arranque. |

## Dirección de las dependencias

Las reglas puras pertenecen a `packages/core`. El comportamiento de persistencia
pertenece a `packages/db`.

Las mutaciones reutilizables pertenecen a `packages/ops`. El comportamiento del
modelo y de la recuperación pertenece a `packages/agent`.

Los adaptadores de superficie en `apps/web`, `packages/cli` y `packages/mcp` no
deben crear un comportamiento de dominio independiente.
