## Applicazioni

| Path | Responsibility |
| --- | --- |
| `apps/web` | Administrator console, widget runtime, public pages, server actions e API v1. |
| `apps/docs` | Applicazione di documentazione Fumadocs e pipeline di traduzione. |

## Pacchetti condivisi

| Path | Responsibility |
| --- | --- |
| `packages/core` | Tipi di dominio, regole Flow pure, valori predefiniti, condizioni e logica di analisi. |
| `packages/db` | Interfacce di persistenza, mock storage e implementazione di Supabase. |
| `packages/agent` | Esecuzione dei turni, provider di modelli, strumenti Knowledge, ingestion e valutazione. |
| `packages/ops` | Operazioni dell'organizzazione condivisa utilizzate dalle azioni della console e dall'API v1. |
| `packages/client` | Client tipizzato per API v1. |
| `packages/cli` | Interfaccia a riga di comando basata sul client tipizzato. |
| `packages/mcp` | Adattatore MCP locale con quattordici strumenti, basato sul client tipizzato. |
| `packages/ui` | Componenti condivisi dell'interfaccia utente. |
| `packages/charts` | Visualizzazioni analitiche condivise. |

## Servizi e infrastruttura

| Path | Responsabilità |
| --- | --- |
| `services/crawl4ai` | Configurazione facoltativa del crawler con rendering JavaScript. |
| `supabase/migrations` | Modifiche allo schema del database in ordine. |
| `deploy` | Deployment di Docker Compose su un singolo host e script di bootstrap. |

## Direzione delle dipendenze

Le regole pure appartengono a `packages/core`. Il comportamento di persistenza
appartiene a `packages/db`.

Le mutazioni riutilizzabili appartengono a `packages/ops`. Il comportamento del
modello e del recupero appartiene a `packages/agent`.

Gli adattatori di superficie in `apps/web`, `packages/cli` e `packages/mcp` non
devono creare un comportamento di dominio separato.
