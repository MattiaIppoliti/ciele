Ciele ist ein TypeScript-Monorepo mit einer Next.js-Produktanwendung, gemeinsam
genutzten Paketen, Postgres und optionalen Workern.

## Hauptabgrenzungen

<Mermaid
  title="Jede Anfrage erreicht Postgres über dieselbe Data-Access-Schicht."
  chart={`

  PG[("Postgres and storage")]

  API --> OPS
  API --> RUNTIME
  OPS --> DB

  DB --> PG
`}
/>

Ein optionaler Worker läuft neben der Runtime für das Crawling. Standardmäßig
bleibt er deaktiviert. Siehe [Background workers](/self-hosting/workers).

Der Flow-Router bleibt maßgebend. Ein Modell kann Absichten klassifizieren,
ausgewählte Aktionen generieren und registrierte Tools aufrufen.

Das Modell kann weder die Flow-Reihenfolge, die Zielbedingungen, die
Aktionseinstellungen, die Organisation-Autorisierung noch die
Netzwerk-Egress-Prüfungen ersetzen.
