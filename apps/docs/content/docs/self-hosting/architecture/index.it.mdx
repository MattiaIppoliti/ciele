Ciele è un monorepo TypeScript con una singola applicazione prodotto Next.js,
pacchetti condivisi, Postgres e worker opzionali.

## Confini principali

Un worker opzionale viene eseguito accanto al runtime per il crawling. Per
impostazione predefinita, rimane disattivato. Consulta
[Background workers](/self-hosting/workers).

Il Flow router rimane l'elemento autorevole. Un modello può classificare
l'intento, generare azioni selezionate e richiamare strumenti registrati.

Il modello non può sostituire l'ordine del Flow, le condizioni degli obiettivi,
la configurazione delle azioni, l'autorizzazione dell'organizzazione o i
controlli di egress di rete.
