---
title: Upgrade
description: Wenden Sie eine neue Repository-Version und die dazugehörigen ausstehenden Migrationen an.
---

## Vor dem Upgrade

1. Lesen Sie die Release-Änderungen.
2. Erfassen Sie den aktuellen Commit oder das aktuelle Tag.
3. Sichern Sie die Datenbank und die hochgeladenen Dateien.
4. Testen Sie den Wiederherstellungsprozess.
5. Planen Sie ein akzeptables Servicefenster.

## Version anwenden

```bash
git pull
docker compose -f deploy/docker-compose.yml up -d --build
```

Der Dienst `migrate` wendet nur ausstehende Migrationen an. Überprüfen Sie das
Ergebnis, bevor Sie die Anwendung als fehlerfrei akzeptieren.

```bash
docker compose -f deploy/docker-compose.yml ps
docker compose -f deploy/docker-compose.yml logs migrate
docker compose -f deploy/docker-compose.yml logs app
```

## Überprüfen Sie das Ergebnis

1. Melden Sie sich bei der Administratorkonsole an.
2. Öffnen Sie einen Assistenten.
3. Testvorschau.
4. Öffnen Sie ein veröffentlichtes Widget.
5. Rufen Sie `GET /api/v1/meta` auf, wenn programmgesteuerte Clients verwendet
   werden.

Stellen Sie kein altes Anwendungs-Image mit einer inkompatiblen migrierten
Datenbank wieder her. Verwenden Sie die Release-Anweisungen für einen
unterstützten Rollback-Pfad.
