The repository contains the administrator console, widget runtime, data layer, migration runner, scheduled jobs, API, CLI, and MCP server.

The supported deployment example uses Docker Compose on one host. It does not include Kubernetes, Helm, or multi-node operation.

## Start here

1. Read [Installation](/self-hosting/installation).
2. Review [Configuration](/self-hosting/configuration).
3. Select optional [Workers](/self-hosting/workers).
4. Configure TLS before public exposure.
5. Read [Upgrading](/self-hosting/upgrade) before you change versions.

Use the [Architecture](/self-hosting/architecture) section to understand current package and request boundaries.
