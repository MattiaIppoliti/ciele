---
title: Processi in background
description: Abilita i servizi opzionali di recupero dei grafi e di crawling con rendering JavaScript.
---

Lo stack predefinito non avvia il profilo `workers`. La ricerca e l'ingestione
di siti web continuano con funzionalità ridotte.

Senza il graph worker, Knowledge utilizza il recupero vettoriale e lessicale.
Senza Crawl4AI, Ciele utilizza il suo crawler di recupero integrato.

## Abilita il profilo

Imposta questi valori in `deploy/.env`:

```dotenv
COMPOSE_PROFILES=db,migrate,app,cron,workers
GRAPH_WORKER_API_TOKEN=<generated-token>
GRAPH_LLM_API_KEY=<provider-key>
CRAWL4AI_API_TOKEN=<generated-token>
CRAWL4AI_SECRET_KEY=<generated-token>
```

Quindi avvia lo stack:

```bash
docker compose -f deploy/docker-compose.yml up -d
```

I due worker opzionali possono richiedere circa 8 GiB di memoria. Misura
l'utilizzo effettivo sull'host selezionato.

## Controlla lo stato del worker

```bash
docker compose -f deploy/docker-compose.yml ps
docker compose -f deploy/docker-compose.yml logs -f graph-worker crawl4ai
```

Non esporre le porte dei worker o i token alla rete pubblica.
