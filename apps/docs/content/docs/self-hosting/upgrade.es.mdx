---
title: Actualizar
description: Aplica una nueva versión del repositorio y sus migraciones pendientes.
---

## Antes de la actualización

1. Lee los cambios de la versión.
2. Registra la confirmación o etiqueta actual.
3. Haz una copia de seguridad de la base de datos y de los archivos subidos.
4. Prueba el proceso de restauración.
5. Programa una ventana de servicio aceptable.

## Aplica la versión

```bash
git pull
docker compose -f deploy/docker-compose.yml up -d --build
```

El servicio `migrate` solo aplica las migraciones pendientes. Inspecciona el
resultado antes de aceptar la aplicación como correcta.

```bash
docker compose -f deploy/docker-compose.yml ps
docker compose -f deploy/docker-compose.yml logs migrate
docker compose -f deploy/docker-compose.yml logs app
```

## Verifica el resultado

1. Inicia sesión en la consola de administración.
2. Abre un Asistente.
3. Vista previa de prueba.
4. Abre un widget publicado.
5. Llama a `GET /api/v1/meta` cuando se estén usando clientes programáticos.

No restaures una imagen de aplicación antigua en una base de datos migrada
incompatible. Utiliza las instrucciones de la versión para una ruta de reversión
compatible.
