Ciele verwendet Postgres mit pgvector. Das Compose-`db`-Profil führt außerdem
Authentifizierung, PostgREST, Speicherung und ein Gateway aus.

## Migrationen anwenden

Der One-Shot-Service `migrate` wendet ausstehende SQL-Migrationen an und
erstellt die erforderlichen Speicher-Buckets. Die Anwendung startet, nachdem
dieser Dienst erfolgreich war.

Bearbeiten Sie keine angewandte Migration. Fügen Sie für jede Schemaänderung
eine neue Migration hinzu.

## Lokale Entwicklung

```bash
pnpm db:start
pnpm db:reset
pnpm db:status
```

`pnpm db:reset` löscht lokale Datenbankdaten und wendet Migrationen und
Seed-Daten erneut an.

## Persistente Daten

Das Volume `postgres-data` enthält die Datenbank. Das Volume `storage-data`
enthält hochgeladene Objekte.

Sichern Sie beide Volumes, um eine vollständige Datenkopie zu erhalten. Testen
Sie die Wiederherstellung, bevor Sie sich auf einen Sicherungsprozess verlassen.

<Callout type="warn" title="Volume deletion removes data">
`docker compose -f deploy/docker-compose.yml down -v` deletes the database and uploaded-file volumes. Use it only for an intentional reset.
</Callout>

## Mandantenisolierung

Konsolenanforderungen verwenden authentifizierten Datenbankzugriff und
Sicherheit auf Zeilenebene. API-Schlüssel-Operationen verwenden einen von der
Organisation festgelegten Datenbank-Wrapper und Berechtigungsprüfungen.
