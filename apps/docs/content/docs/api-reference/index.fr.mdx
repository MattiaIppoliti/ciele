# Référence de l'API

L'API Ciele utilise JSON sur HTTP. Créez une clé API d'organisation dans
**Settings → API Keys** et envoyez-la en tant que
`Authorization: Bearer ciele_sk_…`. Chaque opération indique la capacité
requise, les paramètres de la requête et la réponse.

Choisissez un domaine dans la barre latérale pour afficher ses opérations. Le
contrat couvre les points de terminaison publics `/api/v1`. Les routes de la
console et des widgets sont distinctes.
