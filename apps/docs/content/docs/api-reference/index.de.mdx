# API-Referenz

Die Ciele-API verwendet JSON über HTTP. Erstellen Sie einen Organization
API-Schlüssel in **Settings → API Keys** und senden Sie ihn als
`Authorization: Bearer ciele_sk_…`. Jede Operation zeigt die erforderliche
Berechtigung, die Request-Parameter und die Response an.

Wählen Sie eine Domain in der Seitenleiste aus, um deren Operationen anzuzeigen.
Der Vertrag umfasst öffentliche `/api/v1`-Endpoints. Die Routen für die Console
und für Widgets sind getrennt.
