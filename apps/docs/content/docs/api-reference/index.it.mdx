# Riferimento API

L'API di Ciele utilizza JSON su HTTP. Crea una chiave API dell'organizzazione in
**Settings → API Keys** e inviala come `Authorization: Bearer ciele_sk_…`. Ogni
operazione mostra la capability richiesta, i parametri della richiesta e la
risposta.

Scegli un dominio nella sidebar per visualizzare le relative operazioni. Il
contratto copre gli endpoint pubblici `/api/v1`. I percorsi della Console e dei
widget sono separati.

## Documento OpenAPI

- [Scarica OpenAPI come JSON](/api/openapi.json?download=1)
- [Scarica OpenAPI come YAML](/api/openapi.yaml)

La [developer guide](/developers/api) spiega l'autenticazione, la paginazione e
gli errori più comuni.
