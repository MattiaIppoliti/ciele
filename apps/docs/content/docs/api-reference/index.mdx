# API Reference

The Ciele API uses JSON over HTTP. Create an Organization API key in **Settings → API Keys** and send it as `Authorization: Bearer ciele_sk_…`. Each operation shows the required capability, request parameters, and response.

Choose a domain in the sidebar to see its operations. The contract covers public `/api/v1` endpoints. Console and widget routes are separate.
