# Referencia de la API

La API de Ciele utiliza JSON sobre HTTP. Crea una clave API de organización en
**Settings → API Keys** y envíala como `Authorization: Bearer ciele_sk_…`. Cada
operación muestra la capacidad necesaria, los parámetros de la solicitud y la
respuesta.

Elige un dominio en la barra lateral para ver sus operaciones. El contrato cubre
los endpoints públicos de `/api/v1`. Las rutas de la consola y de los widgets
están separadas.

## Documento OpenAPI

- [Descarga OpenAPI como JSON](/api/openapi.json?download=1)
- [Descarga OpenAPI como YAML](/api/openapi.yaml)

los errores más comunes.
