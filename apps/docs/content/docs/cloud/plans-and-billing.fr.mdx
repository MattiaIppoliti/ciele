Ouvrez **Settings > Billing** dans l'édition gérée. La page affiche l'état
actuel de l'abonnement et les entrées de catalogue disponibles.

## Souscrire ou modifier un abonnement

1. Consultez les limites et le prix de l'abonnement disponible.
2. Sélectionnez le forfait souhaité.
3. Effectuez le paiement Stripe lorsque cela vous est demandé.
4. Revenez sur Ciele.
5. Confirmez l'état actif de l'abonnement.

Ciele rapproche l'état de facturation avec Stripe. Ne présumez pas qu'une
redirection réussie du navigateur prouve l'activation de l'abonnement.

## Compte de facturation

Lorsque Stripe renvoie les données, la page peut afficher :

- informations sur le renouvellement
- le récapitulatif de la carte de paiement actuelle
- factures
- actions de changement de forfait

Les champs de facturation peuvent rester absents lorsque Stripe ne les a pas
fournis.

## Édition auto-hébergée

L'édition auto-hébergée n'affiche ni le catalogue des forfaits gérés ni le
compte d'abonnement.
