Ciele Cloud is the managed edition of Ciele. It runs the same open-source core
you can self-host, with none of the operating work: no servers to provision, no
upgrades to apply, no database to back up. You sign in, create your organization,
and start building assistants.

<Callout title="Managed edition">
Everything in this section is specific to Ciele Cloud. The features here — billing,
usage limits, managed single sign-on, and hosted support — are not part of the
open-source core and do not exist in a self-hosted deployment. For the shared
product features, see the main [Documentation](/).
</Callout>

## What Cloud adds on top of the core

- **Plans and billing.** Choose a subscription plan and manage payment and
  invoices from the console. See [Plans and billing](/cloud/plans-and-billing).
- **Usage and limits.** Each plan comes with monthly quotas that are metered and
  enforced automatically. See [Usage and limits](/cloud/usage-and-limits).
- **Team and single sign-on.** Invite members, manage roles, and connect
  organization single sign-on with onboarding handled for you. See
  [Team and single sign-on](/cloud/team-and-sso).
- **Support and operations.** Hosting, upgrades, backups, and a support channel
  with a service commitment. See [Support](/cloud/support).

## Getting started on Cloud

Building assistants on Ciele Cloud follows the same path as anywhere else. Start
with [Getting started](/getting-started), then come back here when you want to
manage your plan, watch your usage, or set up single sign-on.
