Ciele Cloud runs the Ciele product as a managed service. The public Cloud documentation covers only behavior visible in the current application.

Ciele Cloud is sales-led. A managed Organization is created and activated by Ciele, not through a self-serve signup.

Use these pages to manage:

- the current plan state and billing account
- payment and invoice information returned by Stripe
- recent AI, embedding, and scraping usage
- plan limits and the Organization daily budget

Product configuration is the same documentation used for the open-source core. Start with [Getting started](/getting-started).
