---
title: Ciele Cloud
description: Utilisez l'édition Ciele gérée avec une facturation par forfait et une utilisation mesurée.
---

Ciele Cloud exécute le produit Ciele en tant que service géré. La documentation
du Cloud public ne couvre que le comportement visible dans l'application
actuelle.

Utilisez ces pages pour gérer :

- l'abonnement actuel et le compte de facturation
- les informations de paiement et de facturation renvoyées par Stripe
- l'utilisation récente de l'IA, de l'intégration et du scraping
- les limites du forfait et le budget quotidien de l'organisation

La configuration du produit est la même documentation que celle utilisée pour le
noyau open source. Commencez par [Premiers pas](/getting-started).
