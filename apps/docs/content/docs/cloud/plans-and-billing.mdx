---
title: Plans and billing
description: Select a managed plan and review the current Stripe billing account.
---

Open **Settings > Billing** in the managed edition. The page shows the current plan state and available catalogue entries.

## Start or change a plan

1. Review the available plan limits and price.
2. Select the required plan.
3. Complete the Stripe checkout when requested.
4. Return to Ciele.
5. Confirm the active plan state.

Ciele reconciles the billing state with Stripe. Do not assume that a completed browser redirect proves plan activation.

## Billing account

When Stripe returns the data, the page can show:

- renewal information
- the current payment card summary
- invoices
- plan change actions

Billing fields can remain absent when Stripe has not supplied them.

## Self-hosted edition

The self-hosted edition does not show the managed plan catalogue or subscription account.
