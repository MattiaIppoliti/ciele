Ciele Cloud è l'edizione gestita di Ciele. Funziona con lo stesso core open
source che puoi auto-ospitare, ma senza il lavoro operativo: nessun server da
provisionare, nessun aggiornamento da applicare, nessun database di cui eseguire
il backup. Accedi, crea la tua organizzazione e inizia a costruire assistenti.

<Callout title="Managed edition">
Everything in this section is specific to Ciele Cloud. The features here — billing,
usage limits, managed single sign-on, and hosted support — are not part of the
open-source core and do not exist in a self-hosted deployment. For the shared
product features, see the main [Documentation](/).
</Callout>

## Cosa aggiunge Cloud al core

- **Plans and billing.** Scegli un piano di abbonamento e gestisci pagamenti e
  fatture dalla console. Consulta
  [Piani e fatturazione](/cloud/plans-and-billing).
- **Usage and limits.** Ogni piano prevede quote mensili che vengono misurate e
  applicate automaticamente. Consulta
  [Utilizzo e limiti](/cloud/usage-and-limits).
- **Team and single sign-on.** Invita membri, gestisci i ruoli e collega il
  single sign-on dell'organizzazione con l'onboarding gestito per te. Consulta
  [Team e Single Sign-On](/cloud/team-and-sso).
- **Support and operations.** Hosting, aggiornamenti, backup e un canale di
  assistenza con un impegno di servizio. Vedi [Supporto](/cloud/support).

## Guida introduttiva a Cloud

La creazione di assistenti su Ciele Cloud segue lo stesso percorso di qualsiasi
altra piattaforma. Inizia con [Guida introduttiva](/getting-started), quindi
torna qui quando vuoi gestire il tuo piano, monitorare il tuo utilizzo o
configurare il Single Sign-On.
