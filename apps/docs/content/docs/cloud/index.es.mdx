title: Ciele Cloud

---

Ciele Cloud ejecuta el producto Ciele como un servicio gestionado. La
documentación pública de la nube cubre únicamente el comportamiento visible en
la aplicación actual.

Ciele Cloud está orientada a las ventas. Ciele crea y activa una organización
gestionada; no se hace a través de un registro de autoservicio.

Utiliza estas páginas para gestionar:

- el estado actual del plan y la cuenta de facturación
- la información de pagos y facturas devuelta por Stripe
- el uso reciente de IA, incrustación y scraping
- los límites del plan y el presupuesto diario de la Organización

La configuración del producto es la misma documentación que se utiliza para el
núcleo de código abierto. Empieza con [Primeros pasos](/getting-started).
