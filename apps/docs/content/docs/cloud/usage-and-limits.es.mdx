Cada plan de Ciele Cloud incluye una asignación de uso mensual. Ciele mide el
uso de tu organización a medida que se producen las conversaciones y lo compara
con la asignación de tu plan, para que no haya sorpresas ni recuentos manuales.

## Qué se considera uso

El uso se mide por el trabajo de IA que tus asistentes realizan en nombre de tus
visitantes, principalmente las respuestas que generan los asistentes. La consola
muestra tu uso actual para el período de facturación para que siempre sepas en
qué punto estás.

## Seguimiento de tu uso

Puedes ver el uso del período actual en la consola en cualquier momento.
Vigílalo si estás llevando a cabo una campaña, lanzando un nuevo asistente o si
por cualquier otro motivo esperas un pico, para que puedas pasarte a un
[plan](/cloud/plans-and-billing) más grande antes de que se agote tu asignación.

## Alcanzar el límite

A medida que tu uso se acerca a la asignación del plan, Ciele lo muestra en la
consola. Cuando se alcanza la asignación, se aplica el límite del plan durante
el resto del período de facturación. Al cambiar a un plan con una asignación
mayor, la capacidad se restablece de inmediato; de lo contrario, la asignación
se reinicia al inicio del siguiente período de facturación.

## Mantener un uso eficiente

Las mismas prácticas que mejoran las respuestas también mantienen un uso
eficiente: [conocimiento](/knowledge) focalizado para que la recuperación se
mantenga en el objetivo, [flujos](/flows) que gestionan directamente las
preguntas comunes y [servicios de asistencia](/help-desks) que transfieren el
caso de forma limpia cuando un humano es el siguiente paso adecuado.
