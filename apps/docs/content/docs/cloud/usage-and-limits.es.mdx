---

Abre **Settings > Usage**. La página carga los últimos 30 días de datos de uso
disponibles.

## Contadores de uso

Ciele mide estos grupos de recursos por separado:

- Uso del modelo de IA
- uso de incrustaciones
- uso de scraping

La página indica si la operación se ha financiado con fondos de la plataforma
Ciele o con las credenciales de la organización.

Los créditos representan el coste estimado en céntimos. No son un recuento de
las respuestas del asistente.

## Límites

La página compara el uso actual con los límites disponibles del plan. También
puede mostrar el presupuesto diario de la organización.

Los indicadores monocromáticos muestran el uso de cada ventana. **Near limit** y
**Limit reached** identifican el estado del límite en forma de texto. El
porcentaje puede superar el 100 %, incluso cuando el indicador está lleno. Una
ventana sin límite muestra **N/A**.

Las filas diarias utilizan la Hora Universal Coordinada (UTC). Utiliza este
límite cuando compares los datos de Ciele con una factura de un proveedor.

## Dónde se han destinado los créditos

La página enumera los spenders que utilizaron los créditos del periodo:
Assistants, Teammates, Members, API keys, Routines y Flows.

Cada tarjeta totaliza un tipo de consumidor. Una respuesta de Teammate indica el
nombre del Teammate y también el del compañero que hizo la pregunta. Por lo
tanto, el mismo crédito aparece en dos tarjetas. No sumes las tarjetas.

## Créditos de recarga

La asignación de un plan se restablece con su período. Los créditos de recarga
son un fondo que tu organización mantiene hasta que los gasta.

Ciele solo recurre al fondo común una vez que se ha agotado por completo la
asignación de un período. A continuación, la respuesta continúa en lugar de
pausarse. Cuando el «pool» también está vacío, vuelve a aplicarse el mensaje de
límite habitual.

Compra un pack en **Settings > Billing**. Un pack siempre cuesta más por crédito
que tu plan. Si compras un pack cada mes, te sale más barato pasarte a un plan
superior.

## Otras tareas

Algunos trabajos no consumen créditos: una solicitud API saliente desde un Flow,
un correo electrónico, una ejecución de Flow entrante o una devolución de
llamada de webhook.

La página contabiliza estas operaciones. No les asigna un precio. El recuento te
muestra que un Flow realiza muchas llamadas salientes, algo que ninguna otra
página te indica.

Cada fila también indica el resultado. **Refused by Ciele** significa que
nuestra propia política detuvo la llamada. **Failed** significa que lo hizo el
otro sistema o la red.

## Investiga el uso inesperado

1. Selecciona el contador afectado.
2. Identifica el día UTC y la fuente de financiación.
3. Revisa la actividad de Assistant para el mismo periodo.
4. Comprueba la conexión del proveedor seleccionado.
5. Ajusta el presupuesto de la organización cuando estés autorizado.
