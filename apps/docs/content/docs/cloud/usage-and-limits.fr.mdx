---
title: Utilisation et limites
description: Vérifiez l'utilisation récente de l'IA, de l'intégration et du scraping par rapport aux limites actuelles.
---

Ouvrez **Settings > Usage**. La page affiche les données d'utilisation
disponibles des 30 derniers jours.

## Compteurs d'utilisation

Ciele mesure ces groupes de ressources séparément :

- Utilisation du modèle d'IA
- utilisation des embeddings
- utilisation du scraping

La page indique si l'opération a été financée par le crédit de la plateforme
Ciele ou par les identifiants de l'organisation.

Les crédits représentent le coût estimé en centimes. Ils ne représentent pas un
décompte des réponses de l'Assistant.

## Limites

La page compare l'utilisation actuelle aux limites du forfait disponible. Elle
peut également afficher le budget quotidien de l'organisation.

Les jauges monochromes indiquent l'utilisation de chaque fenêtre. **Near limit**
et **Limit reached** identifient l'état de la limite sous forme de texte. Le
pourcentage peut dépasser 100 %, même lorsque la jauge est pleine. Une fenêtre
sans plafond affiche **N/A**.

Les lignes quotidiennes utilisent l'heure universelle coordonnée (UTC). Utilisez
cette limite lorsque vous comparez les données de Ciele avec une facture de
fournisseur.

## Où les crédits ont été dépensés

La page répertorie les entités ayant consommé les crédits de la fenêtre :
Assistants, Teammates, Members, API keys, Routines et Flows.

Chaque carte totalise un type de « spender ». Une réponse de Teammate indique le
nom du Teammate ainsi que celui du collègue qui a posé la question. Le même
crédit figure donc sur deux cartes. N'additionnez pas les cartes entre elles.

## Crédits de recharge

L'allocation d'un plan est réinitialisée en même temps que sa période. Les
crédits de recharge constituent un pool que votre organisation conserve jusqu'à
ce qu'elle les utilise.

Ciele ne puise dans le pool qu'une fois l'allocation d'une fenêtre entièrement
utilisée. Les réponses se poursuivent ensuite au lieu de s'interrompre. Lorsque
le pool est également vide, le message de limite habituel s'applique à nouveau.

Achetez un pack dans **Settings > Billing**. Le coût par crédit d'un pack est
toujours supérieur à celui de votre plan. Si vous achetez un pack chaque mois,
un passage à un abonnement supérieur est moins coûteux.

## Autres tâches

Certaines tâches ne coûtent aucun crédit : une requête API sortante depuis un
Flow, un e-mail, une exécution de Flow entrant, un rappel de webhook.

La page comptabilise ces opérations. Elle ne leur attribue pas de prix. Le
compteur vous indique qu'un Flow effectue de nombreux appels sortants, ce
qu'aucune autre page ne montre.

Chaque ligne indique également le résultat. **Refused by Ciele** signifie que
notre propre politique a interrompu l'appel. **Failed** signifie que l'autre
système ou le réseau l'a fait.

## Examiner une utilisation inattendue

1. Sélectionnez le compteur concerné.
2. Identifiez le jour UTC et la source de financement.
3. Examinez l'activité de l'Assistant pour la même période.
4. Vérifiez la connexion du fournisseur sélectionné.
5. Ajustez le budget de l'organisation lorsque vous y êtes autorisé.
