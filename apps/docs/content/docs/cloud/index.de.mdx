title: Ciele Cloud

---

Ciele Cloud betreibt das Ciele-Produkt als Managed Service. Die öffentliche
Cloud-Dokumentation deckt nur das Verhalten ab, das in der aktuellen Anwendung
sichtbar ist.

Ciele Cloud ist vertriebsgesteuert. Eine verwaltete Organisation wird von Ciele
erstellt und aktiviert, nicht durch eine Selbstregistrierung.

Auf diesen Seiten können Sie Folgendes verwalten:

- den aktuellen Planstatus und das Abrechnungskonto
- Zahlungs- und Rechnungsinformationen, die von Stripe zurückgegeben werden
- die aktuelle Nutzung von KI, Einbettung und Scraping
- Planlimits und das Tagesbudget der Organisation

Die Produktkonfiguration ist dieselbe Dokumentation, die auch für den
Open-Source-Kern verwendet wird. Beginnen Sie mit
[Erste Schritte](/getting-started).
