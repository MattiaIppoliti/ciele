Ciele Cloud ist die verwaltete Edition von Ciele. Sie läuft auf demselben
Open-Source-Kern, den Sie selbst hosten können, jedoch ohne den Betriebsaufwand:
keine Server bereitzustellen, keine Upgrades anzuwenden, keine Datenbank zu
sichern. Sie melden sich an, erstellen Ihre Organisation und beginnen mit dem
Erstellen von Assistenten.

<Callout title="Managed edition">
Everything in this section is specific to Ciele Cloud. The features here — billing,
usage limits, managed single sign-on, and hosted support — are not part of the
open-source core and do not exist in a self-hosted deployment. For the shared
product features, see the main [Documentation](/).
</Callout>

## Was Cloud zusätzlich zum Kern bietet

- **Plans and billing.** Wählen Sie ein Abonnement und verwalten Sie Zahlungen
  und Rechnungen über die Konsole. Siehe
  [Pläne und Abrechnung](/cloud/plans-and-billing).
- **Usage and limits.** Jedes Paket beinhaltet monatliche Kontingente, die
  automatisch gemessen und durchgesetzt werden. Siehe
  [Nutzung und Limits](/cloud/usage-and-limits).
- **Team and single sign-on.** Laden Sie Mitglieder ein, verwalten Sie Rollen
  und verbinden Sie das Single Sign-On Ihres Unternehmens mit Onboarding, das
  für Sie übernommen wird. Siehe [Team und Single Sign-On](/cloud/team-and-sso).
- **Support and operations.** Hosting, Upgrades, Backups und ein Support-Kanal
  mit Serviceverpflichtung. Siehe [Support](/cloud/support).

## Erste Schritte in der Cloud

Die Erstellung von Assistenten auf Ciele Cloud erfolgt auf die gleiche Weise wie
überall sonst. Beginnen Sie mit [Erste Schritte](/getting-started) und kehren
Sie dann hierher zurück, wenn Sie Ihren Plan verwalten, Ihre Nutzung überwachen
oder Single Sign-On einrichten möchten.
