# Skiper UI attribution

`skiper63.tsx` adapts the filter primitives from **Skiper UI — Apple squicircle
effect**, by **gxuri**: https://skiper-ui.com/v1/skiper63.

The source was read from the official `@skiper-ui/skiper63` registry using
`shadcn view` on 2026-10-02. The free component's published usage terms allow
personal and commercial use and modification and require attribution to Skiper UI.
This notice and the source comment retain that attribution. This component is
not represented as MIT licensed.

Ciele retains the Gaussian blur, alpha matrix and source blend. It exports both
filter names, uses the valid SVG matrix type, expands the filter region to avoid
clipping small surfaces, and mounts one non-interactive definition outside
filtered elements. Demo controls and their dependencies are omitted.
