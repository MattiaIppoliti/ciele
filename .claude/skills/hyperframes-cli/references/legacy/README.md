# Legacy `hyperframes` CLI references

These document the retired `hyperframes` CLI — `init`, `lint`, `check`, `snapshot`, `preview`, `render`, `cloud`, `cloudrun`, `lambda`, `beats`, and friends. That CLI is not the tool any more; the current one is Remotion's, documented in this skill's `SKILL.md`, which also carries a table mapping each retired command to where its capability now lives.

Keep these only for reading a project that still runs the old pipeline. Do not run these commands against a Remotion project.
